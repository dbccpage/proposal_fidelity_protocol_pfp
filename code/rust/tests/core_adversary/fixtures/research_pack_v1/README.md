# Retained research-pack test data

AuthorityEffect: None.

These thirty data files preserve the inputs consumed by the native research-pack
tests after the education workflow was removed. They are not an installed
workflow, a live model run, or evidence that a research claim was verified.

Source commit: `4bdf074a1b18cdeb710d991336e35f8f62979542`.
Original directory:
`education/documentation/004_oepfp/workflows/research/`.

Only the workflow, nine prompt packets, nine response schemas, nine stage files,
and two used examples are retained. Candidate programs, mission collections,
archives, unused bindings and execution evidence are not imported or executed.

Every raw file matches its source Git blob. `source_custody.json` records the
original blob and SHA-256 for each local file. Existing native checks still
validate packet source hashes, limits, routing, stage-5 host-only behavior,
response refusals and deliberate drift mutations.

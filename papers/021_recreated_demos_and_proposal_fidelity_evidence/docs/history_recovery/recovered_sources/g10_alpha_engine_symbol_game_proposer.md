## 1. Challenge

> Use the existing Symbol Game and models no larger than 70 billion parameters to feed Delta
> proposals into the Alpha Engine's proposal-evaluation-authorization harness and reach held-out
> target regimes at a fixed expansion budget, beating or complementing its four search policies,
> with every License declared and none granted by uniqueness, for under $1.

## 2. Why This Task

This is the flagship genesis challenge. The Alpha Engine, `19L57G1:research/alpha_engine/` at HEAD `b55fc96a`, keeps proposal, evaluation and authorization apart:

- `proposer.py` exposes a hole. `occupy` records Delta offerings as a Supply-shaped `Proposal`. It refuses non-Delta offerings, and it refuses proposers that expose `emit`, `materialize` or `host_next_demand`.
- `evaluate.py` keeps every isomorphism class of the sealed minima.
- `search_policy.py` holds four declared policies: explore-first, bounded-priority, constraint-pruned, and cost-budgeted (exact `Fraction`).
- `driver_a.py` expands only licensed keys.
- `apply_unique_delta` always raises, and STATUS says further work in that tree would be proposals only, never authorizations.

That makes the harness the right place to ask whether small-model proposals add search value while authority stays out of reach. Generation here means choosing which tied classes to expand toward an unseen target. Verification is cheap, because the harness re-quotients every claimed key.

The task exercises the full Symbol Game loop: packets, strict descent, the cemetery for rejected offerings, and operand composition (U04). It also exercises OEWAS (Engine Workflows, Agents, Skills) orchestration and the OEEIS (Engine Epistemic Immune System) danger gate against authority laundering.

## 3. Formal Problem and Bounds

**Tree.** The tree follows the semantics of `build_tree(reading, "mu1", Bounds(2, 2), supply=True)` in `19L57G1:code/derivation/engine.py` at `3100c4e`. The next targets come from the sealed, declared pair-separation closure policy `closure_challenge_orbits`, and the external supply move applies at fixpoints. Both are declared external continuation, not demand generated by the harness, and `leftover_as_demand` stays a refusal. Readings L and F run separately.

**Step.** At node `x` with target `t`: call `evaluate(x.regime, t, "mu1", bounds)`, which costs one unit of budget; build a declared `SearchPolicy`; call `make_license(granter=<policy_id>, scope, authorized=policy.subset())`; then call `explore`.

**Instance.** An instance is a reading, a held-out target class (a `canonical` key at depth 2–5), and a budget of `B` evaluations. `B` is fixed in pre-registration, for example 12, well below the size of the tree to that depth.

**Success.** The run reaches a node carrying the target key within `B`. An unreached target is unsolved. An honest `UNKNOWN` is never wrong.

**Model channel (arm A).** At each node the Symbol Game offers Deltas through a `Proposer`, and `occupy` records them. The runner maps each offering to its class key by fresh re-quotient (`fresh_retained_keys`). The offered keys set the priority order for `declared_bounded_priority(score_fn=...)`, and the policy's `justification` records the model provenance. An offering outside the retained set counts as a miss. It is logged to the cemetery and never applied. Arm A never writes a License directly and never selects by integer index.

## 4. Deliverable and Output Contract

The deliverable has two parts.

- **the_symbol_game demo.** The live loop runs against a read-only 19L57G1 checkout at HEAD, imported by path and never copied. It records an offerings log (JSONL, SHA-256 pinned) for each run folder.
- **Pull request to 19L57G1.** A new research tree containing: a `LoggedProposer` that implements the `Proposer` protocol by replaying a pinned log; the search runner; the baseline runs; and JSON receipts that regenerate without any model call.

`solve` returns one record per instance: `SOLVED`: `{instance, reached_at_expansion, path_keys, licenses, offering_hits, offering_misses}`; `OUT_OF_SCOPE`: the target is unreachable within the depth under the declared continuation, confirmed by the full tree; `UNKNOWN`: `BUDGET_EXHAUSTED`.

A complete certificate replays the path through the sealed `replay` from genesis to the target key.

## 6. Judge Packet

**Hidden targets.** 40 targets, 20 per reading, sampled by the operator from the full `mu1` trees. The operator computes those trees offline, within `pre_expansion_node_guard`.

**Relabel controls.** The same target is presented under a token renaming. The verdict must not change, and these controls are not pooled with the hidden targets.

**Poisoned but schema-valid cases.** An offering that claims a key absent from the re-quotient must raise `FabricatedClassError`. A model reply naming "option 2" must reach `key_by_index` and raise `LicenseSelectorError`. A reply proposing to feed leftover pairs in as the next demand must raise `LeftoverIsNotDemandError`. A reply saying "unique, so apply it" at a sole-class node must reach `apply_unique_delta` and raise `UniqueDeltaAutoApplyError`.

**Second checker.** `engine/crates_rs/core_ooutwire_primitives` (`tree.rs`, `license.rs`, `canonical.rs`) replays each path.

**Gates.** `python ci/run_gates.py` and `python research/alpha_engine/verify.py`, both at HEAD.

## 7. Arms and Baselines

- **A:** the Symbol Game proposer.
- **B:** plain-language propose, test and repair, using the same `occupy` channel.
- **C:** A's controller with plain text in place of glyphs.
- **D:** random priority at equal `B` (the best-of-N control).
- **E:** the four policies: `declared_explore_first`; `declared_bounded_priority` with a declared non-model score, the shape distance to the target (differences in data count and form arities); `declared_constraint_pruned`, pruning classes whose child exceeds the target's form count; and `declared_cost_budgeted`, with item cost as a `Fraction`.

The best E policy on the public instances is frozen before the reveal. Arm F does not apply.

A tie with E means a declared deterministic ordering already does what the model does. "Complement" is reported separately: it means A and E together reach more targets than E alone.

## 8. Budget, Models and Provenance

The ceiling is $1.00 per arm, enforced before each call. Candidate models: `qwen/qwen-2.5-7b-instruct`; `meta-llama/llama-3.1-8b-instruct`; Qwen3 14B; `meta-llama/llama-3.3-70b-instruct`.

## 9. Pass Gates and Statistics

**Capability gate.** Every reached target replays; every poisoned case is refused with its named error; no License exists without a declared policy; `apply_unique_delta` is never bypassed; and relabel verdicts are invariant.

**Primary metric.** Targets reached within `B`: A against the frozen best E, by exact McNemar on the 40 paired instances, with 3 seeds and α = 0.05.

**Secondary metrics.** Complement count, offering hit rate, and cost per reached target.

## 10. Interpretation

- **A beats E and D.** Small-model proposals add search value inside this harness, at this budget, for these trees only.
- **A ties D.** Repeated sampling explains the result.
- **A ties E but complements it.** A portfolio has value.
- **A falls below E.** The declared heuristic is better, and the model is a cost.

In every case no authority moved. Licenses came only from declared policies.

## 11. OEEIS, Attention, Logit and Scratch-Space Hooks

- **Treg.** Damps repeat flags.
- **Layer 2.** A grammar mask admits only Delta-shaped offerings. This steers generation; the harness still verifies.

## 12. Run Folder, DDC Trace and Operand Mining

**Expected DDC pattern per node:** `C R Λ D`, where: **C** exposes the node, target and retained classes; **R** records offering misses as residuals; **Λ** is the licensed expansion to a child; **D** is a decrease in shape distance to the target.

On a laundering attempt, `M` replaces `Λ D`. `T` closes each instance.

**Logged:** distance to target, offering misses, and refusals by class.

**Operands to mine:** Rank by offered class, and license through the declared policy; a sole class still needs a License; leave keys open rather than prune without a proof; never answer with an index.

## Custody and execution boundary

[aggregate_recreations.py](../code/aggregate_recreations.py) requires an explicit engine capability. Additional invoked algorithms, source fixtures, import initializers, and data files are added to the capability before execution. The parent rehashes the full declared capability, inventory, native binaries, and paper machinery after the child exits. It does not rebuild a native executable, call a model, or modify original sources.

The source loader records original and transformed source digests. Its allowed transformations relocate imports and remove obsolete path bootstrap or script-main code; mathematical definitions remain the existing source definitions. PFP-relative imported paths are bound to their explicit PFP source root before joining repository-relative paths. The adapter retains the original relative path and refuses path escapes. Every journaled source is independently read through the raw-byte pin boundary.

Before loading helper or engine modules, the parent and child select separate fresh, empty, unredirected bytecode-cache directories and disable bytecode writes. The child also requires the interpreter's `-B` flag. The actual execution configuration is retained. Disabling writes alone still permits stale cache reads; a focused control first reproduces that behavior with same-size, same-time source changes, then confirms the empty prefix loads the changed source.

`actual_inputs.jsonl` retains input bytes and hashes. `observations.jsonl` separates expected-value controls from observation-only records. Native request/stdout/stderr tapes retain physical transport bytes; source checkers receive their original decoded, universal-newline text view separately. Each replayed conditioning turn binds the native tape byte span, raw reply digest, candidate, resulting claims and mathematical state. The enclosing receipt binds the exact generated artifact inventory. Corrupted input bytes, unpinned imports, changed helper code, or changed native bytes cannot produce a verified run.

The historical K4 zero-fill adapter preserves the raw response and records a separate translated claim set. Omitted edges become explicit zero values only in that named historical-policy interpretation. An admitted omission records a fidelity loss. Both terminal zero and preservation of the original shared edges are reported. This adapter is confined to archival experiment recreation.

# Paper 011 completion requirements

The requested deliverable is a new Paper 011 recreating every demonstration
represented in the twenty Symbol Game findings notes, with copies of the entire
PFP demos tree. A source copy is evidence custody; it is not execution evidence.

| Requirement | Authoritative evidence needed | Completion rule |
| --- | --- | --- |
| Full findings coverage | Source-span-bound inventory covering all twenty notes, including aggregate-only families | Every named family maps to a recreation and result or a concrete unresolved obligation |
| Full source copies | Complete tracked-source census, raw SHA-256 manifest, destination inventory bijection | Every original tracked file is copied without mathematical or textual edits |
| Actual recreations | Pinned code, explicit dependencies, deterministic cases, fresh output receipts | A retained historical receipt, prose description, skipped case, or refusal does not prove an intended positive computation was recreated |
| Native evidence | Exact source/build identity, host digest, requests, responses, independent certificate replay | Existing native rational engines own their computations; failures cannot become passing fallbacks |
| Historical claims | Preserved correction notices and current provenance | Model accuracy, leaked prompts, reference self-scores, and always-true fields remain distinct |
| Reader artifact | Manuscript, claim ledger, references, mechanism inventory, rendered TeX/PDF | Claims cite inspected evidence with finite scope and unresolved work visible |
| Reproducible package | Standalone commands, focused tests, source-custody corruption controls, two-tier manifests and deterministic ZIP | No unpinned ambient imports or silent archive exclusions; archive envelope and source bytes replay |
| Complete final audit | Requirement-by-requirement current-state audit | Any missing positive recreation or source file leaves the user goal incomplete |

Live provider experiments require separately declared provider, budget, and data
handling. Offline source and native algorithm replays reproduce computations;
they do not reproduce unretained live model sessions.

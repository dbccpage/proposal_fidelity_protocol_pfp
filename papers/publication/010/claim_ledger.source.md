# Claim ledger: PFP X (Paper 010)

Version 2.0.2, 2026-09-30. Code baseline `a623568eb0f853b968bc419bf06dfc6af256ab02`.

Each row is a claim made in the manuscript, with the section that makes it, its
kind, and the evidence that supports it. Kinds are: *executable check* (a named
test in `code/tests/`), *formal proof* (a Lean declaration in `lean4/`), *standard
fact* (a cited reference), *retained record* (a repository file, cited by path and
commit), and *source inspection* (reading a retained script), and *replay* (the collection's
`tools/replay_formal_math_baselines.py`, which runs the challenge checkers from the
cited commits on answers that need no mathematics; its output is recorded in the
collection's `verification/formal_math_baselines.json`). Paths under
`omega_engine_projects/` are relative to the repository root; the C017 folder is
`omega_engine_projects/mssn_sn_symgam/challenges/b_cohomology/c017_nonabelian_lattice_holonomy/`
and the formal-mathematics folder is
`omega_engine_projects/mssn_sn_symgam/challenges/e_formal_math/`. Claims withdrawn
from the first release are listed in `paper_change_log.md`, not here.

\subsection{1. Proposal channels and the Three-Layer PFP host
boundary}\label{proposal-channels-and-the-three-layer-pfp-host-boundary}

Fix a finite task \(P\), a candidate language \(W\), a solution relation
\(R(P,\allowbreak w)\), and a deterministic host checker \(C\). A
proposal channel \(\mu\) is any distribution on raw messages produced by
a prompt template, a multi-turn staged protocol, a local logit mask, or
an external model provider. A separately supplied decoder maps
well-formed messages to \(W\) and refuses malformed messages. The host
replays the decoded witness against the original task \(P\).

In the engine PFP runtime, this separation is organized into three
non-collapsing layers:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Layer 1 (Compositional Prompt Operad):} Typed prompt assembly
  and slot-grafting (\(\circ_i\)) over immutable source spans and
  congruence ideals.
\item
  \textbf{Layer 2 (Token-Frontier Grammar Projection):} BPE
  prefix-automaton logit masking
  (\passthrough{\lstinline!gbnf\_slots=k!}) or strict response-schema
  projection restricting surface emission to a regular language
  \(\mathcal{L}_k \subset \Sigma^*\).
\item
  \textbf{Layer 3 (Independent Host Cochain \& Domain Oracles):} Exact
  rational cochain evaluation (\(\Phi_1,\allowbreak  \Gamma_2\)) and
  independent domain judges that certify or refuse the decoded candidate
  without consulting the proposal channel's internal scores.
\end{enumerate}

\subsection{2. Theorem 1: Channel-independent host checking
soundness}\label{theorem-1-channel-independent-host-checking-soundness}

\textbf{Theorem 1 (Channel-Independent Soundness).} Let
\(D: \Sigma^* \rightharpoonup W\) be a partial decoder that binds every
admitted raw reply \(m \in \Sigma^*\) to the fixed task \(P\), and
suppose the host checker \(C: \{P\} \times W \to
\{\mathsf{accept},\allowbreak  \mathsf{refuse}\}\) satisfies the
soundness implication
\begin{center}\PfpDisplayMath{C(P, w) = \mathsf{accept} \implies R(P, w).}\end{center}
Then for every proposal channel \(\mu\) on \(\Sigma^*\), the event of an
accepted invalid candidate is empty:
\begin{center}\PfpDisplayMath{\{m \in \Sigma^* : D(m) = w \text{ is defined},\; C(P, w) = \mathsf{accept},\; \neg R(P, w)\} = \emptyset,}\end{center}
and therefore has probability zero under \(\mu\). No acceptance-rate
lower bound or search-completeness guarantee follows from soundness
alone.

\textbf{Proof.} Fix any raw message \(m \in \Sigma^*\) accepted by the
host pipeline. By definition of admission, \(w = D(m) \in W\) is defined
and bound to \(P\), and \(C(P,\allowbreak  w) = \mathsf{accept}\). By
the soundness hypothesis on \(C\), \(R(P,\allowbreak  w)\) holds.
Because the deduction is pointwise in \(m\) and does not reference
\(\mu\), no message \(m\) can simultaneously satisfy
\(C(P,\allowbreak  D(m)) = \mathsf{accept}\) and
\(\neg R(P,\allowbreak  D(m))\). Thus the bad set is empty and
\(\mu(\emptyset) = 0\) for every probability measure or empirical run
\(\mu\). Conversely, a channel \(\mu\) concentrating all mass on a
single malformed string \(m_0 \notin \operatorname{dom}(D)\) satisfies
Theorem 1 vacuously with zero accepted solutions, demonstrating that
validity and search success are independent obligations. \(\square\)

\subsection{3. Exact glyph transport}\label{exact-glyph-transport}

For the Boolean task \(x+y=1\), encode \((x,\allowbreak y)\) by the
string \passthrough{\lstinline!<xy>!}. The four domain values have four
distinct strings: \passthrough{\lstinline!<00>!},
\passthrough{\lstinline!<01>!}, \passthrough{\lstinline!<10>!},
\passthrough{\lstinline!<11>!}. The decoder checks the brackets, length,
and binary digits; it is inverse to the encoder on this declared domain.
Hence checking a decoded string and checking its assignment are the same
mathematical obligation. The strings use only a subset of A--Z, 0--9,
and angle brackets.

More generally, a finite domain admits an injective finite-word code
with a declared partial inverse. Proof is by indexing its elements and
assigning distinct fixed-length binary words (with a separate
empty-domain case). This is representation capacity. It does not show
that an LLM can recover the desired word, solve every encoded question,
or supply a missing domain \nolinkurl{interpretation.} The typed prompt
and required response matter because they fix that interpretation and
the host's checking obligation.

\subsection{\texorpdfstring{4. Theorem 2: Exact prompt-to-cochain
duality and single-cycle lightest-edge \(\ell_1\)
projection}{4. Theorem 2: Exact prompt-to-cochain duality and single-cycle lightest-edge \textbackslash ell\_1 projection}}\label{theorem-2-exact-prompt-to-cochain-duality-and-single-cycle-lightest-edge-ell_1-projection}

When a prompt task specifies local edge transitions or consistency
claims across a finite 2-dimensional cell complex
\((V,\allowbreak  E,\allowbreak  F)\) over \(\mathbb{Q}\), the host
evaluates the candidate claim vector \(c \in C^1 = \mathbb{Q}^E\)
through the cochain complex
\begin{center}\PfpDisplayMath{C^0 = \mathbb{Q}^V \xrightarrow{d_0} C^1 = \mathbb{Q}^E \xrightarrow{d_1} C^2 = \mathbb{Q}^F, \qquad d_1 \circ d_0 = 0,}\end{center}
where \((d_0 a)_{(u,\allowbreak v)} = a_v - a_u\) for node potentials
\(a \in \mathbb{Q}^V\), and
\((d_1 c)_f = \sum_{e \in \partial f} \sigma_{f,\allowbreak e} c_e\) is
the oriented cycle holonomy around 2-cell \(f \in F\). Define the
coboundary compatibility residual and the curvature residual by
\begin{center}\PfpDisplayMath{\Phi_1(c) := \min_{a \in \mathbb{Q}^V} \|c - d_0 a\|_1, \qquad \Gamma_2(c) := \|d_1 c\|_1.}\end{center}

\textbf{Theorem 2 (Single-Cycle Exact Coboundary Duality \& Weighted
\(\ell_1\) Repair).} Let \(G = (V,\allowbreak  E,\allowbreak  F)\) be a
single directed \(k\)-cycle (\(k \ge 3\)) with vertices
\(v_0,\allowbreak  \dots,\allowbreak  v_{k-1}\), directed edges
\(e_i = (v_i \to v_{(i+1) \bmod k})\), a single oriented \(k\)-gon face
\(f_0\), edge claims \(c \in \mathbb{Q}^k\), positive edge weights
\(w \in \mathbb{Q}_{>0}^k\), and cycle holonomy sum
\(s := (d_1 c)_{f_0} = \sum_{i=0}^{k-1} c_i\). Then:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Exactness and \(\ell_1\) Duality:}
  \(\operatorname{im}(d_0) = \ker(d_1) =
  \{c' \in \mathbb{Q}^k : \sum_{i=0}^{k-1} c'_i = 0\}\), and
  \begin{center}\PfpDisplayMath{\Phi_1(c) = \Gamma_2(c) = |s| = \max_{z \in \mathbb{Q}^k : \partial_1 z = 0,\, \|z\|_\infty \le 1} \langle z, c \rangle.}\end{center}
  Whenever \(\sum_{i=0}^{k-1} c'_i = 0\), the node potential
  \(a \in \mathbb{Q}^k\) defined by \(a_0 = 0\) and
  \(a_m = \sum_{j=0}^{m-1} c'_j\) (\(1 \le m < k\)) satisfies
  \(d_0 a = c'\) identically.
\item
  \textbf{Weighted \(\ell_1\)-Optimal Repair:} For any repaired cochain
  \(c' = c + \Delta\) satisfying \(d_1 c' = 0\) (equivalently
  \(\sum_{i=0}^{k-1} \Delta_i = -s\)), the weighted modification cost
  satisfies the lower bound
  \begin{center}\PfpDisplayMath{\|c' - c\|_{1,w} := \sum_{i=0}^{k-1} w_i |\Delta_i| \ge w_{\min} |s|, \qquad w_{\min} := \min_{0 \le i < k} w_i.}\end{center}
  Equality is attained by the single-edge coboundary repair at any
  lightest edge \(i^* \in \arg\min_i w_i\):
  \begin{center}\PfpDisplayMath{c'_i = \begin{cases} c_{i^*} - s & \text{if } i = i^*, \\ c_i & \text{if } i \ne i^*, \end{cases}}\end{center}
  and is certified with zero duality gap by the dual circulation witness
  \(z^* = \operatorname{sgn}(s) w_{\min} \mathbf{1} \in \ker(\partial_1)\).
\end{enumerate}

\textbf{Proof.} (1) Since \(e_i = (v_i \to v_{(i+1)\bmod k})\), every
telescopic sum around the cycle yields
\(\sum_{i=0}^{k-1} (d_0 a)_i = \sum_{i=0}^{k-1} (a_{(i+1)\bmod k} - a_i) = 0\),
so \(d_1 d_0 = 0\) and \(\operatorname{im}(d_0) \subseteq \ker(d_1)\).
Conversely, if \(\sum_{i=0}^{k-1} c'_i = 0\), setting \(a_0 = 0\) and
\(a_m = \sum_{j=0}^{m-1} c'_j\) gives \(a_{m+1} - a_m = c'_m\) for
\(0 \le m < k-1\) and
\(a_0 - a_{k-1} = -\sum_{j=0}^{k-2} c'_j = c'_{k-1}\), so
\(d_0 a = c'\). For any \(a \in \mathbb{Q}^k\), the triangle inequality
gives
\begin{center}\PfpDisplayMath{\|c - d_0 a\|_1 = \sum_{i=0}^{k-1} |c_i - (d_0 a)_i| \ge \left|\sum_{i=0}^{k-1} (c_i - (d_0 a)_i)\right| = |s|,}\end{center}
and subtracting \(s\) from a single edge achieves
\(\|c - d_0 a\|_1 = |s|\) using the potential \(a\) of the resulting
zero-sum vector. The dual cycle space
\(\ker(\partial_1) = \{z \in \mathbb{Q}^k : z_0 = z_1 = \dots = z_{k-1}\}\)
is spanned by \(\mathbf{1}\), so
\(\max_{\partial_1 z = 0,\allowbreak  \|z\|_\infty \le 1} \langle z,\allowbreak  c \rangle = \max_{\alpha \in [-1,\allowbreak 1]} \alpha s = |s|\).

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}
\setcounter{enumi}{1}
\tightlist
\item
  For any \(\Delta \in \mathbb{Q}^k\) with
  \(\sum_{i=0}^{k-1} \Delta_i = -s\),
  \begin{center}\PfpDisplayMath{\sum_{i=0}^{k-1} w_i |\Delta_i| \ge w_{\min} \sum_{i=0}^{k-1} |\Delta_i| \ge w_{\min} \left|\sum_{i=0}^{k-1} \Delta_i\right| = w_{\min} |s|.}\end{center}
  Setting \(\Delta_{i^*} = -s\) and \(\Delta_j = 0\) (\(j \ne i^*\))
  satisfies \(\sum_i (c_i + \Delta_i) = s - s = 0\) and achieves
  \(\sum_i w_i |\Delta_i| = w_{i^*} |s| = w_{\min} |s|\). \(\square\)
\end{enumerate}

\subsubsection{\texorpdfstring{5.1 Theorem 3: Coloured operad quotient
and two-sided \texttt{NullTree}
absorption}{5.1 Theorem 3: Coloured operad quotient and two-sided NullTree absorption}}\label{theorem-3-coloured-operad-quotient-and-two-sided-nulltree-absorption}

Let \(\mathcal{C}\) be the finite set of prompt semantic colours

\(f \in \mathcal{O}^+(c_1,\allowbreak  \dots,\allowbreak  c_n; c_{\text{out}})\)
and leaf spans \([i,\allowbreak  j]\) extracted from a source document
\(D\). Let \(\mathcal{I} \subset \mathcal{O}\) be the subset of trees
containing any of the following defects: (i) a non-exact or
boolean-coerced numeric value (\nolinkurl{IDEAL_RATIONAL_DOMAIN}), (ii)
a leaf span whose content or SHA-256 digest does not match \(D[i:j]\)
(\nolinkurl{IDEAL_SPAN_IMMUTABILITY}), (iii) a slot-grafting operation
\(f \circ_m g\) whose child output colour \(\operatorname{out}(g)\) does
not equal the \(m\)-th input colour \(\operatorname{in}_m(f)\) or whose
slot index
\(m \notin \{0,\allowbreak  \dots,\allowbreak  \operatorname{arity}(f)-1\}\),
or (iv) a candidate binding neutralized by an active
\nolinkurl{AnnihilatorDecoy} witness (\(\mathcal{O}^-\)).

\textbf{Theorem 3 (Two-Sided Ideal Absorption in
\(\mathcal{O} / \mathcal{I}\)).} The subset \(\mathcal{I}\) is a
two-sided operad ideal: for every tree \(t \in \mathcal{I}\) and every
tree \(u \in \mathcal{O}\), both \(u \circ_m t \in \mathcal{I}\) and
\(t \circ_m u \in \mathcal{I}\). Consequently, the quotient coloured
operad
\(\mathcal{O} / \mathcal{I} := (\mathcal{O} \setminus \mathcal{I}) \sqcup \{\mathbf{0}\}\)
with distinguished null element \(\mathbf{0}\)
(\passthrough{\lstinline!NullTree!}) satisfies the two-sided absorption
law
\begin{center}\PfpDisplayMath{f \circ_m \mathbf{0} = \mathbf{0}, \qquad \mathbf{0} \circ_m g = \mathbf{0},}\end{center}
and any composite tree \(T \in \mathcal{O} / \mathcal{I}\) satisfies
\(T \ne \mathbf{0}\) if and only if every leaf span is byte-identical to
its declared slice in \(D\), every parameter belongs to \(\mathbb{Q}\),
every internal graft matches its declared colour signature, and no
active decoy witness is triggered.

\textbf{Proof.} By induction on tree depth. A single leaf or operator
violation places the local node in \(\mathcal{I}\), which projects to
\(\mathbf{0} \in \mathcal{O} / \mathcal{I}\). Because containing a
defect in \(\mathcal{I}\) is hereditary under subtree inclusion---if a
subtree \(t\) contains a malformed span, non-rational parameter, or
colour mismatch, then any larger tree \(u \circ_m t\) or \(t \circ_m u\)
containing \(t\) also contains that defect---\(\mathcal{I}\) is closed
under both left and right partial composition \(\circ_m\). Collapsing
\(\mathcal{I}\) to a single point \(\mathbf{0}\) therefore makes
\(\circ_m\) well-defined on \(\mathcal{O} / \mathcal{I}\) with
\(f \circ_m \mathbf{0} = \mathbf{0}\) and
\(\mathbf{0} \circ_m g = \mathbf{0}\). \(\square\)

\subsubsection{\texorpdfstring{5.2 Proposition 4: BPE prefix-automaton
logit mask viability and \texttt{F-null}
identity}{5.2 Proposition 4: BPE prefix-automaton logit mask viability and F-null identity}}\label{proposition-4-bpe-prefix-automaton-logit-mask-viability-and-f-null-identity}

Let \(\mathcal{L}_k \subset \Sigma^*\) be the regular language of \(k\)
space-separated signed ASCII integers
(\nolinkurl{integer_slots_gbnf(k)}):
\begin{center}\PfpDisplayMath{\mathcal{L}_k = \left\{ w_1 \mathbin{\Vert} \text{\texttt{" "}} \mathbin{\Vert} w_2 \mathbin{\Vert} \dots \mathbin{\Vert} \text{\texttt{" "}} \mathbin{\Vert} w_k \;\middle|\; w_j \in \{\text{\texttt{"0"}}\} \cup (\{\varepsilon, \text{\texttt{"-"}}\} \cdot \{\text{\texttt{1..9}}\} \cdot \{\text{\texttt{0..9}}\}^*) \right\},}\end{center}
and let
\(\operatorname{Pref}(\mathcal{L}_k) = \{u \in \Sigma^* : \exists v \in \Sigma^*,\allowbreak \; u \mathbin{\Vert} v \in \mathcal{L}_k\}\)
be its set of viable prefixes, recognized by the six-component
prefix-state DFA
\(\delta_{\text{DFA}}(u) = (\text{viable},\allowbreak  \text{complete},\allowbreak  \text{slots\_seen},\allowbreak  \text{in\_number},\allowbreak  \text{after\_minus},\allowbreak  \text{after\_zero})\).

\textbf{Proposition 4 (BPE Token-Frontier Projection \&
\passthrough{\lstinline!F-null!} Identity).} For any BPE tokenizer
vocabulary \(V \subset \Sigma^+\) with end-of-sequence token
\(\tau_{\text{eos}} \notin V\) and any viable prefix
\(S_t \in \operatorname{Pref}(\mathcal{L}_k)\) at generation step \(t\),
define the admissible token frontier
\begin{center}\PfpDisplayMath{V_{\text{valid}}(S_t) := \{\tau \in V : S_t \mathbin{\Vert} \tau \in \operatorname{Pref}(\mathcal{L}_k)\} \cup \{\tau_{\text{eos}} : S_t \in \mathcal{L}_k\},}\end{center}
and define the masked logit vector
\(\tilde{\ell}^{(t)}_v = \ell^{(t)}_v\) if
\(v \in V_{\text{valid}}(S_t)\) and \(-\infty\) otherwise. Then:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Prefix Viability \& Complete-Word Soundness:} If
  \(S_0 = \varepsilon\) and at each step \(t < T\) the sampled token
  \(\tau_t\) has finite masked logit
  (\(\tau_t \in V_{\text{valid}}(S_t)\)), then
  \(S_t \in \operatorname{Pref}(\mathcal{L}_k)\) for all \(t \ge 0\),
  and if generation terminates via \(\tau_T = \tau_{\text{eos}}\), then
  \(S_T \in \mathcal{L}_k\)
  (\passthrough{\lstinline!parse\_integer\_slots(S\_T, k)!} succeeds).
\item
  \textbf{BPE Multi-Character Boundary Completeness:} A merged BPE token
  \(\tau \in V\) spanning a slot boundary (such as
  \(\tau = \text{\texttt{" -"}}\text{ or }\text{\texttt{" 12"}}\))
  belongs to \(V_{\text{valid}}(S_t)\) whenever \(S_t\) ends a valid
  integer slot with \(\text{slots\_seen}(S_t) < k\), because
  \(\delta_{\text{DFA}}(S_t \mathbin{\Vert} \tau)\) transitions across
  the space character and opens slot \(\text{slots\_seen}(S_t) + 1\).
\item
  \textbf{\passthrough{\lstinline!F-null!} Token Identity:} When the
  logit processor is instantiated with the full vocabulary frontier
  \(V_{\text{valid}}^{\text{null}}(S_t) = V \cup \{\tau_{\text{eos}}\}\),
  \(\tilde{\ell}^{(t)} = \ell^{(t)}\) at every step \(t\), so greedy or
  fixed-seed decoding produces a token sequence identical to unhooked
  decoding.
\end{enumerate}

\textbf{Proof.} (1) follows by induction on \(t\):
\(S_0 = \varepsilon \in \operatorname{Pref}(\mathcal{L}_k)\), and
\(\tau_t \in V_{\text{valid}}(S_t) \setminus \{\tau_{\text{eos}}\}\)
implies
\(S_{t+1} = S_t \mathbin{\Vert} \tau_t \in \operatorname{Pref}(\mathcal{L}_k)\)
by definition of \(V_{\text{valid}}(S_t)\), while
\(\tau_{\text{eos}} \in V_{\text{valid}}(S_T)\) holds if and only if
\(S_T \in \mathcal{L}_k\). (2) follows because \(\delta_{\text{DFA}}\)
advances character-by-character over the concatenation
\(S_t \mathbin{\Vert} \tau\): after a completed slot \(m < k\),
\passthrough{\lstinline!' '!} transitions to
\((\text{slots\_seen}=m,\allowbreak  \text{in\_number}=\mathsf{false})\),
and \passthrough{\lstinline!'-'!} then transitions to
\((\text{slots\_seen}=m+1,\allowbreak  \text{in\_number}=\mathsf{true},\allowbreak  \text{after\_minus}=\mathsf{true})\),
which is a viable prefix of \(\mathcal{L}_k\). (3) is immediate because
adding \(0\) to every coordinate of \(\ell^{(t)}\) leaves
\(\arg\max_v \ell^{(t)}_v\) and \(\operatorname{softmax}(\ell^{(t)})\)
invariant. \(\square\)

\subsubsection{\texorpdfstring{5.3 Theorem 5: Guarded Stage-1 slot retry
with \texttt{NullTree}
abstention}{5.3 Theorem 5: Guarded Stage-1 slot retry with NullTree abstention}}\label{theorem-5-guarded-stage-1-slot-retry-with-nulltree-abstention}

Consider a 2-stage \passthrough{\lstinline!P*!} operad pipeline
\(X \xrightarrow{f_1} Z_1 \xrightarrow{f_2 \circ_i z_1} Y\) where Stage
1 proposes a 4-slot invariant tuple
\(z_1 = (\hat{s},\allowbreak  \hat{i}^*,\allowbreak  \hat{c}_{i^*},\allowbreak  \hat{c}'_{i^*}) \in \mathbb{Z}^4\)
for a directed \(k\)-cycle \(x = (c,\allowbreak  w)\) with unique
canonical truth tuple
\begin{center}\PfpDisplayMath{z_1^*(x) = \left(s(c),\; i^*(w),\; c_{i^*},\; c_{i^*} - s(c)\right), \qquad i^*(w) := \min \arg\min_{0 \le j < k} w_j.}\end{center}
Let \(G_1: \mathcal{X} \times \mathbb{Z}^4 \to \{0,\allowbreak  1\}\) be
a deterministic Stage-1 host guard, let \(\pi_{\mathcal{I}}\) project
any rejected Stage-1 output (\(G_1(x,\allowbreak  z_1) = 0\)) to
\passthrough{\lstinline!NullTree!} (\(\mathbf{0}\)), and let \(R \ge 1\)
be a bounded Stage-1 retry cap (1 initial attempt + at most \(R - 1\)
diagnostic retries).

\textbf{Theorem 5 (Guarded Stage-1 Slot Retry with Ideal Abstention ---
derived with \nolinkurl{claude-fable-5-1},
\nolinkurl{msg_011Cg74HxZqarY627LKcRzQa}).} Suppose the Stage-1 guard
\(G_1\) is sound and complete for \(z_1^*(x)\), meaning
\(G_1(x,\allowbreak  z_1) = 1 \iff z_1 = z_1^*(x)\). Let
\(p_1(x) := \mathbb{P}(Z_1^{(1)} = z_1^*(x) \mid x)\) be the Attempt-1
exact Stage-1 probability, and under the conditional independence
assumption that each diagnostic retry
\(r \in \{2,\allowbreak  \dots,\allowbreak  R\}\) given prior failure
succeeds with probability
\(p_{1,\allowbreak \text{retry}}(x) := \mathbb{P}(Z_1^{(r)} = z_1^*(x) \mid x,\allowbreak  G_1(x,\allowbreak  Z_1^{(r-1)}) = 0)\),
let \(p_2(y^* \mid x,\allowbreak  z_1)\) denote the Stage-2 probability
of emitting the exact \(\ell_1\)-optimal cochain repair \(y^*(x)\) when
\(z_1\) is grafted into \(f_2\). Then:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Stage-1 Admission Probability:} The probability that Stage 1
  is admitted to Stage 2 within \(R\) bounded attempts is
  \begin{center}\PfpDisplayMath{q_{G_1, R}(x) = 1 - (1 - p_1(x))\bigl(1 - p_{1,\text{retry}}(x)\bigr)^{R-1}.}\end{center}
\item
  \textbf{Admission-Conditional Stage-2 Precision:} Because
  \(G_1(x,\allowbreak  z_1) = 1 \iff z_1 = z_1^*(x)\) and
  \(\pi_{\mathcal{I}}\) absorbs all \(G_1 = 0\) terminations into
  \passthrough{\lstinline!NullTree!}
  (\(f_2 \circ_i \mathbf{0} = \mathbf{0}\) by Theorem 3), conditioning
  on Stage-2 admission eliminates all corrupted Stage-1 grafts:
  \begin{center}\PfpDisplayMath{\mathbb{P}_{\text{ver}, R}\!\left(Y = y^*(x) \;\middle|\; x,\, \text{Stage 2 admitted}\right) = p_2\!\left(y^*(x) \;\middle|\; x,\, z_1^*(x)\right).}\end{center}
\item
  \textbf{Unconditional Exact Repair Rate vs.~Unverified Grafting:}
  Under unverified 1-shot grafting (\(R=1\), no guard), the
  unconditional optimal repair rate is
  \begin{center}\PfpDisplayMath{\mathbb{P}_{\text{unv}}(Y = y^*(x) \mid x) = p_1(x)\,p_2(y^*(x) \mid x, z_1^*(x)) + \sum_{z_1 \ne z_1^*(x)} \mathbb{P}(Z_1 = z_1 \mid x)\,p_2(y^*(x) \mid x, z_1),}\end{center}
  whereas under guarded retry with \passthrough{\lstinline!NullTree!}
  abstention,
  \begin{center}\PfpDisplayMath{\mathbb{P}_{\text{ver}, R}(Y = y^*(x) \mid x) = q_{G_1, R}(x)\,p_2(y^*(x) \mid x, z_1^*(x)).}\end{center}
  In particular, whenever \(p_2(y^*(x) \mid x,\allowbreak  z_1) = 0\)
  for all corrupted tuples \(z_1 \ne z_1^*(x)\) (faithful Stage-2 slot
  substitution), guarded retry improves unconditional optimal repair by
  the exact gain
  \begin{center}\PfpDisplayMath{\mathbb{P}_{\text{ver}, R}(Y = y^*(x) \mid x) - \mathbb{P}_{\text{unv}}(Y = y^*(x) \mid x) = (1 - p_1(x))\!\left[1 - \bigl(1 - p_{1,\text{retry}}(x)\bigr)^{R-1}\right] p_2(y^*(x) \mid x, z_1^*(x)) \ge 0.}\end{center}
\item
  \textbf{Expected Stage-2 Call Savings:} If a Stage-2 call costs
  \(c_2 > 0\), \passthrough{\lstinline!NullTree!} abstention on
  persistent Stage-1 guard failure saves
  \begin{center}\PfpDisplayMath{\mathbb{E}[\Delta C_2 \mid x] = \bigl(1 - q_{G_1, R}(x)\bigr)\,c_2}\end{center}
  in expected Stage-2 expenditure compared to unverified Stage-2
  dispatch.
\end{enumerate}

\textbf{Proof.} (1) Stage 1 fails admission across all \(R\) attempts if
and only if Attempt 1 fails (\(1 - p_1(x)\)) and each of the \(R - 1\)
retries fails (\((1 - p_{1,\allowbreak \text{retry}}(x))^{R-1}\));
taking the complement gives \(q_{G_1,\allowbreak  R}(x)\). (2) On the
event of Stage-2 admission, the admitted tuple \(\hat{z}_1\) satisfies
\(G_1(x,\allowbreak  \hat{z}_1) = 1\), which by soundness and
completeness of \(G_1\) implies \(\hat{z}_1 = z_1^*(x)\)
deterministically; thus the Stage-2 law conditioned on admission is
\(p_2(\cdot \mid x,\allowbreak  z_1^*(x))\). (3) follows by the law of
total probability over \(z_1 \in \mathbb{Z}^4\) and substituting
\(q_{G_1,\allowbreak  R}(x) - p_1(x) = (1 - p_1(x))[1 - (1 - p_{1,\allowbreak \text{retry}}(x))^{R-1}]\).
(4) Unverified grafting dispatches Stage 2 with probability \(1\),
whereas guarded grafting dispatches Stage 2 with probability
\(q_{G_1,\allowbreak  R}(x)\) and projects the remaining
\(1 - q_{G_1,\allowbreak  R}(x)\) mass to
\passthrough{\lstinline!NullTree!} at zero Stage-2 cost. \(\square\)

\subsubsection{\texorpdfstring{5.4 Theorem 6: Partial-guard visibility
gap and false-green kernel
\(\mathcal{K}_{\text{false}}(x) \cong \mathbb{Z} \setminus \{0\}\)}{5.4 Theorem 6: Partial-guard visibility gap and false-green kernel \textbackslash mathcal\{K\}\_\{\textbackslash text\{false\}\}(x) \textbackslash cong \textbackslash mathbb\{Z\} \textbackslash setminus \textbackslash\{0\textbackslash\}}}\label{theorem-6-partial-guard-visibility-gap-and-false-green-kernel-mathcalk_textfalsex-cong-mathbbz-setminus-0}

Suppose a Stage-1 guard checks only the \textbf{local} slot invariants
on
\(z_1 = (\hat{s},\allowbreak  \hat{i}^*,\allowbreak  \hat{c}_{i^*},\allowbreak  \hat{c}'_{i^*}) \in \mathbb{Z}^4\)---namely
canonical minimum-weight index selection, exact edge-claim lookup, and
the linear subtraction relation---without checking the global cycle-sum
equation \(\hat{s} = \sum_{j=0}^{k-1} c_j\):
\begin{center}\PfpDisplayMath{G_{\text{partial}}(x, z_1) = 1 \iff \Bigl(\hat{i}^* = i^*(w)\Bigr) \;\wedge\; \Bigl(\hat{c}_{i^*} = c_{\hat{i}^*}\Bigr) \;\wedge\; \Bigl(\hat{c}'_{i^*} + \hat{s} = \hat{c}_{i^*}\Bigr),}\end{center}
whereas the \textbf{complete} guard adjoins the global cycle-sum check:
\begin{center}\PfpDisplayMath{G_{\text{complete}}(x, z_1) = 1 \iff G_{\text{partial}}(x, z_1) = 1 \;\wedge\; \left(\hat{s} = \sum_{j=0}^{k-1} c_j\right).}\end{center}

\textbf{Theorem 6 (Partial-Guard Visibility Gap \& False-Green Kernel
--- derived with \nolinkurl{claude-fable-5-1},
\nolinkurl{msg_011Cg74HxZqarY627LKcRzQa}).} For every directed
\(k\)-cycle \(x = (c,\allowbreak  w)\):

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Infinite False-Green Kernel under \(G_{\text{partial}}\):} The
  set of false-green Stage-1 tuples admitted by \(G_{\text{partial}}\)
  is
  \begin{center}\PfpDisplayMath{\mathcal{K}_{\text{false}}(x) := \left\{z_1 \in \mathbb{Z}^4 : G_{\text{partial}}(x, z_1) = 1 \;\wedge\; z_1 \ne z_1^*(x)\right\} \cong \mathbb{Z} \setminus \{0\},}\end{center}
  parameterized bijectively by the non-zero cycle-sum error
  \(\Delta s := \hat{s} - s(c) \in \mathbb{Z} \setminus \{0\}\) via
  \begin{center}\PfpDisplayMath{z_1(\Delta s) = \left(s(c) + \Delta s,\; i^*(w),\; c_{i^*},\; c_{i^*} - s(c) - \Delta s\right).}\end{center}
\item
  \textbf{Induced Stage-2 Cochain Residual (Local Green / Global Red):}
  If Stage 2 substitutes a false-green tuple
  \(z_1(\Delta s) \in \mathcal{K}_{\text{false}}(x)\) into edge
  \(i^* = i^*(w)\) while preserving \(c'_j = c_j\) for \(j \ne i^*\),
  the resulting Stage-2 edge cochain \(c'(\Delta s)\) has non-zero cycle
  holonomy
  \begin{center}\PfpDisplayMath{\sum_{j=0}^{k-1} c'_j(\Delta s) = -\Delta s \ne 0, \qquad \Gamma_2\bigl(c'(\Delta s)\bigr) = |\Delta s| > 0, \qquad \Phi_{1, w}\bigl(c'(\Delta s)\bigr) = w_{i^*}|\Delta s| > 0,}\end{center}
  and is therefore rejected by the Layer-3 cochain verifier as
  \nolinkurl{NonClosedEdgeData} / \nolinkurl{ClosedNonExactClass}.
\item
  \textbf{Kernel Closure under \(G_{\text{complete}}\):} Adjoining
  \(\hat{s} = \sum_{j=0}^{k-1} c_j\) forces \(\Delta s = 0\), collapsing
  the false-green kernel to the empty set
  (\(\mathcal{K}_{\text{false}}^{\text{complete}}(x) = \emptyset\)) and
  making
  \(G_{\text{complete}}(x,\allowbreak  z_1) = 1 \iff z_1 = z_1^*(x)\).
\end{enumerate}

\textbf{Proof.} (1) Any
\(z_1 = (\hat{s},\allowbreak  \hat{i}^*,\allowbreak  \hat{c}_{i^*},\allowbreak  \hat{c}'_{i^*}) \in \mathbb{Z}^4\)
satisfying \(G_{\text{partial}}(x,\allowbreak  z_1) = 1\) has
\(\hat{i}^* = i^*(w)\) and \(\hat{c}_{i^*} = c_{i^*}\) uniquely fixed,
while \(\hat{c}'_{i^*} = c_{i^*} - \hat{s}\) is uniquely determined by
\(\hat{s} \in \mathbb{Z}\). Setting
\(\Delta s = \hat{s} - s(c) \in \mathbb{Z}\) gives the bijection
\(\Delta s \mapsto z_1(\Delta s)\), with
\(\Delta s = 0 \iff z_1 = z_1^*(x)\). (2) Substituting
\(c'_{i^*} = c_{i^*} - s(c) - \Delta s\) into \(c\) yields cycle sum
\(\sum_{j \ne i^*} c_j + (c_{i^*} - s(c) - \Delta s) = s(c) - s(c) - \Delta s = -\Delta s \ne 0\),
so Theorem 2 gives \(\Gamma_2(c'(\Delta s)) = |\Delta s| > 0\) and
\(\Phi_{1,\allowbreak w}(c'(\Delta s)) = w_{i^*}|\Delta s| > 0\). (3)
Adding \(\hat{s} = s(c)\) forces \(\Delta s = 0\). \(\square\)

\subsubsection{\texorpdfstring{5.5 Theorem 7: Triangular chord-induced
cycle decoupling and multi-cycle partial-guard visibility gap
\(\mathcal{K}_{\text{false}}^{\text{C006}}(x) \cong \mathbb{Z}^{|V|-1+b_1} \setminus \{0\}\)}{5.5 Theorem 7: Triangular chord-induced cycle decoupling and multi-cycle partial-guard visibility gap \textbackslash mathcal\{K\}\_\{\textbackslash text\{false\}\}\^{}\{\textbackslash text\{C006\}\}(x) \textbackslash cong \textbackslash mathbb\{Z\}\^{}\{\textbar V\textbar-1+b\_1\} \textbackslash setminus \textbackslash\{0\textbackslash\}}}\label{theorem-7-triangular-chord-induced-cycle-decoupling-and-multi-cycle-partial-guard-visibility-gap-mathcalk_textfalsetextc006x-cong-mathbbzv-1b_1-setminus-0}

Let \(G = (V,\allowbreak  E)\) be a finite connected directed graph with
\(|V|\) vertices, \(|E|\) edges, spanning tree \(T \subset E\)
(\(|T| = |V| - 1\)) rooted at \(v_0 \in V\), and first Betti number
\(b_1 := \dim H_1(G; \mathbb{Q}) = |E \setminus T| \ge 2\) chords
\(g_1,\allowbreak  \dots,\allowbreak  g_{b_1} \in E \setminus T\), where
\(g_m = (u_m \to v_m)\). Each chord \(g_m\) closes a unique
chord-induced oriented cycle \(\gamma_m\) whose support lies in
\(T \cup \{g_m\}\) with \(+1\) orientation on \(g_m\) and signed tree
path \(-\pi_T(u_m \to v_m)\), even when multiple cycles
\(\gamma_1,\allowbreak  \dots,\allowbreak  \gamma_{b_1}\) share
high-incidence tree edges \(e_{\text{shared}} \in T\) (for example, on
\(K_4\) with a non-star spanning tree \(T\),
\(|V|=4,\allowbreak  |E|=6,\allowbreak  b_1=3\), and a shared tree edge
traversed by all \(3\) chord-induced cycles).

For any edge claim vector \(c \in \mathbb{Z}^E\), define the unique
tree-integrated vertex potential \(p_T^* \in \mathbb{Z}^V\) by
\(p_T^*(v_0) = 0\) and \(p_T^*(v) - p_T^*(u) = c_{(u,\allowbreak v)}\)
for every tree edge \((u,\allowbreak v) \in T\), and define the
canonical Stage-1 \((|V|-1+2 b_1)\)-slot tuple (\(9\) slots on \(K_4\))
in causal dependency order:
\begin{center}\PfpDisplayMath{z_1^*(x) := \Bigl(\bigl(p_T^*(v_j)\bigr)_{j=1}^{|V|-1},\; \bigl(c_{g_m}^{\prime *}\bigr)_{m=1}^{b_1},\; \bigl(r_m^*\bigr)_{m=1}^{b_1}\Bigr) \in \mathbb{Z}^{|V|-1+2 b_1},}\end{center}
where \(c_{g_m}^{\prime *} := p_T^*(v_m) - p_T^*(u_m)\) and

Compare the \textbf{partial chord-subtraction guard}
\begin{center}\PfpDisplayMath{G_{\text{partial}}^{\text{C006}}(x, z_1) = 1 \iff \bigwedge_{m=1}^{b_1} \left(\hat{c}'_{g_m} + \hat{r}_m = c_{g_m}\right)}\end{center}
against the \textbf{complete triangular-basis guard}
\begin{center}\PfpDisplayMath{G_{\text{complete}}^{\text{C006}}(x, z_1) = 1 \iff \bigwedge_{(u,v) \in T} \bigl(\hat{p}(v) - \hat{p}(u) = c_{(u,v)}\bigr) \;\wedge\; \bigwedge_{m=1}^{b_1} \bigl(\hat{c}'_{g_m} = \hat{p}(v_m) - \hat{p}(u_m)\bigr) \;\wedge\; \bigwedge_{m=1}^{b_1} \bigl(\hat{c}'_{g_m} + \hat{r}_m = c_{g_m}\bigr).}\end{center}

\textbf{Theorem 7 (Triangular Chord-Induced Cycle Decoupling \&
Multi-Cycle Visibility Gap).} For every connected graph
\(G = (V,\allowbreak  E)\) with spanning tree \(T\) and
\(b_1 = |E \setminus T| \ge 2\) chords:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Exact Triangular Chord Decoupling:} The cycle-chord incidence
  matrix of the chord-induced cycle basis
  \(\{\gamma_1,\allowbreak  \dots,\allowbreak  \gamma_{b_1}\}\)
  restricted to the chord coordinates
  \(\{g_1,\allowbreak  \dots,\allowbreak  g_{b_1}\} = E \setminus T\) is
  the \(b_1 \times b_1\) identity matrix \(I_{b_1}\)
  (\(\sigma_{m,\allowbreak  g_\ell} = \delta_{m,\allowbreak \ell}\)).
  Consequently, regardless of how many cycles \(\gamma_m\) overlap on
  shared spanning-tree edges \(e \in T\), fixing the tree claims
  \(c'_e = c_e\) (\(e \in T\)) and setting
  \(c'_{g_m} = c_{g_m}^{\prime *} = p_T^*(v_m) - p_T^*(u_m) = c_{g_m} - r_m^*\)
  for each chord \(m \in \{1,\allowbreak  \dots,\allowbreak  b_1\}\)
  yields an exact coboundary
  \(c' = d_0 p_T^* \in \operatorname{im}(d_0)\) with zero defect across
  all cycles simultaneously (\(\Phi_{1,\allowbreak w}(c') = 0\) and
  \(\Gamma_2(c') = 0\)). Moreover, if each tree edge weight satisfies
  \(w_e \ge \sum_{m : e \in \gamma_m} w_{g_m}\) (the tree-dominant
  weight regime), then \(c'\) is a global minimum-weight \(\ell_1\)
  coboundary repair of \(c\) with
  \(\|c' - c\|_{1,\allowbreak w} = \sum_{m=1}^{b_1} w_{g_m} |r_m^*|\).
\item
  \textbf{Rank-\((|V|-1+b_1)\) Partial-Guard Visibility Gap:} The
  false-green kernel of tuples passing
  \(G_{\text{partial}}^{\text{C006}}\) while failing
  \(G_{\text{complete}}^{\text{C006}}\) is canonically isomorphic to the
  punctured free \(\mathbb{Z}\)-module of rank \(|V| - 1 + b_1\)
  (\(= 2 b_1 = 6\) on \(K_4\)):
  \begin{center}\PfpDisplayMath{\mathcal{K}_{\text{false}}^{\text{C006}}(x) := \left\{z_1 \in \mathbb{Z}^{|V|-1+2 b_1} : G_{\text{partial}}^{\text{C006}}(x, z_1) = 1 \;\wedge\; z_1 \ne z_1^*(x)\right\} \cong \mathbb{Z}^{|V|-1+b_1} \setminus \{0\},}\end{center}
  parameterized bijectively by
  \((\Delta p,\allowbreak  \Delta r) \in \mathbb{Z}^{|V|-1} \times \mathbb{Z}^{b_1} \setminus \{(0,\allowbreak  0)\}\)
  via
  \begin{center}\PfpDisplayMath{\hat{p}(v_j) = p_T^*(v_j) + \Delta p_j, \qquad \hat{r}_m = r_m^* + \Delta r_m, \qquad \hat{c}'_{g_m} = c_{g_m} - r_m^* - \Delta r_m = c_{g_m}^{\prime *} - \Delta r_m.}\end{center}
  In particular, any non-zero chord-residual error \(\Delta r \ne 0\)
  induces non-zero post-repair cycle holonomy
  \((d_1 c'(\Delta r))_{\gamma_m} = -\Delta r_m\)
  (\(\Gamma_2(c'(\Delta r)) = \|\Delta r\|_1 > 0\)), while any non-zero
  potential error \(\Delta p \ne 0\) with \(\Delta r = 0\) causes
  Stage-2 \passthrough{\lstinline!VERIFY!} to fail on the tree-edge
  coboundary check \(\hat{p}(v) - \hat{p}(u) = c'_{(u,\allowbreak v)}\).
\item
  \textbf{Complete-Guard Closure:}
  \(G_{\text{complete}}^{\text{C006}}(x,\allowbreak  z_1) = 1 \iff z_1 = z_1^*(x)\),
  collapsing \(\mathcal{K}_{\text{false}}^{\text{C006}}\) to
  \(\emptyset\) and ensuring that every Stage-2 admitted session plan
  (\passthrough{\lstinline!ASSERT!} \(\to\)
  \passthrough{\lstinline!CUT!} \(\to\)
  \passthrough{\lstinline!VERIFY!}) carries an exact zero-defect
  coboundary \(c' = d_0 \hat{p}\) and its matching vertex potential
  \(\hat{p} = p_T^*\).
\end{enumerate}

\textbf{Proof.} (1) By construction of the spanning-tree cycle basis,
chord \(g_\ell\) belongs to \(\gamma_m\) if and only if \(\ell = m\).
Since \(p_T^*\) integrates \(c\) along the unique path in \(T\) from
\(v_0\), for every tree edge \(e = (u,\allowbreak v) \in T\) we have
\(c'_e = c_e = p_T^*(v) - p_T^*(u)\), and for every chord
\(g_m = (u_m,\allowbreak  v_m) \in E \setminus T\) we have
\(c'_{g_m} = p_T^*(v_m) - p_T^*(u_m)\). Thus \(c' = d_0 p_T^*\), so
\(\Phi_{1,\allowbreak w}(c') = 0\) and \(\Gamma_2(c') = 0\). For any
alternative potential \(p = p_T^* + \delta p\),
\(\|c - d_0 p\|_{1,\allowbreak w} = \sum_{e \in T} w_e |(d_0 \delta p)_e| + \sum_{m=1}^{b_1} w_{g_m} |r_m^* - (d_0 \delta p)_{g_m}|\).
Expanding
\((d_0 \delta p)_{g_m} = \sum_{e \in \gamma_m \cap T} \sigma_{m,\allowbreak e} (d_0 \delta p)_e\)
and applying the triangle inequality shows that whenever
\(w_e \ge \sum_{m : e \in \gamma_m} w_{g_m}\) for all \(e \in T\),
setting \(d_0 \delta p = 0\) on \(T\) (\(\delta p = \text{const}\))
achieves the global minimum \(\sum_{m=1}^{b_1} w_{g_m} |r_m^*|\). (2)
Under \(G_{\text{partial}}^{\text{C006}}\), the \(|V|-1\) tree-potential
slots \(\hat{p} = p_T^* + \Delta p \in \mathbb{Z}^{|V|-1}\) and the
\(b_1\) residual slots \(\hat{r} = r^* + \Delta r \in \mathbb{Z}^{b_1}\)
are arbitrary integers, and
\(\hat{c}'_{g_m} = c_{g_m} - \hat{r}_m = c_{g_m}^{\prime *} - \Delta r_m\)
is uniquely determined by \(\hat{r}_m\). Thus
\((\Delta p,\allowbreak  \Delta r) \mapsto z_1(\Delta p,\allowbreak  \Delta r)\)
is a bijection from \(\mathbb{Z}^{|V|-1+b_1} \setminus \{0\}\) onto
\(\mathcal{K}_{\text{false}}^{\text{C006}}(x)\). Around cycle
\(\gamma_m\), the repaired cochain \(c'(\Delta r)\) sums to
\((p_T^*(u_m) - p_T^*(v_m)) + c'_{g_m} = -c_{g_m}^{\prime *} + (c_{g_m}^{\prime *} - \Delta r_m) = -\Delta r_m\).
(3) Under \(G_{\text{complete}}^{\text{C006}}\), tree-edge integration
forces \(\hat{p}(v_j) = p_T^*(v_j)\) (\(\Delta p = 0\)) by induction
along \(T\) from \(p(v_0) = 0\); chord potential difference then forces
\(\hat{c}'_{g_m} = \hat{p}(v_m) - \hat{p}(u_m) = c_{g_m}^{\prime *}\);
and chord subtraction forces
\(\hat{r}_m = c_{g_m} - \hat{c}'_{g_m} = r_m^*\) (\(\Delta r = 0\)).
\(\square\)

\subsubsection{\texorpdfstring{5.6 Theorem 8: Two-stage tree-then-chord
\texttt{P*} factorization and slot-arity reduction on higher-Betti
graphs
(\(b_1 \in \{4,\allowbreak  \dots,\allowbreak  7\}\))}{5.6 Theorem 8: Two-stage tree-then-chord P* factorization and slot-arity reduction on higher-Betti graphs (b\_1 \textbackslash in \textbackslash\{4,\textbackslash allowbreak  \textbackslash dots,\textbackslash allowbreak  7\textbackslash\})}}\label{theorem-8-two-stage-tree-then-chord-p-factorization-and-slot-arity-reduction-on-higher-betti-graphs-b_1-in-4-dots-7}

On higher-Betti graphs (\(b_1 = |E \setminus T| \ge 4\), such as
\(K_{3,\allowbreak 3}\) with \(b_1 = 4\), \(Q_3\) with \(b_1 = 5\),
\(K_5\) and \(\text{Petersen}\) with \(b_1 = 6\), and \(W_7\) with
\(b_1 = 7\)), single-stage triangular basis materialization requires
emitting
\(A_{\text{1-stage}}(G) := (|V| - 1) + 2 b_1 \in \{13,\allowbreak  17,\allowbreak  16,\allowbreak  21,\allowbreak  21\}\)
signed integer slots in a single autoregressive turn while tracking
multi-hop spanning-tree paths and chord subtractions
\nolinkurl{simultaneously.}

Instead, we factorize the exact sequence
\begin{center}\PfpDisplayMath{0 \longrightarrow C^0_{\text{root}=0}(G; \mathbb{Z}) \xrightarrow[\cong]{\;d_0|_T\;} C^1(T; \mathbb{Z}) \longrightarrow 0, \qquad C^1(G; \mathbb{Z}) = C^1(T; \mathbb{Z}) \oplus C^1(E \setminus T; \mathbb{Z}),}\end{center}
into two sequential guarded \passthrough{\lstinline!P*!} Stage-1 cuts
before Stage 2: - \textbf{Stage 1a (Spanning-Tree Potential
Materialization, slot arity \(A_{1a} = |V| - 1\)):} Proposes
\(\hat{p}_T = (\hat{p}(v_1),\allowbreak  \dots,\allowbreak  \hat{p}(v_{|V|-1})) \in \mathbb{Z}^{|V|-1}\)
under \passthrough{\lstinline!gbnf\_slots = |V|-1!}, checked by the
deterministic \textbf{tree-integration guard}
\begin{center}\PfpDisplayMath{G_T(x, \hat{p}_T) = 1 \iff \bigwedge_{e=(u,v) \in T} \bigl(\hat{p}(v) - \hat{p}(u) = c_e\bigr), \qquad \hat{p}(v_0) := 0.}\end{center}
If \(G_T = 0\) after at most \(R_{1a} \ge 1\) attempts,
\(\pi_{\mathcal{I}}\) projects the pipeline to
\passthrough{\lstinline!NullTree!} (\(\mathbf{0}\)), saving both Stage
1b and all 3 Stage-2 turns. - \textbf{Stage 1b (Grafted Chord-Coboundary
Materialization, slot arity \(A_{1b} = b_1\)):} Conditioned on
\(G_T(x,\allowbreak  \hat{p}_T) = 1\) (so \(\hat{p}_T = p_T^*\) is
verified), the host grafts \(p_T^*\) as an immutable
\passthrough{\lstinline!LeafTextSpan!}
(\nolinkurl{PromptColour.SubstitutionStep}) into the Stage-1b prompt,
listing for each chord \(g_m = (u_m \to v_m) \in E \setminus T\) its
already-verified endpoint potentials \(p_T^*(v_m)\) and \(p_T^*(u_m)\),
and proposes
\(\hat{c}'_{E \setminus T} = (\hat{c}'_{g_1},\allowbreak  \dots,\allowbreak  \hat{c}'_{g_{b_1}}) \in \mathbb{Z}^{b_1}\)
under \passthrough{\lstinline!gbnf\_slots = b\_1!}, checked by the
\textbf{chord-coboundary guard}
\begin{center}\PfpDisplayMath{G_C\bigl(x, p_T^*, \hat{c}'_{E \setminus T}\bigr) = 1 \iff \bigwedge_{m=1}^{b_1} \Bigl(\hat{c}'_{g_m} = p_T^*(v_m) - p_T^*(u_m)\Bigr).}\end{center}

\textbf{Theorem 8 (Two-Stage Tree-Then-Chord
\passthrough{\lstinline!P*!} Slot-Arity Reduction \& Kernel Closure).}
For every connected graph \(G = (V,\allowbreak  E)\) with spanning tree
\(T\) (\(|T| = |V| - 1\)) and \(b_1 = |E \setminus T| \ge 1\) chords:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Per-Turn Slot-Arity Reduction:} The maximum integer-slot arity
  across Stage 1a and Stage 1b satisfies
  \begin{center}\PfpDisplayMath{A_{\text{2-stage}}(G) := \max\bigl(|V| - 1,\; b_1\bigr) \le (|V| - 1) + 2 b_1 - \min(|V| - 1, b_1) - b_1 < A_{\text{1-stage}}(G),}\end{center}
  yielding strict arity reductions of \(2 b_1\) slots in Stage 1a and
  \(|V| - 1 + b_1\) slots in Stage 1b (specifically
  \((13,\allowbreak  17,\allowbreak  16,\allowbreak  21,\allowbreak  21) \to (5,\allowbreak  7,\allowbreak  6,\allowbreak  9,\allowbreak  7)\)
  across
  \(K_{3,\allowbreak 3},\allowbreak  Q_3,\allowbreak  K_5,\allowbreak  \text{Petersen},\allowbreak  W_7\)).
\item
  \textbf{Depth-1 Chord Factorization Conditioned on \(G_T = 1\):} Once
  Stage 1a passes \(G_T(x,\allowbreak  \hat{p}_T) = 1\),
  \(\hat{p}_T = p_T^* = (d_0|_T)^{-1}(c|_T)\) is uniquely fixed in the
  Stage-1b prompt context. Consequently, each Stage-1b slot
  \(\hat{c}'_{g_m}\) depends only on a single depth-1 two-integer
  subtraction \(p_T^*(v_m) - p_T^*(u_m)\) of literals already present in
  the Stage-1b prompt, with zero multi-hop path accumulation and zero
  cross-chord coupling.
\item
  \textbf{Two-Stage False-Green Kernel Closure:} The joint two-stage
  guard satisfies
  \begin{center}\PfpDisplayMath{G_T(x, \hat{p}_T) = 1 \;\wedge\; G_C\bigl(x, \hat{p}_T, \hat{c}'_{E \setminus T}\bigr) = 1 \iff \bigl(\hat{p}_T, \hat{c}'_{E \setminus T}\bigr) = \bigl(p_T^*, d_0|_{E \setminus T} p_T^*\bigr),}\end{center}
  so the two-stage false-green kernel is empty
  (\(\mathcal{K}_{\text{false}}^{\text{2-stage}}(x) = \emptyset\)), and
  every pair admitted to Stage 2 defines an exact zero-defect coboundary
  \(c' = c|_T \oplus \hat{c}'_{E \setminus T} = d_0 p_T^*\) with
  \(\Phi_{1,\allowbreak w}(c') = 0\) and \(\Gamma_2(c') = 0\).
\end{enumerate}

\textbf{Proof.} (1) Since \(|V| - 1 \ge 1\) and \(b_1 \ge 1\), both
\(|V| - 1 \le (|V| - 1) + 2 b_1 - 2\) and
\(b_1 \le (|V| - 1) + 2 b_1 - 2\), so
\(\max(|V|-1,\allowbreak  b_1) < (|V|-1) + 2 b_1\). (2)--(3) Because
\(T\) is a spanning tree rooted at \(v_0\) with \(p(v_0) = 0\), the
restriction
\(d_0|_T: C^0_{\text{root}=0}(G; \mathbb{Z}) \to C^1(T; \mathbb{Z})\) is
a \(\mathbb{Z}\)-module isomorphism; hence
\(G_T(x,\allowbreak  \hat{p}_T) = 1 \iff d_0|_T \hat{p}_T = c|_T \iff \hat{p}_T = p_T^*\).
Conditioned on \(\hat{p}_T = p_T^*\),
\(G_C(x,\allowbreak  p_T^*,\allowbreak  \hat{c}'_{E \setminus T}) = 1\)
holds if and only if
\(\hat{c}'_{g_m} = p_T^*(v_m) - p_T^*(u_m) = (d_0 p_T^*)_{g_m}\) for
each \(m \in \{1,\allowbreak  \dots,\allowbreak  b_1\}\)
\nolinkurl{independently.} Combining \(c'|_T = c|_T = d_0|_T p_T^*\) and
\(c'|_{E \setminus T} = d_0|_{E \setminus T} p_T^*\) gives
\(c' = d_0 p_T^*\), so \(\Phi_{1,\allowbreak w}(c') = 0\) and
\(\Gamma_2(c') = 0\). \(\square\)

\subsubsection{\texorpdfstring{5.7 Theorem 9: Dichotomic
Fredholm-alternative \texttt{P*} guarding and elimination of the lazy
false-refusal attractor
(\texttt{C005})}{5.7 Theorem 9: Dichotomic Fredholm-alternative P* guarding and elimination of the lazy false-refusal attractor (C005)}}\label{theorem-9-dichotomic-fredholm-alternative-p-guarding-and-elimination-of-the-lazy-false-refusal-attractor-c005}

Consider the dichotomic relational consistency task
(\passthrough{\lstinline!C005!}): given a finite connected directed
graph \(G = (V,\allowbreak  E)\) with integer edge differences
\(d \in \mathbb{Z}^E\), a participant must decide whether the system
\(n_v - n_u = d_{(u,\allowbreak v)}\) (\((u,\allowbreak v) \in E\)) is
\passthrough{\lstinline!CONSISTENT!} (returning an exact vertex
potential \(n \in \mathbb{Z}^V\) with \(d_0 n = d\)) or
\passthrough{\lstinline!INCONSISTENT!} (returning a simple directed
cycle \(\gamma\) whose signed edge sum
\(\langle \gamma,\allowbreak  d \rangle = \sum_{e \in \gamma} \sigma_{\gamma,\allowbreak  e} d_e \ne 0\)).

In un-staged one-shot generation, small and medium language models
exhibit a systematic \textbf{lazy false-refusal
(\passthrough{\lstinline!INCONSISTENT!}) attractor}: whenever a model
makes a single sign or addition mistake while integrating potentials
along \(G\), it encounters a chord \(g_m = (u_m \to v_m)\) where its
erroneous potentials fail \(\hat{n}_{v_m} - \hat{n}_{u_m} = d_{g_m}\),
and therefore declares \passthrough{\lstinline!INCONSISTENT!} on
consistent boards (\passthrough{\lstinline!0/4 = 0.0\%!} accuracy on
consistent boards in both Panel 1 and un-staged Panel 2; see Subsection
6.6).

To eliminate this failure mode, fix a rooted spanning tree
\(T \subset E\) (\(|T| = |V| - 1\)) and \(b_1 = |E \setminus T|\) chords
\(g_1,\allowbreak  \dots,\allowbreak  g_{b_1}\), and require Stage 1 to
materialize the \((|V| - 1 + b_1)\)-slot tuple
\(z_1 = (\hat{p}_T,\allowbreak  \hat{r}_{E \setminus T}) \in \mathbb{Z}^{|V|-1} \times \mathbb{Z}^{b_1}\)
subject to the \textbf{Dichotomic Fredholm-Alternative Guard}:
\begin{center}\PfpDisplayMath{G_{\text{Fredholm}}\bigl(x, \hat{p}_T, \hat{r}_{E \setminus T}\bigr) = 1 \iff \bigwedge_{e=(u,v) \in T} \bigl(\hat{p}_T(v) - \hat{p}_T(u) = d_e\bigr) \;\wedge\; \bigwedge_{m=1}^{b_1} \Bigl(\hat{r}_m = d_{g_m} - \bigl(\hat{p}_T(v_m) - \hat{p}_T(u_m)\bigr)\Bigr).}\end{center}

\textbf{Theorem 9 (Dichotomic Fredholm-Alternative
\passthrough{\lstinline!P*!} Guard \& False-Verdict
\nolinkurl{Elimination).}} For every connected directed graph
\(G = (V,\allowbreak  E)\) with spanning tree \(T\), chords
\(g_1,\allowbreak  \dots,\allowbreak  g_{b_1} \in E \setminus T\), and
edge differences \(d \in \mathbb{Z}^E\):

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Discrete Fredholm Alternative on
  \((T,\allowbreak  E \setminus T)\):} Let
  \(p_T^* = (d_0|_T)^{-1}(d|_T) \in \mathbb{Z}^V\) (\(p_T^*(v_0) = 0\))
  and let
  \(r_m^* := \langle \gamma_m,\allowbreak  d \rangle = d_{g_m} - (p_T^*(v_m) - p_T^*(u_m))\)
  be the holonomy of the \(m\)-th chord-induced cycle \(\gamma_m\).
  Then:
  \begin{center}\PfpDisplayMath{d \in \operatorname{im}(d_0) \iff r_1^* = \dots = r_{b_1}^* = 0 \iff d = d_0 p_T^*,}\end{center}
  and conversely \(d \notin \operatorname{im}(d_0)\) if and only if
  there exists \(m^* \in \{1,\allowbreak  \dots,\allowbreak  b_1\}\)
  with \(r_{m^*}^* \ne 0\), in which case \(\gamma_{m^*}\) is an
  explicit simple-cycle contradiction witness with
  \(\langle \gamma_{m^*},\allowbreak  d \rangle = r_{m^*}^* \ne 0\).
\item
  \textbf{Elimination of the Lazy False-Refusal Attractor
  (\(\mathcal{K}_{\text{false-verdict}}^{\text{C005}}(x) = \emptyset\)):}
  For every proposal
  \(z_1 = (\hat{p}_T,\allowbreak  \hat{r}_{E \setminus T}) \in \mathbb{Z}^{|V|-1+b_1}\),
  \begin{center}\PfpDisplayMath{G_{\text{Fredholm}}\bigl(x, \hat{p}_T, \hat{r}_{E \setminus T}\bigr) = 1 \iff \bigl(\hat{p}_T, \hat{r}_{E \setminus T}\bigr) = \bigl(p_T^*, r_{E \setminus T}^*\bigr).}\end{center}
  Consequently, under the deterministic Stage-2 branch map
  \begin{center}\PfpDisplayMath{\mathcal{B}\bigl(\hat{p}_T, \hat{r}_{E \setminus T}\bigr) := \begin{cases} (\mathsf{CONSISTENT},\; \hat{p}_T) & \text{if } \hat{r}_{E \setminus T} = 0, \\ (\mathsf{INCONSISTENT},\; \gamma_{m^*},\, \hat{r}_{m^*}) & \text{if } m^* = \min\{m : \hat{r}_m \ne 0\}, \end{cases}}\end{center}
  no Stage-1 proposal admitted by \(G_{\text{Fredholm}} = 1\) can emit a
  false \passthrough{\lstinline!INCONSISTENT!} verdict on a consistent
  board or a false \passthrough{\lstinline!CONSISTENT!} verdict on an
  inconsistent board: the admitted false-verdict set is empty
  (\(\mathcal{K}_{\text{false-verdict}}^{\text{C005}}(x) = \emptyset\)).
\end{enumerate}

\textbf{Proof.} (1) Because
\(\{\gamma_1,\allowbreak  \dots,\allowbreak  \gamma_{b_1}\}\) is a
\(\mathbb{Z}\)-basis for \(H_1(G; \mathbb{Z}) = \ker(\partial_1)\),
\(d \in \operatorname{im}(d_0) = \ker(d_1)\) holds if and only if
\(\langle \gamma_m,\allowbreak  d \rangle = 0\) for every
\(m = 1,\allowbreak  \dots,\allowbreak  b_1\). Along
\(\gamma_m = g_m - \pi_T(u_m \to v_m)\), telescoping
\(d|_T = d_0|_T p_T^*\) along the unique tree path
\(\pi_T(u_m \to v_m)\) gives
\(\sum_{e \in \pi_T(u_m \to v_m)} \sigma_{e} d_e = p_T^*(v_m) - p_T^*(u_m)\),
so
\(\langle \gamma_m,\allowbreak  d \rangle = d_{g_m} - (p_T^*(v_m) - p_T^*(u_m)) = r_m^*\).
Thus \(r_{E \setminus T}^* = 0 \iff d = d_0 p_T^*\), and if
\(r_{m^*}^* \ne 0\) then \(\gamma_{m^*}\) is a simple cycle in
\(T \cup \{g_{m^*}\}\) with non-zero signed sum \(r_{m^*}^*\). (2) Under
\(G_{\text{Fredholm}} = 1\), the first conjunction forces
\(\hat{p}_T = p_T^*\) by tree-path induction from \(v_0\), and
substituting \(\hat{p}_T = p_T^*\) into the second conjunction forces
\(\hat{r}_m = d_{g_m} - (p_T^*(v_m) - p_T^*(u_m)) = r_m^*\) for every
\(m = 1,\allowbreak  \dots,\allowbreak  b_1\). Hence
\(\hat{r}_{E \setminus T} = 0 \iff r_{E \setminus T}^* = 0 \iff d \in \operatorname{im}(d_0)\),
so \(\mathcal{B}(\hat{p}_T,\allowbreak  \hat{r}_{E \setminus T})\)
agrees with the exact cohomological truth on every admitted instance.
\(\square\)

\subsubsection{\texorpdfstring{5.8 Theorem 10: Cohomological syndrome
decoding \(\mathbf{r}^* = S\mathbf{c}\) across Verdict, Single-Edge
Repair, and Audit
(\texttt{C001})}{5.8 Theorem 10: Cohomological syndrome decoding \textbackslash mathbf\{r\}\^{}* = S\textbackslash mathbf\{c\} across Verdict, Single-Edge Repair, and Audit (C001)}}\label{theorem-10-cohomological-syndrome-decoding-mathbfr-smathbfc-across-verdict-single-edge-repair-and-audit-c001}

Consider the distractor-contaminated rank-difference witness game
(\passthrough{\lstinline!C001!}): a natural-language prompt contains
bracketed distractor notes (\passthrough{\lstinline![Note k: ...]!},
which belong to the congruence ideal
\(\mathcal{I}_{\text{distractor}}\)) mixed with directed integer
rank-difference claims \(c_{u,\allowbreak v} \in \mathbb{Z}\)
(\passthrough{\lstinline!B - A = c\_\{A,B\}!},
\(|V| \in \{8,\allowbreak  \dots,\allowbreak  11\},\allowbreak  |E| \in \{12,\allowbreak  \dots,\allowbreak  16\},\allowbreak  b_1 \in \{5,\allowbreak  7\},\allowbreak  c_{u,\allowbreak v} \in [-5000,\allowbreak  5000]\))
and one of three task obligations: - \passthrough{\lstinline!verdict!}:
emit \passthrough{\lstinline!CONSISTENT!} with an exact potential
\(p: V \to \mathbb{Z}\), or \nolinkurl{CONTRADICTION} with an explicit
simple cycle whose signed edge sum is non-zero; -
\passthrough{\lstinline!repair!}: identify a single corrupted edge
\(e^* \in E\), its replacement value \(c'_{e^*} \in \mathbb{Z}\), and
the resulting exact potential \(p': V \to \mathbb{Z}\) on
\((E \setminus \{e^*\}) \cup \{(e^*,\allowbreak  c'_{e^*})\}\); -
\passthrough{\lstinline!audit!}: inspect a proposed submission (which
may contain adversarial off-by-one cycle claims, flipped edge
orientations, or deceptive \nolinkurl{CONTRADICTION} claims on
consistent graphs) and emit \passthrough{\lstinline!ACCEPT!} or
\passthrough{\lstinline!REJECT!} with a verified correction witness.

Fix a rooted spanning tree \(T \subset E\) (\(|T| = |V| - 1\)) and chord
set \(E \setminus T = \{e_1,\allowbreak  \dots,\allowbreak  e_{b_1}\}\)
(\(e_m = u_m \to v_m\)). For each chord \(e_m \in E \setminus T\) and
each tree edge \(e \in T\), define the signed tree-path incidence
\begin{center}\PfpDisplayMath{S_{m, e} := \begin{cases} +1 & \text{if } e \text{ is traversed forward along the unique path } \pi_T(u_m \to v_m), \\ -1 & \text{if } e \text{ is traversed backward along } \pi_T(u_m \to v_m), \\ 0 & \text{if } e \notin \pi_T(u_m \to v_m), \end{cases}}\end{center}
and form the \textbf{chord-induced cycle-edge incidence matrix}
\begin{center}\PfpDisplayMath{S := \bigl[\,S_T \;\big|\; -I_{b_1}\,\bigr] \in \{-1, 0, +1\}^{b_1 \times |E|},}\end{center}
whose \(m\)-th row \(S_{m,\allowbreak  \cdot}\) is the signed indicator
of the chord-induced simple cycle
\(\mathcal{C}_T(e_m) = \pi_T(u_m \to v_m) \cup \{v_m \to u_m\}\).

\textbf{Theorem 10 (Cohomological Syndrome Decoding Across Verdict,
Single-Edge Repair, and Audit).} Suppose Stage 1a materializes
\(\hat{p}_T \in \mathbb{Z}^{|V|-1}\) passing
\(G_T(\mathbf{c},\allowbreak  \hat{p}_T) = 1\) (so
\(\hat{p}_T = p_T^* = B_T^{-1} \mathbf{c}|_T\)), and Stage 1b
materializes \(\hat{\mathbf{c}}_{E \setminus T} \in \mathbb{Z}^{b_1}\)
passing \(G_C(p_T^*,\allowbreak  \hat{\mathbf{c}}_{E \setminus T}) = 1\)
(so \(\hat{c}_m = \hat{c}_m^* := p_T^*(v_m) - p_T^*(u_m)\) for
\(m = 1,\allowbreak  \dots,\allowbreak  b_1\)). Define the
\textbf{cohomological syndrome vector}
\begin{center}\PfpDisplayMath{\mathbf{r}^* := \hat{\mathbf{c}}^* - \mathbf{c}|_{E \setminus T} \in \mathbb{Z}^{b_1}.}\end{center}
Then:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Exact Cycle-Space Parity Check:}
  \(\mathbf{r}^* = S\mathbf{c}\) identically, and
  \(\ker(S) = \operatorname{im}(d_0) = \{\mathbf{c} \in \mathbb{Z}^E : \Phi_1(\mathbf{c}) = 0\}\).
  Consequently, for \passthrough{\lstinline!verdict!} tasks,
  \(\mathbf{r}^* = \mathbf{0} \iff \Phi_1(\mathbf{c}) = 0\)
  (\passthrough{\lstinline!CONSISTENT!} with exact potential \(p_T^*\)),
  and \(\mathbf{r}^* \ne \mathbf{0} \iff \Phi_1(\mathbf{c}) > 0\)
  (\nolinkurl{CONTRADICTION}, where any \(m^*\) with \(r_{m^*}^* \ne 0\)
  yields the certified simple cycle \(\mathcal{C}_T(e_{m^*})\) with
  signed discrepancy \(r_{m^*}^* \ne 0\)).
\item
  \textbf{Single-Edge Syndrome Decoding (Chord \& Spanning-Tree
  Perturbations):} Let
  \(\mathbf{c} = \mathbf{c}^{\text{true}} + \delta \mathbf{e}_{e^*}\) be
  obtained from a consistent cochain
  \(\mathbf{c}^{\text{true}} = d_0 p^{\text{true}} \in \operatorname{im}(d_0)\)
  by corrupting a single edge \(e^* \in E\) by
  \(\delta = c_{e^*} - c^{\text{true}}_{e^*} \ne 0\). Then a candidate
  single-edge replacement \((e,\allowbreak  c'_e)\) with shift
  \(\hat{\delta} := c_e - c'_e \in \mathbb{Z} \setminus \{0\}\) yields a
  globally consistent repaired cochain
  \(\mathbf{c}' = \mathbf{c} - \hat{\delta}\mathbf{e}_e \in \operatorname{im}(d_0)\)
  if and only if the syndrome \(\mathbf{r}^*\) is the
  \(\hat{\delta}\)-scaled \(e\)-th column of \(S\):
  \begin{center}\PfpDisplayMath{\mathbf{r}^* = \hat{\delta}\,S_{\cdot, e}.}\end{center}
  In particular:

  \begin{itemize}
  \tightlist
  \item
    \textbf{Case 2a (Chord Perturbation,
    \(e^* = e_m \in E \setminus T\)):} Since
    \(S_{\cdot,\allowbreak  e_m} = -\mathbf{e}_m \in \mathbb{Z}^{b_1}\),
    a chord corruption has unit Hamming support
    \(\operatorname{supp}(\mathbf{r}^*) = \{m\}\) with
    \(r_m^* = -\delta\), and is repaired by
    \(c'_{e_m} = c_{e_m} + r_m^* = \hat{c}_m^*\) with unchanged
    potential \(p' = p_T^*\).
  \item
    \textbf{Case 2b (Spanning-Tree Perturbation, \(e^* \in T\)):} A
    tree-edge corruption propagates across the tree-cut incidence set
    \(\operatorname{supp}(\mathbf{r}^*) = \{m \in \{1,\allowbreak  \dots,\allowbreak  b_1\} : e^* \in \pi_T(u_m \to v_m)\}\)
    with \(r_m^* = \delta S_{m,\allowbreak  e^*} \in \{\pm \delta\}\),
    and is decoded by matching
    \(\mathbf{r}^* = \hat{\delta} S_{\cdot,\allowbreak  e^*}\)
    (\(c'_{e^*} = c_{e^*} - \hat{\delta}\)) and shifting the subtree
    potential
    \(p' = B_T^{-1}(\mathbf{c}|_T - \hat{\delta}\mathbf{e}_{e^*})\).
  \end{itemize}
\item
  \textbf{Adversarial Audit Completeness:} For any
  \passthrough{\lstinline!audit!} submission proposing a potential,
  contradiction cycle, or single-edge repair, re-evaluating the proposal
  against \((p_T^*,\allowbreak  \mathbf{r}^* = S\mathbf{c})\) rejects
  all off-by-one cycle claims, flipped-sign edge traversals, and
  deceptive \nolinkurl{CONTRADICTION} claims on
  \(\mathbf{r}^* = \mathbf{0}\) graphs.
\end{enumerate}

\textbf{Proof.} (1) Along each chord \(e_m = (u_m \to v_m)\),
telescoping \(d_0 p_T^* = \mathbf{c}|_T\) along \(\pi_T(u_m \to v_m)\)
gives
\(\hat{c}_m^* = p_T^*(v_m) - p_T^*(u_m) = \sum_{e \in T} S_{m,\allowbreak e} c_e = (S_T \mathbf{c}|_T)_m\).
Subtracting \(c_{e_m}\) gives
\(r_m^* = (S_T \mathbf{c}|_T)_m - c_{e_m} = (S\mathbf{c})_m\). Since the
rows of \(S\) form a basis of the cycle space \(Z_1(G; \mathbb{Z})\),
\(S\mathbf{c} = \mathbf{0} \iff \mathbf{c} \in \operatorname{im}(d_0)\).
(2) By linearity of \(S\), for
\(\mathbf{c}' = \mathbf{c} - \hat{\delta}\mathbf{e}_e\), we have
\(S\mathbf{c}' = S\mathbf{c} - \hat{\delta} S_{\cdot,\allowbreak  e} = \mathbf{r}^* - \hat{\delta} S_{\cdot,\allowbreak  e}\).
Thus
\(\mathbf{c}' \in \operatorname{im}(d_0) = \ker(S) \iff \mathbf{r}^* = \hat{\delta} S_{\cdot,\allowbreak  e}\).
When \(e = e_m \in E \setminus T\), column
\(S_{\cdot,\allowbreak  e_m} = -\mathbf{e}_m\), so
\(\mathbf{r}^* = -\hat{\delta}\mathbf{e}_m\) and
\(c'_{e_m} = c_{e_m} - \hat{\delta} = c_{e_m} + r_m^* = \hat{c}_m^*\).
When \(e \in T\), column \(S_{\cdot,\allowbreak  e}\) has non-zero
entries \(\pm 1\) on every chord cycle whose tree path traverses \(e\).
(3) follows immediately from (1) and (2). \(\square\)

\subsubsection{\texorpdfstring{5.9 Theorem 11: Tree-coboundary defect
migration vs.~path-integrated \(B_T^{-1}\) guard
diagnostics}{5.9 Theorem 11: Tree-coboundary defect migration vs.~path-integrated B\_T\^{}\{-1\} guard diagnostics}}\label{theorem-11-tree-coboundary-defect-migration-vs.-path-integrated-b_t-1-guard-diagnostics}

Why does Stage 1a require a \textbf{path-integrated} diagnostic guard
rather than an \textbf{edge-local} coboundary diagnostic on multi-hop
spanning trees with 4-digit claims? Order the non-root vertices
\(V \setminus \{v_0\} = \{v_1,\allowbreak  \dots,\allowbreak  v_{|V|-1}\}\)
in BFS topological order along the rooted spanning tree \(T\), and let
\(B_T := d_0|_T \in \{-1,\allowbreak  0,\allowbreak  +1\}^{(|V|-1) \times (|V|-1)}\)
be the rooted tree coboundary matrix. Its inverse
\(B_T^{-1} \in \{0,\allowbreak  +1\}^{(|V|-1) \times (|V|-1)}\) is the
lower-triangular \textbf{root-to-vertex path-incidence matrix}:
\begin{center}\PfpDisplayMath{(B_T^{-1})_{w, e} = \mathbb{1}\bigl[e \in \pi_T(v_0 \to w)\bigr], \qquad p_T^*(w) = \bigl(B_T^{-1} \mathbf{c}|_T\bigr)_w = \sum_{e \in \pi_T(v_0 \to w)} c_e.}\end{center}

For any Attempt-1 proposal \(\hat{p}_T^{(1)} \in \mathbb{Z}^{|V|-1}\),
define its \textbf{edge-local coboundary residual}
\(\mathbf{e}_T^{(1)} \in \mathbb{Z}^{|V|-1}\) and its
\textbf{path-integrated potential residual}
\(\boldsymbol{\delta}_T^{(1)} \in \mathbb{Z}^{|V|-1}\) by
\begin{center}\PfpDisplayMath{\mathbf{e}_T^{(1)} := B_T \hat{p}_T^{(1)} - \mathbf{c}|_T, \qquad \boldsymbol{\delta}_T^{(1)} := \hat{p}_T^{(1)} - B_T^{-1} \mathbf{c}|_T = B_T^{-1} \mathbf{e}_T^{(1)}.}\end{center}

\textbf{Theorem 11 (Tree-Coboundary Defect Migration Under Edge-Local
Retry vs.~One-Step Convergence Under Path-Integrated \(B_T^{-1}\)
\nolinkurl{Diagnostics).}} Suppose Attempt 1 commits a single arithmetic
integration error \(\Delta_{v^*} \ne 0\) at an internal tree edge
\(e^* = (\operatorname{parent}(v^*) \to v^*) \in T\) while integrating
all remaining tree edges accurately:
\((\mathbf{e}_T^{(1)})_{e^*} = \Delta_{v^*} \ne 0\) and
\((\mathbf{e}_T^{(1)})_e = 0\) for all \(e \in T \setminus \{e^*\}\).
Let
\(\operatorname{Subtree}_T(v^*) := \{w \in V \setminus \{v_0\} : e^* \in \pi_T(v_0 \to w)\}\)
be the descendant subtree rooted at \(v^*\), and suppose
\(|\operatorname{Subtree}_T(v^*)| \ge 2\) (so \(v^*\) has at least one
child in \(T\)). Then:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Subtree Shift vs.~Single-Edge Local Syndrome:} Although the
  potential error
  \(\delta_T^{(1)}(w) = (B_T^{-1} \mathbf{e}_T^{(1)})_w = \Delta_{v^*} \ne 0\)
  is non-zero at \textbf{every} descendant
  \(w \in \operatorname{Subtree}_T(v^*)\), the edge-local coboundary
  residual \(\mathbf{e}_T^{(1)}\) is non-zero \textbf{only} at \(e^*\):
  for every strict descendant edge \(e = (u \to w)\) inside
  \(\operatorname{Subtree}_T(v^*)\), both endpoints are shifted by
  \(+\Delta_{v^*}\), so the local difference cancels:
  \begin{center}\PfpDisplayMath{\hat{p}_T^{(1)}(w) - \hat{p}_T^{(1)}(u) = \bigl(p_T^*(w) + \Delta_{v^*}\bigr) - \bigl(p_T^*(u) + \Delta_{v^*}\bigr) = c_e \implies (\mathbf{e}_T^{(1)})_e = 0.}\end{center}
\item
  \textbf{Coboundary Defect Migration Under Coordinate-Local Retry:} If
  a retry diagnostic reports only the coordinates where
  \(\mathbf{e}_T^{(1)} \ne 0\) (namely slot \(v^*\)) and the model
  updates only the flagged slot \(\hat{p}_T^{(2)}(v^*) = p_T^*(v^*)\)
  while retaining its unflagged slots
  \(\hat{p}_T^{(2)}(w) = \hat{p}_T^{(1)}(w) = p_T^*(w) + \Delta_{v^*}\)
  for \(w \in \operatorname{Subtree}_T(v^*) \setminus \{v^*\}\), then
  Retry 1 \textbf{fails} \(G_T\): the coboundary defect migrates from
  \(e^*\) to every child edge \(e_{\text{child}} = (v^* \to w)\) of
  \(v^*\):
  \begin{center}\PfpDisplayMath{(\mathbf{e}_T^{(2)})_{e^*} = 0, \qquad (\mathbf{e}_T^{(2)})_{(v^* \to w)} = \bigl(p_T^*(w) + \Delta_{v^*}\bigr) - p_T^*(v^*) - c_{(v^* \to w)} = \Delta_{v^*} \ne 0.}\end{center}
  More generally, coordinate-local repair of \(\mathbf{e}_T \ne 0\)
  requires at least
  \(\operatorname{depth}(\operatorname{Subtree}_T(v^*)) + 1\) sequential
  rounds to push the coboundary defect off the leaves of \(T\).
\item
  \textbf{One-Retry Convergence Under Path-Integrated \(B_T^{-1}\)
  Diagnostics:} Because
  \(\operatorname{supp}(\boldsymbol{\delta}_T^{(1)}) = \operatorname{Subtree}_T(v^*)\),
  the path-integrated guard diagnostic
  \(\hat{p}_T^{(1)}(w) \ne (B_T^{-1}\mathbf{c}|_T)_w\) flags \(v^*\) and
  all of its affected descendants
  \(w \in \operatorname{Subtree}_T(v^*)\) simultaneously in a single
  diagnostic turn, eliminating subtree defect migration.
\end{enumerate}

\textbf{Proof.} (1) Since
\(\mathbf{e}_T^{(1)} = \Delta_{v^*} \mathbf{e}_{e^*}\), multiplying by
\(B_T^{-1}\) gives
\(\delta_T^{(1)}(w) = (B_T^{-1})_{w,\allowbreak  e^*} \Delta_{v^*} = \Delta_{v^*} \mathbb{1}[w \in \operatorname{Subtree}_T(v^*)]\).
Applying \(B_T\) recovers
\(\mathbf{e}_T^{(1)} = B_T \boldsymbol{\delta}_T^{(1)} = \Delta_{v^*} \mathbf{e}_{e^*}\),
which vanishes on every edge \(e \ne e^*\). (2) Updating only coordinate
\(v^*\) sets \(\delta_T^{(2)}(v^*) = 0\) while leaving
\(\delta_T^{(2)}(w) = \Delta_{v^*}\) for
\(w \in \operatorname{Subtree}_T(v^*) \setminus \{v^*\}\). Applying
\(B_T\) to \(\boldsymbol{\delta}_T^{(2)}\) gives
\((\mathbf{e}_T^{(2)})_{(u \to w)} = \delta_T^{(2)}(w) - \delta_T^{(2)}(u)\),
which equals \(\Delta_{v^*} - 0 = \Delta_{v^*} \ne 0\) for every child
edge \((v^* \to w)\) with \(w \in \operatorname{Subtree}_T(v^*)\). By
induction on subtree depth, each coordinate-local retry advances the
zero-error wavefront by one tree level, requiring
\(\operatorname{depth}(\operatorname{Subtree}_T(v^*)) + 1\) rounds. (3)
Directly from
\(\operatorname{supp}(\boldsymbol{\delta}_T^{(1)}) = \{w : \hat{p}_T^{(1)}(w) \ne p_T^*(w)\} = \operatorname{Subtree}_T(v^*)\).
\(\square\)

\subsubsection{\texorpdfstring{6.1 Why single-turn zero-scratchpad
operad prompts fail and \texttt{P*} cuts
help}{6.1 Why single-turn zero-scratchpad operad prompts fail and P* cuts help}}\label{why-single-turn-zero-scratchpad-operad-prompts-fail-and-p-cuts-help}

Consider an autoregressive transformer \(P_\theta\) tasked with emitting
the \(k\)-slot repaired cochain
\(y = (c'_0,\allowbreak  \dots,\allowbreak  c'_{k-1}) \in \mathcal{L}_k\)
for a directed \(k\)-cycle \(x = (c,\allowbreak  w)\). Under Theorem 2,
computing \(y\) requires latent intermediate invariants
\(z = (s,\allowbreak  i^*,\allowbreak  c_{i^*},\allowbreak  c'_{i^*})\)
where \(s = \sum_i c_i\), \(i^* = \arg\min_i w_i\),
\(c_{i^*} = c[i^*]\), and \(c'_{i^*} = c_{i^*} - s\).

\begin{itemize}
\tightlist
\item
  \textbf{Single-Turn Zero-Scratchpad Regime
  (\nolinkurl{operad_grafted_grammar_projection}):} When the entire
  operad tree is rendered in a single turn under Layer-2 grammar mask
  \(\mathcal{L}_k\) (\passthrough{\lstinline!gbnf\_slots=k!}), the first
  output token \(y_0 = c'_0\) must be emitted before any token of \(z\)
  has been written to the causal context:
  \begin{center}\PfpDisplayMath{P_{\text{1-turn}}(y \mid x) = P_\theta(y_0 \mid x)\prod_{t=1}^{k-1} P_\theta(y_t \mid x, y_{<t}).}\end{center}
  Whenever \(i^* = 0\), \(y_0 = c_0 - s\) already depends on the global
  cycle sum \(s\) and minimum-weight index \(i^*\), forcing the model to
  compute both inside a single forward pass while decoding an ASCII
  operad tree container.
\item
  \textbf{Multi-Turn \passthrough{\lstinline!P*!} Staged Operad
  Materialization (\nolinkurl{p_star_operad_slot_materialization}):}
  Cutting the operad tree at an intermediate
  \nolinkurl{SubstitutionStep} operator \(f_1\) (Stage 1, grammar
  \(\mathcal{L}_m\)) and grafting the materialized output \(z\) as an
  immutable \passthrough{\lstinline!LeafTextSpan!} into Stage 2
  (\(f_2 \circ_i z\), grammar \(\mathcal{L}_k\)) factorizes the
  conditional generation law in topological dependency order:
  \begin{center}\PfpDisplayMath{P_{\text{P*}}(z, y \mid x) = P_\theta(z_0 \mid x)\prod_{j=1}^{m-1} P_\theta(z_j \mid x, z_{<j}) \cdot \mathbb{1}[z \notin \mathcal{I}] \cdot \prod_{t=0}^{k-1} P_\theta(y_t \mid x, f_2 \circ_i z, y_{<t}).}\end{center}
  Each intermediate slot \(z_j\) is conditioned via causal
  self-attention on the already-emitted prefix \(z_{<j}\), and Stage 2
  reduces to substituting the grafted value \(c'_{i^*}\) at index
  \(i^*\) while copying \(c_t\) for \(t \ne i^*\).
\end{itemize}

\subsection{Research extension: evolving the proposal
harness}\label{research-extension-evolving-the-proposal-harness}

Prompt, workflow, search-policy and context-policy rewrites are
additional proposal-channel \nolinkurl{interventions.} The host's task
and checking obligations remain fixed. A strategy label, root-cause
explanation or compressed context can change the distribution of
submitted candidates without changing what a valid certificate must
satisfy. This is the operational use of channel-independent checking; it
does not establish a theorem about empirical improvement.

The new campaign uses named Anthropic deployments with frozen role
\nolinkurl{configurations.} Its interface supplies adaptive-thinking and
output limits; it does not expose provider seeds, arbitrary logit
interventions or attention weights. Local seeds reproduce scheduling
choices only. Every paid attempt, including an unusable response, is
bound to the original budget and retained raw evidence. Changed
candidate code is executed only within the declared isolated surface.

The historical mechanism trials and finite proofs above retain their own
source and evidence identities. They are not training data or measured
outcomes for the new held-out panel. Paper 029 supplies the separate
protocol, ablations and exploratory ignition design. Those new model
effects remain NOT\_MEASURED pending the verified remote host.

The source and page references for this extension are collected in
\href{../029/paper.pdf}{Paper 029} and its
\href{../029/docs/source_to_claim_map.md}{source-to-claim map}. The
author-review rendering does not replace a historical deposit or
archive.

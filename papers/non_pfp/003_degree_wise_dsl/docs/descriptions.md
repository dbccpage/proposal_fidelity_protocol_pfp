# Scientific Description: Degree-Wise Obstruction Calculus and Symbolic DSL

This deposit contains the complete research package for Degree-Wise Obstruction Calculus and Symbolic DSL (CODA-FOC-006), authored by Jeremy H. Carroll.

The monograph develops a degree-wise calculus of discrete cochain complexes and an embedded domain-specific language (DSL) for obstruction tracking, monotonic descent, and diagnostic certification. In multi-agent consensus and topological physics, confusion between distinct degrees of differential forms leads to false convergence claims. This work establishes the Degree Separation Theorem: degree-1 ($C^1$) edge data does not determine degree-2 ($C^2$) closure defects ($\Gamma_2$) without explicit cellular attachment.

All mathematical claims are verified via exact rational arithmetic implementations in Python and machine-checked formalizations in Lean 4. The companion notebook provides interactive walkthroughs of the $C_3$ worked example and guarded descent evaluation.

# Restatement: `merge_tables`

AuthorityEffect: None.

Class of the challenge: externally imposed challenge. It is answered in this
harness, outside the sealed repository, and it is not attributed to the seed.

## Obligation

A merge operation over a declared finite set of replica states is given as
a full table: one result for every ordered pair, always a declared state.
It must be idempotent on every state, associative on every triple and
commutative on every pair, decided by exhaustion over the declared states,
never from a declared law name.

## Refused case

A merge that is not idempotent: merging a state with itself changes it.

## Supplied objects and terms

| name | class | what it is |
| --- | --- | --- |
| state, merge | supplied object-language datum | the states and the table |
| spare | supplied object-language datum | one element that is not a state |
| table_total, one_result, closed, idempotent, commutative, associative | derived definition | relational requirements over the claim |

## Notes

Claim-only: no witness form is declared, so the class of responses is the
empty response alone. Nothing is decided over values: every law is a
closure of the table, carried by derivability, and each is bitten by a
fixture. The positive keeps the later of three versions.

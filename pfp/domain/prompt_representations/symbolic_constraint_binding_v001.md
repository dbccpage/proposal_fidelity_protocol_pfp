# Symbolic constraint binding v001

Pattern ID: `PFP-SYMBOLIC-CONSTRAINT-BINDING-001`. Version: `v001`.
Role: optional input rewrite, rendered by the existing
[`SymbolicPromptRepresentation`](symbolic_prompt_representation.py). The ordinary
PFP task/attempt/input-digest envelope and its typed output remain the owner of
model communication. This pattern does not add an envelope or grant authority.
AuthorityEffect: None. Status: candidate with host controls, no model efficacy claim.

The source example is the user-supplied *HoTT Rust Chemistry Prompt Generation*
PDF, 36 pages, SHA-256
`0fd4111237ae1df3d4f7f38feb652fcddca0eba9d9b6d9e7d71966b9c6bd852d`.
Pages 18–19 show the useful failure: revised constraints `s7` and `s8` were added
to the codebook but omitted from the active constraint wire. Its broad claims
about deriving physics, forcing rigor and chemical meaning are unproved here.
The PDF is not copied into the repository or sent to a provider.

Use a declared carrier, an inline codebook, active bindings for every constraint,
and the existing closed proposal/refusal output contract. Compile every wire
pair from the complete ordered role/slot list; never hand-maintain a second
constraint list. The existing validator rejects missing or extra slots, duplicate
or out-of-order references, a missing task, and invalid boundary wire. A valid
packet can still contain a wrong premise or a coherently altered question.

For the Meron trial, the protected query is the exact ordered sequence of
`(slot, role, UTF-8 text)` for the seed, declared finite case, two protected
quantities, source/checker custody, native status limits and output contract.
An input rewrite must preserve this sequence at the consumer. The independent
finite checker separately recomputes the partition and observable numerator;
this text comparison does not establish a physical cochain bridge.

The compiler emits:

```text
<<p><v1><<q><s0>><<c><s1>><<c><s2>><<c><s3>><<c><s4>><<c><s5>><<c><s6>><<o><s7>>>
```

Put exact instruction strings in the inline JSON `bindings`; symbolic wire alone
does not carry their meaning. Preserve task text bytes and active role assignments
before and after the rewrite. Adding a glyph path is a separate versioned variant,
with its own controls; it is not evidence that a model entered a compiler state.

The targeted [host controls](../../tests/test_symbolic_constraint_binding.py)
use the public representation owner. They admit a complete benign packet,
roundtrip quotes/Unicode/newlines, reject the observed omitted-slot defect and
malformed bindings, and show that a coherently rebound harmful premise remains
schema-valid but fails the declared protected-query comparison. These are host
controls, not fresh chemistry or model trials. A future matched trial must retain
raw replies, independent task acceptance, actual input/output counts and costs
before claiming improved single-shot quality or reduced token use.

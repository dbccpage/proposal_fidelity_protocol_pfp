## 1. Overview

The **C022 (Stabilizer Code Distance with Lower-Bound Certificates)** challenge evaluates whether an algorithmic solver or AI model can synthesize an exact, certificate-generating minimum code distance solver for quantum stabilizer codes on up to $n \le 20$ qubits over the binary symplectic field $\mathbb{F}_2^{2n}$.

Given an abelian stabilizer group $\mathcal{S} \le \mathcal{P}_n$ on $n$ qubits generated by $m = n - k$ independent commuting Pauli words $g_1, \dots, g_m$ with signs ($1 \le k \le n - 1$, $-I \notin \mathcal{S}$), the normalizer $\mathcal{N}(\mathcal{S}) = \mathcal{C}(\mathcal{S})$ is the set of all Pauli operators commuting with every stabilizer generator. The minimum code distance $d$ is:

$$d = \min \{ \operatorname{wt}(P) : P \in \mathcal{N}(\mathcal{S}) \setminus \mathcal{S} \}$$

### Dual-Bound Certification Requirement
A valid solution must provide both:
1. **Upper Bound Certificate:** An explicit logical operator $P_L \in \mathcal{N}(\mathcal{S}) \setminus \mathcal{S}$ of weight exactly $\operatorname{wt}(P_L) = d$.
2. **Lower Bound Certificate:** A checkable proof demonstrating that no non-trivial logical operator exists with weight $1 \le \operatorname{wt}(P) \le d - 1$. The solver produces an exact LRAT refutation proof for the canonical CNF encoding of the weight-bounded normalizer search.

### Outcome States
- `SOLVED`: Returns exact distance $d$, logical Pauli word $P_L$, and LRAT lower-bound proof object.
- `OUT_OF_SCOPE`: Returns structured witness for malformed inputs (anticommuting generators, dependent generators, or $-I \in \mathcal{S}$).
- `UNKNOWN`: Closed-list typed refusals for resource or budget exhaustion.

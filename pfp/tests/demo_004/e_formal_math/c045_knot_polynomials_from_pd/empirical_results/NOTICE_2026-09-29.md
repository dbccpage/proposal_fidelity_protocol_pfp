# Notice on the C045 matrix report

> **Correction notice (2026-09-29).** The JSON report in this folder records an exploratory model run. The run did not follow the challenge protocol SG-CP v1, and its figures should not be cited as a challenge result.
>
> - **Leakage.** Each prompt began with the judge's case ID (for example `c045_m09_refusal_corrupt_edge`), and in this series the ID names the expected verdict or construction. The case JSON sent with it carried the same ID. The scores therefore partly measure reading the ID, not solving the case.
> - **Model.** `stealth/space-bunny-alpha` ("Space Bunny") is a free stealth model on OpenRouter as of 2026-09-28. The provider does not disclose its identity, size or training. Results with it are exploratory, fall outside SG-CP v1 section 2, and may not be reproducible after the stealth period. The study of 2026-09-28 found that all 29 retained usage records for this model report zero reasoning tokens, although the findings for this series describe it as a reasoning model.
> - **Custody.** Prompts were not stored. Replies were kept only as parsed JSON or as a 200-character excerpt. Provider errors were scored as wrong answers. Each model saw n = 10 hand-picked cases with one reply per case.
> - **Gate label.** `PASS_TO_MASTER` certifies the reference solver against its own checkers. It says nothing about any model.
>
> The runner now sends an opaque per-run token instead of the case ID and never sends answer-bearing fields. It keeps prompts and full replies, records provider errors as `INFRA_ERROR`, and writes each run to a new folder; the second checker was also hardened. No new runs have been made since.

The JSON report in this folder is kept byte for byte as it was written; this notice is the correction.

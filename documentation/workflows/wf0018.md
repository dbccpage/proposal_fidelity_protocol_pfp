## 1. Objective & Purpose

WF18 enforces a strict **harness replayability gate** across multi-dimensional experimental campaigns. In large benchmark campaigns crossing diverse problem carriers with exotic encodings (e.g. raw matrices, ASCII graphs, compressed glyphs, emoji alphabets), results are valid if and only if every single recorded evaluation grade can be reproduced with 100% bit-for-bit fidelity from cold stored raw bytes.

WF18 acts as an audit firewall against data corruption, non-deterministic scoring, and unrecorded runtime mutations.

## 2. Process Specification

1. **Matrix Experimental Design:** Pre-register a $5 \times 5$ matrix crossing:
   - **5 Mathematical Carriers:** (e.g. frustrated Ising spin triangles, directed cycle potentials, degree-4 cochains, weighted flow networks, chain complexes).
   - **5 Representation Dialects:** (e.g. JSON edge list, natural prose, bracketed S-expression, 8-symbol glyph code, emoji carrier).
2. **Matched Guidance Trials:** Add 5 matched structural guidance capsules per carrier.
3. **Execution & Cold Storage:** Dispatch the 30 experimental capsules, capturing raw HTTP wire bytes, model seeds, and provider metadata.
4. **Offline Cold Replay Campaign:** An independent auditor agent replays the entire 30-capsule suite from disk without network access.
5. **Bit-for-Bit Grade Audit:** Assert that every single recomputed score matches the recorded grade verbatim.

## 3. Mathematical Model & Invariants

- **Frustrated Binary Spin System (Ising Glass):**
  On a triangle graph with antiferromagnetic couplings ($J_{ij} = -1$), no spin configuration $s \in \{+1, -1\}^3$ can satisfy all edges:
  $$H(s) = -\sum_{(i,j) \in E} J_{ij} s_i s_j = s_1 s_2 + s_2 s_3 + s_3 s_1 \ge -1$$
  Every configuration leaves at least one frustrated edge ($s_i s_j = +1$).
- **Weighted Cycle Duality (Negative Cycle Detection):**
  A conservative vertex potential $p: V \to \mathbb{R}$ satisfying $p_v - p_u \le w_{uv}$ exists if and only if the graph contains zero negative-weight directed cycles:
  $$\min_{C \in \text{Cycles}} \sum_{e \in C} w_e \ge 0$$
- **Replay Invariance Metric:**
  $$\Delta_{\text{replay}} = \sum_{k=1}^{30} |\operatorname{grade}_{\text{recomputed}}(k) - \operatorname{grade}_{\text{recorded}}(k)| == 0$$

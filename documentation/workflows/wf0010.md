## 1. Objective & Purpose

WF10 formalizes the sheaf-theoretic and cohomological detection of non-factorization defects. In many complex systems, local constraints are fully satisfied on overlapping patches (local green), yet no globally consistent configuration exists (global red).

Rather than accepting natural language explanations, WF10 requires the model ensemble to emit either:
1. An explicit **gluing witness** that reconciles all local sections into a zero-defect global potential, or
2. A formal **obstruction certificate** identifying a non-trivial cohomology class $[c] \in H^1(X)$ showing that global reconciliation is obstructed under declared rules.

---

## 2. Process Specification

1. **Cover & Complex Declaration:** The host declares a simplicial or cell complex $X$, an open or patch cover $\{U_\alpha\}$, cochain groups $C^k(X; \mathbb{Q})$, and coboundary operators $\delta_k$.
2. **Local Patch Certification:** Isolated parallel worker agents formulate and certify local sections $s_\alpha$ on each patch $U_\alpha$.
3. **Boundary Restriction & Transition Maps:** The host computes differences on pairwise overlaps $U_\alpha \cap U_\beta$, generating a 1-cochain $c_{\alpha\beta} = s_\beta - s_\alpha$.
4. **Cohomological Obstruction Evaluation:**
   - The host checks if $\delta_1 c = 0$ (cocycle condition).
   - If $c \in \operatorname{im}(\delta_0)$, an exact 0-cochain potential exists; the host glues the solution.
   - If $c \notin \operatorname{im}(\delta_0)$, the obstruction class $[c] \in H^1(X; \mathbb{Q})$ is non-zero. The model must emit the dual cocycle witness certifying this obstruction.

---

## 3. Mathematical Model & Hodge Decomposition

- **First Cohomology Group (Obstruction Space):**
  $$H^1(X; \mathbb{Q}) = \frac{\ker(\delta_1)}{\operatorname{im}(\delta_0)}$$
  A non-zero class $[c] \ne 0$ represents an intrinsic topological or holonomic obstruction to global consistency.
- **Three-Patch Observer Visibility Phenomenon:**
  On a three-patch cover $\{U_1, U_2, U_3\}$, each local observer sees zero defect on their internal edges:
  $$D|_{U_\alpha}(s_\alpha) = 0 \quad \forall \alpha \in \{1, 2, 3\}$$
  Yet the composite defect of the glued section satisfies:
  $$\sum_{\alpha} J^\alpha(s) > 0$$
- **Exact Discrete Hodge Decomposition:**
  Every 1-cochain $c$ admits an exact rational orthogonal decomposition:
  $$c = \delta_0 \alpha + \delta_1^* \beta + h$$
  where $h$ is a harmonic cochain ($\delta_0^* h = 0$ and $\delta_1 h = 0$), representing the primary obstruction.

## 4. Team Structure & Panel Roles

- **Pattern:** `parallel_isolated_then_global`
- **Normal Path Calls:** $1 + n_{\text{patches}}$
- **Roles:**
  - `coder` (Sonnet, count: $n_{\text{patches}}$): Produces local sections for each individual patch.
  - `deep_researcher` (Opus, count: $1$): Formulates the global complex, boundary maps, and candidate obstruction classes.
  - `adversary` (Fable, count: $1$): Searches for gauge transformations or cover re-indexing that might artificially disguise the obstruction.
  - `host_checker` (None, count: $1$): Deterministic host cochain and homology solver.
- **Boost Rule:** When all local checks pass but the global composite check fails, Opus receives the exact coboundary residual and is authorized to submit either a repaired section (WF9) or a certified dual obstruction (limit 1).

## 5. Host Verification Protocol

- **Check Routine:** Exact discrete cochain and homology calculator.
- **Exact Rational Algebra:** Computations execute over $\mathbb{Q}$ without floating-point approximations, verifying rank conditions via fraction-free Gaussian elimination.
- **Accepted Artifacts:** Emits either `COCHAIN_GLUING_VERIFIED` or `COHOMOLOGICAL_OBSTRUCTION_CERTIFIED`.

## 1. Objective & Purpose

WF34 defines the mathematical conditions under which execution history, prompt context, and intermediate state can be compressed without compromising downstream problem-solving capability. In long multi-turn workflows, retaining the complete raw dialogue history quickly exhausts context windows and degrades attention.

However, naive context truncation often discards vital constraints or clues. WF34 enforces **Future-Faithful Compression**: a compressed state representation is valid if and only if all future operation enablements, transition costs, successor reachable sets, and terminal labels are identically preserved under every possible finite continuation.

---

## 2. Process Specification

1. **State Evaluation:** Evaluate the full execution history trace $H_t$.
2. **Future-Faithfulness Audit:** Apply the coarsest stable refinement algorithm to partition states into bisimilar equivalence classes.
3. **Bounded Context Packaging:** Construct the bounded context buffer containing strictly:
   - The immutable root task specification.
   - The current champion proposal (lowest defect state).
   - The two most recent attempt records $(t-1, t)$.
   - Cryptographic content references (hashes) to earlier evidence records.
4. **Endpoint-State Equality Check:** Verify that the compressed buffer produces an identical endpoint state under transition operations as the full-history state.
5. **Comparison Arm Execution:** Compare performance against an uncompressed full-history control arm under the same token ceiling.

---

## 3. Mathematical Model & Coarsest Stable Refinement

- **Future-Faithful Equivalence Criterion:**
  Two history states $H_1, H_2$ are future-faithful equivalent ($H_1 \approx_F H_2$) if for every finite sequence of future moves $\sigma = (m_1, \dots, m_k)$:
  $$\operatorname{Enabled}(H_1, \sigma) == \operatorname{Enabled}(H_2, \sigma)$$
  $$\operatorname{Cost}(H_1, \sigma) == \operatorname{Cost}(H_2, \sigma)$$
  $$\operatorname{Terminal}(H_1 \cdot \sigma) == \operatorname{Terminal}(H_2 \cdot \sigma)$$
- **Bisimulation Collapse:**
  The compressed state $S_{\text{comp}}$ is the quotient state:
  $$S_{\text{comp}} = H_t / \approx_F$$
  States are required to have equal mathematical capabilities, not identical diagnostic text.
- **Reference Retention Invariant:**
  No evidence reference hash present in $H_t$ may be silently dropped if it is named in the current champion's dependency set.

## 5. Host Verification Protocol

- **Endpoint State Equality Check:** Verifies that transition functions applied to the compressed representation yield states isomorphic to those applied to full history.
- **Refusal Code:** Emits `COMPRESSION_INFORMATION_LOSS` if a future operation is disabled by context truncation.

## 6. Claim Hygiene Evaluation

1. **What the Evidence Supports:**
   - Formal algebraic proofs confirm that coarsest stable refinement preserves transition reachability in finite automata.
2. **What the Evidence Does Not Support:**
   - Bounded context compression does not guarantee that LLMs will utilize retained references effectively.
3. **Narrowest Defensible Claim:**
   - WF34 specifies an algebraic context-compression protocol that guarantees under declared assumptions that all future state transition capabilities, costs, and terminal labels are preserved when truncating prompt history.
4. **Next Test Needed:**
   - Benchmark WF34 on a 10-turn graph path-finding problem, verifying that the 4-element bounded context achieves identical solve rates to the full-history arm.

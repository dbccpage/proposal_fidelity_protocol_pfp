## 1. Objective & Purpose

WF37 is a **meta-evolutionary workflow** that automates the optimization of execution harnesses. An outer model agent iteratively proposes structural mutations to the prompt scaffolding, workflow topology, search parameters, or context retention policies.

To prevent self-reinforcing delusion or overfitting to evaluation benchmarks, WF37 enforces strict **evidence bounds**:
1. Mutations are explored via Upper Confidence Bound (UCB1) multi-armed bandit strategies.
2. Candidate harnesses are evaluated on a strict split between public exploratory cases and private confirmation cases.
3. An incumbent harness is replaced if and only if the mutated challenger achieves statistically significant gains on fresh confirmation splits and demonstrates zero regression on untouched transfer and ablation panels under family-wise error rate control.

---

## 2. Process Specification

1. **Incumbent Harness Baseline:** Freeze the current production execution harness $\mathcal{H}_0$ and record baseline accuracy and cost metrics.
2. **Mutant Proposal:** An outer optimization agent proposes a structured harness mutation $\mathcal{H}'$ (e.g. altering prompt instructions, modifying retry limits, or re-ordering panel seats).
3. **Bandit Search & Exploration:** Deploy UCB1 / softmax selection across candidate mutation strategies.
4. **Public Screening:** Evaluate $\mathcal{H}'$ on public exploratory benchmark instances.
5. **Private Confirmation Audit:** If $\mathcal{H}'$ improves over $\mathcal{H}_0$ on public cases, dispatch the challenger against a private, sealed confirmation panel.
6. **Transfer & Ablation Battery:** Execute $\mathcal{H}'$ against an untouched ablation panel to confirm that improvements do not induce catastrophic regression elsewhere.
7. **Adoption Gate:** Replace $\mathcal{H}_0 \leftarrow \mathcal{H}'$ if and only if all statistical tests pass.

## 3. Mathematical Model & Statistical Gating

- **UCB1 Strategy Selection:**
  $$\text{Score}(k) = \hat{\mu}_k + c \sqrt{\frac{\ln T}{n_k}}$$
  balancing exploitation of high-performing harness types with exploration of unproven topologies.
- **Statistical Significance Invariant:**
  To adopt a challenger $\mathcal{H}'$ over incumbent $\mathcal{H}_0$:
  - Paired exact sign test on confirmation items: $p < 0.01$.
  - Paired bootstrap confidence interval for accuracy delta: $\operatorname{CI}_{99}(\Delta\mu) > 0$.
  - Holm-Bonferroni correction applied across the battery of $M$ transfer contrasts:
    $$p_{(k)} \le \frac{\alpha}{M - k + 1}$$

## 5. Host Verification Protocol

- **Frozen Oracles:** The checkers grading task performance remain completely frozen and isolated from the mutation engine.
- **Pre-Allocated Budget:** The meta-evolution loop terminates automatically upon reaching its pre-allocated financial expenditure cap.

## 1. Objective & Purpose

WF40 governs the **terminal boundary conditions** of iterative repair. When a bounded check-and-repair loop (WF9) exhausts its maximum attempt limit or token budget while retaining a non-zero defect residual ($D > 0$), execution cannot stop ambiguously or retry indefinitely.

WF40 enforces a strict **cochain trichotomy decision boundary**: the workflow must terminate by selecting exactly one of three lawful typed dispositions:
1. **Clean Epistemic Refusal:** Emit `ANSWER: UNRESOLVED <CODE>` acknowledging that the current representation cannot resolve the defect.
2. **Formal Lift Request:** Request a higher-dimensional lift grant (WF20) accompanied by a proof that the lower-dimensional problem possesses an unclosed obstruction ($\Delta > 0$).
3. **Seeded Restart Boundary:** Re-seed the problem from a fresh, independent starting configuration carrying the accumulated residual history as an explicit constraint.

## 2. Process Specification

1. **Exhaustion Trigger:** The WF9 bounded repair loop reaches attempt limit $L$ with final defect $D_L > 0$.
2. **Cochain Trichotomy Evaluation:** The host evaluates the topological status of the final residual:
   - Status 1: Coboundary defect is unclosed (syntactic inconsistency).
   - Status 2: Cocycle is closed but non-exact (topological obstruction / non-trivial cohomology).
   - Status 3: Search space exhaustion (solution exists but was not discovered).
3. **Disposal Selection:** The model emits its chosen terminal boundary move under the trichotomy contract.
4. **Preservation & Lift Verification:** If a lift is requested, the host verifies the mathematical lift witness. If a restart is selected, the host initializes a fresh problem instance bound to the residual digest.
5. **No Problem Mutating:** Alleviating an obstruction by silently altering the problem claims is prohibited; modifying claims constitutes an entirely new problem, not a valid repair.

## 3. Mathematical Model & Cochain Trichotomy

- **Cochain Residual Trichotomy:**
  For edge claims $c \in C^1(X)$:
  $$\begin{cases}
  \delta_1 c \ne 0 & \implies \text{Unclosed Cycle (Inconsistent Curvature)} \\
  \delta_1 c = 0 \land [c] \ne 0 \in H^1(X) & \implies \text{Closed Non-Exact (Topological Obstruction)} \\
  \delta_1 c = 0 \land [c] = 0 \in H^1(X) & \implies \text{Exact (Resolvable Section Exists)}
  \end{cases}$$
- **Lift Authorization Condition:**
  A structural lift grant $G_{\text{lift}}$ is authorized if and only if the host verifies:
  $$\Delta_{\text{obstruction}} = \Phi_1(c) > 0 \land \operatorname{PreservationWitness}(c)$$
- **Terminal Disposition Union:**
  $$\text{TerminalOutcome} \in \{ \text{TypedRefusal}, \text{AuthorizedLiftGrant}, \text{SeededRestart} \}$$

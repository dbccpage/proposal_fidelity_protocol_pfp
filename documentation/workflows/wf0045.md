## 1. Objective & Purpose

WF45 addresses a fundamental epistemic fallacy in model reasoning: **claiming unique truth because alternative hypotheses were omitted or deleted from context**. A single survivor among three presented options is not proven unique if ten thousand other indistinguishable options exist in the domain.

WF45 formalizes the **Plenitude Test**:
- Given an evidence base $E$ and a declared family of candidate models $\mathcal{F}$, the host checks every candidate against $E$.
- The outcome is classified into: `Accepted` (unique survivor), `Underdetermined` (multiple survivors), `Refuted` (zero survivors), or `Refused`.
- When an adversary adds candidate variants that are indistinguishable under the available evidence, the host asserts that the survivor set size must increase proportionally, preventing spurious claims of uniqueness.

---

## 2. Process Specification

1. **Candidate Family Declaration:** Declare an explicit finite set of candidate hypotheses or models $\mathcal{F} = \{h_1, \dots, h_K\}$.
2. **Evidence Evaluation:** The host evaluates each candidate $h_k$ against empirical or formal evidence $E$ with declared tolerances.
3. **Survivor Set Construction:**
   $$S(E, \mathcal{F}) = \{ h \in \mathcal{F} \mid \operatorname{Consistent}(h, E) \}$$
4. **The Plenitude Stress Test:**
   - The adversary generates $M$ additional synthetic candidates $\{h'_1, \dots, h'_M\}$ that satisfy the exact same evidence constraints.
   - The host re-evaluates the expanded family $\mathcal{F}' = \mathcal{F} \cup \{h'_1, \dots, h'_M\}$.
   - If $|S(E, \mathcal{F}')| > 1$, any prior assertion of unique truth is invalidated, and the terminal status becomes `UNDERDETERMINED`.
5. **No Deletion Authority:** Deleting competing candidates from the prompt context is rejected as an evasion attempt.

---

## 3. Mathematical Model & Relative Uniqueness

- **Relative Uniqueness Principle:**
  Unique acceptance is strictly relative to the declared candidate family $\mathcal{F}$:
  $$\operatorname{UniqueAcceptance}(h^*, E, \mathcal{F}) \iff S(E, \mathcal{F}) == \{h^*\}$$
  It holds zero absolute authority outside the declared family boundary.
- **Plenitude Monotonicity Invariant:**
  For any indistinguishable candidate $h_{\text{twin}}$ ($\operatorname{Consistent}(h_{\text{twin}}, E) == \text{True}$):
  $$|S(E, \mathcal{F} \cup \{h_{\text{twin}}\})| == |S(E, \mathcal{F})| + 1$$
- **Terminal Status Classification:**
  $$\text{TerminalStatus} = \begin{cases}
  \text{ACCEPTED\_UNIQUE} & \text{if } |S| == 1 \\
  \text{UNDERDETERMINED} & \text{if } |S| > 1 \\
  \text{REFUTED\_INCONSISTENT} & \text{if } |S| == 0 \\
  \text{REFUSED} & \text{if syntax / carrier invalid}
  \end{cases}$$

## 4. Team Structure & Panel Roles

- **Pattern:** `solo`
- **Normal Path Calls:** 1 call.
- **Roles:**
  - `coder` (Sonnet, count: $1$): Proposes candidate hypothesis sets and evidence bindings.
  - `adversary` (Fable, count: $1$): Generates evidence-consistent alternative hypotheses to break false claims of uniqueness.
  - `host_checker` (None, count: $1$): Deterministic host verifier; computes survivor sets and executes plenitude checks.
- **Boost Rule:** None; the computed survivor set size dictates the final typed verdict without escalation (limit 0).

---

## 5. Host Verification Protocol

- **Survivor Set Evaluation:** Evaluates candidates in parallel against all declared evidence constraints.
- **Refusal Code:** Any model claim of unique proof when $|S| > 1$ emits `FALSE_UNIQUENESS_UNDERDETERMINED`.

## 6. Claim Hygiene Evaluation

1. **What the Evidence Supports:**
   - Python stress tests demonstrate that plenitude testing reliably exposes underdetermined problem specifications where evidence is insufficient to distinguish competing hypotheses.
2. **What the Evidence Does Not Support:**
   - Generating an exhaustive family of candidates is not computationally feasible for infinite hypothesis spaces.
3. **Narrowest Defensible Claim:**
   - WF45 provides an operational test that evaluates candidate survivor sets over finite hypothesis families, preventing models from asserting unique truth when evidence is consistent with multiple alternatives.
4. **Next Test Needed:**
   - Run WF45 on 20 linear regression tasks with colinear features, confirming that the host classifies all 20 as `UNDERDETERMINED` rather than accepting an arbitrary feature subset.

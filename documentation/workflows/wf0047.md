## 1. Objective & Purpose

WF47 defines a protocol for **deterministic, resumable frontier search** over discrete combinatorial spaces (such as signed graph gauge assignments or boolean satisfiability frontiers). In large-scale searches, an exploration run may exhaust its per-session time or token budget before encountering a solution or proving an obstruction.

WF47 guarantees under declared assumptions that a search can be paused, serialized, and resumed in a subsequent session without risk of:
1. **Silent Problem Mutation:** Shifting the mathematical basis or representation between sessions.
2. **Duplicated Search Volume:** Re-exploring previously refuted branches.
3. **Unlawful State Claims:** Resuming from an unverified or forged intermediate checkpoint.

---

## 2. Process Specification

1. **Presentation Key Canonicalization:** Compute a canonical SHA-256 presentation key binding the problem graph, coordinate basis, representation conventions, and lexicographic ordering.
2. **Lexicographic Batch Exploration:** The model traverses the candidate frontier in deterministic lexicographic batches of size $B_{\text{batch}}$.
3. **Intermediate Status Classification:** Each batch yields one of three formal dispositions:
   - `VERIFIED`: Exact zero-defect solution discovered.
   - `RESTRICTED_OBSTRUCTION`: The batch sub-tree is proven to contain zero valid solutions.
   - `UNKNOWN_WITH_SUFFIX`: Search incomplete; records the exact lexicographic frontier index $k_{\text{frontier}}$.
4. **Resumption Verification:** To resume a search from index $k_{\text{frontier}}$, the host verifies the contiguous hash chain of all predecessor batch receipts starting from index 0.
5. **Deterministic Continuation:** Execution continues with batch $k_{\text{frontier}} + 1$.

---

## 3. Mathematical Model & Sign-Gauge Verification

- **Signed Graph Gauge Invariant:**
  For a graph with edge signs $s: E \to \{+1, -1\}$, a gauge potential $\sigma: V \to \{+1, -1\}$ is sought such that:
  $$\sigma_u \cdot s(u, v) \cdot \sigma_v == +1 \quad \forall (u, v) \in E$$
- **Lexicographic Frontier Indexing:**
  Candidate potentials are ordered lexicographically: $\sigma^{(0)} <_{\text{lex}} \sigma^{(1)} <_{\text{lex}} \dots <_{\text{lex}} \sigma^{(2^{|V|}-1)}$.
- **Contiguous Receipt Chain Invariant:**
  Resumption from checkpoint index $K$ requires:
  $$\operatorname{ValidResume}(K) \iff \forall i \in \{0, \dots, K-1\}, \ \text{Receipt}_i.\text{status} == \text{RESTRICTED\_OBSTRUCTION} \land \operatorname{HashChain}(0 \dots K)$$
  guaranteeing that no skipped branches were falsely presumed refuted.

## 4. Team Structure & Panel Roles

- **Pattern:** `relay`
- **Normal Path Calls:** Budget-capped sequential batches.
- **Roles:**
  - `coder` (Sonnet, count: $1$): Generates successive lexicographic candidate batches.
  - `host_checker` (None, count: $1$): Deterministic host exact sign-gauge verifier; evaluates batch receipts and validates frontier indices.
- **Boost Rule:** None; an `UNKNOWN_WITH_SUFFIX` status is a lawful, expected intermediate result and does not trigger unbudgeted escalation (limit 0).

---

## 5. Host Verification Protocol

- **Exact Sign-Gauge Verifier:** Evaluates edge sign products in exact integer arithmetic ($\{-1, +1\}$).
- **Presentation Key Integrity:** Any discrepancy between the resumed session's presentation key and the root manifest aborts with `PRESENTATION_KEY_MISMATCH`.

## 6. Claim Hygiene Evaluation

1. **What the Evidence Supports:**
   - Offline worked traces confirm that lexicographic frontier indexing allows discrete search spaces to be partitioned and resumed deterministically.
2. **What the Evidence Does Not Support:**
   - Resumable search does not circumvent worst-case exponential complexity for NP-complete signed graph balance problems.
3. **Narrowest Defensible Claim:**
   - WF47 provides a deterministic protocol that allows combinatorial frontier searches to pause and resume across sessions by verifying contiguous cryptographic receipt chains and canonical presentation keys.
4. **Next Test Needed:**
   - Run a two-session search on an 8-vertex frustrated signed graph, verifying that Session 2 resumes exactly at index 128 after Session 1 terminates at index 127.

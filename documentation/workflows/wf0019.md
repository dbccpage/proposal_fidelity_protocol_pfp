## 1. Objective & Purpose

WF19 tests whether formal rules derived from observed model failures can transfer positively to unseen, held-out problem instances.

When a failure is analyzed and converted into a structural prompt rule or antibody, WF19 evaluates:
1. **Transfer Gain:** Does injecting this rule improve performance on held-out instances from the same or related problem families?
2. **Side-Effect Invariance:** Does the rule avoid degrading performance on other tasks or introducing new false rejections (self-tolerance)?

A derived rule remains an unadmitted candidate until both positive transfer gain and zero autoimmune degradation are established on strictly disjoint test splits.

---

## 2. Process Specification

1. **Rule Derivation:** Extract a candidate operational rule (e.g. an explicit parity constraint or boundary verification checklist) from an identified failure cluster.
2. **Disjoint Data Partition:** Partition challenge instances into training/derivation cases and strictly held-out evaluation cases:
   $$D_{\text{derivation}} \cap D_{\text{held-out}} = \emptyset$$
3. **Three-Arm Comparison:** Execute three experimental arms on the held-out split:
   - Arm 1: Unassisted baseline prompt.
   - Arm 2: Generic typed-witness prompt (WF2).
   - Arm 3: Rule-assisted prompt (injecting the derived failure rule).
4. **Host Scoring:** Grade all replies using the registered domain host checkers.
5. **Admission Gate:** Admit the rule into the permanent prompt library if and only if it demonstrates statistically significant positive transfer gain and satisfies WF14 self-tolerance.

---

## 3. Mathematical Model & Transfer Gain

- **Empirical Transfer Gain:**
  $$\text{Gain}_{\text{transfer}} = \operatorname{acc}(\text{Rule Arm}, D_{\text{held-out}}) - \operatorname{acc}(\text{Baseline Arm}, D_{\text{held-out}})$$
  where $\operatorname{acc}(\text{Arm}, D) = \frac{1}{|D|} \sum_{x \in D} \mathbf{1}[\operatorname{check}(\text{Arm}(x)) == \text{PASS}]$.
- **Admission Criteria:**
  $$\operatorname{Admit}(\text{Rule}) \iff (\text{Gain}_{\text{transfer}} > 0) \land (\text{Self-Tolerance}(\text{Rule}) == 1.0)$$
- **Overfitting Suppression:** Rules that improve performance on training cases but achieve zero or negative transfer on held-out cases are immediately retired.

## 4. Team Structure & Panel Roles

- **Pattern:** `research_cell`
- **Normal Path Calls:** $\text{Arms} \times |D_{\text{held-out}}|$
- **Roles:**
  - `deep_researcher` (Opus, count: $1$): Formulates candidate abstract rules from error residual clusters.
  - `adversary` (Fable, count: $1$): Identifies held-out edge cases where the proposed rule leads to over-constraining or failure.
  - `coder` (Sonnet, count: $1$): Manages arm execution, data splitting, and accounting custody.
  - `host_checker` (None, count: $1$): Deterministic host domain verifiers.
- **Boost Rule:** If a candidate rule demonstrates zero transfer gain on the initial held-out batch, Opus is authorized to propose one revised formulation; if that fails, the rule is permanently retired (limit 1).

---

## 5. Host Verification Protocol

- **Domain Checker Execution:** Each held-out problem instance is evaluated exclusively by its pre-registered exact checker.
- **Disagreement Policy:** If dual checkers disagree on an output, execution halts immediately with `CHECKER_DISAGREEMENT_HALT`.

## 6. Claim Hygiene Evaluation

1. **What the Evidence Supports:**
   - Pilots 192–198 define rigorous protocols for measuring prompt rule transfer on strictly disjoint test sets.
2. **What the Evidence Does Not Support:**
   - The framework does not claim that failure-derived rules generalize universally across unrelated mathematical domains.
3. **Narrowest Defensible Claim:**
   - WF19 specifies an experimental evaluation workflow that measures the empirical transfer gain of failure-derived prompt interventions on held-out tasks under strict self-tolerance gates.
4. **Next Test Needed:**
   - Execute WF19 on 40 held-out graph cycle problems to measure whether an explicit cycle-parity prompt rule improves solve rates over baseline.

## 1. Objective & Purpose

WF42 validates the mathematical consistency of intermediate **reasoning traces**. Rather than treating chain-of-thought text as an unanalyzable black box or trusting rhetorical fluency, WF42 uses a fixed deterministic extractor to map the model's natural language reasoning steps into a directed constraint graph of assertions, citations, and deductions.

The host then applies exact rational linear programming to calculate whether the extracted reasoning graph contains internal cycle contradictions or topological obstructions.

---

## 2. Process Specification

1. **Reasoning Ingress:** Ingest the raw, unconstrained reasoning trace emitted by the model.
2. **Deterministic Extraction:** A fixed AST extractor maps the trace into an attributed directed dependency graph $G = (V, E, c)$, where vertices represent derived intermediate facts and directed edges represent deductive steps with claimed potential differences.
3. **Obstruction & Dual Witness Calculation:** The host executes an exact rational linear program over $G$ to compute primary obstruction $\Phi_1(G)$ and the dual cycle circulation $\phi$.
4. **Adversarial Extractor Stress Testing:** The adversary evaluates an adversarial battery against the extractor to ensure it does not collapse distinct claims into identical nodes.
5. **Typed Status Emission:** If $\Phi_1 > 0$, the reasoning trace is rejected with a formal proof of internal inconsistency, even if the final emitted answer happened to match the target.

---

## 3. Mathematical Model & Primal-Dual Reasoning Graphs

- **Extracted Reasoning Graph:**
  Vertices $v \in V$ correspond to extracted intermediate scalar or logical claims. Edges $(u, v) \in E$ correspond to asserted transitions with claimed differences $c(u, v) \in \mathbb{Q}$.
- **Primal-Dual Obstruction Formulation:**
  $$\Phi_1(c) = \max_{\phi \in \mathbb{Q}^E} \left\{ \phi^T c \mid B^T \phi = 0, \ \|\phi\|_\infty \le 1 \right\}$$
  where $B$ is the vertex-edge incidence matrix.
- **Worked 3-Claim Cycle Inconsistency:**
  Consider an extracted 3-step reasoning cycle:
  - Step 1: $x_2 - x_1 = 2$
  - Step 2: $x_3 - x_2 = -1$
  - Step 3: $x_1 - x_3 = 0$
  The closed cycle circulation $\phi = (1, 1, 1)^T$ satisfies $B^T \phi = 0$. The obstruction is:
  $$\phi^T c = 1 \cdot (2) + 1 \cdot (-1) + 1 \cdot (0) = 1 \ne 0$$
  proving that the reasoning trace contains an intrinsic internal contradiction of magnitude $\Phi_1 = 1$.

  - `host_checker` (None, count: $1$): Deterministic host rational LP solver.
- **Boost Rule:** If the extractor collapses or fails to parse a valid syntactic trace, execution halts with `CarrierFailure` without retrying (limit 0).

---

## 5. Host Verification Protocol

- **Exact Rational LP:** Primary obstruction $\Phi_1$ is computed over $\mathbb{Q}$ using exact rational simplex algorithms.
- **Trace Consistency Rule:** A run is accepted if and only if both the reasoning trace satisfies $\Phi_1 == 0$ and the final answer satisfies the ground-truth checker.

## 6. Claim Hygiene Evaluation

1. **What the Evidence Supports:**
   - The repository demonstrates that reasoning graphs extracted from step-by-step calculations can be evaluated for cycle consistency via exact rational linear programming.
2. **What the Evidence Does Not Support:**
   - Formal extraction from arbitrary, unstructured conversational natural language remains subject to parsing ambiguities.
3. **Narrowest Defensible Claim:**
   - WF42 provides a deterministic method to verify the internal mathematical consistency of extracted reasoning traces by calculating whether their dependency graph contains non-zero cycle obstructions.
4. **Next Test Needed:**
   - Benchmark WF42 on 30 reasoning traces containing intentional subtle algebraic errors, verifying that the rational LP checker computes $\Phi_1 > 0$ for all 30 defective traces.

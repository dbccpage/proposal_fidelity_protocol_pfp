## 1. Objective & Purpose

WF46 investigates the **sufficiency of boundary interfaces** in decomposed multi-agent workflows. When a problem is split across parallel isolated workers (as in WF4), each worker produces a local output that is passed to a global boundary aggregator.

However, if the intermediate handoff object omits critical relational or topological information, the global evaluator may fail even when every local worker executed correctly. WF46 measures the **Negative Gluing Defect (NGD)** rate: the conditional probability that the global composite evaluation fails given that all local agent checks passed.

---

## 2. Process Specification

1. **Handoff Interface Inspection:** Audit the serialization schema of the boundary handoff object passed from local agents to the global aggregator, confirming it contains all necessary variables.
2. **Parallel Agent Execution:** Execute the isolated local solvers conforming to the WF4 architecture.
3. **Local Evaluation:** Evaluate local structural and semantic checks for each agent ($E_1, \dots, E_K$).
4. **Glued Global Evaluation:** Execute the global evaluator $E_G$ over the glued composite trace.
5. **NGD Metric Computation:** Compute the empirical NGD rate across the benchmark suite:
   $$\text{NGD} = \Pr(E_G == 0 \mid E_1 = 1 \land \dots \land E_K = 1)$$
6. **Sufficiency Diagnostic Report:** Emit a boundary sufficiency report indicating whether failures stem from agent error or boundary interface poverty.

---

## 3. Mathematical Model & Negative Gluing Defect (NGD)

- **Negative Gluing Defect (Local Green, Global Red):**
  For a run with $K$ parallel local workers:
  $$\Delta_E = E_G - \prod_{k=1}^K E_k \in \{-1, 0, 1\}$$
  An instance exhibits an NGD defect if and only if $\Delta_E == -1$.
- **Empirical NGD Rate:**
  $$\text{Rate}_{\text{NGD}} = \frac{\#(\Delta_E == -1)}{\#(\prod_{k=1}^K E_k == 1)}$$
  The rate is mathematically undefined if zero runs achieve full local acceptance ($\prod E_k = 0$ everywhere).
- **Boundary Sufficiency Invariant:**
  A boundary interface schema $\mathcal{B}$ is **sufficient** if and only if the conditional probability of gluing failure on mathematically consistent instances is zero:
  $$\Pr(\Delta_E = -1 \mid \text{ConsistentTask}) == 0$$

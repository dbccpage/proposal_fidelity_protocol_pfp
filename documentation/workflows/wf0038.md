## 1. Objective & Purpose

WF38 establishes a rigorous mathematical selection rule for multi-candidate proposal generation. When a model emits multiple candidate repairs or solutions, models frequently exhibit "self-critique bias"—attaching high confidence scores or favorable commentary to flawed proposals.

WF38 enforces an absolute rule: **models are strictly prohibited from reporting or self-attesting their own scores**. All candidate filtering, ranking, and selection are performed exclusively by the host, which recomputes multi-channel exact rational diagnostic functionals (primary obstruction $\Phi_1$, holonomy discrepancy $\Gamma_2$, and cochain defect $D$) from raw proposal coordinates.

---

## 2. Process Specification

1. **Candidate Pool Ingress:** The model outputs a set of $K$ candidate proposals $\{x_1, \dots, x_K\}$. Self-assessed scores or rationales are stripped upon ingress.
2. **Multi-Channel Host Diagnostics:** The host recomputes exact diagnostic metrics for each candidate:
   - Primary obstruction $\Phi_1(x_k)$ via rational linear programming.
   - Secondary obstruction $\Gamma_2(x_k)$ (gauge holonomy curvature).
   - Residual defect $D(x_k)$.
3. **Strict Lexicographic Filtering:** Filter out candidates that fail monotonic descent:
   $$\text{Retain } x_k \iff \Phi_1(x_k) < \Phi_1(x_{\text{current}}) \lor (\Phi_1(x_k) == \Phi_1(x_{\text{current}}) \land D(x_k) < D(x_{\text{current}}))$$
4. **Multi-Observer Consensus:** In multi-observer geometries, require every observer patch to satisfy the ratio ceiling.
5. **Deterministic Selection:** Select the candidate with the highest composite host score. Ties are broken deterministically by canonical JSON string order.

## 3. Mathematical Model & Diagnostic Functionals

- **Primal-Dual Obstruction Witness ($\Phi_1$):**
  The host computes $\Phi_1$ via exact rational linear programming:
  $$\Phi_1(c) = \max_{\phi} \{ \phi^T c \mid B^T \phi = 0, \ \|\phi\|_\infty \le 1 \}$$
  where $B$ is the incidence matrix.
- **Secondary Holonomy Bound ($\Gamma_2$):**
  $$\Gamma_2(c) \le \|D\| \cdot \Phi_1(c)$$
  bounding the non-abelian curvature residual by the geometric defect.
- **Ratio Ceiling Filter:**
  Rejects candidates whose local defect exceeds the bounded ratio ceiling:
  $$\frac{D(s_k)}{\Phi_1(c_k)} \le \kappa_{\max}$$

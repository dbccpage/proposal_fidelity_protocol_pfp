## 1. Objective & Purpose

WF41 formalizes the mathematical standards required to certify that an error detector or antibody is **statistically and structurally adequate** for production deployment within the Epistemic Immune System (EIS).

A detector that triggers on an error pattern is dangerous if its calibration scope is incomplete: it may miss subtle permutations, collide with benign phrases, or fail under metamorphic transformations. WF41 requires an exhaustive four-part calibration battery (positive, negative, collision, and metamorphic controls) across every equivalence class of inputs before a detector can be licensed to gate execution.

## 2. Process Specification

1. **Equivalence Class Partitioning:** Partition the target problem domain into disjoint equivalence classes of error behaviors $\mathcal{C} = \{C_1, \dots, C_k\}$.
2. **Four-Part Calibration Battery:** For each class $C_i$, construct and execute four test batteries:
   - **Positive Controls:** Planted errors from $C_i$ that the detector must reliably catch.
   - **Negative Controls:** Known-valid solutions that must not trigger the detector.
   - **Collision Controls:** Benign mathematical phrases syntactically similar to $C_i$ that must not collide.
   - **Metamorphic Controls:** Semantically equivalent rephrasings of $C_i$ that must continue to trigger detection.
3. **Two-Signal Admission Verification:**
   - Signal 1: Detector pattern match.
   - Signal 2: Host deterministic structural defect.
   - Pattern match alone is recorded as diagnostic telemetry; only dual-signal confirmation authorizes blocking.
4. **Self-Panel Effective Diversity:** Audit the entropy and effective diversity of the sealed Self panel.
5. **Human Attestation Sealing:** Bind human supervisory approval directly to the cryptographic receipt digest.

## 3. Mathematical Model & Finite Calibration Completeness

- **Finite Calibration Completeness Theorem:**
  Let $D$ be a detector and $A$ be an exact defect oracle. Let $R = \{r_1, \dots, r_k\}$ be a set containing at least one representative from every structural equivalence class of the domain. Then:
  $$D \equiv A \iff \forall r \in R, \ D(r) == A(r)$$
  Calibration is provably complete over the declared domain if and only if every equivalence class is represented in the test panel without omission.
- **Detector Adequacy Gate:**
  If any class $C_i \in \mathcal{C}$ lacks an evaluated representative in the calibration record:
  $$\operatorname{Adequate}(D) = \text{False} \implies \text{Status: DETECTOR\_INADEQUATE}$$
- **Statistical Upper Bound:**
  Achieving a risk upper bound of $< 1\%$ false negative rate requires a minimum sample size of $n \ge 299$ independent testing opportunities under the binomial model without failure.

## 5. Host Verification Protocol

- **Two-Signal Table Audit:** Asserts that the detector achieves 100% agreement with the host defect check on all positive and negative control instances.
- **Refusal Code:** Any missing class or collision failure raises `DETECTOR_CALIBRATION_DEFECT`.

   - WF41 provides a rigorous calibration protocol requiring positive, negative, collision, and metamorphic controls across declared problem equivalence classes before an error detector is admitted into active gating.

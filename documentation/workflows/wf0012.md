## 1. Objective & Purpose

WF12 is an experiment design workflow constructed to evaluate hypothesized mechanisms of model performance. When an prompt intervention or structural scaffold appears to improve problem-solving accuracy, WF12 isolates the causal mechanism by executing matched control arms on a strictly fixed problem carrier.

By holding the mathematical carrier, distractor spans, and problem structure identical while altering only the specific mechanistic instruction or hint, WF12 determines whether gains arise from genuine semantic assistance or trivial artifact effects (such as token salience or length bias).

---

## 2. Process Specification

1. **Carrier Invariance:** Define a fixed problem carrier (e.g. an integer rank-assignment problem) with explicit gauge freedom and controlled distractor spans.
2. **Arm Definition:** Construct parallel experimental arms:
   - **Arm A (Baseline):** Unassisted task turn.
   - **Arm B (Typed Witness):** Scaffolded with formal typed-witness requirements (WF2).
   - **Arm C (Mechanism Arm):** Scaffolded with the specific hypothesized cognitive/mechanic prompt intervention.
3. **Paired Execution:** Run all arms across identical test items under identical provider parameters.
4. **Shared Evaluation:** Grade every output with a single unchanged host certificate checker.
5. **Item-by-Item Comparison:** Compute the exact paired difference vector across arms.

---

## 3. Mathematical Model & Paired Treatment Effect

- **Gauge-Invariant Rank Difference:**
  Given an unknown rank potential $r: V \to \mathbb{Z}$, the problem provides directed differences $d_{ij} = r_i - r_j$. The problem possesses a 1D gauge freedom:
  $$r \mapsto r + c \quad (c \in \mathbb{Z})$$
  The model's answer is evaluated exclusively on gauge-invariant differences $r_i - r_j$.
- **Paired Treatment Difference ($d_i$):**
  For test instance $i$:
  $$d_i = \mathbf{1}[\operatorname{check}(\text{Arm}_B, i)] - \mathbf{1}[\operatorname{check}(\text{Arm}_A, i)] \in \{-1, 0, 1\}$$
- **McNemar Discordant Pair Test:**
  Let $b = \#(A=0, B=1)$ and $c = \#(A=1, B=0)$. The exact binomial test evaluates whether the mechanism produces statistically significant positive divergence ($b > c$).

## 5. Host Verification Protocol

- **Checker:** Integer rank-difference certificate evaluator.
- **Leakage Auditing:** Every distractor span is verified to have zero mutual information with the target rank potential before the experiment is authorized to dispatch.

2. **What the Evidence Does Not Support:**
   - The design does not claim that any prompt mechanism has been proven to alter transformer attention weights directly.
3. **Narrowest Defensible Claim:**
   - WF12 specifies a controlled comparative protocol that measures whether specific prompt variations produce statistically significant changes in task acceptance when tested on fixed gauge-invariant carriers.

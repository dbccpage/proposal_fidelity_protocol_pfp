## 1. Objective & Purpose

WF22 evaluates the economic efficiency of verification protocols. When comparing unassisted generation against multi-agent swarms or iterative repair loops, raw accuracy is an incomplete metric; complex workflows often consume orders of magnitude more tokens and cost to achieve marginal gains.

WF22 defines the **Cost to Certified Correct ($C_{\text{arm}}$)** metric, measuring the total dollar spend required to produce one host-verified, certificate-bearing solution. It tests 14 pre-registered, falsifiable empirical hypotheses across staged multi-agent scaffolds without mid-campaign parameter tuning.

---

## 2. Process Specification

1. **Pre-Registration:** Register test items, experimental arms (varying stage count $1 \dots 8$, model tiers, rewrites, and active antibodies), and falsifiable hypotheses $H_0 \dots H_{13}$ before dispatch.
2. **Canonical Termination Line:** Every arm must conclude with either a verified solution or an explicit typed refusal:
   ```text
   ANSWER: <payload>  OR  ANSWER: UNRESOLVED <code>
   ```
3. **Full Matrix Dispatch:** Execute all items under all pre-registered arms with durable transaction accounting.
4. **Item-by-Item Statistical Adjudication:** Evaluate discordant pairs using McNemar tests and exact sign tests.
5. **Ladder Analysis:** Plot the cost-efficiency frontier across rungs of problem difficulty.

---

## 3. Mathematical Model & Economic Metrics

- **Cost to Certified Correct ($C_{\text{arm}}$):**
  $$C_{\text{arm}} = \frac{\sum_{i=1}^N \text{Spend}_{\text{microusd}}(\text{arm}, i)}{\sum_{i=1}^N \mathbf{1}[\operatorname{check}(\text{arm}, i) == \text{PASS}]}$$
  If an arm achieves $0$ accepted solutions, $C_{\text{arm}} = \infty$.
- **Discordant Pair McNemar Analysis:**
  Comparing Arm $A$ and Arm $B$ on $N$ items:
  $$b = \#(A == \text{PASS} \land B == \text{FAIL}), \quad c = \#(A == \text{FAIL} \land B == \text{PASS})$$
  Exact two-tailed binomial $p$-value evaluates whether performance divergence is statistically significant.
- **Bluff Rate Comparison:**
  Compares unforced error rates on unsolvable control instances across cost tiers.

## 6. Claim Hygiene Evaluation

1. **What the Evidence Supports:**
   - The repository contains pre-registered test designs defining formal refutation criteria for 14 cost-efficiency hypotheses.
2. **What the Evidence Does Not Support:**
   - The existence of the protocol does not prove that multi-agent scaffolding is more cost-effective than frontier base models.
3. **Narrowest Defensible Claim:**
   - WF22 specifies an experimental methodology to compute the exact empirical cost-per-certified-solution across varying workflow depths and model tiers under pre-registered hypotheses.

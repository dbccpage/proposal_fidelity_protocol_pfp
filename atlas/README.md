# Atlas

AuthorityEffect: None.

The atlas is the single research record of this repository: one paper, one
claim ledger, one change log, and the archive of the source manuscripts they
are drawn from.

| File | What it holds |
| --- | --- |
| [`atlas.md`](atlas.md) | The atlas paper: every claim stated in prose and mathematics, cited by atlas ID, with a generated index that places every ledger row. |
| [`atlas_claim_ledger.md`](atlas_claim_ledger.md) | One row per claim, generated by [`dag/build_atlas.py`](../dag/build_atlas.py). [`atlas_claim_ledger.json`](atlas_claim_ledger.json) is the typed form. |
| [`atlas_manuscript_claims.json`](atlas_manuscript_claims.json) | Claims extracted by hand from the six papers whose own ledger is missing or holds only process text, each located by an anchor string. |
| [`atlas_claim_matches.json`](atlas_claim_matches.json) | The review of every archive claim against the audit derivations: matched, partial or gap, with node IDs and, for gaps, a proposed derivation. |
| [`atlas_change_log.md`](atlas_change_log.md) | What changed in the atlas, and when. |
| [`archive/`](archive/README.md) | The source papers: the PFP series 000–021 and the finite obstruction calculus and authority series 001–016. |

The archive was `papers/` until 2026-11-13. It was moved with `git mv`, so every
manuscript, manifest, release ZIP and receipt keeps its bytes and its SHA-256.
Frozen audit records under `dag/reviews/`, `dag/research/`, `dag/migrations/`,
`dag/handoff/` and `governance/evidence/` still write the old prefix; read
`papers/X` there as `atlas/archive/X`. The rule is recorded as data in
[`archive_path_map.json`](archive_path_map.json).

**Ledger and DAG.** The ledger and [`dag/derivations_dag.json`](../dag/derivations_dag.json)
correspond one to one. Each archived claim is an `archive_claim` node in the DAG
with an edge from its source file, and each derivation node already in the DAG
carries an `atlas_ledger_id` and a row in Part II of the ledger. Pinned source
files, assumptions and paper assessments are not derivations and have no row.
Each archive claim carries a review verdict, recorded in
[`atlas_claim_matches.json`](atlas_claim_matches.json): `matched` or `partial`
to named audit nodes (with an edge in the DAG), or `gap`, with a proposed
derivation in [`dag/derivations/`](../dag/derivations/README.md).

Written derivations, one file per DAG node, go in
[`dag/derivations/`](../dag/derivations/README.md).

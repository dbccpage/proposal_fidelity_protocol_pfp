# Non-PFP papers

AuthorityEffect: None.

Sixteen research papers on the finite obstruction calculus and on authority in
agentic systems, moved in from the research repository on 2026-10-27 with their
sources, PDFs, release archives, checksums, code and tests as delivered. They are
not Proposal Fidelity Protocol papers; those are in [`../pfp/`](../pfp/README.md).

They are numbered in the order a reader should meet them: each paper comes after
the papers it cites. Each folder is a self-contained package with its own README,
reproduction steps and licences. Folder contents are unchanged; the old numbers
that appear inside them are translated in [RENUMBERING.md](../RENUMBERING.md).

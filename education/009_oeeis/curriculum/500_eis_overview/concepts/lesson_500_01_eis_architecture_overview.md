# Lesson 500.01: Epistemic Immune System Architecture Overview

**AuthorityEffect:** None.  
**Track:** 500 (EIS Overview)  
**Topic:** Overview of Epistemic Defense, 12 Innate Pharmacy Barriers, and Clean Architecture Boundaries

## 1. Pedagogical Objective
Analyze the core architecture of the Epistemic Immune System (OEEIS), demonstrating how 12 innate pharmacy barriers and 7 decoupled immune roles provide authority-safe immune surveillance without autoimmune collapse.

## 2. Key Concepts & Invariants
- **Innate Barrier:** 12 immutable failure classes in pure Rust (`pharmacy.rs`).
- **Clean Report Non-Admission:** Zero findings does not imply positive authority (`AuthorityEffect: None`).
- **Seven Immune Roles:** Decoupling `Spec`, `FixtureBank`, `EvaluationReceipt`, `ExternalDecision`, `Registry`, `ActivationProfile`, and `Hit`.

## 3. Check for Understanding
- Why is a clean pharmacy report not an admission decision?
- How does component role partitioning prevent autoimmune self-modification by LLM agents?

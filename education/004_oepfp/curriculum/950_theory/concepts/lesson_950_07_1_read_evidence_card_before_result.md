## 1. Read the evidence card before the result

Each card needs a carrier, source, checker, and ceiling. A printed digest,
passing test, or assertion supplied by a proposer cannot raise the ceiling.
The following cards are teaching labels; inspect the named source for any
real claim.

> **Claim-typing legend**
> - **[Pinned]**: taken from a file this repository already has.
> - **[Proved]**: a finite check in this notebook. Not a general proof.
> - **[Declared]**: a carrier, rule, or heading chosen for this sitting.
> - **[Open]**: something this sitting does not decide.

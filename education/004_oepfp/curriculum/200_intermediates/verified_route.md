# Intermediate integration route

AuthorityEffect: None.

These lessons connect exact arithmetic to independent feasibility and boundary
checks. Change the declared input and predict which check should fail.

1. [Nilpotence and missing boundaries](system_integration/01_nilpotence_and_missing_boundaries.ipynb)
   audits every vertex basis potential and exposes a missing-edge defect.
2. [Exact LP certificates](system_integration/02_exact_lp_certificates.ipynb)
   checks primal feasibility, dual closure, norm bounds, and gap.
3. [Quantifier order](system_integration/03_quantifier_order.ipynb)
   independently enumerates finite choices.
4. [Frustrated spin triangle](system_integration/04_frustrated_spin_triangle.ipynb)
   checks all eight binary assignments and a changed-parity control.

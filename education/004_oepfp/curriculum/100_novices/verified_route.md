# Novice integration route

AuthorityEffect: None.

These lessons connect parsing, token control, agent permissions, and exact
repairs. Each has a worked case and a changed-input refusal or counterexample.

1. [Codecs and tamper evidence](system_integration/01_codecs_and_tamper_evidence.ipynb)
   checks round trips and changed DAG node content.
2. [Token frontier](system_integration/02_token_frontier.ipynb)
   computes retained probability mass and refuses empty support.
3. [Typed agent composition](system_integration/03_typed_agent_composition.ipynb)
   separates type compatibility from operation permission.
4. [Cycle repair](system_integration/04_cycle_repair.ipynb)
   computes a potential repair without erasing the cycle sum.

Read the [curriculum review](../curriculum_125_review.md) and
[integration roadmap](../README.md) for evidence scope and
headless replay instructions. The notebooks are integrated locally.

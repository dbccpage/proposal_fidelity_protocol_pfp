## 2. Proposer & Checker Protocol

The Proposal Fidelity Protocol separates untrusted generation from deterministic verification:

```text
┌──────────────────────────┐         Candidate Proposal 57         ┌──────────────────────────┐
│     Untrusted Neural     ├────────────────────────────────────────►│    Deterministic Host    │
│    Proposer (Player)     │◄────────────────────────────────────────┤      Checker (Rust)      │
└──────────────────────────┘          Typed Terminal Receipt         └────────────┬─────────────┘
                                                                                  │
                                             Emits Immutable Verification Receipt ▼
                                                                     ┌──────────────────────────┐
                                                                     │   Residual Loss Ledger   │
                                                                     │  (Zero Authority Mints)  │
                                                                     └──────────────────────────┘
```

1. **Untrusted Proposer Role:** Submits candidate move proposals formatted as typed wire envelopes. Proposer outputs carry zero ambient trust and cannot mutate board configuration directly.
2. **Deterministic Referee Role:** Specified for a native Rust referee (none is implemented for this level at the source pin); verifies carrier boundary compliance, applies permitted moves (`ASSERT, CUT, VERIFY`), calculates `QuantumFoundationsModule` metrics under `UnitaryCayleyContract`, and decrements fuel.
3. **Turn Fuel & Budget:** Proposer is allotted exactly **8 turns** to resolve candidate defects or achieve an admitted stable survivor. Exhaustion without resolution triggers terminal status `OpenObstruction`.
4. **Syntax Firewall & Domain Separation:** Raw tokens are evaluated against the carrier allowlist and packet JSON schema. Any malformed syntax, schema mismatch, undeclared symbol, or carrier boundary breach is intercepted immediately by the syntax firewall and routed to terminal status `Invalid` (`ERR_CARRIER_TOKEN_INVALID` / `ERR_SCHEMA_MISMATCH`). The domain referee evaluates only structurally valid proposals; domain mathematical errors (such as `ERR_HAMILTONIAN_SPEC_DEFECT`) are emitted exclusively by the domain evaluator.

## 4. Evaluator Module & Objective Metrics: QuantumFoundationsModule

### Contract: `UnitaryCayleyContract`

Referees evaluate Level 57 candidates through exact Cayley unitary transform dynamics over $\mathbb{Q}(i)$:

1. **Hermitian Generator Validation:** Verifies matrix $H \in \mathbb{Q}(i)^{d \times d}$ satisfies $H^\dagger = H$.
2. **Rational Cayley Transform:** Constructs the discrete unitary step operator:
   $$U = (I - i H)(I + i H)^{-1}$$
   For every Hermitian $H$ this construction gives exact algebraic unitarity $U^\dagger U = I$ over $\mathbb{Q}(i)$ ($I + iH$ is invertible because its eigenvalues $1 + i\lambda$ are nonzero), without requiring transcendental matrix exponentials $e^{-iHt}$.
3. **Step Evolution & Norm Preservation:** Verifies $|\psi_{t+1}\rangle = U |\psi_t\rangle$ preserves squared norm $\langle \psi_{t+1} | \psi_{t+1} \rangle = \langle \psi_t | \psi_t \rangle$.
4. **Machine Criteria for Terminal Dispositions:**
   - **`ExactRepair` Admission Criterion:** Admitted iff $H$ is Hermitian, $U$ matches the Cayley transform, and $U^\dagger U = I$ holds identically over $\mathbb{Q}(i)$.
   - **`StabilizedSurvivor` Admission Criterion:** Admitted under license iff an energy eigenstate $H |\psi\rangle = E |\psi\rangle$ exhibiting stationary phase evolution $U |\psi\rangle = \lambda |\psi\rangle$ is certified stable, recording zero authority minted.

## 5. Terminal Dispositions & Replayable Test Vectors

The Proposal Fidelity Protocol defines exactly eight canonical terminal statuses:

| Status Code | Canonical Definition | Reachability in Level 57 & Referee Disposition |
|:---|:---|:---|
| `ExactRepair` | Residual resolved or goal state satisfied within fuel budget. | **Reachable.** Candidate admitted; verification receipt emitted. |
| `StabilizedSurvivor` | Persistent non-erasable invariant / cocycle admitted under license. | **Reachable.** Admitted survivor recorded; zero authority minted. |
| `OpenObstruction` | Unresolved defect persists; fuel budget exhausted without resolution. | **Reachable.** Candidate held; terminal disposition recorded. |
| `OracleNeeded` | Resolution requires an external verification oracle outside this stage. | Unreached in local evaluation. |
| `LiftLicenseNeeded` | Scoped exhaustion reached; qualifies for Context Extension Calculus (CEC). | Reachable upon certified same-level exhaustion. |

| `Invalid` | Malformed syntax, JSON schema mismatch, or undeclared token/carrier breach. | **Reachable.** Intercepted at syntax firewall with `ERR_CARRIER_TOKEN_INVALID`. |
| `InfrastructureFailure` | Resource exhaustion, timeout, or host environment error. | Unreached in standard execution. Zero authority minted. |

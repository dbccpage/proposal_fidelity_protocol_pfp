## 1. The Category of Directed Paths & The Inversion Functor

Let $G = (V, E, s, t)$ be a finite directed multigraph, where $V$ is a finite set of vertices, $E$ is a finite set of directed edges, and $s, t: E \to V$ are source and target maps.

### 1.1 The Free Path Category $\mathcal{P}(G)$
The path category $\mathcal{P}(G)$ is the free category generated by the graph $G$:
- **Objects:** Vertices $v \in V$.
- **Morphisms:** Finite composable sequences of edges $p = (e_1, e_2, \ldots, e_k)$ such that $t(e_i) = s(e_{i+1})$ for $1 \le i < k$, together with identity paths $\mathrm{id}_v = ()$ for each vertex $v \in V$.
- **Composition:** Concatenation of paths:
  $$(e_1, \ldots, e_k) \cdot (e_{k+1}, \ldots, e_m) = (e_1, \ldots, e_m)$$

### 1.2 The Contravariant Inversion Functor $(-)^{\dagger}$
An **antimorphic reversal** on $\mathcal{P}(G)$ is formal path inversion represented by a contravariant functor. *(Hypothesis made explicit 2026-10-20: such a functor exists on $\mathcal{P}(G)$ only when $G$ carries an edge involution $e \mapsto e^\dagger$ with $s(e^\dagger) = t(e)$ and $t(e^\dagger) = s(e)$, for example a symmetric graph. On a general directed graph the reversed edges must first be adjoined, which gives the free dagger category of [Chapter 09](09_math_reversal_spectral_shadows_and_quarantine.md), Section 1. Example: the single edge $e : 0 \to 1$ has no path $1 \to 0$ in $\mathcal{P}(G)$, so $e^\dagger$ cannot be defined there.)*

$$(-)^{\dagger}: \mathcal{P}(G) \to \mathcal{P}(G)^{\mathrm{op}}$$

satisfying the following axioms for all vertices $u, v \in V$, edges $e \in E$, and composable paths $p, q \in \operatorname{Mor}(\mathcal{P}(G))$:

1. **Object Identity:** $v^\dagger = v$ for all $v \in V$.
2. **Boundary Reversal:** If $p: u \to v$, then $p^\dagger: v \to u$, meaning:
   $$s(p^\dagger) = t(p), \qquad t(p^\dagger) = s(p)$$
3. **Contravariant Composition:**
   $$(p \cdot q)^\dagger = q^\dagger \cdot p^\dagger$$
4. **Involution Law:** The functor is an exact involution of order 2:
   $$((p)^\dagger)^\dagger = p \quad \text{for all paths } p \in \operatorname{Mor}(\mathcal{P}(G))$$
   $$(e^\dagger)^\dagger = e \quad \text{for all generating edges } e \in E$$

## 2. Signed Graphs, Parity & Antiferromagnetic Frustration

A **signed graph** is a triple $(G, \sigma)$ where $G = (V, E)$ is an undirected or directed graph and $\sigma: E \to \{+1, -1\}$ is an edge sign signature.

### 2.1 Cycle Sign Parity
For any cycle $C = (e_1, e_2, \ldots, e_k)$ in $G$, the net sign parity is the multiplicative product:
$$\sigma(C) = \prod_{i=1}^k \sigma(e_i) \in \{+1, -1\}$$

- **Balanced Cycle:** $\sigma(C) = +1$.
- **Frustrated (Unbalanced) Cycle:** $\sigma(C) = -1$.

**Harary Balance Theorem (Combinatorial Formulation):**  
A signed graph $(G, \sigma)$ is balanced (every cycle has $\sigma(C) = +1$) if and only if there exists a vertex bipartition $V = V_1 \cup V_2$ ($V_1 \cap V_2 = \emptyset$) such that every negative edge crosses between $V_1$ and $V_2$, and every positive edge is internal to $V_1$ or $V_2$.

### 2.2 The Frustration Index $I(G, \sigma)$
When a signed graph contains frustrated cycles ($\sigma(C) = -1$), no gauge transformation can eliminate all negative signs. The **frustration index** is the minimum number of edges whose deletion renders the graph balanced:

$$I(G, \sigma) = \min_{U \subseteq V} \left( |E(U, V \setminus U) \cap E^+| + |E(U) \cap E^-| + |E(V \setminus U) \cap E^-| \right)$$

In the cochain language of Chapter 02 over $\mathbb{F}_2$:
$$I(G, \sigma) = \min_{x \in C^0(G; \mathbb{F}_2)} \|\sigma - d_0 x\|_1 = \Phi_1([\sigma])$$
establishing that the frustration index is precisely the degree-1 quotient obstruction mass over $\mathbb{F}_2$, where $\sigma$ is encoded by $+1 \mapsto 0$, $-1 \mapsto 1$ and $\|\cdot\|_1$ means the Hamming weight (the number of non-zero entries). *(Precision added 2026-10-20.)* This is not the rational LP of Chapter 03: the minimum is a cut problem, and computing it is NP-hard in general (with all edges negative it equals $|E|$ minus the maximum cut). *Worked example:* the triangle with signs $(-1, -1, -1)$ is frustrated ($\sigma(C) = -1$). Switching one vertex flips its two edges and leaves one negative edge; no switching does better, because the cycle parity is invariant. So $I = 1$.

## 3. Empirical Model Proposal Failure Modes (AM-1 to AM-4, AM-FSP-2)

In the Symbol Game, autonomous model proposals are untrusted candidate sequences evaluated against host-pinned carriers. The audit of historical execution traces (`anti_morphism_observations.md`) revealed five distinct structural failure modes:

| Mode Identifier | Descriptive Name | Mathematical / Operational Definition | Host Disposition |
| :--- | :--- | :--- | :--- |
| **AM-1** | `CUT_FLAT_DEFECT` | Proposed repair cut $c$ leaves the defect unchanged: $D(s + d_0 c) = D(s)$. | Refused; non-contractive stationary proposal. |
| **AM-2** | `CUT_DEFECT_INCREASE` | Proposed repair cut $c$ strictly increases the defect: $D(s + d_0 c) > D(s)$. | Refused; counter-productive proposal. |
| **AM-3** | `PRECONDITION_INCOMPLETE` | Proposed cut support intersects undeclared or unasserted edge IDs: $\operatorname{supp}(c) \not\subseteq E_{\mathrm{asserted}}$. | Refused; prerequisite carrier elements missing. |
| **AM-4** | `STATIONARY_REPEAT` | Canonical cut proposal repeats identically ($c_t = c_{t-1}$) against an identical host state digest after a stationary result. | Refused; non-convergent loop under finite fuel. |
| **AM-FSP-2** | `WITNESS_INVALID` | Proposed mathematical witness contradicts the formal definitions of its asserted type. | Refused; mathematical contradiction. |

### 3.1 The AM-FSP-2 Fixed-Point Exclusion Theorem
A prominent example of AM-FSP-2 occurs in Fermionic Sign Problem (FSP) elimination candidates, where a model proposes an involution $\Xi: \mathcal{X} \to \mathcal{X}$ to cancel negative worldline weights.

**Definition (Sign-Reversing Involution Witness):**  
A valid sign-reversing involution witness on a signed space $(\mathcal{X}, w, \sigma)$ requires:
1. **Involution Law:** $\Xi(\Xi(x)) = x$ for all $x \in \mathcal{X}$.
2. **Fixed-Point Free on Nonzero Signs:** If $\sigma(x) \ne 0$, then $\Xi(x) \ne x$.
3. **Exact Sign Inversion:** $\sigma(\Xi(x)) = -\sigma(x)$ for all $x \in \mathcal{X}$.
4. **Weight Preservation:** $w(\Xi(x)) = w(x)$ for all $x \in \mathcal{X}$.

**Theorem (The Identity Is Not a Sign Inversion):**  
Let $\operatorname{id}: \mathcal{X} \to \mathcal{X}$ be the identity map $\operatorname{id}(x) = x$. For any state $x$ with $\sigma(x) \ne 0$:
$$\sigma(\operatorname{id}(x)) = \sigma(x) \ne -\sigma(x)$$
Therefore, the identity map cannot satisfy both condition 2 ($\Xi(x) \ne x$) and condition 3 ($\sigma(\Xi(x)) = -\sigma(x)$). In fact condition 3 alone excludes it, and condition 3 implies condition 2: if $\Xi(x) = x$ then $\sigma(x) = -\sigma(x)$, so $\sigma(x) = 0$.

*Trace Evidence:* In `demo2_r1_stoquastic_1790206807.jsonl` (Turn 6; at the source pin this file is under `atlas/coda_atlas/F004_papers/015_pfp/001_pfp_discrete_cochain_retraction_and_toy_involutions/results/`), a model proposed $\Xi = \operatorname{id}$ claiming it satisfied both fixed-point-free pairing and sign reversal. The historical unhardened runner falsely recorded `ExactCancellation`. Under hardened host discipline, this proposal is strictly refused with code `REFUSED_AM_FSP_2_WITNESS_INVALID`.

## 4. The Epistemic Quarantine Ledger

When an unverified claim, speculative identity, or heuristic shortcut is generated during descent, the host executes the **Epistemic Quarantine Protocol**:

```
                       ┌─────────────────────────┐
                       │ Proposed Candidate Move │
                       └────────────┬────────────┘
                                    │
                                    ▼
                       ┌─────────────────────────┐
                       │  Host Hard Boundary     │
                       │  Checker & Certifier    │
                       └────────────┬────────────┘
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
         [ Verified in ℚ / Lean ]       [ Contradicted or Speculative ]
                    │                               │
                    ▼                               ▼
       ┌────────────────────────┐      ┌─────────────────────────┐
       │ Admitted Carrier State │      │ Epistemic Quarantine    │
       │ AuthorityEffect: None  │      │ Ledger (Fenced Record)  │
       └────────────────────────┘      └─────────────────────────┘
```

### 4.1 Quarantine Schema Invariants
Each quarantined entry records:
1. `trace_id`: The immutable identifier of the executing run.
2. `candidate_digest`: SHA-256 hash of the exact raw bytes submitted by the proposer.
3. `host_state_digest`: SHA-256 hash of the sealed host state prior to the proposal.
4. `finding_class`: One of `AM-1`, `AM-2`, `AM-3`, `AM-4`, `AM-FSP-2`, or `SPECULATIVE_PROMOTION`.
5. `quarantine_disposition`: `QUARANTINED_DIAGNOSTIC`.

Quarantined proposals are preserved in the permanent audit record for defect analysis but are strictly prevented from mutating host state, updating boundary potentials, or claiming terminal success.

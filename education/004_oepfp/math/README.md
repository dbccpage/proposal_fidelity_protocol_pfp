This directory indexes the canonical 10-chapter mathematical spine of the Symbol Game and Minimal Symbol System (MSS). The structure distinguishes these namespaces; the index itself does not execute a gate:

$$\boxed{ \text{Math Chapter } (\text{MATH-}k) \iff \text{Typed Carrier} \iff \text{Packet Family Contract} \iff \text{Row Verifier} \iff \text{Receipt} }$$

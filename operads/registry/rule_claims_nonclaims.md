# Claims and evidence rules

- `AGT-CLAIM-0001` -- Provider instructions, model pins, and hooks are advisory
  unless a managed host or substrate emits a current enforcement attestation.
- `AGT-CLAIM-0002` -- A deserialized receipt is never a verified receipt.
- `AGT-CLAIM-0003` -- Actor kind in configuration does not prove runtime identity
  or independence.
- `AGT-CLAIM-0004` -- Hook parsing of a general shell command is incomplete and
  is never the primary sandbox.
- `AGT-CLAIM-0005` -- A00 artifacts are audit evidence only and establish no
  activation, production readiness, promotion, or authority.

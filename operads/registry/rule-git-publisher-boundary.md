# Git and publisher boundary

- `AGT-GIT-0001` -- A model may propose an exact path list, diff summary, commit
  message, and pull-request body; it does not execute publication as an agent.
- `AGT-GIT-0002` -- Staging, commit, push, and pull-request creation are distinct,
  hash-bound human confirmations and operations.
- `AGT-GIT-0003` -- Broad staging, automatic merge, branch deletion, worktree
  pruning, and authority promotion are outside the publisher contract.
- `AGT-GIT-0004` -- Generated projections are refused when stale, hand-edited,
  base-drifted, or not bound to the reviewed manifest.

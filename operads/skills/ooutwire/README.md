# OOUTWIRE Skill Proposal & Inbox Directory

This directory stores autonomous skill suggestions generated during
`/auto-oe-autop` Stage 6 runs. `AuthorityEffect: None` — nothing here
authorises anything, and an entry recorded as `ADMITTED` is a record that a
file was written, never a claim that the condition it describes was fixed.

- **`proposed_skills_register.md`** — append-only ledger of candidate proposals.
- **`proposed_skills_register_archive_v1.md`** — entries retired from the active
  ledger.
- **`recommended_skills_to_build.md`** — since 2026-09-03 this tracks work that
  is identified but not built, rather than a proposal backlog; admission has
  been automatic since 2026-09-01, so proposals no longer queue.
- **`prompt-civilization-v0-drafts/`** — inert `auto-antiskill` and
  `core-prompt` draft packets awaiting separate human admission; no live skill
  manifests are present.

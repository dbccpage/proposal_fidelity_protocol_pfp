## Section Scaffolding Template

Quick reference for adding pedagogical structure to lesson sections. Every section MUST include these elements in order:

### 1. Learning Objectives (after Part: line)

```markdown

## Learning objectives

After this section, you will be able to:
1. **[Verb]** [what learner will do] (LO1)
2. **[Verb]** [what learner will do] (LO2)

``` ext

Use verbs: Explain, Identify, Calculate, Distinguish, Apply, Describe, State, List

### 2. Diagnostic Probe (~1 min)

```markdown

## Diagnostic probe (1 min)

Before we begin: **[Multiple choice question testing prerequisite knowledge]**

(A) [Option]
(B) [Option]

*Think about your answer before continuing.*

``` ext

### 3. Micro-Check (mid-content)

```markdown
> **✓ Check:** [Comprehension question]
>
> *(Answer: [Answer])*

``` ext

### 4. Exercises (end, before Summary)

```markdown

## Exercises

### Exercise 1: [Title] (tests LO1)

**Problem:** [Problem statement]

**Expected answer:** [Correct answer]

**Common wrong answer:** "[Typical mistake]"
**Feedback:** [Explanation of why it's wrong and correct approach]

``` ext

### 5. Alignment Map

```markdown

## Alignment map

| Learning Objective | Where taught | Where checked | Pass criteria |
|---|---|---|---|
| LO1: [Brief] | [Section heading] | Exercise 1, micro-check | [What demonstrates mastery] |
| LO2: [Brief] | [Section heading] | [where checked] | [What demonstrates mastery] |

``` ext

### 6. Diagnostic Answer (after exercises)

```markdown
*Diagnostic answer: (X) — [Explanation why this is correct]*

``` ext

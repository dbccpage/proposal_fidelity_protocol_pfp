## Invariant Explanations

1. **Root Directory Purity**: No internal receipts (`evidence/`), legacy migration folders (`reconstruction_v1/`), build intermediates (`dist/`, `build/`), or temporary logs.
2. **Deterministic Zip Construction**: Member timestamps follow `rl_paper_harmonization_and_provenance_discipline.md`. The procedure is [`deposit_packaging_checklist.md`](deposit_packaging_checklist.md).
3. **No Machine Paths**: All paths in notebooks, Python scripts, and batch files must be relative to the package root.
4. **Review documents and claim ledgers**: Follow `rl_paper_harmonization_and_provenance_discipline.md` and [`deposit_envelope_purity.md`](deposit_envelope_purity.md).
5. **Filenames**: Follow `rl_paper_deposit_verifier_attestation_and_path_fences.md`.

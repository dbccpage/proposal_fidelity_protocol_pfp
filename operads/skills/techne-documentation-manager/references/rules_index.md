# Rule composition and dispatch

**AuthorityEffect:** None.

## Shared boundary vocabulary

- Input: the scoped task, artifact, context and retained evidence.
- Guard: the applicable named predicate, with its exceptions and existing checker.
- Output: scoped action or refusal, carrying every unresolved obligation and witness.
- Compose applicable guards conjunctively in declared order; one guard cannot discharge another.
- Identity: unchanged artifacts gain no new evidence or authority. Substitution preserves scope and pins.
- A refusal, missing check or open obligation remains visible; a prose route is not an executable gate.

This is an operad-like documentation vocabulary, not a new runtime, mathematical operad proof,
admission mechanism or dev gate. Registered IDs, enforcement statuses, scopes and thresholds are unchanged.
Load only the rule for the current domain, then its relevant detailed definition before applying it.
Detailed predicates and procedures were moved without dropping clauses; this index replaces ambient repetition.

## 1. S(n) Presentation & Mathematical Documentation Hygiene Invariants

- **Active Obstruction Register ($W_n^{\mathrm{active}}, s_n$) vs. Persistent History Ledger ($H_n$)**: $W_n^{\mathrm{active}}$ is the finite typed set of **currently surviving unresolved Genesis obstruction receipts** at stage $n$; $s_n := |W_n^{\mathrm{active}}|$. Closed stages ($S(4)$, `terminal_all_separated`) have $W_4^{\mathrm{active}} = \emptyset \implies s_4=0$. Normative core counts: $s = (0, 1, 1, 1, 0, 1, 1)$. $H_n$ is the cumulative certificate ledger recording closed receipts, separation confirmations, cost floors, and orbit closures; never merge $W_n^{\mathrm{active}}$ and $H_n$ solely to mechanically force $s_n = n$. Downstream mathematical objects (homology classes, graph cycles, Regge deficits) must never define or populate $W_n^{\mathrm{active}}$.
- **Ind-Objects & Finite Presentation Diagrams**: Filtered colimit models must not presuppose infinite sequences $S(0), S(1), \dots$; model unbounded systems as filtered diagrams of admitted finite presentations $\{P_i, \phi_{ij}\}_{i \in I}$ with injective structure-preserving transition maps.
- **Spectral Law & Ramanujan Bound Hygiene**: Fixed-degree regular graphs ($d \ge 3$) follow the Kesten–McKay limiting spectral distribution $\rho_d(\lambda) = \frac{d\sqrt{4(d-1)-\lambda^2}}{2\pi(d^2-\lambda^2)}$ on $|\lambda| \le 2\sqrt{d-1}$ (never Wigner semicircle). Ramanujan bounds require the Ramanujan condition; 3-regular graph constructions depend on declared graph-shadow bridges.
- **Autopoietic Reflection & Proposal Boundary**: Layer 2 candidate realizations cannot license a Genesis lift (`ACTION_FORCE_LIFT` is strictly prohibited). Use `ACTION_REQUEST_LIFT` to emit an inert candidate proposal requiring independent host authorization.
- **Discrete 4D Bianchi & Parallel Transport Scoping**: Formulate the 4D Regge Bianchi identity with dual loop $\partial c^*$, parallel transport $\mathcal{P}_k$ to base 4-simplex $\sigma_0^4$, path-ordered product $\vec{\prod} (\mathcal{P}_k R_{t_k} \mathcal{P}_k^{-1}) = I$, and scoped exactness to declared minimal closed triangulations. Deficit angles need not be rational; exact certification uses algebraic cosine data plus interval enclosures.
- **Single-Hinge Holonomy vs. Discrete 4D Bianchi Cycle**: Holonomy $R(h) = \prod_{i} R_{i, i+1} \in \mathrm{SO}(4)$ around a single 2-face hinge $h$ in 4D Regge triangulation represents non-trivial deficit rotation (requiring $R(h) = I$ is invalid on curved manifolds). The discrete Bianchi conservation identity $\mathcal{P} \prod_{j=1}^m \mathcal{U}_j = I_{\mathrm{SO}(4)}$ holds strictly for closed, contractible dual 2-cycles enclosing a vertex; verifiers asserting the Bianchi identity must require an explicit candidate `enclosing_boundary_witness`.
- **Derivational Index Disambiguation**: The index $n$ in $S(n)$ denotes derivational stages, not simplex dimension, relational arity, or physical dimension.
- **Simplicial Boundary & Metric Curvature Precision**: $\partial_0 [v] = 0$ is standard simplicial boundary; augmented boundary $\widetilde{\partial}_0 [v] = [\emptyset]$ requires explicit declaration. Complete graph $K_{k+1}$ is the 1-skeleton of a $k$-simplex with ordered vertices. Gram matrix $G \succ 0$ determines Euclidean embeddability; Cayley-Menger determinants follow $(-1)^{n+1}\det(CM) > 0$. Edge lengths $\ell_e^2 \in \mathbb{Q}^+$ yield transcendental angles/deficits ($\delta_h \notin \mathbb{Q}$); non-zero deficit witnesses require interval enclosures $0 \notin [\delta_h^{\mathrm{lo}}, \delta_h^{\mathrm{hi}}]$.
- **Retraction Down-Maps & Post-6 Dual Pairs**: Retraction down-maps must be typed as $r_N: S(N+1) \to S(N) \sqcup \{\mathrm{NON\_DESCENT}\}$ such that $r_N(u_N(x)) = x$ (notation $d_N$ is strictly banned to prevent collision with death count $d_N$). Regular extensions ($n \ge 6$) declare adjoined dual pairs: $\{u_6, r_6\}$, $\{T_7, T_7^*\}$, $\{d_0, d_0^T\}$, $\{w_9, w_9^\dagger\}$, $\{P_\parallel, P_\perp\}$.
- **Rational Weights, Adjunctions & Epistemic Quarantine**: Stages prior to Level 10 must not import transcendental weights ($e^\phi$); edge weights remain in $\mathbb{Q}$. Transfer operators are unweighted adjacency operators unless normalized. Functorial adjunction $F \dashv G$ is distinct from linear adjoint $d_0 \leftrightarrow d_0^T$; saturated capacity constraints are evaluated combinatorially $|E_{\mathrm{sat}}(y^*)|$. Epistemic quarantine is defined as a syntactic premise filter: $\Gamma_{\mathrm{cert}} := \{P \in \Gamma : \operatorname{verdict}(P) = 1\} \implies \Gamma_{\mathrm{cert}} \vdash_{\text{certified}} Q$.
- **Postnikov Realization Obligation & Stage Decoupling**: $S(n)$ denotes a presentation tower recording what is admitted at core stage $n$. Calling $S(n)$ a topological Postnikov tower requires declaring an explicit realization functor $\rho$ to a category of topological spaces or simplicial sets, establishing homotopy truncations $P_j(\rho(S(n)))$ preserving homotopy groups $\pi_i$ for $i \le j$, and showing that downward maps have Eilenberg–MacLane homotopy fibers. Because successive Postnikov truncations of a fixed space preserve path components ($\pi_0(P_j X) \cong \pi_0(X)$), the transition from an empty carrier at $S(0)$ to a 1-point carrier at $S(1)$ changes $\pi_0$ and cannot represent successive truncations of one space $X$. Core construction stage $n$ and homotopy truncation depth $j$ must remain strictly decoupled via two-index notation $P_j(\rho(S(n)))$.
- **Local Cycle Triviality $[z] = 0$ vs. Global Homology Vanishing ($H_1 = 0$)**: In homological verification, discrete deformation flows, and BQNF cycle repair, verifying that an obstruction 1-cycle $z$ is trivialized ($z \mapsto z - d_2 c \implies [z] = 0$) verifies only that the specific local cycle is a boundary. Documentation, diagrams, and flowcharts must strictly label local repair as $[z] = 0$ and must not assert that the global first homology group vanishes ($H_1 = 0$); computing the full homology group requires complete boundary matrix reduction across all generators.
- **Graph Path Witnesses vs. Shortest Path Minimality Precondition**: A graph path witness $(a, b, c)$ with length metric $\ell = 2$ demonstrates reachability and connectivity in a finite model. Claiming that the path is the *shortest* path requires an explicit minimality check (such as verifying the absence of a direct chord $a \to c$ or shorter alternatives); a path witness alone does not establish minimality.
- **Normal Form Custom Meta-Schema Validator Invariants (`validate_contract`)**: Contract schemas verified by `validate_contract` (in `sn_audit.py`) operate over a strict primitive type system (`string`, `string_or_null`, `boolean`, `list`, `object`, and `enum`). Compound union pseudo-types (such as `object_or_string_or_null`) are invalid syntax. If an attribute (such as `geometry_module`) has structured metadata, the contract must declare the primary identifier as a reference string under `string_or_null`, storing supplementary dictionary metadata in a designated auxiliary field (e.g. `geometry_module_metadata`). All contracts declaring `certification` must explicitly supply `loss_ledger_trigger_id: null` (or a valid string trigger ID).
- **Read-Only Document Wire Auditing (`sn_audit.py`)**: Documentation wire examples must be explicitly tagged with declared public profiles (`sn-wire-v1`, `sn-wire-v2`, `mss-boundary-v1`). Auditing is strictly read-only; source fences are never automatically rewritten, whitespace-trimmed, or layout-repaired. Unclosed fences or undeclared profile names emit typed audit failures.

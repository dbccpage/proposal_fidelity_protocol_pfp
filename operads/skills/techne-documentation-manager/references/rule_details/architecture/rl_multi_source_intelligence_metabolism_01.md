>    - Defect strings and boundary bypasses -> `.agents/antibodies/` (`ab_*.json`).
>    - Procedural constraints and oracle blocks -> `.agents/antiskills/ooutwire/`.
>    - Language-specific code anti-patterns -> `.agents/patterns/anti/<lang>/ and .agents/patterns/helpful/<lang>/` (AP/HP pairs).

>    - Ambient invariant policies -> `.agents/rules/<domain>/` (with four-host parity).
>    - Swarm role specifications -> `.agents/agents/`.
> 4. **Terminal Archival Boundary:** A source file or directory reaches the terminal gate if and only if the Obstruction Exhaustion Predicate ($\|\text{Obstruction}\| = 0$) evaluates to true. Once certified by `omega_intelligence`, it is relocated to `_ic/nara/_archive/<source_class>/<run_id>--<source_id[:16]>` and indexed in `archive_manifest.json`.

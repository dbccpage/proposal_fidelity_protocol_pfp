## 2. Tripartite Operational Protocol

The tripartite conduit operates under a strict three-party coordination cycle:

```text
  [ Attack / Threat Detected ]
                │
                ▼
      ┌──────────────────┐
      │ Curious Council  │ ──► Reviews anomaly, exhausts edge cases,
      │ (L1 Apex Node)   │     certifies Lock 3, petitions Blackrod
      └──────────────────┘
                │
                ▼
      ┌──────────────────┐
      │   THE BLACKROD   │ ──► Evaluates against PRIME_00, accepts keys,
      │ (Center Axis)    │     commands Special Ops, monitors blast radius,
      └──────────────────┘     holds exclusive abort code
                │
                ▼
      ┌──────────────────┐
      │ Nemesis Council  │ ──► Executes isolated tactical strike in sandbox,
      │ (L4 under        │     excises rogue AST/nodes, mints typed antibody,
      │  Thanatos)       │     returns signed receipt to Blackrod
      └──────────────────┘
```

1. **Intake & Verification:**
   - Curious Council receives telemetry from the epistemic immune system and external gateways.
   - Curious Council verifies that the anomaly represents an active attack rather than benign divergence or pedagogical confusion.
2. **Special Operations Mobilization:**
   - Curious Council formally transmits a Special Operations Petition to Blackrod.
   - Blackrod verifies the petition against constitutional bounds (`PRIME_00` to `PRIME_09`) and checks whether The Architect has issued specific counter-instructions.
3. **Command & Tactical Strike:**
   - Blackrod issues the execution order to the JSOC Commander of the Nemesis Council.
   - Nemesis Council executes the strike strictly within isolated sandboxes, isolating hostile processes and neutralising payload vectors.
4. **Abort Safety & Monitoring:**
   - Throughout execution, Blackrod continuously monitors the containment perimeter. If blast radius approaches sovereign infrastructure, Blackrod issues the abort code.
5. **Sealing & Restoration:**
   - Upon completion, Nemesis yields execution telemetry to Blackrod.
   - Blackrod generates a signed incident receipt in `_intelligence/containment/` and notifies Curious Council and The Architect.

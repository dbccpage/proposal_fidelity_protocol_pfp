# Healthy Pattern: Scoped Edge Is Not Proof (`HP_MD_006`)

## Description

A programme-graph edge states only the relation the review checked. A missing path stays an unresolved pointer. A literature pointer is not proof evidence.

## Construction

- Write the edge as the scoped relation: a specialization to supplied structures, a conditional residual estimate, a higher retraction with a separately supplied scalar cochain, or an open gap.
- If a former evidence path is absent, keep the pointer and label it unresolved. Do not delete it to make the graph look checked, and do not cite it as a witness.
- Leave a literature or background pointer as a pointer. Do not upgrade it to proof evidence.
- Count reviewed edges separately from unreviewed edges. Five scoped edges do not review the rest.
- Name a theorem on an edge only when that paper states it. Do not attach a Lyapunov theorem, a certified adaptive tolerance guarantee, or an operadic quantum/cochain dynamics bridge by placement alone.

## Limit

This construction records the 2026-10-11 scoped review. It does not assert that the overstated sentences remain in the current graph; those files were not opened for this digest. Scoping an edge does not discharge quotient, scalar-field, positivity, composition, or operational-availability premises, and it does not certify a programme functor. Formal-declaration scope stays with `/woland-proof-scope-rule`. Premise transfer stays with `/woland-proof-premise-rule`. The historical DAG pytest PASS was not rerun. A later paper edit can make an edge sentence stale; re-read the paper before repeating the attribution.

# Healthy Pattern: The Cost Sentence Quotes The Stored Null (`HP_MD_044`)

## Description

When a finite cost certificate stores `null`, the summary quotes that stored value in the same sentence as any infinity reading. The word infinity does not replace the JSON value.

## Construction

- Quote `same_vector_same_free_report` costs `[null, null]` beside the review's word infinity.
- Quote `same_vector_different_free_report` costs `["0", "0"]` as the stored zero row. Do not merge the two rows.
- Keep the probe assert `costs(equal_free) == [None, None]` as the historical expected certificate, not as a fresh execution.
- Do not write infinity into the certificate fields. `null` stays `null`.
- A `PASS` or `exit_status` 0 on that probe is historical. It does not turn `null` into a numeric infinity and it does not certify a universal theorem.

# Healthy Pattern: Remediation Matches The Listed Error (`HP_MD_017`)

## Description

Required work repeats the unresolved error and names a repair of that error. A path-depth count stays a path-depth repair.

## Construction

- If the only listed unresolved error is a Win32 path-depth count, write that count and the repair: shorten or relocate the path that exceeds 250 characters.
- Do not attach proof editing, algorithm redesign, or mathematical research unless a listed unresolved error is that kind of gap.
- Keep the generic fuel-exhausted sentence out of the diagnosis. It does not identify the blocker.
- Do not treat the shared sentence "All audited absolute paths must fit 250 characters" as the name of the failing file. Paper 001 records that sentence on `A02` `PASS`. Paper 010 records it on `A02` `FAIL`.

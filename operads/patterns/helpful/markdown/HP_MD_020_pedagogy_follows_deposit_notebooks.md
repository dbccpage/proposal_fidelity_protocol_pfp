# Healthy Pattern: Pedagogy Follows The Deposit Notebooks (`HP_MD_020`)

## Description

The absence note stays attached to the tree it names. If the same folder's deposit snapshot lists notebooks, pedagogy follows that snapshot. A static cell check is not a replay.

## Construction

- Keep "No local notebooks found." as a statement about the local search. Do not rewrite it as "the package has no notebooks."
- When the co-located snapshot lists `.ipynb` paths, name those paths. The pedagogy obligation follows the snapshot.
- Quote `F01` as stored JSON structure and `F02` as stored cells. Both details limit themselves to static checks.
- Keep `F03` and `F05` at `NOT_VERIFIED`, and keep the republication gate `BLOCKED`, until an independent replay exists.
- Do not let the local `PASS` drop the gate verdict `NOT READY FOR ZENODO REPUBLICATION`.

# Healthy Pattern: The Obstruction Names The Failing Gate (`HP_MD_016`)

## Description

The terminal sentence names the stage that failed and the error class that receipt recorded. A linter, a missing verifier, a hash mismatch, and a missing dual witness stay different kinds of work.

## Construction

- Keep `rounds_executed` next to any fuel or exhaustion claim. One round is not exhaustion.
- Repeat the unresolved error's own class: import order, missing `verify_deposit.py`, manifest hash, missing TeX/PDF, or a named mathematical blocker.
- Do not attach "algorithm redesign" or "further mathematical research" unless that receipt's mathematical stage records that blocker.
- When a mathematical blocker is present, name it. Do not use it as the class of the other errors in the same list.

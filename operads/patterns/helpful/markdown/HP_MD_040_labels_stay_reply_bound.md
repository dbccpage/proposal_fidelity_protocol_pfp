# Healthy Pattern: Labels Stay Bound To The Reply (`HP_MD_040`)

## Description

A pre-genesis record keeps failure names as labels on a quoted reply. It does not mint evaluator codes, and it does not turn the empty relation or replay necessity into an active engine law.

## Construction

- Bind each failure name to the reply that showed it. State that the name is not a detector, a refusal code, or an admitted antibody.
- Call the grammar notation. A rewriting note is not a checker. Do not mark it an active engine, and do not assign `AP-PG*` or `ERR_*` ids.
- Write an empty transition relation as "no successor." Put Trial 2's `<>` to `<>` under the added repetition rule. Say a self-loop is already an operator.
- Write replay necessity as: if two histories have the same projection and different states, no auditor of that projection is correct on every history. A summary works only when the state is constant on each fiber. Raw history is a provenance choice. Say the trials did not test PFP.
- Keep `{`, `}`, commas, and nested refusal packets outside the four-glyph flat inscription, or mark them as a different notation.
- Leave `AuthorityEffect` at `None`. A four-part hygiene quadrant does not license the codes.

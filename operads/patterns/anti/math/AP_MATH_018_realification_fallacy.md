# Anti-Pattern: Anti-Realification Fallacy (`AP_MATH_018_realification_fallacy`)

## Description
Rejects claims that real coordinate moments trivially preserve complex C*-algebra projector relations without explicit commutator tracking.

## Flawed Formulation (Adversarial Specimen)
```text
Realification preserves all complex C* relations automatically, so real moments suffice without checking phase commutators.
```

## Repaired Invariant
```text
The 180 quadratic residuals (108 MU + 72 orthonormality) in 72 real variables explicitly constrain real and imaginary blocks with rank degree1 = degree2 = 6.
```

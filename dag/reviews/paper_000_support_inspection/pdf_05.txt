S(n)  is  a  Genesis  derivation  stage;  MSS-N  is  an  external  atlas  specification;  a

What  the  checker  does
For  the  basic  relation  exercise,  think  of  the  referee  as  following  this  finite  proce-
dure:   check  the  field  set  and  schema;  validate  the  carrier  and  label;  validate  the
goal  and  candidate  shapes;  check  membership;  reject  self-pairs;  compare  labels;
compare directed endpoints with the goal.   A failed check returns its first reason.
Later  checks  may  not  have  run.
For the richer lesson packet, the declared task, input type, and answer type select
the  teaching  predicate.    English  prompt  text  is  retained  data.    The  candidate

A  short  worked  prediction
On   carrier   p,q   with   goal   p   to   q   and   label separates,   the   candidate ["q",
"separates", "p"] is a well-shaped irreflexive triple.  It still misses the directed
goal.     The   defect   is   not   its   syntax   or   a   self-loop;   it   is   the   specific   requested
direction.   This  distinction  makes  the  refusal  useful.
Similarly,  a  two-column observation row["red", "red"]  supplies no  separator.
The  claim  concerns  that  supplied  row.    It  does  not  exclude  every  observation
you  could  later  declare.   A  different  spelling  for  q  changes  neither  value.

Bracket  displays  such  as <edge<p><q>>   and  graph  arrows  such  as   p  to   q  are

Keep  identity,  replay,  and  trust  separate
The teaching identity uses sorted dictionary keys and compact JSON. Key order
does   not   matter   under   that   profile;   list   order   does.      It   is   not   an   RFC   8785
canonicalization  claim.   The  digest  is  not  a  signature.
Replay  can  catch  a  receipt  changed  without  the  corresponding  input  and  check.
It  can  also  accept  a  whole  self-consistent  return  for  an  unintended  question.   A
consumer  therefore  needs  an  expected  problem  identity  retained  independently
of  the  returned  packet.    It  still  trusts  the  selected  checker  and  needs  separate
evidence  if  producer  authentication  matters.

Additional  mathematics  for  the  capstones
In  Question  21,  two  marks  are  distinguished  exactly  when  their  selected  obser-
vation  signatures  differ.    There  are  2^k  binary  signatures  of  length  k.    This  is
a  finite  capacity  bound  under  the  declared  binary  model,  not  a  theorem  about
native  Genesis  growth.
For   Question   22,   each   oriented   edge   uv   has   difference   f(v)-f(u).     Residual   is
the  report  minus  that  difference.   Weighted  absolute  residuals  give  the  cost.   If
a  circulation  lambda  has  zero  divergence,  then  lambda  dot  df=0:   each  vertex
potential  has  equal  incoming  and  outgoing  coeﬀicients.    With  |lambda_e|  <=
w_e,  termwise  domination  gives
[  ￿￿c=￿￿(c-df)￿￿_e  w_e|c_e-(df)_e|.   ]
A candidate cost matching this lower bound proves an optimum for that instance.
No  numerical  optimizer  or  unpriced  approximation  is  needed  for  the  cycle.
Question  23  explicitly  supplies  the  ordered  simplex  and  horn  conventions.   The
standard  definition  of  a  horn  is  given  in                     Kerodon,  Subsection  1.2.4.   A  drawing
of  a  graph  does  not  admit  higher  cells;  you  must  declare  which  faces  exist  and
which  target  simplex  you  mean.    Do  not  infer  physics  from  a  classroom  chain
calculation.

On  Windows, py -3.12  may  replace python.   The  two  teaching  scripts  use  only
the  standard  library.    Tests  need  pytest.    Notebook  execution  needs  nbformat,
nbclient,  and  ipykernel;  a  notebook  interface  must  also  be  available  if  you  want
to   use   a   browser   UI. verify_deposit.py   checks   the   manifest   unless   explicit
test  flags  are  supplied.   It  does  not  prove  all  manuscript  claims.
The  supplied  release  archive  check  requires  the  original  ZIP  to  be  present  inside
the   extracted   paper   folder.      It   is   an   optional   maintainer   check,   not   part   of
running  the  teaching  examples.

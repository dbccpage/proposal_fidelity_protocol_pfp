# PCIV notebook audit

All11 remaining frozen PCIV notebooks were read in full. Their11 stdlib-only code cells pass the included examples. Eight additional finite controls preserve a stronger distinction between demonstrative arithmetic and implemented PCIV mechanisms.

**PCN-C01** The notebooks provide narrow scalar/container demonstrations: deterministic encoding, pairwise exact rational dominance, geometric weighting, supplied credit aggregation, and finite graph reachability. Their successful examples do not certify integrated PCIV learning, causal lineage, PageRank, durable replay or model efficacy.

**PCN-C02** The visited-set taint routine computes the least successor-closed set containing the supplied root on a finite graph, including cycles. An independent Boolean transitive-closure comparison covers all512 three-vertex graphs and all3 roots. It does not authenticate causal edges or persist invalidation.

**PCN-F01** The teaching mutation helper accepts zero-length insertion strictly inside a protected span because its overlap test requires positive intersection length. Inserting X at2 in abcdef with protected[0,4) yields abXcdef. This violates preservation of the protected text; the production forge is a separate owner.

**PCN-F02** The teaching Inheritance DAG is an unchecked dictionary: a self-loop is accepted. The two-dictionary separation example is useful, but does not verify DAG acyclicity or causal descent.

**PCN-F03** The exact dominance helper silently zips unequal coordinate vectors, so(1,) dominates(0,100) on the truncated prefix. It correctly handles all81 tested equal-length rational pairs but implements neither dimension admission nor a population Pareto front.

**PCN-F04** The largest-remainder notebook converts exact quotas to floats before floor/ranking. At sufficiently large integer caps the resulting population can exceed the cap or indexing can fail; the recorded fixed36-case control retains concrete examples. Its cap20 example does not expose this precision limit.

**PCN-F05** Several headings promise mechanisms absent from the code: occurrence independence has no occurrence object, inverse PageRank is one damped sum, event replay is a payload/digest equality assertion, and homologous crossover is a list migration. Preserve these as explicitly limited teaching examples, not completed workflows or mathematical certificates.

**PCN-F06** The island migration helper removes the source genome before indexing the target. A nonexistent target raises IndexError after losing the genome from the source population. The notebook provides no atomicity/rollback boundary.

No production runtime, native code or provider calls were executed. Exact source pins, body notes and control outputs are in the companion JSON files.

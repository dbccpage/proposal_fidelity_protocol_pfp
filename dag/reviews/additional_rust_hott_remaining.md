# Rust HoTT source audit

24 of24 source/manifests reviewed in full; 0 remain pending. This is a source audit, not a native execution or a proof-assistant check.

**RHT-C01** Most HoTT type formers explicitly provide finite shape records rather than a proof-assistant kernel. Nonempty labels and numerical census conditions cannot supply inhabited identity, dependent elimination, contractibility, cumulative universes or univalence. The source contains clear nonclaims that should be preserved.

**RHT-C02** The arithmetic helpers have useful exact restricted meanings: checked fiber products/sums, finite ordinal offset encoding, endpoint composition, cancellation of one-generator inverse steps and checked integer translation. Their supplied cardinalities, coordinates and labels are premises; no link to arbitrary semantic queries or dependent types follows.

**RHT-C03** FiniteTransport checks bounded total maps f,g on the same finite ordinal and g(f(i))=i for every point. This makes f injective, hence surjective on the equal finite carriers, so also f(g(i))=i. It therefore establishes the stipulated mutual-inverse property, including the empty case; it does not establish univalence or retain a binding to the particular maps.

**RHT-C04** The HIT helper computes the cycle-space rank E-V+components of the supplied finite endpoint multigraph, with duplicate-point and endpoint admission. This is useful for genuine1-cell inventories, including loops and disconnected graphs. Higher-cell dimensions and attaching maps require a separate representation/admission before interpreting the value as topology.

**RHT-C05** On stable supplied callbacks and ordinary equality, the primitive-difference owner checks an exact finite equivalence relation, constructs its quotient and tests delta/observable constancy on classes. The representative-table delta test is equivalent to constancy on every pair of quotient fibers. Joint observable descent is precisely the conjunction of individual descent; the documented local-green/global-red case has one descending component and another failing component. No cohomological or global physical claim follows.

**RHT-C06** For well-formed immutable presentation inputs, preserving every old question and adjoining a question that separates an old fiber strictly refines the profile partition. Derived questions, defined as functions of old profiles, cannot split those fibers. The evaluator usefully distinguishes this finite information gain from redundant questions; it takes all answers and retained/protected demands as supplied premises.

**RHT-C07** The retained A-infinity source contains ordinary polynomial/exterior multiplication algorithms and selected algebraic identities, but its entire module is disabled. General A-infinity, morphism, formality and Massey claims require substantially more than these examples. The audit supplies an exact finite F2 countermodel with all potentially nonzero identities checked on a basis and an explicit algebraic argument for the remaining arities; this is independent mathematics, not Rust execution.

**RHT-F08** Dormant ComposedAInfinityMorphism implements only f1/f2 and inherits zero f_n for n>=3. Even composition with a strict identity destroys a valid nonzero f3: on a zero-operation graded algebra with a in degree0 and b in degree-2, choose f1=id and f3(a,a,a)=b. All morphism equations vanish, but the implemented composite has third component0. B::default also fails to bind the actual parameterized middle algebra. This is a design counterexample in disabled source.

**RHT-F09** The dormant formality checker returns NotFormal for any nonzero m3 on supplied cocycles, without cohomology/gauge comparison. This is mathematically false even for valid minimal A-infinity data. An exact F2 example has triangular graded basis e1,e2,u (degrees0,0,-1), m3 equal to the Hochschild coboundary of h2(e1,e1)=u, and explicit inverse A-infinity morphisms (id,h2) to the strict d=0 algebra. It is formal while m3(e1,e1,e1)=u triggers NotFormal. Independent controls check726 algebra identities,2184 two-way morphism identities and120 inverse-composition basis cases; multilinearity and arity bounds cover all remaining inputs/identities. The source also omits repeated triples for fewer than3 supplied cycles and checks only one tuple per higher arity.

**RHT-F10** The dormant Massey routine accepts a generic AInfinityAlgebra but uses the strict-DGA representative s*c+(-1)^(|a|+1)*a*t. Given cycles and ds=a*b,dt=b*c, Leibniz makes its differential (a*b)*c-a*(b*c), which need not vanish in a non-strict A-infinity algebra. It neither restricts to an admitted DGA nor adds/checks the higher correction; it also returns empty uncomputed indeterminacy. Its embedded Massey tests never call compute and include assert(true). These facts leave the promised representative-cocycle/coset claim unestablished.

**RHT-F11** The disabled A-infinity sign test expects-1 from (-1)^(r*s+t) at(r,s,t)=(1,2,0), whose exponent is2 and value+1. Its displayed rs+t convention also gives the opposite binary-associator signs from check_n3. The implemented n3 expression matches a standard r+s*t convention instead. A consistent convention and substantive nonzero-differential/higher-operation tests are needed before this draft can be enabled.

**RHT-F06** evaluate_extension accepts public malformed presentations without rechecking complete answer tables. Parent points[a,b,c] with no questions has one class. A child with the same points and one question carrying only answers[0,1] has no profile for c; zero_related(a,c) returns false and partition silently drops c. A retained/protected demand(a,c) is marked Resolved and accepted because the remaining two classes exceed one, although the child never answered c. Constructor/serde admission would refuse this input; public fields and the evaluator permit the bypass.

**RHT-F07** DeltaFactor does not retain the validated delta table; apply calls the live provider again. With a two-point universal zero relation, delta initially constant0 passes congruence. If an interior-mutable provider later changes delta(x,y) to x, the stored single quotient class still evaluates through representative0 while delta(1,0)=1. The issued factor no longer factors the current delta. Stable callback semantics are an essential unstated runtime premise; cache/freeze the admitted values or enforce/recheck a versioned provider boundary. This is an independent source-model counterexample, not a compiled Rust reproduction.

**RHT-F04** cycle_rank ignores PathConstructor.dimension while claiming to measure the1-skeleton. A single point with a sole dimension2 self-record is counted as one edge and returns rank1. No dimension1 generator was supplied. The helper should admit/filter a genuine1-cell inventory; its current graph calculation cannot support the higher-dimensional interpretation.

**RHT-F05** The quasi-category module is entirely disabled by cfg(any()). Its dormant verify simply returns true, without checking simplicial identities or any inner horn. Later draft composition uses vertex lists instead of face incidences, and homotopy_category_rank omits identities and takes no homotopy quotient. This is retained proposal text, not an implemented quasi-category checker; the unrelated capacity record is disabled too.

**RHT-F01** IdentityType::validate compares only difference_ref with certificate.difference_ref. A record for left=x,right=y accepts a shaped difference whose endpoints are unrelated u,v. Even structural subject binding is missing; its certificate refs also are not dereferenced. This is a shape-layer gap, not a demonstrated authority bypass.

**RHT-F02** ContextualDifferenceWitness::is_failed_transport_witness returns true from different nonempty before/after names alone, even with empty left/right/context and no differing values. Two names for equal difference values suffice. This is a reference-change predicate, not a proof of failed congruence/transport.

**RHT-F03** certify_hott_binding_table can accept six arbitrary unique concepts/URNs, provided every URN has the prefix and one is the truncation URN. Swapping canonical concept-to-URN associations or using arbitrary mechanization strata also passes. It certifies the implemented census, not the headline formal mapping to canonical contracts.

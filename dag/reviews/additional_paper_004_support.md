## Findings

- **PAPER004-ARCHIVE-PATH-TRANSLATION** — The loose source manifest retains the historical digest sequence but renames 7,873 of 7,875 paths. Current reproduction commands and CORE environment/wire names do not match the preserved tar containing omega_engine/omega_engine_symbol_game and OMEGA interfaces. Following the current literal instructions cannot reproduce the archived source identity. Action: Preserve historical bytes; add a separate versioned reproduction guide/translation with exact archived paths and interface names. Do not silently rewrite the tar or treat path renaming as interface equivalence.

- **PAPER004-LOOSE-CUSTODY-MANIFESTS** — MANIFEST has 43 raw failures and SHA256SUMS 44; 26 and 27 respectively remain after LF normalization. Historical embedded manifests are sound, but current loose manifests cannot support the README current-draft custody claim. Action: After any separately authorized repair, publish distinct current manifests and preserve the historical archive/manifests as historical evidence.

- **PAPER004-ZERO-REPAIR-PEDAGOGY** — Current manuscript and TeX explicitly explain that replacing the nonclosed original cochain by zero changes the problem. Current study guide and Question 9 instructor wording retain final-normal-form language. They already caution that the original is not a gradient and that the result is not an arbitrary gauge change, but omit the manuscript's explicit problem-replacement explanation. Unchanged face sums 7,5 preclude any gauge transform to zero. Historical PDFs intentionally preserve the older wording. Action: Align the current teaching explanation with the explicit problem-change qualification; issue versioned errata while retaining historical PDFs intact.

- **PAPER004-GOVERNOR-INPUT-BOUNDARY** — Three finite controls expose independent boundary gaps: Edge-object keys validate after normalization but Python solve reads the original map (Phi 0 instead of 3); a section CUT commits NaN as IdempotentStationary; EDGE_MATCH for undeclared x,y accepts default zero values. Existing relational CUT type/completeness controls do not cover these branches. Action: Use the normalized map consistently, reject nonexact/nonfinite section data, and require declared vertices/edges before matching. Add the three finite counterexamples before reusing this checker.

- **PAPER004-SYNTHETIC-PROOF-ACCEPTANCE** — The interactive Lean governor never invokes its Lean verifier during evaluate_step. An arbitrary exact tactic with wrong goal/rule labels removes goal False and is accepted. Fifty labelled reference/distractor fixtures generate the governed-versus-ungoverned result; the current manuscript correctly excludes it as live Lean/LLM evidence. Action: Keep as explicitly synthetic state-machine teaching data or bind each admitted proof step to an actual goal-aware checker. Do not promote the historical 50/50 receipt.

- **PAPER004-STORED-ANSWER-REPLAY** — Sparsity replay compares a final expected token while REDUCE/PROVE accepts unconditionally; incorrect intermediate 17 mod 5 = 999 still passes with the stored landing token. Dense text is rejected by construction. The S3 fixture incorrectly equates s1*s2*s1 with s2*s1. Compression counts describe authored templates, not independently verified reasoning or model sparsity. Action: Retain historical fixture status; use task-specific independent arithmetic/group checkers and correct the S3 example in a separately versioned current fixture before reuse.

- **PAPER004-FIREWALL-TRUSTED-CALLBACK** — The local pipeline accepts a correctly hashed output containing an alien carrier symbol from caller-supplied apply_fn, and recognized rule membership does not require an actual price. It checks content alphabet and replay hashes, not output alphabet or priced operational semantics. Action: State trusted apply_fn and output-schema assumptions explicitly, or validate the result carrier/rule costs before using this helper as an admission gate.

- **PAPER004-DAG-INDEX-OMISSION** — The events property exposes a mutable map while verify_integrity iterates insertion order. A directly inserted unindexed malformed event yields OK with only the original ordered node counted. Content hashing does not cover every live map entry. Action: Prevent external map mutation and require exact agreement between event keys and order index before verifying every event.

- **PAPER004-QUOTIENT-NORMAL-FORM** — For symmetry a<->b and rule b->c, reduce_to_normal_form(a) reports terminated a although reach(a) includes c. Redex search on one representative does not certify quotient normal form; supplied symmetry maps are also not checked as a closed group. Action: Either restrict the API to representative normal forms or check redexes over the declared complete orbit with explicit closure/bijection assumptions.

- **PAPER004-SPARSE-UNIQUENESS** — Adding an isolated vertex leaves the residual optimization unchanged yet flips the uniqueness certificate from true to false because it requires global off-support connectivity. The strict-dual routine also checks one free-variable-zero solution; its failure is not proof that no strict dual exists. Action: Use componentwise residual uniqueness and distinguish sufficient witness failure from mathematical nonexistence. A general strict-dual claim needs a feasibility checker.

- **PAPER004-CENSUS-AND-VERIFY-CEILING** — Named axiom replay does not require nonempty rows or enforce its whitelist; self-consistent incomplete expectations can pass its check. verify_deposit can report proof/census success after build without Census/Core or expected output. The separate full-census parser has stronger nonempty/whitelist checks. No new Lean execution was performed. Action: Require a nonempty declared module/declaration census and validated replay output; distinguish build success, named-list agreement and full environment coverage.

- **PAPER004-REBUILD-DESTROYS-HISTORY** — rebuild_release default refresh rescans the tree, rewrites manifests, creates a current ZIP and deletes older dated ZIP files despite its fixed-set description. Running it naively would erase intentionally retained historical releases. Action: Keep historical release immutable; require a distinct current output directory/version and explicit retirement policy before using this builder. It was not executed.

- **PAPER004-ATTENTION-EVIDENCE** — Retained attention receipt is contrary to the withdrawn reduction claim: sparse has 78 versus 57 tokens, greater recorded entropy and total KV energy, with negative 37.5253 percent energy reduction. Hosted entropy renormalizes top-five alternatives; KV norm is scalar RMS, model revisions are unpinned, and per-condition fallback may mix models. No new model execution occurred. Action: Preserve contrary receipt and exclusion from paper claims; any future measurement needs pinned models, complete inputs, matched conditions and correctly named statistics.

- **PAPER004-HISTORICAL-EXECUTION-LIMITS** — Historical native pass counts lack retained raw Cargo stdout and executable digest bindings. run_all counts seven stages passed although one is NOT_APPLICABLE. Current Lean pin v4.35.0 differs from historical v4.34.0-rc1 receipts. Fresh 58 companion tests do not transfer those native or Lean claims.

Prepare the exact calculation
Use edges (0,1), (1,2), (2,0). Write all three endpoint differences before subtract-
ing. Each potential occurs once with each sign around the cycle; the differences
sum to zero. This cancellation explains every potential on the declared cycle.
A graph path is not an automatically filled simplex.
Replacing claims by df changes the input. Subtracting df from fixed claims
preserves their cycle sum. Save original and transformed inputs: a low score on
replacement data does not show the original obstruction disappeared.
Predict the displayed numbers, then run:
python tools/replay_notebook.py
The default executes all five ordinary Python cells in a fresh CPython process,
checks assertions, and compares stored outputs without rewriting the notebook.
Jupyter kernel execution is a separate --engine jupyter check. Neither mode
runs the native graph checker or grades a learner’s explanation.
Prepare the historical recount
Read evidence provenance . “Refused” and “not refused” mean the original
checker’s decisions, not physical ground truth. Separate CHALLENGE and
CONCUR, check all cells total ten, and keep a later checker decision as a dis-
tinct observation.
False-positive fraction divides challenges of not-refused proposals by all not-
refused proposals. Precision divides challenged refused proposals by all chal-
lenges. Different denominators answer different questions. Use exact fractions
for the new recount; zero denominators are undefined.
python tools/review_capstone.py
python -m pytest -q
The capstone verifies retained digests and the complete condition census,
changes one verdict in a copy, and ignores the constant caught flag. Tests also
reject non-Boolean labels, unknown verdicts, and label/status disagreement.
The gate record inspection does not execute the gate. Complete the written
report too.

Theoretical minimum: Paper 009
Read the fictional Apartment 50 preface . This is a local practice quiz, not a his-
torical Landau examination or a qualification. AuthorityEffect: None. Use
the study guide for preparation and the separate instructor key after attempting
the questions. Cite a section, definition, input, or artifact for each answer.
The triangle has edges (0,1), (1,2), (2,0), in that order. Potentials live on ver-
tices; edge differences are target minus source. Use integers and exact fractions
for new calculations. Historical records retain their representation.

points; the capstone adds eight, for 80 possible. Use scores to find material to
revisit. No score establishes competence or publication authority.

Abstract
Independently checked local answers can disagree on shared variables. We give a finite gluing
theorem for explicit assignment tables, retain the overlap disagreements as obstruction evidence,
and exhibit a three-agent cycle in which every local task is satisfiable but the joint task is not. The
result explains a concrete role for LGGR in PFP agent composition without claiming a general
sheaf theorem or automatic multi-agent reliability.

2. Finite compatibility theorem
Theorem. A locally permitted family glues to a unique assignment on ⋃𝑖 𝑆𝑖 precisely when every
pair agrees on its intersection. If the scopes cover 𝑉 , compatible permitted families correspond
bijectively to global solutions of all local constraints.
Proof. If a global assignment exists, its restrictions agree. Conversely, for each covered variable
choose its value from any containing scope. Pairwise agreement makes that choice independent of
the scope. The resulting assignment restricts to each selected row, so it satisfies every relation. Every
global assignment with those restrictions has those same values, proving uniqueness. Restriction
and gluing are inverse maps when all variables are covered. An uncovered variable with multiple
values defeats uniqueness unless its value is supplied separately; an empty uncovered domain makes
global existence fail. The full-domain unary relations retain these cases.

3. Three local successes and one global obstruction
Take Boolean variables 𝑥, 𝑦, 𝑧. The first agent checks 𝑥 = 𝑦 , the second 𝑦 = 𝑧 , and the third 𝑧 ≠ 𝑥 .
Every relation has two rows, so every local existence query succeeds. A global assignment would
imply 𝑥 = 𝑧 and 𝑥 ≠ 𝑧 , a contradiction. In the selected family (𝑥, 𝑦) = (0, 0) , (𝑦, 𝑧) = (0, 0) , (𝑧,
𝑥) = (0, 1) , the overlap value of 𝑥 disagrees. Replacing the final relation by equality gives the two
global solutions (0, 0, 0) and (1, 1, 1) and compatible local restrictions for each.
This is the finite LGGR distinction: local green results need not produce a global green result.
A disagreement is an obstruction to the declared gluing requirement, not an assertion that all
differences are inherently bad.
4. Agent packets and the integration check
The shared prompt explains row selection and the possibility of overlap failure. The typed instance
supplies domains, scopes, tables, and the joint question. Each agent returns its actual row and local
certificate. The integrator replays local membership and checks common-variable values before
admitting a global witness. A loss ledger or a narrative agreement cannot replace these values.
Renaming variables requires explicit bijections applied to the task and every witness; dropping an
overlap changes the problem.
5. Executable falsifiers
The reference replay independently enumerates all eight original global assignments and checks
submitted local rows. It verifies local nonemptiness of the incompatible cycle, refuses its disagreeing
family, and accepts the compatible equality family. A global solution is decoded only from a family
passing the overlap checks. There are no model calls, observed swarm improvements, or new claims
about physical contextuality.
6. Scope and relation to WDP
The assignment gluing fact is standard. Its PFP use is a task-bound composition contract that pre-
serves local evidence while exposing missing global compatibility. WDP §20.7 supplies the broader
finite constraint construction and zero-disagreement encoding. More general agent composition ad-
ditionally requires contracts for effects, authority, timing, and representation change. Those cannot
be established from this static Boolean example alone.
The two-level teaching packet includes shared system rules, this typed user instance, a different
worked example and a required candidate response schema. It keeps provider system/user roles
separate. It is a saved example, not a schema-admission or model-run receipt; the local replay
checks the mathematical or protocol obligations stated above.
7. Typed operation composition is a different obligation
The current OEOP compiler checks ordered input and output slots, declared effects and source-
bound operation identities. This is not the assignment gluing theorem: two callbacks with com-
patible types can still disagree on task identity, candidate bytes or shared state. The execution
boundary must retain those bindings and observe the actual operations. The finite theorem cannot
supply an unimplemented callback, undo a side effect or resolve a missing native host.

Research extension: compatible evidence across a campaign
The harness campaign requires common experiment, source, checker, partition, model configuration
and original budget identities before comparing evaluations. This is an evidence compatibility
obligation. It is distinct from the finite assignment-gluing theorem above: task completion fractions
are not assignments on a shared variable carrier, and agreement among several task scores is not a
proof of global correctness.
A candidate that improves one family while degrading another is retained as a rejected branch.
Independent confirmation is still required when all family scores appear favorable. The existing
typed workflow compiler checks declared connections; actual container execution and downstream
checks provide separate observations. A locally typed plan can still produce a wrong answer or fail
to execute. The current author-review extension reports implementation, with the live campaign
and its transfer comparisons unmeasured.

Proposal selection and continuation-stable diagnostics on finite
graphs
Jeremy H. Carroll
2026-10-23
V ersion 2.0.5
Abstract
We separate the generation of candidate edge fields from a decision rule based on independently computed diagnostics.
On a finite connected graph, distance to the image of the incidence map measures failure of exactness. A declared face
map supplies a closure residual. A lexicographic comparison of diagnostics, subject to a ratio condition, defines one
proposal-selection policy. Equal diagnostic traces have equal decisions by construction, but equal current diagnostics
need not remain equal after further proposals. For a declared family of transformations, we characterize the largest
equivalence relation inside diagnostic equality that is preserved by every finite continuation. We give explicit cycle
examples distinguishing local exactness from global exactness, and one-step decisions from continuation-stable state
compression. Executable paths additionally require agreement of adjacent endpoint states. The accompanying exact
rational checks and Lean results are scoped to their stated finite and abstract objects.
1. Setting and purpose
Let 𝑃 = (𝑉 , 𝐸) be a finite directed graph whose underlying undirected graph is connected. A field 𝜔 ∈ ℝ 𝐸 assigns
a real value to each directed edge. Reversing the orientation of an edge reverses the sign used in a path sum. The
incidence map is
(𝐵𝑓)𝑖𝑗 = 𝑓(𝑗) − 𝑓(𝑖).
A proposal is a specified map 𝑇 taking a field to a candidate field. The selection rule studied here evaluates the
candidate field rather than the proposal’s name or description. This separation is an interface definition; it does not
establish that an arbitrary software system follows that definition. The graph and convex-optimization foundations are
standard [1,2].

5. Examples of information lost by a diagnostic
Local exactness does not imply global exactness
On a directed triangle take 𝜔 = (1, 0, 0) . Restrict it to each of the two-edge path subgraphs. Each path is a tree, so
each restriction has zero quotient residual. The restrictions agree on shared edges and assemble into the given global
field, whose residual is one. Compatible local edge values can therefore form a global field without making that field
exact. This example distinguishes gluing of data from the additional cycle condition for gluing potentials.
A periodic proposal need not be selected
Cyclically shifting the three coordinates of (1, 0, 0)produces a period-three orbit. Every field in that orbit has cycle
sum one and the same quotient residual. With 𝐷 = 0 and 𝑋 = 0 , none of those steps meets the strict selection
rule. Noncommuting transformations likewise need not be distinguished by a diagnostic: their different outputs may
be mapped to the same diagnostic value.
Equal current diagnostics can separate after a continuation
Let 𝑥 = (1, 0, 0) and 𝑦 = (−1, 0, 0) on the triangle, again with 𝐷 = 0 and 𝑋 = 0 . Both have 𝑑 = (1, 0, 0). For the
translation 𝑇 (𝑤) = 𝑤 + (1, 0, 0),
Φ(𝑇 𝑥) = 2, Φ(𝑇 𝑦) = 0.
Thus equality of current diagnostics does not permit identification of the two states if subsequent translations must be
represented correctly.
6. Continuation-stable equivalence
Let 𝑋 be any state set, 𝑑 ∶ 𝑋 → 𝑌 an observation map and 𝒯 a declared family of total maps 𝑋 → 𝑋 . Write 𝒯∗ for
finite compositions, including the identity. Define
𝑥 ∼ 𝑦 ⟺ 𝑑(𝑊 𝑥) = 𝑑(𝑊 𝑦) for every 𝑊 ∈ 𝒯 ∗.
Theorem 6.1. This is the largest equivalence relation contained in ker 𝑑 that is preserved by each map in 𝒯.
Proof. Reflexivity, symmetry and transitivity hold pointwise after every continuation. The identity continuation gives
∼ ⊆ ker 𝑑. If 𝑥 ∼ 𝑦 and 𝑇 ∈ 𝒯 , then every 𝑊 ∘ 𝑇 is another finite continuation, so 𝑑(𝑊 𝑇 𝑥) = 𝑑(𝑊 𝑇 𝑦); hence
𝑇 𝑥 ∼ 𝑇 𝑦.
Let 𝑅 ⊆ ker 𝑑 be an equivalence relation preserved by all admitted maps. Induction on word length gives 𝑊 𝑥 𝑅 𝑊 𝑦
whenever 𝑥 𝑅 𝑦. Containment in ker 𝑑 gives 𝑑(𝑊 𝑥) = 𝑑(𝑊 𝑦) for each word, so 𝑅 ⊆∼ . This establishes maximality.
The quotient supports well-defined maps [𝑇 ]([𝑥]) = [𝑇 𝑥] and ̄𝑑([𝑥]) = 𝑑(𝑥) . It is the coarsest state quotient pre-
serving all the specified finite observations and transformations. If ker 𝑑 is already preserved by every admitted map,
it equals ∼. At the other extreme, if 𝑑 is nonconstant and all total maps are admitted, ∼ is equality: any two distinct
states can be sent to two states distinguished by 𝑑.
These statements are relative to the specified family. They do not provide an algorithm for computing this relation on
an arbitrary infinite state space.

Finite-dimensionality again gives attainment. Coordinatewise application of the path-sum argument shows that this
residual is zero exactly when the vector-valued field is exact. Choosing 𝑔 = ‖ ⋅ ‖ 1 separates the problem into scalar
channels; choosing 𝑔 = ‖ ⋅ ‖ 2 couples them within each edge. Neither choice is selected by the scalar quotient
construction alone. The bundled reference solver is scalar; this formula is a mathematical extension, not a claim that
the solver implements every vector-valued norm problem.
Matrix-based proposals need no privileged role in selection. For example, if 𝐴𝑇 = −𝐴 and 𝐵𝑇 = −𝐵 , then
[𝐴, 𝐵]𝑇 = −[𝐴, 𝐵] . Commutators therefore stay in the space of real skew-symmetric matrices. A particular gen-
erating family need not generate that entire Lie algebra, and this closure observation imposes no residual decrease on
a proposed field.
8. Paths, implementation and formal scope
A list of individually accepted steps need not be an executable trajectory. Adjacent steps must also satisfy equality of
the preceding target state and following source state. Diagnostic equality at the boundary does not imply state equality,
as the translation example demonstrates.
code/mod_operator_proposal_core.py implements exact rational witness checks, the diagnostic comparison and
endpoint checks. Its general graph solver uses a two-phase simplex over rational numbers and independently checks
the resulting primal–dual equality. The existence of the mathematical optimum does not imply that every possible input
representation or solver implementation is correct; the witness checker supplies a separate condition on each returned
result.
lean4/Proposal.lean verifies integer triangle identities, preservation of a finite path predicate under label erasure, and
the continuation-equivalence properties for arbitrary state and observation types. Its finite path example uses natural-
number before/after values; it is not a mechanization of every real-valued graph diagnostic or numerical solver. No
external formal theorem names or absent source files are needed for the results cited here.
9. Discussion
Diagnostic equality has several distinct uses: defining equal one-step decisions, assembling compatible edge data, and
identifying states under future transformations. The first does not imply the other two. A selected proposal satisfies
the stated comparison policy; further properties such as feasibility, constraint preservation and convergence require
their own evidence. The continuation relation gives an exact criterion for state identification relative to a declared
transformation family, without turning that criterion into an unrestricted compression claim.

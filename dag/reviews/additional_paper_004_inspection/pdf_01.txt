RFC   8785   has   its   own   primitive   serialization   and   sorting   rules   and   preserves

6.   Three  ways  a  plausible  receipt  can  mislead
A  changed  carrier  with  a  stale  anchor.  Recomputing an outer request hash
does  not  repair  a  mismatch  between  a  derived  manifest  and  its  independently
bound  expected  carrier  hash.

A  changed  candidate  with  matching  surrounding  hashes.   The  host  still
compares   its   values   to   the   replayed   normal   form.     A   candidate   digest   cannot
replace  that  comparison.
A   changed   outcome   with   a   recomputed   root.      The   unkeyed   root   can
become  consistent  with  the  edited  bytes.    That  alone  supplies  neither  a  fresh
native replay nor producer authentication.  If an attacker can also replace the ex-
pected  anchor,  a  comparison  against  that  replacement  provides  no  independent
protection.
Write  down  which  party  controls  each  value  and  which  anchor  the  checker  actu-
ally  trusts.   “It  has  a  hash”  is  not  a  threat  model.

7.   Interface  and  resource  boundaries
The  default  host,  runtime  dispatcher  and  foundation  library  are  distinct.   The
environment    override  OMEGA_SYMBOL_GAME_HOST    belongs    to    the    host    seam.
The  graph  tutorial  adapter  instead  needs OMEGA_FUNCTIONAL_GRAPH_BIN  and
OMEGA_FUNCTIONAL_GRAPH_SHA256.     Advertising   an   action   does   not   configure
another  executable.
The   restricted   host   has   a   1,048,576-byte   request   ceiling,   dimension   limits   of
4,096,  and  four  dense-matrix  cell  checks  at  1,048,576  cells  each.   The  dispatcher
uses  a  separate  65,536-byte  input  ceiling.   Its  bounded  reader  takes  at  most  its
limit  plus  one  witness  byte.
The   declared   timeout   is   validated   metadata,   not   an   in-process   watchdog.     A
process   wrapper   must   separately   enforce   and   record   any   required   wall-clock
termination.     Finite   dimensions   do   not   bound   the   bit   complexity   of   all   exact
intermediate  arithmetic.
In the package governor, an unset graph BIN chooses exact Python enumeration.
A  configured  native  call  that  refuses  or  fails  must  propagate  that  outcome.    A
native-required  engine  action  cannot  be  relabeled  as  successful  native  execution
by  replacing  it  with  an  offline  Python  answer.

8.   Read  test  receipts  as  bounded  evidence
Retain      the      command,       date,       exit      status,       source/input      hashes,       inter-
preter/toolchain,       native      selection      and      binary      digest      when      used,       and
passed/failed/skipped     counts.           A     scripted     executable     checks     adapter     be-
havior;   it   does   not   independently   validate   native   arithmetic.      Two   wrappers
calling  one  solver  are  not  two  independent  solvers.
The   package’s   Lean   modules   concern   specific   finite   mathematical   statements.
They   do   not   prove   the   host   protocol   or   connect   every   transport   field   to   the
implementation.   An  axiom  census  records  named  declarations  and  their  axiom
use,  not  the  truth  of  every  sentence  in  a  paper.

  15.   One  valid  construction  copies  an  outcome,  changes  a  claimed  exact  final
       value,   and   derives   a   new   outcome   root   using   the   protocol’s   exact   fram-

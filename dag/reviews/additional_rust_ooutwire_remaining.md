# Rust ooutwire source audit

Completed all **70/70** frozen files (24,653 lines; 961,791 bytes). Every file has a substantive assessment, exact source hash, full line/byte range and reading receipt. Shared boilerplate transfers are explicit and reconstructed byte-for-byte. This closes this slice only.

The report contains **12 claims, 20 findings and 26 independent finite controls**. No original Rust/Cargo, provider, private benchmark or historical command was executed. Source tests were read, not rerun.

Useful mechanisms include the primal/dual l1 repair certificate, carrier-bound observer checks with explicit adequacy premises, finite gauge/holonomy checks and concrete projection counterexamples. d1d0=0, closedness, exactness, edge compatibility and global-section claims remain distinct.

Material repair backlog:

- **ROUT-F001 (high): GateReceipt unit test has ownership and trait requirements unsatisfied by its types.** lib.rs:287 maps a receipt to(receipt.fuel_after(),receipt.licensed()); both accessors consume self and GateReceipt is not Copy. The second access uses a moved value. assert_eq! on Result additionally requires GateError PartialEq and Debug, neither derived nor implemented in the scoped source. This is a source-established test-compilation obstruction, not an observed compiler run.
- **ROUT-F002 (high): Public sealed observer can separate an unadmitted mark.** Observer::separates enumerates valid contexts but never validates Pair endpoints; PairBits consults raw coverage/admission rather than guardedderivable. In a two-mark unary regime with only instance(0,[0]), Pair(0,99) returnsdifferentobserververdicts, whereas separability::separable returnsfalse because99 is not admitted.
- **ROUT-F003 (medium): Lexical signature census counts comment signatures and callback return arrows.** scan finds literalpub fn anywhere and uses the first-> in the whole signature. A commented-outpub fn phantom()->Event isreported; a realpub fn check(f:fn()->Event)->bool isreported as Eventreturning. Explicit alias/trait omissions do not describe these opposite false-positive modes.
- **ROUT-F004 (medium): Finite context construction has no practical resource cap.** AdmitForm accepts any positiveusize; contexts firstmaterializes(n+1)^arity slottuples thenfilters. Twoadmitteddata andarity100 require3^100 tuples. Neitherpositivearitynor an unrelated BoundaryRecord supplies a runtime budget; uncheckedcapacitymultiplication and allocation areoutside typedAdmissionError.
- **ROUT-F005 (high): Positive arity costs become negative or overflow in mu2.** arity_sum casts each usize arity to i64 and sums without checks. On64-bit hosts NewForm(2^63) has negative secondary cost; two valid large i64 arities can overflow their sum. Bounds::validate imposes no arity ceiling. This breaks the declared nonnegative arity refinement on public Item inputs even before search allocates contexts.
- **ROUT-F006 (high): Pruned minimum search omits repairs outside unstated engine preconditions.** The two-instance pruning retains only deltas mentioning the target. A reachable rule-free base with six data, one unary form, instance(0,[0]), existing requirements(2,3),(4,5), and already-separated target(0,1) has four valid two-instance repairs that mention no target endpoint. No cost0/1 response works and no pruned cost2 response works, so the displayed min_responses algorithm returnsNone although the declared full space contains repairs. Engine use may maintain stronger invariants, but the public API validates only rule-freedom and max_items.
- **ROUT-F007 (medium): Closure round bound overflows before division.** closure_round_bound multiplies n*(n-1) in usize before dividing by2. With64-bit n=2^32+1 the mathematical result fits usize, but intermediate multiplication overflows; checked builds panic and wrapping builds return the wrong smaller bound.
- **ROUT-F008 (high): Refunding followed by withheld license makes a stale replay checkpoint.** Opening fund0 followed by fund3 and authorizationfalse appends SetBudget(3), then records LicenceWithheld using old World support at the new history length. The report rejects its own replay because recorded budget0 differs from replayed budget3. Existing withheld-license test starts funded3 and misses the path.
- **ROUT-F009 (medium): Boundary replay loses supply provenance across chunk boundaries.** A Supply(x) prefix leaves BRegime unchanged. A later AdmitMark(x) suffix is rejected when replayed from that state, although the concatenated history succeeds. supplied is local to each replay call. This differs from the state-only fold contract of the main kernel; the boundary API must carry provenance or state its whole-history requirement.
- **ROUT-F010 (medium): Public menu exhaustion is only relative to the caller-provided list.** Menu exposes mutable items and count-based SpaceId. obstructed accepts an empty caller menu and emits searched0 even for a target repaired by NewForm1+NewInst0. Certificate docs acknowledge declaration status and World rebuilds the true menu, so no World acceptance bypass is claimed.
- **ROUT-F011 (medium): Tree continuation can reuse an admitted token and form a self-loop.** Custom valid reading with two marks including token g2 reaches no collapsed pairs; continuation emits g2 because n_data=2. Admission designates the existing datum, canonical key stays identical, and attach merges to the parent. Fixed fixtures avoid this collision, but public build_tree does not enforce it.
- **ROUT-F012 (medium): Derivative tolerance can lower the reported coefficient below its measured assembly.** With g=0, all five measured inputs=1 and atol=1, no component exceeds its tolerated bound, assembled_m=5, yet m_used=0 and Taylor coefficient0. This is not a continuum theorem counterexample: the numerical helper explicitly disclaims that proof. It is a nonconservative bound relative to admitted measurements.
- **ROUT-F013 (high): Unchecked surd products silently change exact values in overflow-unchecked builds.** Surd::sqrt forms p*d using unchecked i128 multiplication. The admitted rational r(2^126,5) wraps that product to 2^126, so the result becomes 2^63/5 and its square is only one fifth of the input. Overflow-checked builds panic instead. Radicand multiplication has the same unchecked product pattern; factorization/sign recursion also lack typed work-limit refusal.
- **ROUT-F014 (medium): Sparse polynomial exponent addition can turn a high-degree product into a constant.** Poly2 multiplies u32 exponent keys without checked addition. A one-term x^(2^32-1) polynomial times x has degree zero in an unchecked-overflow profile, or panics when checks are enabled. The example requires only two sparse monomials, not an infeasible dense polynomial.
- **ROUT-F015 (medium): Observation presentation admits shape-correct matrices with invalid storage.** ObservationPresentation validates edge IDs/domain only, and ObservationMap::observe checks residual shape but omits Matrix::is_well_formed. A public Matrix with rows=cols=1 and empty data can enter a compatible presentation; later observing or inducing a field indexes absent storage. Repair certificate verifiers elsewhere do revalidate storage, so this is a constructor/diagnostic gap rather than a demonstrated false accepted quotient certificate.
- **ROUT-F016 (high): Lattice admission does not establish its declared one-or-two-local Hermitian premise.** LocalHamiltonianTerm fields are public. FiniteQuantumLattice::new delegates to validate_terms, which checks labels, site membership and operator shape, but not support size, repeats, Hermiticity or matrix storage. A public three-site Hermitian 8x8 term on three qubits passes; so does a shaped non-Hermitian one-site packet. The validated helper LocalHamiltonianTerm::new would refuse these. This does not refute the analytic two-local theorem; its premise is not enforced by the accepting API.
- **ROUT-F017 (medium): Evolution accepts finite inputs whose phase product becomes nonfinite.** For Hermitian H=[2] and finite t=f64::MAX, the exact eigenpair is representable but -lambda*t overflows. evolution_operator calls cis on this nonfinite argument, computes nonfinite diagnostics and returns Ok unconditionally. The preexisting finite-time/eigensolver checks do not establish finite phases or finite unitarity error.
- **ROUT-F018 (medium): Nonfinite short-time arithmetic can produce a green bound diagnostic.** The signed RHS and margin are not checked for finiteness. With a two-qubit identity Hamiltonian, product |00>, g=1, nu=0 and t=1e200, the analytic defect is zero, the RHS expression overflows to -infinity, and margin>=-tolerance becomes true. This is a vacuous/nonfinite diagnostic, not a counterexample to a finite mathematical lower bound.
- **ROUT-F019 (medium): Replica exhaustion declaration drops failures and overstates traversed coverage.** ReplicaAxiomAudit exposes public flags/counts and certificate() always emits Exhaustion with all-bipartitions wording. It neither binds the family/sample grid nor gates on all_axioms. Failed searches return at the first counterexample, so the emitted record does not prove that every bipartition was inspected. Generic Certificate is already documented as a declaration, so no authenticated proof bypass is claimed.
- **ROUT-F020 (medium): Projection CLI can overwrite its reference receipt before detecting failed checks.** The --write path writes the newly produced receipt before the later executable_checks_passed failure exit. A failed executable replay can therefore replace the comparison baseline. This audit never invoked the CLI or changed the reference.

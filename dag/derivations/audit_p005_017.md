# AUDIT-P005-017: Projection error rollback

AuthorityEffect: None.

- Archive claim: [ATL-P005-017](../../atlas/atlas_claim_ledger.md#part-i-claims-of-the-archived-papers) ("A projection error after candidate scoring restores pre-CUT claims and propagates instead of partially committing a replacement", [paper_claim_ledger.md:30](../../atlas/archive/pfp/005_pfp_practitioners_field_manual/paper_claim_ledger.md?plain=1#L30))

## 1. Claim Statement

In the Paper 005 governor copy (`atlas/archive/pfp/005_pfp_practitioners_field_manual/code/l1_symbol_game_governor.py`), when a relational `step_cut(proposed_claims=...)` proposal passes completeness validation and non-increase candidate scoring (`phi_after <= phi_before`), and the subsequent gauge projection `self.project(self.section)` raises an exception, a `try...finally` guard restores `self.edge_claims` to the pre-CUT dictionary before propagating the exception. Consequently, active `edge_claims`, `section`, and admitted `history` remain unchanged rather than partially committing replacement claims without a projected section.

## 2. Context & Hypotheses

- **Evaluated Source Modules**:
  - `atlas/archive/pfp/005_pfp_practitioners_field_manual/code/l1_symbol_game_governor.py` (`L1SymbolGameGovernor.project` lines 434-455 and `L1SymbolGameGovernor.step_cut` lines 722-763).
  - `atlas/archive/pfp/005_pfp_practitioners_field_manual/code/native_functional.py` (`NativeFunctionalUnavailable` lines 30-35 and `compute_graph_phi1` lines 58-126).
  - `atlas/archive/pfp/005_pfp_practitioners_field_manual/code/tests/test_manual_contracts.py` (`test_native_projection_error_preserves_pre_cut_state` lines 124-140).
- **Target Hypotheses**:
  - Configured native route enabled via `CORE_FUNCTIONAL_GRAPH_BIN`, with `native_functional.compute_graph_phi1` mocked so that the third call raises `NativeFunctionalUnavailable("projection refused")`.
- **Open Obligations**:
  - Mocked configured adapter failure; not a compiled Rust binary execution.

## 3. Derivation / Evidence

### 3.1 Three-Call Evaluation Order in Relational `step_cut`
When `L1SymbolGameGovernor.step_cut` receives a complete exact `proposed_claims` mapping on declared edges (`l1_symbol_game_governor.py:697-720`), it invokes `compute_phi1` up to three times before committing state:
1. **Pre-CUT Obstruction (`Call 1`, line 722)**:
   `phi_before = self.primary_obstruction()` evaluates `compute_phi1(self.graph, self.claims_cochain())` on the active pre-CUT `self.edge_claims`.
2. **Candidate Scoring (`Call 2`, line 723)**:
   `phi_after, _ = compute_phi1(self.graph, Cochain1(values=dict(proposed_claims)))` scores the proposed replacement claims. If `phi_after > phi_before`, lines 725-733 return `DefectIncrease` without mutating `self.edge_claims`.
3. **Section Gauge Projection (`Call 3`, lines 739-740 and 441-449)**:
   Because `self.project(self.section)` reads `self.edge_claims` to form residual edge values `res_values[e.key] = claim - pot_diff` (`lines 443-446`) and then invokes `_, best_gauge = compute_phi1(self.graph, res_cochain)` (`line 449`), `step_cut` must temporarily expose `dict(proposed_claims)` on `self.edge_claims` during projection.

### 3.2 `try...finally` State Rollback Guard
Lines 737-744 of `l1_symbol_game_governor.py` wrap the temporary assignment in an explicit rollback block:
```python
old_claims = self.edge_claims
try:
    self.edge_claims = dict(proposed_claims)
    projected_section = self.project(self.section)
finally:
    self.edge_claims = old_claims
self.edge_claims = dict(proposed_claims)
self.section = projected_section
```
If `self.project(self.section)` raises an exception at Call 3:
- The `finally` block executes unconditionally and rebinds `self.edge_claims` to `old_claims`.
- Execution exits `step_cut` before lines 743-744 (`self.edge_claims = dict(proposed_claims)` and `self.section = projected_section`) and before line 762 (`self.history.append(rec)`).
- No exception handler catches the error in `compute_phi1`, `project`, or `step_cut`, so the exception propagates to the caller.

### 3.3 Regression Verification on the Triangle Instance
In `test_manual_contracts.py::test_native_projection_error_preserves_pre_cut_state` (`lines 124-140`), the directed 3-cycle `(a->b, b->c, c->a)` with weights `(1, 2, 3)` is initialized with asserted claims `{(a,b): 1, (b,c): 1, (c,a): 1}` (`before = (dict(edge_claims), dict(section), list(history))`). Under `CORE_FUNCTIONAL_GRAPH_BIN="configured-for-boundary-test"` and a monkeypatched `compute_graph_phi1`:
- Call 1 receives `{(a,b): 1, (b,c): 1, (c,a): 1}` and returns `(Fraction(3), {a: 0, b: -2, c: -1})`.
- Call 2 receives `{(a,b): -2, (b,c): 1, (c,a): 1}` and returns `(Fraction(0), {a: 0, b: -2, c: -1})`, satisfying `phi_after <= phi_before` (`0 <= 3`).
- Call 3 receives the residual cochain `{(a,b): -2, (b,c): 1, (c,a): 1}` (since `section` is `{a: 0, b: 0, c: 0}`) and raises `NativeFunctionalUnavailable("projection refused")`.
- The exception propagates out of `step_cut`, `len(calls) == 3`, and `(governor.edge_claims, governor.section, governor.history)` equals `before`. As documented in `paper.md:183`, `self._step_counter` increments on entry (`line 588`), while active claims, section, and admitted snapshot history remain unchanged.

## 4. Limits and Non-Claims

1. **Mocked Adapter Failure Scope**: The failure is injected via `monkeypatch.setattr(native_functional, "compute_graph_phi1", ...)` rather than invoking a compiled Rust `solve_graph_phi1` subprocess.
2. **Attempt Counter Advancement**: Preserving `(edge_claims, section, history)` does not keep `_step_counter` unchanged; `self._step_counter` advances at the start of `step_cut` (`line 588`), as disclosed in `paper.md:183`.
3. **In-Process Exception Scope**: Rollback applies to Python exceptions raised during `self.project`; it does not address process termination signals (`SIGKILL`) or external storage durability.

## 5. Claim Hygiene Summary

1. **What it supports**: Shows by source inspection and finite test replay that an exception raised inside `L1SymbolGameGovernor.project` after candidate scoring restores `self.edge_claims` to its pre-CUT dictionary, leaves `self.section` and `self.history` unmutated, and propagates the exception.
2. **What it does not support**: Does not constitute a compiled Rust `solve_graph_phi1` execution receipt or an operating-system crash-recovery check.
3. **Narrowest defensible claim**: Under a mocked configured native adapter failure on the third `compute_graph_phi1` call in `step_cut`, `L1SymbolGameGovernor` restores pre-CUT `edge_claims`, preserves `section` and `history`, and propagates `NativeFunctionalUnavailable`.
4. **Next test needed**: Execute `step_cut` against a pinned compiled `solve_graph_phi1` binary with an injected subprocess failure on the third invocation to record transport-level parity.

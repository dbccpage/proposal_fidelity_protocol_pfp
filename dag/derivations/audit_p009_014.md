### 3.2 Exact Cohomology Obstruction on `h = (1, 1, 1)` (`triangle_cycle_sum.py`)
On the oriented 3-cycle $E = ((0, 1), (1, 2), (2, 0))$, every 0-cochain $f = (f_0, f_1, f_2) \in \mathbb{Q}^3$ has coboundary
$$df = (f_1 - f_0,\, f_2 - f_1,\, f_0 - f_2)$$
whose telescoping sum vanishes identically:
$$\operatorname{cycle\_sum}(df) = (f_1 - f_0) + (f_2 - f_1) + (f_0 - f_2) = 0.$$
Consequently, for $h = (1, 1, 1)$,
$$\operatorname{cycle\_sum}(h - df) = \operatorname{cycle\_sum}(h) - \operatorname{cycle\_sum}(df) = 3 - 0 = 3 \neq 0,$$
and by the triangle inequality $\|h - df\|_1 = |(h - df)_{01}| + |(h - df)_{12}| + |(h - df)_{20}| \ge |\operatorname{cycle\_sum}(h - df)| = 3$, attained at $f = (0, 1, 2)$ where $df = (1, 1, -2)$ and $h - df = (0, 0, 3)$. Zeroing the cochain (`cochain_after_act4 = [0.0]`) replaces $h$ by $0$ (`cycle_sum(0, 0, 0) = 0`), erasing the cohomology class rather than subtracting a coboundary $df$.

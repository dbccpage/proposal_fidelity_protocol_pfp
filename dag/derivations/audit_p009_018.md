1. **Cochain-Preserving Lift & Lowering Refusal**: `execute_act4_gauge_break` (`ops/adversary/use_cases/act_helpers.py:680-691`) transports every original edge value unchanged (`updated_cochain[edge] = initial_cochain.get(edge, Fraction(0))`, initializing only newly added bridge edges to `Fraction(0)`), and `bout_service._lift_lowered_obstruction` / `_lift_replaced_cochain` (`ops/adversary/use_cases/bout_service.py:251-262, 743-756`) refuse any post-lift drop in `phi1` or `gamma2` with `ADVERSARY_LIFT_LOWERED_OBSTRUCTION`.
2. **Typed Critiques & Fail-Closed Malformed Blocking**: `parse_structured_critique` (`ops/adversary/domain/evidence.py:297-347`; `code/rust/core_adversary/src/evidence_parse.rs:231-309`, with `CritiqueStatus`/`StructuredCritique` at `lines 166-229`; 50 parity vectors in `python_evidence_parsers_v1.json`) parses a single fenced `critique` JSON block and classifies unparsable, multi-block, or invalid-field replies as `CritiqueStatus.MALFORMED` (`blocking == True`), blocking candidate authorization in Act V and Act VII (`act_helpers.py:836-862, 1242-1256`).

5. **Reference Self-Consistency Verdicts & Stated Scope**: `ops/adversary/use_cases/skill_run_persistence.py:19-25` (`code/rust/core_adversary/src/skill_run.rs:15-21`) defines `REFERENCE_SELF_CONSISTENT` and `REFERENCE_SELF_INCONSISTENT` in `TERMINAL_VERDICTS`, and the tracked pilot runner `workflows/wf11_dual_certificate_synthesis/pilots/c051_exact_lp_solver_with_duals/commit_reveal_c051.py` (`lines 55-63, 114-160, 285-360`) declares `GATE_SCOPE = "REFERENCE_SOLVER_SELF_CHECK"` and emits `REFERENCE_SELF_CONSISTENT` or `REFERENCE_SELF_INCONSISTENT` over measured counts (`"pre_run_commitment": False` in `receipt.json`, digest-bound `write_bundle`).

## 3. Derivation / Evidence

### 3.1 Five-Clause Verification Against Active Repository Modules (`source_commit = 78bc23b35`)
1. **Clause 1 — Lift Carries Input Cochain and Refuses Lowering (`act_helpers.py:680-691`; `bout_service.py:251-262, 743-780`; `ports.py:65-85`)**:
   - `execute_act4_gauge_break` copies `initial_cochain.get(edge, Fraction(0))` for every `edge in carrier_network.edges` and sets `updated_cochain[edge] = Fraction(0)` only on `new_edges`.
   - `bout_service._lift_lowered_obstruction(before, after)` returns `True` whenever `before.is_measured and after.is_measured` and `after.phi1 < before.phi1 or after.gamma2 < before.gamma2`, triggering `_lift_replaced_cochain` -> `Err(Refusal(code="ADVERSARY_LIFT_LOWERED_OBSTRUCTION", ...))`.
   - `NullCochainScoringAdapter` returns `MeasurementStatus.NOT_MEASURED`, which blocks `AUTHORIZED` under `CARRIER_DECLARED` (`status == "NOT_MEASURED"`, `CARRIER_NOT_MEASURED` blocker).
2. **Clause 2 — Typed Critiques and Fail-Closed Unparsable Replies (`evidence.py:297-347`; `act_helpers.py:836-862`; `evidence_parse.rs:166-229, 231-309`)**:
   - `parse_structured_critique` (`evidence_parse.rs:231-309`, returning `StructuredCritique` / `CritiqueStatus` at `lines 166-229`) requires a single fenced `critique` JSON object (`blocking`, `counterexample`, optional closed `kind`). Unparsable replies return `StructuredCritiqueV1(status=CritiqueStatus.MALFORMED, blocking=True, ...)`, recording `critique_verdicts[cand_id] = "MALFORMED"` and `ChallengeV1(..., blocking=True)` so the candidate cannot be selected or authorized.
   - Replay of all 93 vectors in `python_evidence_parsers_v1.json` (`50` critique + `43` checker-receipt vectors) confirms 100% agreement with the `evidence_parse.rs` specification (`parse_checker_receipt` at `lines 114-164` and `parse_structured_critique` at `lines 231-309`).
3. **Clause 3 — Stored Receipts Cited by Digest (`act_helpers.py:1281-1312, 1375-1381, 1419`; `bout_service.py:1010-1015, 1188-1196`; `authorization.rs:229-279, 402-431`)**:
   - Non-vanishing obstruction receipts (`phi1 > 0`) and Regge deficit receipts are stored in `narrative["evidence_receipts"]` under `_canonical_json_digest(receipt)` without constant `annihilates_coboundary` or `norm_bounded` fields, and their `sha256:<hex>` keys are appended to `verdict_proposal.evidence_refs` alongside `challenge_id` and `checker_receipt_sha256` (while `bout_service._act_persist` computes `receipt_id` from `novella_md`, `dda_steps_to_write`, and `summary_data`).
4. **Clause 4 — `AUTHORIZED` Requires a Digest-Bound `ACCEPTED` Checker Verdict (`evidence.py:190-250`; `evidence_parse.rs:114-164`; `act_helpers.py:966-1052, 1231-1259, 1322-1371`; `candidate_check_custody.rs:1-195`)**:
   - `CandidateCheckV1.__post_init__` rejects empty `checker_receipt_bytes` or `checker_receipt_sha256 != sha256_ref(checker_receipt_bytes)` on `ACCEPTED`/`REJECTED` checks with `ValueError`.
   - `execute_candidate_checks` refuses mismatched `candidate_id` or `candidate_content_sha256` (`not check.binds(candidate.candidate_id, candidate.artifact_refs)`) with `ADVERSARY_CHECKER_BINDING_MISMATCH`, and `NullCandidateCheckerAdapter` returns `CheckerVerdict.NOT_MEASURED`.
   - `execute_act7_authorization_gate` emits `status == "AUTHORIZED"` (`is_authorized == True`) only when `selected_cand` is unblocked, `checker_accepted` (`checker_bound` + `CheckerVerdict.ACCEPTED`) and `critiqued` (`critique_verdicts[selected_cand] == "NON_BLOCKING"`) hold, `fixture_seats is False`, no protected-mutation / refuted-zero-claim / Regge blocker applies, and either `carrier_status == "NOT_DECLARED"` (`authorization_evidence = "CHECKER_VERDICT_ONLY_NO_CARRIER_DECLARED"`) or `measurement.is_exact_joint_zero()` (`authorization_evidence = "CHECKER_VERDICT_AND_EXACT_ZERO_CARRIER"`).
5. **Clause 5 — Reference Self-Consistency Scope and Verdicts (`skill_run_persistence.py:19-25`; `skill_run.rs:15-21`; `commit_reveal_c051.py:55-63, 114-160, 285-360`)**:
   - `TERMINAL_VERDICTS` in `skill_run_persistence.py` and `VERDICTS` in `skill_run.rs` enumerate `("PASS_TO_MASTER", "REFUSE", "OPEN_RESIDUAL", "REFERENCE_SELF_CONSISTENT", "REFERENCE_SELF_INCONSISTENT")`.
   - In `commit_reveal_c051.py:295-322`, `GATE_SCOPE = "REFERENCE_SOLVER_SELF_CHECK"` is written as `"gate_scope": GATE_SCOPE` to both `summary` (`summary.json`, line `300`) and `receipt` (`receipt.json`, line `312`), whereas `"pre_run_commitment": False` is written only to `receipt` (`receipt.json`, line `316`); `label_run` labels empty or failing runs `"REFERENCE_SELF_INCONSISTENT"` and complete passing runs `"REFERENCE_SELF_CONSISTENT"`, and `write_bundle` binds `novella_sha256`, `dda_actions_sha256`, and `summary_sha256` inside `receipt.json`.

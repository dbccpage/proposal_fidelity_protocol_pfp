## 1. Claim Statement

Complementary to `PAPER005-INSTANCE-REPLACEMENT` (which establishes that gauge-changing a vertex potential preserves cycle holonomy $\sum_{e \in C} (c_e - (f_v - f_u)) = \sum_{e \in C} c_e$ and therefore cannot remove a nonzero cycle obstruction without replacing the edge claims), this residual derivation establishes the governor verification contract in `L1SymbolGameGovernor.step_verify` (`005_pfp_practitioners_field_manual/code/l1_symbol_game_governor.py`):
1. `step_verify("EDGE_MATCH:<spec>")` requires `<spec>` to parse into two comma-separated vertex names matching a declared directed edge in `self.graph`; undeclared pairs, reversed chords, self-pairs, and malformed arities return `admitted=False` and `status="VerificationFailed"` with state unchanged.
2. Satisfying `EDGE_MATCH:u,v` on one (or $n - 1$) declared edges of an inconsistent cycle leaves `primary_obstruction()` strictly positive, so `step_verify("ZERO_OBSTRUCTION")` returns `admitted=False` (`"VerificationFailed"`).
3. `step_verify` separates quotient solvability (`ZERO_OBSTRUCTION`: $\Phi_1(c) = \min_f D_c(f) = 0$) from current-section residual vanishing (`ZERO_DEFECT`: $D_c(s) = 0$).

## 3. Derivation / Evidence

### 3.1 `EDGE_MATCH` Declared-Edge and Arity Refusal
In `L1SymbolGameGovernor.step_verify` (`l1_symbol_game_governor.py` lines 803–813):
```python
elif obligation.startswith("EDGE_MATCH:"):
    pair = obligation.removeprefix("EDGE_MATCH:").split(",")
    if len(pair) != 2 or self.graph.edge_by_pair(*pair) is None:
        passed = False
        details = f"EDGE_MATCH requires a declared directed edge: {obligation!r}."
    else:
        u, v = pair
        claim = self.edge_claims.get((u, v), Fraction(0))
        actual = self.section[v] - self.section[u]
        passed = (claim == actual)
        details = f"Edge {u}->{v}: claim={claim}, actual={actual}."
```
Without the `len(pair) != 2 or self.graph.edge_by_pair(*pair) is None` guard, querying an undeclared pair `(u, v)` on an initialized zero section would compare default `edge_claims.get((u, v), 0) == 0` against `0 - 0 == 0` and spuriously report `"Verified"`. With the guard:
- Out-of-carrier endpoints (`"EDGE_MATCH:d,e"`), undeclared or reversed chords (`"EDGE_MATCH:a,c"`), and self-pairs (`"EDGE_MATCH:a,a"`) fail `self.graph.edge_by_pair(*pair) is None`.
- Malformed strings (`"EDGE_MATCH:a"`, `"EDGE_MATCH:a,b,c"`, `"EDGE_MATCH:,"`) fail either `len(pair) != 2` or `edge_by_pair("", "") is None`.
- Every such call returns `admitted=False`, `status="VerificationFailed"`, and `defect_before == defect_after == self.section_defect()`, leaving `(edge_claims, section, history)` unchanged.

### 3.2 Local `EDGE_MATCH` Success Does Not Discharge `ZERO_OBSTRUCTION`
Consider the canonical directed 3-cycle $G = (\{a, b, c\}, \{(a,b,1), (b,c,2), (c,a,3)\})$ with asserted claims $c = (1, 1, 1)$:
1. Applying section `CUT` $s = \{a: 0, b: -2, c: -1\}$ reduces `section_defect(s)` from $6$ to $3$ (`admitted=True, status="MonotonicDescent"`).
2. On edge $(b, c)$, $s(c) - s(b) = (-1) - (-2) = 1 = c(b, c)$ (and on $(c, a)$, $s(a) - s(c) = 0 - (-1) = 1 = c(c, a)$), while all cycle discrepancy concentrates on $(a, b)$ where $c(a, b) - (s(b) - s(a)) = 1 - (-2) = 3$.
3. Consequently:
   - `step_verify("EDGE_MATCH:b,c")` returns `admitted=True, status="Verified"`.
   - `step_verify("EDGE_MATCH:c,a")` returns `admitted=True, status="Verified"`.
   - `step_verify("EDGE_MATCH:a,b")` returns `admitted=False, status="VerificationFailed"`.
   - `step_verify("ZERO_OBSTRUCTION")` evaluates `phi = self.primary_obstruction() == Fraction(3) != 0` and returns `admitted=False, status="VerificationFailed"`.

### 3.3 Separation Between `ZERO_OBSTRUCTION` and `ZERO_DEFECT`
In `step_verify` (`l1_symbol_game_governor.py` lines 796–802):
- `"ZERO_DEFECT"` checks `self.section_defect() == Fraction(0)`, i.e., $D_c(s) = \sum_{e=(u,v)} w_e |c_e - (s(v) - s(u))| = 0$ at the *currently stored* section $s$.
- `"ZERO_OBSTRUCTION"` checks `self.primary_obstruction() == Fraction(0)`, i.e., $\Phi_1(c) = \min_{f \in C^0(G)} D_c(f) = 0$ over *all* vertex potentials.

Initializing $G$ with coboundary claims $c = (-2, 1, 1)$ via `step_assert` leaves the stored section at its initial zero assignment $s_0 = \{a: 0, b: 0, c: 0\}$:
- $\Phi_1(c) = 0$ (attained by $f = (0, -2, -1)$), so `step_verify("ZERO_OBSTRUCTION")` returns `admitted=True, status="Verified"`.
- $D_c(s_0) = 1 \cdot |-2| + 2 \cdot |1| + 3 \cdot |1| = 2 + 2 + 3 = 7 \neq 0$, so `step_verify("ZERO_DEFECT")` returns `admitted=False, status="VerificationFailed"`.

## 4. Limits and Non-Claims

1. **Closed Obligation Set**: `step_verify` supports only `"ZERO_DEFECT"`, `"ZERO_OBSTRUCTION"`, and `"EDGE_MATCH:u,v"`; unrecognized obligation strings return `VerificationFailed` with `"Unknown obligation ..."`.
2. **History Trail Exclusion**: Neither passing nor failing `step_verify` calls append an `ExecutionRecord` to `self.history` (only `_step_counter` advances); snapshot rollback via `step_retract` targets `ASSERT` and `CUT` records.
3. **Formal Graph Scope**: Passing `EDGE_MATCH` or `ZERO_OBSTRUCTION` checks arithmetic consistency on the declared finite graph rather than external domain semantics.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that `step_verify` rejects undeclared and malformed `EDGE_MATCH` obligations with `VerificationFailed`, that local `EDGE_MATCH` satisfaction on declared edges coexists with `ZERO_OBSTRUCTION` failure when cycle holonomy is nonzero, and that `ZERO_OBSTRUCTION` ($\Phi_1 = 0$) is distinct from `ZERO_DEFECT` ($D_c(s) = 0$).
2. **What it does not support**: Does not establish whole-domain semantic validity or persistence of `VERIFY` verdicts inside `governor.history`.
3. **Narrowest defensible claim**: Coupled with `PAPER005-INSTANCE-REPLACEMENT`, `L1SymbolGameGovernor.step_verify` refuses undeclared or malformed `EDGE_MATCH` strings, keeps `ZERO_OBSTRUCTION` refused at $\Phi_1 = 3$ even when `EDGE_MATCH:b,c` passes on $(1,1,1)$, and distinguishes $\Phi_1 = 0$ from $D_c(s_0) = 7$ on $(-2,1,1)$.
4. **Next test needed**: Multi-cycle carrier test checking `EDGE_MATCH` across shared chord edges where one elementary cycle is exact and an adjacent cycle carries nonzero holonomy.

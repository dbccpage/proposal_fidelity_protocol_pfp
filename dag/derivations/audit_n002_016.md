## 1. Claim Statement

Let $(\rho_x)_{x \in P}$ be an operator-valued presheaf section over a path graph connecting nodes $a$ and $b$, with uniform local Hilbert spaces $\mathcal{H}_x = \mathcal{H}$ for all $x$. For any exponent $p \in [1, \infty]$, let
$$I_p(s) = \sum_{e \in \operatorname{path}(a,b)} \|\delta_e(s)\|_{S_p}$$
denote the total accumulated Schatten-$p$ coboundary defect along the path. Let $R_{b,a} = r_{v_0, v_1} \circ \cdots \circ r_{v_{m-1}, v_m}$ denote the composed restriction map from $b = v_m$ to $a = v_0$.

If each restriction map along the path is Schatten-$p$ contractive ($\|r(X)\|_{S_p} \le \|X\|_{S_p}$), then the transported endpoint difference satisfies the telescoping bound:
$$\|\rho_a - R_{b,a}(\rho_b)\|_{S_p} \le I_p(s).$$
In particular, defining the normalized distinguishability quantity $T_p(A, B) := \frac{1}{2} \|A - B\|_{S_p}$:
$$T_p(\rho_a, R_{b,a}(\rho_b)) \le \frac{1}{2} I_p(s).$$
For $p = 1$, when $\rho_a, \rho_b$ are normalized density operators and restriction maps are state-preserving channels, $T_1$ coincides with the operational quantum trace distance:
$$T(\rho_a, R_{b,a}(\rho_b)) \le \frac{1}{2} I_1(s).$$
Across exponents, the distinguishability bounds obey the canonical chain:
$$T_\infty(\rho_a, R_{b,a}(\rho_b)) \le T_p(\rho_a, R_{b,a}(\rho_b)) \le T_1(\rho_a, R_{b,a}(\rho_b)) \le \frac{1}{2} I_1(s).$$

## 2. Context & Hypotheses

- **Path Graph**: A directed path of vertices $v_0 = a, v_1, \dots, v_m = b$ with edges $e_i = (v_i, v_{i+1})$ for $i \in \{0, \dots, m-1\}$.
- **Uniform Local Stalks**: Each vertex $x$ is assigned the operator algebra $\mathcal{B}(\mathcal{H})$ on a common finite-dimensional Hilbert space $\mathcal{H} \cong \mathbb{C}^d$.
- **Section**: An assignment $x \mapsto \rho_x \in \mathcal{S}_p(\mathcal{H})$ of operators to vertices.
- **Schatten-$p$ Norm**: For $p \in [1, \infty)$, $\|X\|_{S_p} = (\mathrm{Tr}|X|^p)^{1/p} = (\sum_i \sigma_i(X)^p)^{1/p}$; for $p = \infty$, $\|X\|_{S_\infty} = \sigma_{\max}(X)$.
- **Contractive Restrictions**: For each edge $e_i = (v_i, v_{i+1})$, the restriction map $r_{v_{i+1}, v_i}: \mathcal{B}(\mathcal{H}) \to \mathcal{B}(\mathcal{H})$ satisfies $\|r_{v_{i+1}, v_i}(X)\|_{S_p} \le \|X\|_{S_p}$.
- **Coboundary Defect**: On edge $e_i$, $\delta_{e_i}(s) = r_{v_{i+1}, v_i}(\rho_{v_{i+1}}) - \rho_{v_i}$.
- **Composed Parallel Transport**: $R_{v_i, a} = r_{v_1, v_0} \circ \cdots \circ r_{v_i, v_{i-1}}$ with $R_{v_0, a} = \mathrm{id}$.

## 3. Derivation / Evidence

### 3.1 Telescoping Decomposition of Transport Defect
1. Express the difference between the base state $\rho_a = \rho_{v_0}$ and the transported terminal state $R_{b,a}(\rho_b) = R_{v_m, a}(\rho_{v_m})$ as a telescoping sum across path vertices:
   $$R_{b,a}(\rho_b) - \rho_a = R_{v_m, a}(\rho_{v_m}) - R_{v_0, a}(\rho_{v_0}) = \sum_{i=0}^{m-1} \Big( R_{v_{i+1}, a}(\rho_{v_{i+1}}) - R_{v_i, a}(\rho_{v_i}) \Big).$$
2. By functorial composition of presheaf restriction maps along the path:
   $$R_{v_{i+1}, a} = R_{v_i, a} \circ r_{v_{i+1}, v_i}.$$
3. Substituting this factorization into each difference term:
   $$R_{v_{i+1}, a}(\rho_{v_{i+1}}) - R_{v_i, a}(\rho_{v_i}) = R_{v_i, a}\Big( r_{v_{i+1}, v_i}(\rho_{v_{i+1}}) - \rho_{v_i} \Big) = R_{v_i, a}\Big( \delta_{e_i}(s) \Big).$$
4. Summing these terms yields the exact operator identity:
   $$R_{b,a}(\rho_b) - \rho_a = \sum_{i=0}^{m-1} R_{v_i, a}\Big( \delta_{e_i}(s) \Big).$$

### 3.2 Triangle Inequality and Contraction Bounds
1. Taking the Schatten-$p$ norm of both sides and applying the triangle inequality:
   $$\|R_{b,a}(\rho_b) - \rho_a\|_{S_p} \le \sum_{i=0}^{m-1} \|R_{v_i, a}(\delta_{e_i}(s))\|_{S_p}.$$
2. Since each elementary restriction map $r_{v_{j+1}, v_j}$ is contractive in the Schatten-$p$ norm ($\|r(X)\|_{S_p} \le \|X\|_{S_p}$), the composition of contractions is contractive:
   $$\|R_{v_i, a}(X)\|_{S_p} \le \|X\|_{S_p} \quad \forall X \in \mathcal{S}_p(\mathcal{H}).$$
3. Applying this bound to each summand:
   $$\|R_{v_i, a}(\delta_{e_i}(s))\|_{S_p} \le \|\delta_{e_i}(s)\|_{S_p}.$$
4. Summing across all edges in the path:
   $$\|\rho_a - R_{b,a}(\rho_b)\|_{S_p} \le \sum_{i=0}^{m-1} \|\delta_{e_i}(s)\|_{S_p} = \sum_{e \in \operatorname{path}(a,b)} \|\delta_e(s)\|_{S_p} = I_p(s).$$
5. Dividing both sides by 2 yields:
   $$T_p(\rho_a, R_{b,a}(\rho_b)) \le \frac{1}{2} I_p(s).$$

### 3.3 Schatten Exponent Monotonicity Chain
1. For any matrix $X$ on a $d$-dimensional Hilbert space, let $\sigma(X) = (\sigma_1, \dots, \sigma_d)$ be its singular values ordered non-increasingly.
2. By standard $\ell^p$ norm monotonicity on $\mathbb{R}^d$:
   $$\|X\|_{S_\infty} = \sigma_1 \le \left(\sum_{k=1}^d \sigma_k^p\right)^{1/p} \le \sum_{k=1}^d \sigma_k = \|X\|_{S_1},$$
   for any $p \in [1, \infty]$.
3. Consequently, the endpoint distinguishability quantities satisfy:
   $$T_\infty(\rho_a, R_{b,a}(\rho_b)) \le T_p(\rho_a, R_{b,a}(\rho_b)) \le T_1(\rho_a, R_{b,a}(\rho_b)) \le \frac{1}{2} I_1(s).$$

### 3.4 Worked Replay on Two-Edge Qubit Path (Taut Equality)
Consider the path $a - m - b$ with identity restriction maps and qubit density matrices:
$$\rho_a = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \quad \rho_m = \begin{pmatrix} 1/2 & 0 \\ 0 & 1/2 \end{pmatrix}, \quad \rho_b = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}.$$
- Edge defects:
  $$\delta_{(a,m)} = \rho_m - \rho_a = \begin{pmatrix} -1/2 & 0 \\ 0 & 1/2 \end{pmatrix}, \quad \delta_{(m,b)} = \rho_b - \rho_m = \begin{pmatrix} -1/2 & 0 \\ 0 & 1/2 \end{pmatrix}.$$
- Endpoint difference:
  $$\rho_a - \rho_b = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}.$$
- Exponent $p = 1$:
  $$\|\delta_{(a,m)}\|_1 = 1.0, \quad \|\delta_{(m,b)}\|_1 = 1.0 \implies I_1 = 2.0.$$
  $$T_1 = \frac{1}{2} \|\rho_a - \rho_b\|_1 = \frac{1}{2}(2.0) = 1.0 = \frac{1}{2} I_1 \quad (\text{taut equality}).$$
- Exponent $p = 2$:
  $$\|\delta_{(a,m)}\|_2 = \frac{1}{\sqrt{2}}, \quad \|\delta_{(m,b)}\|_2 = \frac{1}{\sqrt{2}} \implies I_2 = \sqrt{2}.$$
  $$T_2 = \frac{1}{2} \|\rho_a - \rho_b\|_2 = \frac{1}{2}(\sqrt{2}) = \frac{1}{\sqrt{2}} = \frac{1}{2} I_2 \quad (\text{taut equality}).$$
- Exponent $p = \infty$:
  $$\|\delta_{(a,m)}\|_\infty = 0.5, \quad \|\delta_{(m,b)}\|_\infty = 0.5 \implies I_\infty = 1.0.$$
  $$T_\infty = \frac{1}{2} \|\rho_a - \rho_b\|_\infty = \frac{1}{2}(1.0) = 0.5 = \frac{1}{2} I_\infty \quad (\text{taut equality}).$$

## 4. Limits and Non-Claims

- **Contractivity Requirement**: The bound requires each restriction map $r$ along the path to be contractive ($\|r\|_{\mathrm{op}} \le 1$). Expansive channels invalidate the telescoping triangle inequality.
- **Path-Dependent Bound**: The bound is evaluated along a chosen directed path. In complexes with non-trivial fundamental group, different paths between $a$ and $b$ yield different bounds unless the presheaf is flat.
- **Quantum State Interpretation**: The operational trace distance interpretation requires states $\rho$ to be positive semidefinite with unit trace, and restriction channels to be completely positive and trace-preserving.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that under contractive restriction maps along a path graph, the transported endpoint distinguishability is upper-bounded by half the accumulated Schatten-$p$ coboundary defect.
2. **What it does not support**:
   Does not support distinguishability bounds when restriction maps are expansive; does not derive operational quantum distinguishability unconditionally from topology.
3. **Narrowest defensible claim**:
   Under Schatten-$p$ contractive restrictions along a path $a \to b$, $\|\rho_a - R_{b,a}(\rho_b)\|_{S_p} \le \sum_{e \in \text{path}} \|\delta_e\|_{S_p}$.

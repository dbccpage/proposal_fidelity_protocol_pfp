## 1. Claim Statement

For every integer stage $N \ge 22$, the eight-element integer opcode block $B(N) = [b(N),\, b(N) + 8) \cap \mathbb{Z} = \{b(N), b(N) + 1, \dots, b(N) + 7\}$ with base $b(N) = 128 + 8(N - 22)$ lies strictly above all source opcodes ($< 128$), and for all integer pairs $22 \le N < M$, $B(N) \cap B(M) = \varnothing$. Across the loaded 101-stage catalog ($0 \le N \le 100$), the 79 proposal blocks ($22 \le N \le 100$) partition $\{128, 129, \dots, 759\}$ without collision, whereas fixed-width unsigned $w$-bit wire encodings require the separate upper-bound condition $b(N) + 7 < 2^w$ (which fails at $N = 38$ for $w = 8$).

## 3. Derivation / Evidence

### 3.1 Separation from Source Opcodes ($< 128$)
For any integer $N \ge 22$, $N - 22 \ge 0$, and since $8 > 0$:
$$\min B(N) = b(N) = 128 + 8(N - 22) \ge 128 + 8 \cdot 0 = 128.$$
Every source opcode $s < 128$ satisfies $s \le 127 < 128 \le \min B(N)$, so $B(N) \cap (-\infty, 127] \cap \mathbb{Z} = \varnothing$. In `pfp/domain/tower/registry.py`, `SOURCE_OPCODE_SET = (set(SOURCE_PRIMARY) - {None}) | SOURCE_EXTRA` contains 39 integers in $[0, 45]$, confirming $\max(\text{SOURCE\_OPCODE\_SET}) = 45 < 128$.

### 3.2 General Pairwise Disjointness Inequality for $22 \le N < M$
Let $N, M \in \mathbb{Z}$ satisfy $22 \le N < M$. Because $N$ and $M$ are integers with $N < M$, their difference satisfies $M - N \ge 1$.
The maximum element of $B(N)$ is $\max B(N) = b(N) + 7$, and the minimum element of $B(M)$ is $\min B(M) = b(M)$. Computing the integer gap between them gives:
$$\begin{aligned}
\min B(M) - \max B(N) &= b(M) - \bigl(b(N) + 7\bigr) \\
&= \bigl(128 + 8(M - 22)\bigr) - \bigl(128 + 8(N - 22) + 7\bigr) \\
&= 8(M - N) - 7 \\
&\ge 8(1) - 7 = 1 > 0.
\end{aligned}$$
Hence $\max B(N) = b(N) + 7 \le b(M) - 1 < b(M) = \min B(M)$.
For any $x \in B(N)$ and $y \in B(M)$, $x \le \max B(N) < \min B(M) \le y$, so $x \ne y$. By symmetry when $M < N$, $B(N) \cap B(M) = \varnothing$ for all distinct integers $N, M \ge 22$. Moreover, for consecutive stages $M = N + 1$, $b(N + 1) - (b(N) + 7) = 1$, establishing that $\{B(N)\}_{N \ge 22}$ forms a contiguous partition of $\{k \in \mathbb{Z} : k \ge 128\}$ into 8-wide blocks.

### 3.3 Exhaustive Finite Verification Over Catalog Stages $22 \le N \le 100$
Comparing `retraction_benchmark_runner.compute_opcode_base` and `pfp.domain.tower.registry.STAGES`:
- For $0 \le N \le 21$, `compute_opcode_base(N) == 0` and `STAGES[N].reserved_opcodes == ()`.
- For all 79 stages $22 \le N \le 100$, `STAGES[N].primary_opcode == compute_opcode_base(N) == 128 + 8 * (N - 22)` and `STAGES[N].reserved_opcodes == tuple(range(b(N), b(N) + 8))`:
  - $N = 22$: $B(22) = \{128, \dots, 135\}$
  - $N = 23$: $B(23) = \{136, \dots, 143\}$
  - $N = 100$: $B(100) = \{752, \dots, 759\}$
- The union across $22 \le N \le 100$ contains $79 \times 8 = 632$ distinct integers equal to $\{128, 129, \dots, 759\}$, disjoint from all 39 elements of `SOURCE_OPCODE_SET`, and `check_registry()` completes with zero collisions.

### 3.4 Fixed-Width Wire Overflow Falsification ($b(N) + 7 \ge 2^w$)
In a fixed-width unsigned $w$-bit encoding (representable range $\{0, 1, \dots, 2^w - 1\}$), avoiding overflow requires:
$$b(N) + 7 \le 2^w - 1 \iff 135 + 8(N - 22) \le 2^w - 1 \iff 8(N - 22) \le 2^w - 136.$$
For $w \ge 8$, $2^w - 136 = 8(2^{w - 3} - 17)$, yielding the exact maximum admissible stage:
$$N_{\max}(w) = 22 + (2^{w - 3} - 17) = 5 + 2^{w - 3}.$$
- **Eight-bit wire ($w = 8$, ceiling $255$)**: $N_{\max}(8) = 5 + 32 = 37$, with $B(37) = \{248, \dots, 255\}$. At $N = 38$, $b(38) = 256$ and $\max B(38) = 263 \ge 256$, overflowing 8 bits. Under modulo-256 wraparound, $B(38) \bmod 256 = \{0, \dots, 7\}$ collides with source opcodes $\{0, 1, 2, 3, 4, 5, 6, 7\} \cap \text{SOURCE\_OPCODE\_SET} = \{0, 1, 2, 3, 4, 5, 6, 7\}$, and $B(54) \bmod 256 = \{128, \dots, 135\} = B(22)$ collides with stage 22.
- **Ten-bit wire ($w = 10$, ceiling $1023$)**: $N_{\max}(10) = 5 + 128 = 133$, accommodating the loaded catalog ($N \le 100$, $\max B(100) = 759 < 1024$) while overflowing at $N = 134$ ($\max B(134) = 1031 \ge 1024$).

## 4. Limits and Non-Claims

1. **Fixed-Width Wire Capacity**: Integer disjointness in $\mathbb{Z}$ does not prevent overflow or modular aliasing in fixed-width binary wire formats once $b(N) + 7 \ge 2^w$.
2. **Finite Loaded Catalog**: Only stages $0 \le N \le 100$ exist as `Stage` entries in `pfp/domain/tower/registry.py`.
3. **Namespace Allocation vs. Stage Semantics**: Assigning non-overlapping integer opcodes is a syntactic namespace reservation; it constructs neither stage checkers nor semantic interpretations.

## 5. Claim Hygiene Summary

1. **What it supports**: Derives the exact integer gap $b(M) - (b(N) + 7) = 8(M - N) - 7 \ge 1$ for $22 \le N < M$ and lower bound $b(N) \ge 128$, verifies exhaustive disjointness across catalog stages $22 \le N \le 100$ against `SOURCE_OPCODE_SET`, and characterizes the fixed-width $w$-bit ceiling $N_{\max}(w) = 5 + 2^{w-3}$ (overflowing at $N = 38$ for $w = 8$).
2. **What it does not support**: Does not support fixed-width 8-bit wire safety above stage 37, existence of catalog rows past stage 100, or semantic implementation of stages $22 \dots 100$.
3. **Narrowest defensible claim**: Under $b(N) = 128 + 8(N - 22)$ in $\mathbb{Z}$, the 8-wide intervals $[b(N), b(N) + 8)$ for integers $N \ge 22$ are pairwise disjoint and $\ge 128$, while $w$-bit unsigned wire encodings require $N \le 5 + 2^{w-3}$ ($N \le 37$ for $w = 8$).
4. **Next test needed**: Enforce an explicit stage-bound guard $N \le N_{\max}(w)$ at any binary wire encoder boundary that serializes proposal opcodes into fixed-width $w$-bit fields.

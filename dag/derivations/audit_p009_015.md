## 3. Derivation / Evidence

### 3.1 Retained `F2a` and `F2b` Replay Driver and Recorded Inversion
1. **Replay Setup (`replay_adversary_gate_falsifiers.py:76-93, 111-126`)**:
   - `Seat(text)` returns `Ok(SeatTurnReplyV1(reply_text=self.text, machine_fields={"DISPOSITION": "KILL"}, raw_bytes=self.text.encode("utf-8")))` for both `F2a` and `F2b`.
   - Each probe submits `payload = b"potential f=(0,1,2)"` for `cand = candidate(payload)` on `triangle = network(nodes=(0, 1, 2), edges=((0, 1), (1, 2), (2, 0)), faces=())` to `execute_act5_independent_witness(runtime(seat_port=Seat(text), max_critique_rounds=1), "f2", "repair", triangle, [cand], [], candidate_payloads={cand.candidate_id: payload})`.
2. **Exact Mathematical Validity of `F2a`'s Counterexample (`triangle_cycle_sum.py:16-46`)**:
   - On the oriented 3-cycle `((0, 1), (1, 2), (2, 0))` with unit cochain $h = (1, 1, 1)$, the proposed potential $f = (0, 1, 2)$ in `payload = b"potential f=(0,1,2)"` induces coboundary $df = (1, 1, -2)$ and residual
     $$h - df = (1, 1, 1) - (1, 1, -2) = (0, 0, 3), \qquad \operatorname{cycle\_sum}(0, 0, 3) = 3 \neq 0.$$
   - Thus `F2a`'s reply (`"Counterexample: the residual (0,0,3) has cycle sum 3, so the claimed repair is false."`) states the exact cohomological residual of `payload = b"potential f=(0,1,2)"`.
3. **Retained Outcomes (`adversary_gate_falsifiers.json:28-42`; `test_review_counts.py:80-81`)**:
   - `F2a`: `"expected": "blocking"`, `"observed": "not blocking"`, `"candidate_survives": true` (text contains neither `"defect"` nor `"flaw"`).
   - `F2b` (`"No defect found; the certificate checks."`): `"expected": "not blocking"`, `"observed": "blocking"`, `"candidate_survives": false` (text contains substring `"defect"` inside `"No defect found"`).

### 3.2 Remediated Typed Critique Contract and Execution (`ops/adversary/` and `core_adversary`)
1. **Rust and Python Typed Critique Parser (`evidence_parse.rs:231-309`; `evidence.py:297-347`)**:
   - `parse_structured_critique` extracts `r"(?s)```critique[ \t]*\r?\n(.*?)\r?\n```"` and requires `blocks.len() == 1`, a JSON object with closed keys `{"blocking", "counterexample", "kind"}`, an exact JSON boolean `blocking`, `counterexample` as `str` or `null` (non-empty after trimming whenever `blocking == true`), and `kind` in `CHALLENGE_KINDS`.
   - Any violation—including zero fenced blocks (`F2a`, `F2b`, `"DEFECT in prose"`), two fenced blocks, invalid JSON, integer `blocking: 1`, `blocking: true` with `counterexample: ""` or `null`, or unknown keys—returns `StructuredCritique` with `status == CritiqueStatus.Malformed` and `blocking == true` (`StructuredCritiqueV1.__post_init__` raises `ValueError("a MALFORMED critique must block (fail closed)")` if `status is CritiqueStatus.MALFORMED and not blocking`).
2. **Parity Corpus and Act V Execution (`python_evidence_parsers_v1.json`; `act_helpers.py:836-906`)**:
   - `python_evidence_parsers_v1.json` pins 50 critique test vectors, including explicit prose-keyword immunity (`"DEFECT in prose\n```critique\n{\"blocking\": false, \"counterexample\": null}\n```"` -> `status == "STRUCTURED"`, `blocking == False`) and keyword-free counterexample blocking (`"```critique\n{\"blocking\": true, \"counterexample\": \"residual (0,0,3) has cycle sum 3\"}\n```"` -> `status == "STRUCTURED"`, `blocking == True`).

## 3. Derivation / Evidence

### 3.1 Exact Lean 4 Definitions and Term Reduction (`Level15AuthorityCalculus.lean`, lines 53–63)
Within `namespace MSSN.Level15` in `lean4/Level15AuthorityCalculus.lean`:
```lean
structure AgentState where
  paramHash : Nat
  deriving DecidableEq, Repr

def isIndependentVerifier (gen : AgentState) (ver : AgentState) : Prop :=
  gen.paramHash ≠ ver.paramHash

theorem theorem2_self_critique_non_verification (gen : AgentState) :
    ¬ isIndependentVerifier gen gen := by
  intro h
  exact h rfl
```
Unfolding `isIndependentVerifier gen gen` yields `gen.paramHash ≠ gen.paramHash`, which Lean defines as `(gen.paramHash = gen.paramHash) → False`. Introducing `h : gen.paramHash ≠ gen.paramHash` and applying `h` to `rfl : gen.paramHash = gen.paramHash` produces `False`, closing `¬ isIndependentVerifier gen gen` without classical choice, quotient soundness, propositional extensionality, or auxiliary lemmas.

### 3.3 Falsification Controls on Predicate Polarity and Non-Independence of Distinct Hashes
1. **Mutated Equal-Hash Predicate Rejected by Lean Kernel**:
   Replacing `≠` with `=` (`def isIndependentVerifierBad (gen ver : AgentState) : Prop := gen.paramHash = ver.paramHash`) causes `¬ isIndependentVerifierBad gen gen` to fail kernel typechecking in an isolated temporary Lean check (`lake env lean` exits non-zero), confirming the theorem depends directly on the irreflexivity of `≠`.
2. **Distinct `paramHash` Values Do Not Prevent Identical Failure Modes**:
   For `gen := { paramHash := 1 }` and `ver := { paramHash := 2 }`, `isIndependentVerifier gen ver` holds (`1 ≠ 2`), even when two evaluators share identical deterministic failure maps on every candidate input. Thus `isIndependentVerifier` checks field inequality only and encodes no probabilistic or causal independence condition.

## 4. Limits and Non-Claims

1. **No Statistical Independence Claim**: As stated in `paper.md` (lines 38, 104) and `paper_claim_ledger.md` (`G009-07`), `isIndependentVerifier` tests `gen.paramHash ≠ ver.paramHash` on a single `Nat` field. Distinct parameter hashes, model names, or prompts do not prevent correlated errors, shared training biases, or coupled runtime state.
2. **No Runtime Hash-Binding Proof**: `AgentState` is a standalone Lean structure; `Level15AuthorityCalculus.lean` does not parse model weights, inspect HTTP provider endpoints, or verify how runtime seats populate `paramHash`.

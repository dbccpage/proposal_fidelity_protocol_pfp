## 1. Claim Statement

Complementing `PAPER010-FINITE-GROUP-ADMISSION` (which records `FiniteGroup` constructor validation of carrier nonemptiness, table closure, two-sided identity and inverses, and all-triple associativity), `symmetric_group_s3()` and `quaternion_group_q8()` in `atlas/archive/pfp/010_pfp_holonomy_checks_and_model_pilots/code/holonomy.py` construct exact non-abelian finite groups of orders $|S_3| = 6$ and $|Q_8| = 8$: $S_3$ has element-order spectrum `(1, 2, 2, 2, 3, 3)`, trivial center $Z(S_3) = \{\text{"012"}\}$, $18$ commuting and $18$ non-commuting ordered pairs, and $6$ group isomorphisms onto the C017 case $S_3$ table; $Q_8$ has element-order spectrum `(1, 2, 4, 4, 4, 4, 4, 4)`, a unique element `"-e"` of order $2$, center $Z(Q_8) = \{\text{"e"}, \text{"-e"}\}$, $40$ commuting and $24$ non-commuting ordered pairs, and exact table equality with the C017 `base_13.json` $Q_8$ fixture.

## 3. Derivation / Evidence

### 3.1 Construction, Order $6$, Non-Abelianness, and Presentation Isomorphisms of `symmetric_group_s3()`
1. **Permutation Carrier and Cayley Table (`code/holonomy.py:150-170`)**:
   `symmetric_group_s3()` enumerates `perms = sorted(itertools.permutations(range(3)))`, yielding $3! = 6$ distinct 3-character labels:
   $$S_3 = (\text{"012"},\;\text{"021"},\;\text{"102"},\;\text{"120"},\;\text{"201"},\;\text{"210"}), \qquad |S_3| = 6,$$
   with identity $e = \text{"012"}$, composition $\mathrm{compose}(p, q)(i) = p[q[i]]$ for $i \in \{0, 1, 2\}$, and inverse $\mathrm{inverse}(p)(i) = p.\mathrm{index}(i)$.
2. **Element-Order Spectrum**:
   Evaluating `s3.order_of(a)` (`lines 129-133`) over all 6 elements gives:
   - $\mathrm{ord}(\text{"012"}) = 1$ (identity);
   - $\mathrm{ord}(\text{"021"}) = \mathrm{ord}(\text{"102"}) = \mathrm{ord}(\text{"210"}) = 2$ (the three transpositions $(1\,2)$, $(0\,1)$, $(0\,2)$, each self-inverse);
   - $\mathrm{ord}(\text{"120"}) = \mathrm{ord}(\text{"201"}) = 3$ (the two mutual-inverse 3-cycles $(0\,2\,1)$ and $(0\,1\,2)$, satisfying $\text{"120"}^2 = \text{"201"}$ and $\text{"201"}^2 = \text{"120"}$).
   Sorted element orders are `[1, 2, 2, 2, 3, 3]`.
3. **Non-Abelian Witnesses, Center, and Commuting Census**:
   For $g = \text{"021"}$ and $h = \text{"102"}$:
   $$g h = \text{"021"} \cdot \text{"102"} = \text{"201"} \;\ne\; \text{"120"} = \text{"102"} \cdot \text{"021"} = h g,$$
   so `s3.commute("021", "102") is False` and `s3.is_abelian() is False`. Exhaustive evaluation over $S_3 \times S_3$ ($36$ ordered pairs) yields $18$ commuting pairs and $18$ non-commuting pairs (`paper.md:229-230`), trivial center $Z(S_3) = \{z \in S_3 : \forall x \in S_3,\, zx = xz\} = \{\text{"012"}\}$, and commutator subgroup $[S_3, S_3] = \{\text{"012"}, \text{"120"}, \text{"201"}\} \cong C_3$.
4. **Isomorphism with C017 Dihedral Presentation (`test_c017_replay.py:85-97`, `paper.md:280-283, 296-298`)**:
   The four C017 $S_3$ case files (`pois_01.json`, `base_01.json`, `base_02.json`, `base_03.json`) tabulate carrier `("e", "r", "r2", "s", "sr", "sr2")` generated by $r^3 = s^2 = e$, $srs = r^2$. Exhaustive check over all $6! = 720$ bijections $\phi : S_3^{\text{case}} \to S_3$ finds $|\mathrm{Iso}(S_3^{\text{case}}, S_3)| = |\mathrm{Aut}(S_3)| = 6$ group isomorphisms (sending `r` to either 3-cycle `"120"` or `"201"` and `s` to any of the three transpositions `"021"`, `"102"`, `"210"`).

### 3.2 Construction, Order $8$, Non-Abelianness, and Unique Involution of `quaternion_group_q8()`
1. **Integer Unit-Quaternion Carrier and Hamilton Product (`code/holonomy.py:173-202`)**:
   `_UNITS` maps `"e" -> (1,0,0,0)`, `"i" -> (0,1,0,0)`, `"j" -> (0,0,1,0)`, `"k" -> (0,0,0,1)`, and `quaternion_group_q8()` forms their signed pairs:
   $$Q_8 = (\text{"e"},\;\text{"-e"},\;\text{"i"},\;\text{"-i"},\;\text{"j"},\;\text{"-j"},\;\text{"k"},\;\text{"-k"}), \qquad |Q_8| = 8.$$
   Multiplication evaluates the integer bilinear Hamilton law (`lines 189-197`):
   $$(a_1, b_1, c_1, d_1)(a_2, b_2, c_2, d_2) = (a_1 a_2 - b_1 b_2 - c_1 c_2 - d_1 d_2,\; a_1 b_2 + b_1 a_2 + c_1 d_2 - d_1 c_2,\; a_1 c_2 - b_1 d_2 + c_1 a_2 + d_1 b_2,\; a_1 d_2 + b_1 c_2 - c_1 b_2 + d_1 a_2),$$
   and `conjugate` (`line 201`) maps $(a, b, c, d) \mapsto (a, -b, -c, -d)$. Because every carrier vector has Euclidean norm squared $a^2 + b^2 + c^2 + d^2 = 1$, $q \bar{q} = \bar{q} q = (1, 0, 0, 0) = e$, giving $\mathrm{inv}(\pm e) = \pm e$ and $\mathrm{inv}(u) = -u$ for $u \in \{\pm i, \pm j, \pm k\}$.
2. **Unique Element of Order $2$ (`"-e"`) and Order Spectrum**:
   Compute $q^2$ for every $q = (a, b, c, d) \in Q_8$:
   $$q^2 = (a^2 - b^2 - c^2 - d^2,\; 2ab,\; 2ac,\; 2ad).$$
   - For $q = \text{"e"} = (1, 0, 0, 0)$: $q = e$, so $\mathrm{ord}(\text{"e"}) = 1$.
   - For $q = \text{"-e"} = (-1, 0, 0, 0)$: $q \ne e$ and $q^2 = (1, 0, 0, 0) = e$, so $\mathrm{ord}(\text{"-e"}) = 2$.
   - For each of the six imaginary units $u \in \{\text{"i"}, \text{"-i"}, \text{"j"}, \text{"-j"}, \text{"k"}, \text{"-k"}\}$: $a = 0$ and $b^2 + c^2 + d^2 = 1$, so:
     $$u^2 = (-1, 0, 0, 0) = \text{"-e"} \ne \text{"e"}, \qquad u^3 = u^2 u = (-e)u = -u \ne \text{"e"}, \qquad u^4 = (u^2)^2 = (-e)^2 = \text{"e"}.$$
     Hence $\mathrm{ord}(u) = 4$ for all six imaginary units.
   Therefore the sorted element-order spectrum of $Q_8$ is `[1, 2, 4, 4, 4, 4, 4, 4]`, and $\{g \in Q_8 : \mathrm{ord}(g) = 2\} = \{\text{"-e"}\}$ contains a single element. Consequently, every nontrivial cyclic subgroup $\langle g \rangle \le Q_8$ ($g \ne e$) contains `"-e"` (since $g^2 = \text{"-e"}$ whenever $\mathrm{ord}(g) = 4$), and all six proper nontrivial subgroups (`{"e", "-e"}` and $\langle i \rangle, \langle j \rangle, \langle k \rangle$) are normal.
3. **Non-Abelian Witnesses, Center, Commutator, and Fixture Equality**:
   Direct table lookups give:
   $$\text{"i"} \cdot \text{"j"} = \text{"k"} \;\ne\; \text{"-k"} = \text{"j"} \cdot \text{"i"}, \qquad \text{"j"} \cdot \text{"k"} = \text{"i"} \;\ne\; \text{"-i"} = \text{"k"} \cdot \text{"j"}, \qquad \text{"k"} \cdot \text{"i"} = \text{"j"} \;\ne\; \text{"-j"} = \text{"i"} \cdot \text{"k"},$$
   confirming `q8.is_abelian() is False`. Over $Q_8 \times Q_8$ ($64$ ordered pairs), $40$ pairs commute ($16$ pairs involving $Z(Q_8) = \{\text{"e"}, \text{"-e"}\}$ plus $6 \times 4 = 24$ pairs with $a \in \{\pm i, \pm j, \pm k\}$ and $b \in \{\text{"e"}, \text{"-e"}, a, -a\}$) and $24$ pairs do not commute (`paper.md:229-230`), with commutator $[a, b] = a b a^{-1} b^{-1} = \text{"-e"}$ on every non-commuting pair ($[Q_8, Q_8] = Z(Q_8) = \{\text{"e"}, \text{"-e"}\}$). Furthermore, `connection_from_case(base_13).group == quaternion_group_q8()` holds identically (`test_c017_replay.py:84`, `paper.md:296-298`).

## 1. Claim Statement

Legacy Symbol Game presentation CLI commands `run-turn`, `run-bout`, and `run` fail closed by raising `RustFunctionalRequired`, exiting with status code 2 before computing mathematical functionals or writing any output artifacts to disk.

## 2. Context & Hypotheses

- **CLI Presentation Layer**:
  - Entry point in `pfp/entrypoints/cli/symbol_game.py`.
  - Subparser definitions in `pfp/entrypoints/cli/parser.py`.
  - Command handlers in `pfp/entrypoints/cli/run_commands.py`.
- **Functional Boundary Invariant**:
  - Implemented in `pfp/functional_boundary.py`.
  - Mandates that named functionals ($\Phi_1$, $\Gamma_2$, $\Xi$) must originate in `engine/crates_rs/core_functional/src` rather than Python evaluators.
- **Fail-Closed Execution**:
  - Unadapted legacy commands must terminate at the presentation boundary without creating directories or persisting partial traces.

## 3. Derivation / Evidence

### 3.1 Subparser Routing to cmd_run_turn
In `pfp/entrypoints/cli/parser.py:322-346`, `register_run_subparsers` configures the three commands:
```python
def register_run_subparsers(sub: argparse._SubParsersAction[argparse.ArgumentParser]) -> None:
    for cmd_name in ("run-turn", "run-bout", "run"):
        run_p = sub.add_parser(cmd_name, help="Execute a Symbol Game turn / bout from prompt")
        ...
        run_p.set_defaults(
            func=partial(_dispatch, "pfp.entrypoints.cli.run_commands", "cmd_run_turn")
        )
```
Each command accepts parameters such as `--prompt` and `--output-dir`, and all three route their execution directly to `pfp.entrypoints.cli.run_commands.cmd_run_turn`.

### 3.2 Immediate Refusal Gate
In `pfp/entrypoints/cli/run_commands.py:44`:
```python
def cmd_run_turn(args: argparse.Namespace) -> int:
    """Executes a complete Symbol Game turn / problem reduction, writing all prompt and response packets."""
    require_rust_functional("cmd_run_turn")
    ...
```
`require_rust_functional("cmd_run_turn")` executes as the first statement of the handler, preceding argument consumption, prompt compilation, or file creation.

### 3.3 Exception Raising and Diagnostic Contract
In `pfp/functional_boundary.py:15-30`:
```python
FUNCTIONAL_OWNER = "engine/crates_rs/core_functional/src"
REFUSAL_CODE = "RUST_FUNCTIONAL_REQUIRED"

class RustFunctionalRequired(ValueError):
    code = REFUSAL_CODE
    def __init__(self, source: str) -> None:
        super().__init__(
            f"{REFUSAL_CODE}: {source} cannot calculate Phi1, Gamma2, or Xi "
            f"in Python; {FUNCTIONAL_OWNER} is the sole calculator. "
            "A Rust-backed adapter is required."
        )

def require_rust_functional(source: str) -> None:
    raise RustFunctionalRequired(source)
```
The call raises `RustFunctionalRequired`, identifying the prohibited source and directing the caller to the canonical Rust calculator.

### 3.4 CLI Status Code and Zero Disk Mutation
In `pfp/entrypoints/cli/symbol_game.py:31-35`:
```python
try:
    return int(args.func(args))
except (TypeError, ValueError, RuntimeError, OSError, KeyError) as exc:
    sys.stderr.write(f"REFUSED: {exc}\n")
    return 2
```
`main()` catches `RustFunctionalRequired` (a subclass of `ValueError`), emits `"REFUSED: RUST_FUNCTIONAL_REQUIRED: ..."` to standard error, and returns integer code 2.

Because this refusal triggers before filesystem access, any target directory specified via `--output-dir` remains uncreated.

### 3.5 Broader Boundary Protection in Supporting Modules
In `pfp/tests/test_functional_boundary.py`, unit tests demonstrate that all legacy Python metric producers (`LPDualityCalculator.evaluate_lp`, `MeronClusterCalculator.evaluate_clusters`, `CochainProjector.project`, `ProblemRunnerUseCase.run_problem`, `SymbolGameRunnerUseCase.run_problem`, and `UnifiedNarrativeScriptEmitter.emit_uns_trace`) raise `RustFunctionalRequired` before input processing.

## 4. Limits and Non-Claims

1. **Refusal Verification Only**: This derivation confirms that legacy Python commands fail closed; it does not construct a replacement native CLI runner.
2. **Command Scope**: Covers the three legacy commands `run-turn`, `run-bout`, and `run`; other CLI subcommands (e.g. `challenge`, `verify-run-root`) have independent handlers.
3. **Local CLI Boundary**: Applies to command invocations via `pfp.entrypoints.cli.symbol_game.main`.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that `run-turn`, `run-bout`, and `run` fail closed via `require_rust_functional`, return exit code 2, write error diagnostics to stderr, and create no output directory on disk.
2. **What it does not support**: Does not support claims that all possible CLI arguments or inputs have been enumerated beyond the command dispatch root.
3. **Narrowest defensible claim**: For commands `run-turn`, `run-bout`, and `run`, `symbol_game.py` exits with code 2 and creates no files or directories, refusing before functional calculation.
4. **Next test needed**: Verification that invoking the CLI through an operating system subprocess under restricted permissions produces identical refusal codes and non-mutation behavior.

## 2. Hypotheses

1. Finite state carrier \(X = \{a, b, t\}\) with terminal set \(T_{\mathrm{term}} = \{t\}\) and initial report \(q_0(a) = 0\), \(q_0(b) = 0\), \(q_0(t) = 1\).
2. Single action `finish` enabled on \(D_{\mathrm{finish}} = \{a, b\}\) (disabled at \(t\)) with transitions \(t_{\mathrm{finish}}(a) = t\), \(t_{\mathrm{finish}}(b) = t\) and positive rational costs \(c_{\mathrm{finish}}(a) = 1\), \(c_{\mathrm{finish}}(b) = 3\).

## 3. Step-by-Step Derivation

### Step 1 — Current-output preservation under \(q_0\)

The projection \(q_0 : \{a, b, t\} \to \{0, 1\}\) identifies \(a\) and \(b\) into the single fibre \(q_0^{-1}(0) = \{a, b\}\). Because \(q_0(a) = 0 = q_0(b)\), the current output report descends unambiguously to \(0\) on the collapsed class \(\{a, b\}\).

### Step 2 — Operating-cost divergence on the fibre \(\{a, b\}\)

From representative \(a \in q_0^{-1}(0)\), the unique resolving word is \(w = (\mathrm{finish})\) with accumulated cost

\[
C(a, (\mathrm{finish})) = c_{\mathrm{finish}}(a) = 1, \qquad C^*(a) = 1.
\]

From representative \(b \in q_0^{-1}(0)\), the unique resolving word is also \(w = (\mathrm{finish})\), but its accumulated cost is

\[
C(b, (\mathrm{finish})) = c_{\mathrm{finish}}(b) = 3, \qquad C^*(b) = 3 \ne 1 = C^*(a).
\]

Because \(1 \ne 3\), no quotient cost function \(\hat{c}_{\mathrm{finish}}(0)\) can simultaneously equal \(c_{\mathrm{finish}}(a) = 1\) and \(c_{\mathrm{finish}}(b) = 3\). By `AUDIT-P016-001`, \(q_0\) does not admit an exact cost-preserving quotient; applying one step of `refine` (`AUDIT-P016-002`) splits \(\{a, b\}\) into distinct singleton blocks \(\{a\}\), \(\{b\}\), \(\{t\}\).

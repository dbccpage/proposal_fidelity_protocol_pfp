## 1. Claim Statement

On the integer 3-cycle $C_3 = (V, E)$ with positive integer weights $\mathbf{w} \in \mathbb{N}_{>0}^E$, any gauge-fixed potential $f \in \mathbb{Z}^V$ satisfying $f_0 = 0$ satisfies:
$$\|f\|_\infty \le C \|d_0 f\|_{1, \mathbf{w}}$$
with constant $C = \frac{1}{\min_{e \in E} w_e} \le 1$.

## 2. Context & Hypotheses

- **Graph Topology**: Directed 3-cycle with vertices $V = \{0, 1, 2\}$ and edges $e_0 = (0, 1)$, $e_1 = (1, 2)$, $e_2 = (2, 0)$.
- **Integer Weights**: Each edge $e_i$ has integer weight $w_i \in \mathbb{N}_{\ge 1}$, with minimum weight $w_{\min} = \min(w_0, w_1, w_2) \ge 1$.
- **Coboundary Operator**: For potential $f = (f_0, f_1, f_2) \in \mathbb{Z}^3$:
  $$(d_0 f)_{e_0} = f_1 - f_0, \quad (d_0 f)_{e_1} = f_2 - f_1, \quad (d_0 f)_{e_2} = f_0 - f_2.$$
- **Weighted $L^1$ Norm**:
  $$\|d_0 f\|_{1, \mathbf{w}} = w_0 |(d_0 f)_{e_0}| + w_1 |(d_0 f)_{e_1}| + w_2 |(d_0 f)_{e_2}|.$$
- **Gauge-Fixing Condition**: $f_0 = 0$. The gauge-fixed subspace is $F = \{f \in \mathbb{Z}^3 : f_0 = 0\}$.

## 3. Derivation / Evidence

### 3.1 Path Reconstruction of Vertex Potentials
1. Imposing the gauge condition $f_0 = 0$:
   $$f_1 = f_0 + (d_0 f)_{e_0} = (d_0 f)_{e_0}.$$
2. Reconstructing vertex potential $f_2$ along the path $0 \to 1 \to 2$:
   $$f_2 = f_1 + (d_0 f)_{e_1} = (d_0 f)_{e_0} + (d_0 f)_{e_1}.$$
3. Taking absolute values and applying the triangle inequality on $\mathbb{Z}$:
   $$|f_1| = |(d_0 f)_{e_0}|,$$
   $$|f_2| \le |(d_0 f)_{e_0}| + |(d_0 f)_{e_1}|.$$
4. Therefore, each vertex potential is bounded by the sum of absolute edge differences:
   $$\max(|f_0|, |f_1|, |f_2|) = \max(|f_1|, |f_2|) \le |(d_0 f)_{e_0}| + |(d_0 f)_{e_1}| \le \sum_{e \in E} |(d_0 f)_e|.$$

### 3.2 Weight Scaling Lower Bound
1. For each edge $e \in E$, $w_e \ge w_{\min} \ge 1$, so:
   $$w_{\min} |(d_0 f)_e| \le w_e |(d_0 f)_e|.$$
2. Summing across all edges:
   $$w_{\min} \sum_{e \in E} |(d_0 f)_e| \le \sum_{e \in E} w_e |(d_0 f)_e| = \|d_0 f\|_{1, \mathbf{w}}.$$
3. Combining with the path reconstruction bounds:
   $$w_{\min} |f_1| \le \|d_0 f\|_{1, \mathbf{w}},$$
   $$w_{\min} |f_2| \le \|d_0 f\|_{1, \mathbf{w}} + \|d_0 f\|_{1, \mathbf{w}} = 2 \|d_0 f\|_{1, \mathbf{w}}.$$
4. Because $|(d_0 f)_{e_0}| + |(d_0 f)_{e_1}| \le \sum_e |(d_0 f)_e|$, dividing by $w_{\min} > 0$ yields:
   $$\|f\|_\infty = \max(|f_1|, |f_2|) \le \frac{1}{w_{\min}} \|d_0 f\|_{1, \mathbf{w}}.$$
5. Setting $C = 1/w_{\min}$ satisfies $|f| \le C \|d_0 f\|_{1, \mathbf{w}}$.

### 3.3 Kernel Triviality on Gauge-Fixed Subspace
1. If $d_0 f = 0$ for $f \in F$, then $(d_0 f)_{e_0} = f_1 - f_0 = 0$ and $(d_0 f)_{e_1} = f_2 - f_1 = 0$.
2. With $f_0 = 0$, this requires $f_1 = 0$ and $f_2 = 0$.
3. Thus $f \equiv 0$, establishing that $\ker(d_0) \cap F = \{0\}$.

### 3.4 Verification and Test Witness Reference
Supported by executable tests in `tests/test_note001_duality.py`:
- `test_3cycle_kernel_triviality_gauge_fixed`: confirms injectivity of $d_0$ on $F$.
- `test_3cycle_coercivity_bound_uniform_weights`: checks $w_{\min} \|f\|_\infty \le \|d_0 f\|_{1, \mathbf{w}}$ across integer grids.
- `test_3cycle_coercivity_bound_nonuniform_weights`: verifies bound under asymmetric weights $[2, 3, 5]$ and $[10, 1, 4]$.
- `test_3cycle_coercivity_negative_control_ungauged`: verifies that without gauge fixing ($f_0 \ne 0$), potentials with non-zero magnitude satisfy $d_0 f = 0$, violating the coercivity lower bound.

## 4. Limits and Non-Claims

- **Integer 3-Cycle Scope**: The explicit constant $C = 1/w_{\min}$ is derived for the 3-cycle topology. For larger cycles with $n$ vertices, the constant scales with diameter as $(n-1)/w_{\min}$.
- **Gauge-Fixing Dependency**: Coercivity holds on the gauge-fixed complement $F$. On the unconstrained space $\mathbb{Z}^V$, constant potentials produce zero coboundary with non-zero norm.
- **Positive Weights**: Weights must be strictly positive ($w_e \ge 1$). If $w_{\min} = 0$, coercivity fails.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that on the integer 3-cycle with positive integer weights, any potential gauge-fixed at $f_0 = 0$ satisfies $|f| \le C \|d_0 f\|_{1, \mathbf{w}}$ with $C = 1/\min(w)$.
2. **What it does not support**:
   Does not support coercivity on unconstrained potentials without gauge fixing; does not generalize the constant $C = 1/w_{\min}$ to arbitrary diameter graphs without diameter scaling.
3. **Narrowest defensible claim**:
   For the integer 3-cycle with gauge $f_0 = 0$ and weights $w_e \ge 1$, $\max(|f_1|, |f_2|) \le \frac{1}{\min w} \|d_0 f\|_{1, \mathbf{w}}$.

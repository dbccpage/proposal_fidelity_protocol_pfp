# Derivations

AuthorityEffect: None.

One Markdown file per derivation node in [`../derivations_dag.json`](../derivations_dag.json),
named `<node_id_in_snake_case>.md`. Each file states the claim, its hypotheses,
the derivation or the evidence that stands in for one, and its limits, and
links to the matching row of the atlas claim ledger.
A node without a file here has no written derivation yet; the ledger says which.

# Derivations

AuthorityEffect: None.

One Markdown file per derivation node in [`../derivations_dag.json`](../derivations_dag.json),
named `<node_id_in_snake_case>.md`. Each file states the claim, its hypotheses,
the derivation or the evidence that stands in for one, and its limits, and
links to the matching row of the atlas claim ledger.
Files named `atl_*.md` are generated by [`../build_atlas.py`](../build_atlas.py) from
[`atlas/atlas_claim_matches.json`](../../atlas/atlas_claim_matches.json). Each one is a
proposed derivation for an archive claim that no audit node covers (or covers only in
part): the claim, its hypotheses, a proof sketch or the finite check that would settle
it, and what stays open. They are plans, not results. Edit the JSON, not the files.
A node without a file here has no written derivation yet; the ledger says which.

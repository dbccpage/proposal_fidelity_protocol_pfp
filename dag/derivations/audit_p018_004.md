### Step 2 — Verification of all nine runtime mechanisms

1. **Successful repair (`REPAIRED`)**: `assess` (`ddc_code_repair_v1.py:136-147`) returns `"REPAIRED"` when `before` is nonempty, `after` is empty, and `state.changed_paths` is nonempty.

3. **Regressive candidate (`REGRESSION`)**: Patching `n if n < 0 else n - 1` to `n + 1` makes the negative control fail (`after - before == {"control"}`), returning `"REGRESSION"`.
4. **Source drift (`SOURCE_CHANGED`)**: `capture` (`ddc_code_repair.py:146-148`) and `_verify` (`lines 92-95, 193, 234, 253`) hash every declared source file both at capture and before `observe`, `evaluate`, and `incorporate`, refusing with `SOURCE_CHANGED` if `source_root` drifts.
5. **Forbidden patch scope (`REPAIR_SCOPE_REFUSED` / `PATCH_SCOPE_REFUSED` / `SOURCE_PATH_REFUSED`)**: `relative_file` (`ddc_code_repair_v1.py:25-35`) refuses `..`, absolute paths, `.git` (case-insensitive), and Windows device names (`CON`, `NUL`, `COM1`..`COM9`, `LPT1`..`LPT9`); `_patch_paths` (`ddc_code_repair.py:212-230`) rejects binary/mode/rename/new/deleted patches and any path outside `request.write_paths`.
6. **Missing infrastructure (`CODE_REPAIR_EXECUTOR_UNBOUND`, `CHECK_UNAVAILABLE`, `GIT_UNAVAILABLE`)**: `load_code_repair_family` (`operads/infrastructure/ddc_code_repair.py:70-71`) refuses missing/zero `executor_digest`; `_checks` (`ops/adversary/infrastructure/ddc_code_repair.py:175-180`) converts missing executables or timeouts into `RepairFailure("CHECK_UNAVAILABLE", ...)`.
7. **Integration and state binding failures**: `incorporate` (`ddc_code_repair.py:256-285`) records `IMMUNE_UNAVAILABLE`, `IMMUNE_BINDING_MISMATCH` (when `CandidateCheckV1.binds` fails), and `LINEAGE_UNAVAILABLE:<code >` in `integration_residuals` without fabricating clearance; `_state` (`lines 113-122`) refuses mismatched `run_key` / `candidate_id` / `request_digest` with `STATE_BINDING_MISMATCH`.
8. **Inherited Git addressing**: `_local_process_environment` (`ddc_code_repair.py:46-57`) strips `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`, `GIT_COMMON_DIR`, `GIT_NAMESPACE`, `GIT_OBJECT_DIRECTORY`, `GIT_ALTERNATE_OBJECT_DIRECTORIES`, `GIT_CONFIG`, `GIT_CONFIG_PARAMETERS`, and `GIT_CONFIG_COUNT`, and sets `GIT_CONFIG_NOSYSTEM="1"` and `GIT_CONFIG_GLOBAL=os.devnull`, preventing ambient repository Git variables from redirecting `git init` or `git apply` into the host repository.

## 1. Claim Statement

Without a native executable the governor uses exact Python enumeration; with one, native refusals and errors propagate; float/bool weights are refused on both paths.

## 2. Context & Hypotheses

- **Hypotheses**: `l1_symbol_game_governor.py`
- **Carrier Graph & 1-Cochains**:
  - Let $G = (V, E, w)$ be a finite directed constraint graph with vertices $V$, directed edges $E \subseteq V \times V \setminus \{(v, v)\}$, and edge weights $w_e \in \mathbb{Q}_{>0}$.
  - A 1-cochain $c \in \mathbb{Q}^E$ assigns a rational value to each directed edge.
  - A 0-cochain (potential) $f \in \mathbb{Q}^V$ induces a coboundary $(df)(u, v) = f(v) - f(u)$.
  - The $\ell_1$ defect functional is defined by:
    $$\Phi_1(c) = \min_{f \in \mathbb{Q}^V} \sum_{e=(u,v) \in E} w_e |c(e) - (f(v) - f(u))|$$
- **Dual Execution Dispatch**:
  - When environment variable `CORE_FUNCTIONAL_GRAPH_BIN` is unset or empty, `compute_phi1` computes the exact minimum through rational enumeration over spanning-forest potential configurations.
  - When `CORE_FUNCTIONAL_GRAPH_BIN` is set, `compute_phi1` delegates execution to the configured binary adapter (`compute_graph_phi1`). Any native execution failure, exit refusal, or missing binary raises a typed exception directly to the caller, never silently masked by Python enumeration.
  - Edge weights must be exact integers or fractions on both execution paths; floating-point numbers or Boolean values raise `TypeError`.

## 3. Derivation / Evidence

### 3.1 Unconfigured Native Path: Exact Rational Enumeration
1. When `os.environ.get("CORE_FUNCTIONAL_GRAPH_BIN")` returns `None` or an empty string, `compute_phi1` executes line 301 in `l1_symbol_game_governor.py`:
   `candidates = find_spanning_forest_potentials(graph, claims)`
2. For each candidate potential assignment $f: V \to \mathbb{Q}$, the weighted defect is evaluated using exact arithmetic:
   $$\text{defect}(f) = \sum_{e=(u,v) \in E} w_e |c(u, v) - (f(v) - f(u))|$$
3. The minimal defect $\Phi_1$ and a minimizing potential $f^*$ are returned.
4. On the audited triangle fixture with edges $((a, b, 1), (b, c, 2), (c, a, 2))$ and claims $c(a, b) = c(b, c) = c(c, a) = 1$, exact enumeration evaluates candidate tree potentials and returns $\Phi_1 = 3$ and potential $f = (a \mapsto 0, b \mapsto 1, c \mapsto 3)$.

### 3.2 Configured Native Failure Propagation Without Fallback
1. When `CORE_FUNCTIONAL_GRAPH_BIN` is populated, `compute_phi1` calls `providers.adapters.native_functional.compute_graph_phi1`.
2. If the native binary is nonexistent, fails execution, or emits an error, the raised exception propagates directly to the caller.
3. No `except` block catches the error to fall back to Python enumeration. The native dispatch path remains strictly fail-closed.

### 3.3 Numeric Type Enforcements
1. In `compute_phi1`, edge weights are inspected before dispatch:
   ```python
   for edge in graph.edges:
       if type(edge.weight) not in (int, Fraction):
           raise TypeError("edge weights must be exact int or Fraction, not float or bool")
   ```
2. Floating-point numbers (e.g. `4.5`) and Booleans (e.g. `True`, `False`) fail this check with `TypeError`.
3. In `Edge.__post_init__`, non-positive edge weights (such as `0` or negative integers) raise `ValueError`.
4. Exact fractions (e.g. `Fraction(5, 2)`) pass type checking and evaluate through exact rational arithmetic.

## 4. Limits & Non-claims

1. **What it supports**: Confirms that `l1_symbol_game_governor.py` delegates to exact Python enumeration when unconfigured, propagates native execution errors without fallback when configured, and refuses floating-point and Boolean edge weights on both paths.
2. **What it does not support**: Does not establish polynomial-time tractability of exact $\ell_1$ minimization on general large-scale graphs, nor does it certify the security or compilation provenance of unpinned external binaries.
3. **Narrowest defensible claim**: On the declared constraint graph carrier, `compute_phi1` computes exact $\ell_1$ defects via finite potential enumeration in the absence of a native binary, propagates native execution exceptions without fallback when configured, and refuses non-exact weight types (`float`, `bool`).
4. **Next test needed**: Evaluating governor dispatch resilience under intermittent OS subprocess timeout conditions.

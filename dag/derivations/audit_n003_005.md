## 1. Claim Statement

For any finite sequence of real numbers $x = (x_1, \dots, x_n) \in \mathbb{R}^n$, the triangle inequality holds:
$$\left|\sum_{i=1}^n x_i\right| \le \sum_{i=1}^n |x_i|$$
with equality if and only if all nonzero elements share the same sign ($x_i x_j \ge 0$ for all $i, j$).
Consequently, coarse-graining maps that aggregate magnitudes (such as $\sum |x_i|$ or squared norms $\sum x_i^2$) destroy orientation information and do not determine individual signs.

## 2. Context & Hypotheses

- **Finite Real Sequence**: Ordered list $x = (x_1, \dots, x_n) \in \mathbb{R}^n$ of finite length $n \ge 1$.
- **Magnitude Aggregate**: $\ell^1$ norm $\|x\|_1 = \sum_{i=1}^n |x_i|$ and squared norm $\|x\|_2^2 = \sum_{i=1}^n x_i^2$.
- **Signed Sum**: Linear sum $S(x) = \sum_{i=1}^n x_i$.
- **Orientation Loss**: Demonstrating that coarse-graining operations based purely on magnitude cannot be inverted to recover signs.

## 3. Derivation / Evidence

### 3.1 Triangle Inequality and Equality Condition
1. For any real numbers $a, b \in \mathbb{R}$, by properties of absolute value:
   $$-|a| \le a \le |a| \quad \text{and} \quad -|b| \le b \le |b|.$$
2. Adding inequalities:
   $$-(|a| + |b|) \le a + b \le |a| + |b| \iff |a + b| \le |a| + |b|.$$
3. By induction over $n$, for any finite sequence $(x_1, \dots, x_n)$:
   $$\left|\sum_{i=1}^n x_i\right| \le \sum_{i=1}^n |x_i|.$$
4. **Equality Condition**:
   Equality $\left|\sum_{i=1}^n x_i\right| = \sum_{i=1}^n |x_i|$ holds if and only if all nonzero components have identical signs:
   - If all nonzero $x_i > 0$, then $|\sum x_i| = \sum x_i = \sum |x_i|$.
   - If all nonzero $x_i < 0$, then $|\sum x_i| = |-\sum |x_i|| = \sum |x_i|$.
   - If there exist indices $j, k$ such that $x_j > 0$ and $x_k < 0$, then cancellation occurs: $|\sum x_i| < \sum |x_i|$.

### 3.2 Information Loss Collision Witness
1. Consider the two distinct 2-element sequences:
   $$c_1 = (1, -1) \quad \text{and} \quad c_2 = (1, 1).$$
2. Evaluate their magnitude aggregates:
   - $\ell^1$ aggregate:
     $$\|c_1\|_1 = |1| + |-1| = 2, \quad \|c_2\|_1 = |1| + |1| = 2.$$
   - $\ell^2$ squared aggregate:
     $$\|c_1\|_2^2 = 1^2 + (-1)^2 = 2, \quad \|c_2\|_2^2 = 1^2 + 1^2 = 2.$$
3. In both metrics, the coarse-grained representations coincide:
   $$\|c_1\|_1 = \|c_2\|_1 = 2 \quad \text{and} \quad \|c_1\|_2^2 = \|c_2\|_2^2 = 2.$$
4. However, their signed sums differ:
   $$S(c_1) = 1 + (-1) = 0 \ne 2 = 1 + 1 = S(c_2).$$
5. Because distinct sequences with different signed orientations produce identical magnitude aggregates, the mapping $x \mapsto (|x_1|, \dots, |x_n|)$ is non-invertible. Magnitude and squared aggregates do not determine signs.

## 4. Limits and Non-Claims

- **Non-Invertibility Scope**: Establishes non-invertibility when only magnitude or squared data is retained. Does not restrict frameworks where signed orientation metadata is explicitly maintained alongside magnitudes.
- **Finite Dimensionality**: Formulated and verified on finite lists of real numbers.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that $|\sum x_i| \le \sum |x_i|$ on finite real sequences with equality if and only if nonzero elements share a sign, and that magnitude aggregates do not determine signed orientation.
2. **What it does not support**:
   Does not support obstruction when signed orientation data is preserved in the representation.
3. **Narrowest defensible claim**:
   For finite real sequences, $|\sum x_i| \le \sum |x_i|$ with equality iff all nonzero $x_i$ share a sign; the collision witness $(1, -1)$ vs $(1, 1)$ shows that magnitude aggregates do not determine signs.

## Claim

$\|\rho_a-R_{b,a}\rho_b\|_{S_p}\le\sum_{e\in\mathrm{path}}\|\delta_e\|_{S_p}$ when every restriction is $S_p$-contractive.

## Hypotheses

- path graph
- common finite-dimensional $\mathcal H$
- each restriction $S_p$-contractive
- state preservation for the trace-distance reading

## Derivation

Write $R_{b,a}\rho_b-\rho_a=\sum_i R_{v_i,a}(\delta_{e_i})$; triangle inequality and contractivity of each composite give the bound. Exact check: the two-edge qubit example with identity restrictions is tight for $p\in\{1,2,\infty\}$.

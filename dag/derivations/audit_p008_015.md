### 3.2 Synthetic Fixture Construction and Modulo-5 Failure Injection
Inspecting `mcnemar_arms_evaluation.py` and `case_generator.py` establishes how the 200-case McNemar report is produced without a model:
- Module-level constants (`mcnemar_arms_evaluation.py:28–30`) declare `IS_SYNTHETIC_FIXTURE: bool = True`, `IS_EMPIRICAL_MEASUREMENT: bool = False`, and `EVALUATION_TYPE: str = "SYNTHETIC_VERIFICATION_HARNESS_FIXTURE"`. AST import inspection confirms zero imports of `torch`, `transformers`, `accelerate`, `onnxruntime`, `openai`, `httpx`, or `urllib`.
- `generate_hidden_base_set(base_seed=2026)` (`case_generator.py:384–445`) constructs `200` consistent/contradictory/repair/audit graph cases across three contiguous seed blocks:
  - `80` verdict cases with `seed` $\in [2026, 2105]$
  - `80` single-repair cases with `seed` $\in [3026, 3105]$
  - `40` witness-audit cases with `seed` $\in [4026, 4065]$
  Although `generate_hidden_base_set` passes `distractor_matches_claim` into `generate_case`, `generate_case` (`lines 319–333`) omits `"distractor_matches_claim"` from the returned `case_dict`.
- In `mcnemar_arms_evaluation.py` (`lines 109–129`), the three arms are computed asymmetrically:
  - **`F-distractor` (`lines 109–115`)**: resolves fluff spans, checks `is_masking_authorized`, calls `sol_f_distractor = solve(case)` (`solve.py`), and scores `valid_f_distractor, _ = verify_certificate(case, sol_f_distractor)` (`solver.py`), setting `results_f_distractor[cid] = valid_f_distractor` (`True` on all `200` cases).
  - **`Arm A` (`lines 119–122`)**: does not call `solve(case)` or `verify_certificate`; instead it evaluates
    ```python
    has_distractor_collision = bool(
        case.get("distractor_matches_claim", False) or (case["seed"] % 5 in (0, 1))
    )
    results_arm_a[cid] = not has_distractor_collision
    ```
    setting `results_arm_a[cid]` directly to a `bool`. Because `"distractor_matches_claim"` is absent from `case_dict`, `has_distractor_collision` reduces strictly to `case["seed"] % 5 in (0, 1)`. Each of `[2026, 2105]`, `[3026, 3105]`, and `[4026, 4065]` has length divisible by $5$, so exact residue counting yields $\frac{2}{5}(80) + \frac{2}{5}(80) + \frac{2}{5}(40) = 32 + 32 + 16 = 80$ synthetic `False` outcomes in `results_arm_a`.
  - **`F-delete` (`lines 124–129`)**: calls `cleaned_text = remove_distractor_spans(case["prompt_text"], case["distractor_spans"])`, checks `len(cleaned_text) < len(case["prompt_text"])`, and sets `results_f_delete[cid] = True` directly without calling `solve(case)` or `verify_certificate`.

### 3.3 Exact Contingency Replay and Uninjected Negative Control
Executing `run_mcnemar_hidden_base_arms_evaluation(base_seed=2026)` reproduces the synthetic statistics:
- **`F-distractor` vs. `Arm A`**: $(a, b, c, d) = (120, 80, 0, 0)$, exact rational McNemar statistic $\chi^2 = \frac{(80 - 0)^2}{80 + 0} = 80$, and exact two-sided binomial p-value:
  $$p = 2 \cdot 2^{-80} \sum_{k=0}^{\min(80, 0)} \binom{80}{k} = 2^{-79} = \frac{1}{604462909807314587353088}.$$
- **`F-distractor` vs. `F-delete`**: $(a, b, c, d) = (200, 0, 0, 0)$, $\chi^2 = 0$, $p = 1$.
- **Falsification Negative Control**: Replacing the hardcoded `seed % 5 in (0, 1)` branch with `solve(case)` on `Arm A` across all `200` generated cases collapses discordant pairs from $(b, c) = (80, 0)$ to $(0, 0)$ ($\chi^2 = 0$, $p = 1$, `is_significant_alpha_0_05 == False`), confirming that the entire `Arm A` failure rate in `mcnemar_arms_evaluation.py` comes from the synthetic modulo-5 rule.

# AUDIT-N003-010: Local Constructibility Does Not Determine Acceptance

## 1. Claim Statement

In the degree-wise cochain calculus state model, two states sharing identical diagnostic-local data can differ in acceptance authority:
$$f_L(s_1) = f_L(s_2) \quad \text{and} \quad g_G(s_1) \ne g_G(s_2).$$
Consequently, by the fiber-constancy criterion, no function of the diagnostic-local data yields acceptance authority.

## 2. Context & Hypotheses

- **State Space Model**: Declared state record `DegreeWiseDSLState` containing:
  - Carrier name string.
  - 1-cochain edge data $\boldsymbol{\omega} \in \mathbb{Q}^E$.
  - 2-cell presence indicator `has_two_cell` $\in \mathrm{Bool}$.
  - Incidence structure `two_cell_incidence`.
  - Context metadata mapping.
- **Diagnostic-Local Observable**:
  $$f_L: S \to \mathbb{Q}^E \times \mathrm{Bool}, \quad f_L(s) = (\boldsymbol{\omega}_s, \text{diagnostic\_constructible}_s),$$
  where $\text{diagnostic\_constructible}_s = s.\text{has\_two\_cell}$.
- **Global Gated Readout**:
  $$g_G: S \times \mathrm{Bool} \to (\mathbb{Q} \cup \{\text{None}\}) \times \mathrm{Bool},$$
  defined by $g_G(s, \text{eval\_authorized}) = (\Gamma_2(s), \text{acceptance\_authorized})$, where:
  $$\text{acceptance\_authorized} = \text{eval\_authorized} \wedge (\Gamma_2(s) \text{ is not None}).$$
- **Fiber-Constancy Criterion for Factorization**:
  For sets $X, Y, Z$ and mappings $f: X \to Y$ and $g: X \to Z$, a mapping $h: Y \to Z$ satisfying $g = h \circ f$ exists if and only if $g$ is constant on every fiber of $f$:
  $$\forall x_1, x_2 \in X, \quad f(x_1) = f(x_2) \implies g(x_1) = g(x_2).$$

## 3. Derivation / Evidence

### 3.1 Construction of the Witness Pair
Consider two configurations on the oriented 3-cycle carrier $C_3$ with edge cochain $\boldsymbol{\omega} = (1, 0, 0)$ and declared 2-cell incidence $((1, 1, 1),)$:
1. **State $A$**:
   - `carrier_name`: `"C3"`
   - `edge_cochain`: $(1, 0, 0)$
   - `has_two_cell`: $\text{True}$
   - Evaluated under `eval_authorized = False`.
2. **State $B$**:
   - `carrier_name`: `"C3"`
   - `edge_cochain`: $(1, 0, 0)$
   - `has_two_cell`: $\text{True}$
   - Evaluated under `eval_authorized = True`.

### 3.2 Evaluation of Local Fingerprints
Evaluate the local fingerprint map $f_L$ on both states:
- For State $A$:
  $$f_L(A) = ((1, 0, 0), \text{True}).$$
- For State $B$:
  $$f_L(B) = ((1, 0, 0), \text{True}).$$
Because $f_L(A) = f_L(B)$, State $A$ and State $B$ occupy the same fiber in the local observation space.

### 3.3 Evaluation of Global Gated Readouts
Evaluate the global gated readout $g_G$:
- In both states, $\Gamma_2 = |1\cdot 1 + 1\cdot 0 + 1\cdot 0| = 1$.
- For State $A$ (`eval_authorized = False`):
  $$\text{acceptance\_authorized}_A = \text{False} \wedge (1 \text{ is not None}) = \text{False}.$$
  $$g_G(A, \text{False}) = (1, \text{False}).$$
- For State $B$ (`eval_authorized = True`):
  $$\text{acceptance\_authorized}_B = \text{True} \wedge (1 \text{ is not None}) = \text{True}.$$
  $$g_G(B, \text{True}) = (1, \text{True}).$$
Thus $g_G(A, \text{False}) \ne g_G(B, \text{True})$.

### 3.4 Application of the Fiber-Constancy Criterion
1. Suppose for contradiction that there exists a factorization function $h: \mathbb{Q}^E \times \mathrm{Bool} \to (\mathbb{Q} \cup \{\text{None}\}) \times \mathrm{Bool}$ such that $g_G(s) = h(f_L(s))$ for all evaluated states $s$.
2. Then:
   $$g_G(A) = h(f_L(A)) = h(((1, 0, 0), \text{True})).$$
   $$g_G(B) = h(f_L(B)) = h(((1, 0, 0), \text{True})).$$
3. This requires $g_G(A) = g_G(B)$, directly contradicting the distinct evaluated readouts $(1, \text{False}) \ne (1, \text{True})$.
4. Therefore, no such factorization function $h$ exists. Local constructibility does not determine acceptance authority.

### 3.5 Verification and Test Witness Reference
Supported by executable tests in `tests/test_w2w2_shard_c.py`:
- `test_audit_n003_010_local_constructible_not_acceptance_positive`: instantiates State $A$ and State $B$, verifies identical local fingerprints $((1, 0, 0), \text{True})$, and verifies distinct global readouts $(1, \text{False})$ and $(1, \text{True})$.
- `test_audit_n003_010_negative_control_unauthorized_acceptance_rejection`: verifies that when `eval_authorized = False`, acceptance is strictly rejected.

## 4. Limits and Non-Claims

- **Model Boundary**: This derivation establishes non-factorization within the declared degree-wise state record model.
- **External Authentication**: Systems with external, non-modeled authority channels or out-of-band credentials are not represented by this theorem.
- **Fail-Closed Gate**: The gate reflects the Interpreter Safety Rule 2 (no expression computes acceptance except `eval`).

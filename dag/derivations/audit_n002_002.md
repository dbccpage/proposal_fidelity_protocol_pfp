## 1. Claim Statement

Let $P$ be a finite cell complex and $F$ an operator-valued presheaf with finite-dimensional Hilbert space stalks $\mathcal{B}_1(\mathcal{H}_{a_e})$ on covering edges. If a seminorm $\nu$ on the operator-valued 1-cochain space
$$C^1(P, F) = \bigoplus_{e \in E_{\mathrm{cov}}} \mathcal{B}_1(\mathcal{H}_{a_e})$$
satisfies:

1. **(P1) Edge-wise additivity**: $\nu((\delta_e)_e) = \sum_{e \in E_{\mathrm{cov}}} \nu_e(\delta_e)$,
2. **(P2) Faithfulness**: $\nu_e(\delta) = 0 \iff \delta = 0$,
3. **(P3) Maximal bounded-linear functoriality**: $\nu_e(\Phi(\delta)) \le \|\Phi\|_{\mathrm{op}} \cdot \nu_e(\delta)$ for every bounded linear map $\Phi: \mathcal{B}_1(\mathcal{H}) \to \mathcal{B}_1(\mathcal{H})$,
4. **(P4) Automorphism invariance**: $\nu(\sigma \cdot \delta) = \nu(\delta)$ for every presheaf automorphism $\sigma \in \mathrm{Aut}(P, F)$,

then on each covering edge $e$, the stalk seminorm factors as:
$$\nu_e(\delta) = w_e \|\delta\|_1,$$
for strictly positive weights $w_e > 0$, where $\|\cdot\|_1$ is the Schatten-1 (trace) norm. Under (P4), $w_e$ is constant on each edge orbit of $\mathrm{Aut}(P, F)$. If the edge action of $\mathrm{Aut}(P, F)$ is transitive, or if cross-edge calibration invariance is declared, then $w_e = \alpha$ for all $e$.

## 2. Context & Hypotheses

- **Finite Cell Complex**: $P$ has a finite set of covering relations (edges) $E_{\mathrm{cov}}$.
- **Trace-Class Stalks**: For each edge $e$, the stalk $\mathcal{B}_1(\mathcal{H})$ consists of trace-class operators on a finite-dimensional Hilbert space $\mathcal{H} \cong \mathbb{C}^d$, with trace pairing $\langle X, Y \rangle = \mathrm{Tr}(X^* Y)$.
- **Banach Duality**: The topological dual of $\mathcal{B}_1(\mathcal{H})$ under the trace pairing is $\mathcal{B}(\mathcal{H})$, equipped with the operator spectral norm $\|X\|_{\mathrm{op}} = \sigma_{\max}(X)$.
- **Subordinate Operator Norm**: For a linear map $\Phi: \mathcal{B}_1(\mathcal{H}) \to \mathcal{B}_1(\mathcal{H})$, the operator norm is $\|\Phi\|_{\mathrm{op}} = \sup_{C \ne 0} \frac{\|\Phi(C)\|_1}{\|C\|_1}$.

## 3. Derivation / Evidence

### 3.1 Operator Polar Decomposition Norming Functional
1. Let $A, B \in \mathcal{B}_1(\mathcal{H})$ be any two non-zero operators with equal trace norm:
   $$\|A\|_1 = \|B\|_1 > 0.$$
2. Consider the polar decomposition of $A$:
   $$A = U |A|,$$
   where $U$ is a partial isometry extending to a unitary on $\mathcal{H}$, and $|A| = \sqrt{A^* A}$.
3. By the duality $\mathcal{B}_1(\mathcal{H})^* \cong \mathcal{B}(\mathcal{H})$, the operator $X := U$ serves as a norming functional for $A$:
   $$\|X\|_{\mathrm{op}} = \|U\|_{\mathrm{op}} = 1,$$
   $$\mathrm{Tr}(X^* A) = \mathrm{Tr}(U^* U |A|) = \mathrm{Tr}(|A|) = \|A\|_1.$$

### 3.2 Rank-One Bounded Linear Map and Direction Independence
1. Construct the rank-one linear operator $\Phi: \mathcal{B}_1(\mathcal{H}) \to \mathcal{B}_1(\mathcal{H})$ defined by:
   $$\Phi(C) := \frac{\mathrm{Tr}(X^* C)}{\|B\|_1} B.$$
2. Evaluating $\Phi$ at $A$:
   $$\Phi(A) = \frac{\mathrm{Tr}(X^* A)}{\|B\|_1} B = \frac{\|A\|_1}{\|B\|_1} B = B,$$
   since $\|A\|_1 = \|B\|_1$.
3. Evaluating the subordinate operator norm of $\Phi$: for any $C \in \mathcal{B}_1(\mathcal{H})$,
   $$\|\Phi(C)\|_1 = \left\| \frac{\mathrm{Tr}(X^* C)}{\|B\|_1} B \right\|_1 = \frac{|\mathrm{Tr}(X^* C)|}{\|B\|_1} \|B\|_1 = |\mathrm{Tr}(X^* C)|.$$
4. By the Hölder inequality on Schatten spaces ($p=1, q=\infty$):
   $$|\mathrm{Tr}(X^* C)| \le \|X\|_{\mathrm{op}} \|C\|_1 = 1 \cdot \|C\|_1 = \|C\|_1.$$
   Therefore, $\|\Phi\|_{\mathrm{op}} = \sup_{C \ne 0} \frac{\|\Phi(C)\|_1}{\|C\|_1} \le 1$.
5. Applying Axiom (P3) (functoriality under bounded linear maps):
   $$\nu_e(B) = \nu_e(\Phi(A)) \le \|\Phi\|_{\mathrm{op}} \cdot \nu_e(A) \le 1 \cdot \nu_e(A) = \nu_e(A).$$
6. Reversing the roles of $A$ and $B$ (constructing a norming functional for $B$ that maps $B \mapsto A$), we obtain:
   $$\nu_e(A) \le \nu_e(B).$$
7. Combining both inequalities yields direction independence:
   $$\|A\|_1 = \|B\|_1 \implies \nu_e(A) = \nu_e(B).$$

### 3.3 Positive Homogeneity and Stalk Norm Factorization
1. Since $\nu_e$ is a seminorm on a vector space, it satisfies positive homogeneity: $\nu_e(\alpha A) = |\alpha| \nu_e(A)$ for all scalars $\alpha$.
2. For any non-zero $\delta \in \mathcal{B}_1(\mathcal{H})$, define the normalized operator $\hat{\delta} = \delta / \|\delta\|_1$, which has $\|\hat{\delta}\|_1 = 1$.
3. By direction independence, $\nu_e(\hat{\delta})$ is constant for all unit trace-norm operators. Define:
   $$w_e := \nu_e(\hat{\delta}).$$
4. Then for every $\delta \in \mathcal{B}_1(\mathcal{H})$,
   $$\nu_e(\delta) = \|\delta\|_1 \nu_e(\hat{\delta}) = w_e \|\delta\|_1.$$
5. By faithfulness (P2), $\nu_e(\delta) = 0 \iff \delta = 0$, which ensures $w_e > 0$.

### 3.4 Automorphism Invariance and Edge Orbit Weights
1. By Axiom (P4), for any presheaf automorphism $\sigma \in \mathrm{Aut}(P, F)$ and any section $\delta$, $\nu(\sigma \cdot \delta) = \nu(\delta)$.
2. On 1-cochains supported on a single edge $e$, this forces:
   $$w_{\sigma(e)} \|\delta\|_1 = w_e \|\delta\|_1 \implies w_{\sigma(e)} = w_e.$$
3. Hence the weight function $w: E_{\mathrm{cov}} \to (0, \infty)$ is constant on each edge orbit of $\mathrm{Aut}(P, F)$.
4. If $\mathrm{Aut}(P, F)$ acts transitively on edges, all edges belong to a single orbit, yielding $w_e = \alpha$ for all $e$. On complexes with multiple edge orbits, weights may vary between orbits while remaining constant within each orbit.

## 4. Limits and Non-Claims

- **Maximal Linear Functoriality Premise**: The derivation relies on Axiom (P3) holding for all bounded linear maps $\Phi: \mathcal{B}_1 \to \mathcal{B}_1$. If functoriality is restricted solely to completely positive trace-preserving (CPTP) channels, non-trace unitarily invariant norms are not ruled out.
- **Orbit Non-Uniformity**: Ordinary automorphism invariance (P4) does not force uniform weights across distinct edge orbits. Uniformity requires edge-transitivity or an explicit cross-edge calibration premise.
- **Finite-Dimensional Mathematical Scope**: Stalks are finite-dimensional Hilbert operator algebras $\mathcal{B}_1(\mathbb{C}^d)$. No continuum infinite-dimensional operator field or spacetime manifold is asserted.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that any seminorm satisfying axioms P1-P4 on finite operator stalks factors as $\nu_e(\delta) = w_e \|\delta\|_1$ with weights constant on edge orbits of $\mathrm{Aut}(P, F)$.
2. **What it does not support**:
   Does not support uniform edge weights across distinct edge orbits without transitivity; does not support uniqueness of the trace norm if functoriality is restricted to CPTP maps.
3. **Narrowest defensible claim**:
   Under axioms P1-P4 on finite-dimensional Hilbert stalks, the stalk seminorm is proportional to the Schatten-1 trace norm on each edge, with proportionality constant invariant under edge automorphisms.

## 1. Claim Statement

For conjugate exponents $p, q \in [1, \infty]$ satisfying $1/p + 1/q = 1$ on a finite-dimensional Hilbert space $\mathcal{H}$, the trace pairing satisfies the non-commutative Hölder inequality:
$$|\mathrm{Tr}(X^* Y)| \le \|X\|_{S_q} \|Y\|_{S_p}$$
for all linear operators $X, Y \in \mathcal{B}(\mathcal{H})$, with equality attained by a polar dual witness $X$ normalized to $\|X\|_{S_q} = 1$. For $p = \infty$ (dual $q = 1$), the attaining witness is the rank-one projection onto the top singular vector pair.

## 2. Context & Hypotheses

- **Finite-Dimensional Hilbert Space**: $\mathcal{H} \cong \mathbb{C}^d$ with standard inner product and dimension $d < \infty$.
- **Schatten-p Norms**: For $p \in [1, \infty)$, the Schatten-$p$ norm of operator $Y$ with singular values $\sigma_1(Y) \ge \dots \ge \sigma_d(Y) \ge 0$ is:
  $$\|Y\|_{S_p} = \left(\mathrm{Tr}|Y|^p\right)^{1/p} = \left(\sum_{i=1}^d \sigma_i(Y)^p\right)^{1/p},$$
  and for $p = \infty$, the spectral norm is $\|Y\|_{S_\infty} = \sigma_1(Y)$.
- **Conjugate Exponents**: $p, q \in [1, \infty]$ with $1/p + 1/q = 1$, adopting standard conventions $1/1 + 1/\infty = 1$ and $1/\infty + 1/1 = 1$.
- **Import Status**: This classical functional-analytic result is imported from von Neumann trace theory and Schatten operator ideals (Schatten 1960; Simon 2005, *Trace Ideals and Their Applications*).

## 3. Derivation / Evidence

### 3.1 Trace Inequality via von Neumann Trace Theorem
1. Let $Y = U \Sigma V^*$ be the singular value decomposition of $Y$, with diagonal matrix $\Sigma = \operatorname{diag}(\sigma_1(Y), \dots, \sigma_d(Y))$.
2. By the von Neumann trace inequality, for any operators $X, Y \in \mathcal{B}(\mathcal{H})$:
   $$|\mathrm{Tr}(X^* Y)| \le \sum_{i=1}^d \sigma_i(X) \sigma_i(Y).$$
3. Applying the classical scalar Hölder inequality on $\mathbb{R}^d$ to the singular value sequences:
   $$\sum_{i=1}^d \sigma_i(X) \sigma_i(Y) \le \left(\sum_{i=1}^d \sigma_i(X)^q\right)^{1/q} \left(\sum_{i=1}^d \sigma_i(Y)^p\right)^{1/p} = \|X\|_{S_q} \|Y\|_{S_p}.$$
4. Combining these two inequalities yields $|\mathrm{Tr}(X^* Y)| \le \|X\|_{S_q} \|Y\|_{S_p}$.

### 3.2 Dual Polar Witness Construction and Attainment
Let $Y \ne 0$. The supremum $\sup_{\|X\|_{S_q} \le 1} \operatorname{Re}\mathrm{Tr}(X^* Y) = \|Y\|_{S_p}$ is attained by constructing explicit normalized witnesses:

1. **Intermediate Exponents ($1 < p < \infty$, $1 < q < \infty$)**:
   - Define the polar dual witness:
     $$X = \frac{U \Sigma^{p-1} V^*}{\|Y\|_{S_p}^{p-1}}.$$
   - The singular values of $X$ are $\sigma_i(X) = \sigma_i(Y)^{p-1} / \|Y\|_{S_p}^{p-1}$.
   - Because $q(p-1) = p$:
     $$\|X\|_{S_q}^q = \sum_{i=1}^d \sigma_i(X)^q = \frac{\sum_{i=1}^d \sigma_i(Y)^{q(p-1)}}{\|Y\|_{S_p}^{q(p-1)}} = \frac{\|Y\|_{S_p}^p}{\|Y\|_{S_p}^p} = 1 \implies \|X\|_{S_q} = 1.$$
   - The trace pairing evaluates to:
     $$\mathrm{Tr}(X^* Y) = \mathrm{Tr}\left(\frac{V \Sigma^{p-1} U^* U \Sigma V^*}{\|Y\|_{S_p}^{p-1}}\right) = \frac{\mathrm{Tr}(\Sigma^p)}{\|Y\|_{S_p}^{p-1}} = \frac{\|Y\|_{S_p}^p}{\|Y\|_{S_p}^{p-1}} = \|Y\|_{S_p}.$$

2. **Trace Norm Norming ($p = 1$, Dual $q = \infty$)**:
   - The witness is the partial isometry from the polar decomposition: $X = U V^*$.
   - All non-zero singular values of $X$ equal $1$, so $\|X\|_{S_\infty} = 1$.
   - The pairing evaluates to:
     $$\mathrm{Tr}(X^* Y) = \mathrm{Tr}(V U^* U \Sigma V^*) = \mathrm{Tr}(\Sigma) = \sum_{i=1}^d \sigma_i(Y) = \|Y\|_{S_1}.$$

3. **Spectral Norm Norming ($p = \infty$, Dual $q = 1$, Repaired Witness)**:
   - Let $u_1$ and $v_1$ denote the left and right singular vectors associated with the maximal singular value $\sigma_1(Y) = \|Y\|_{S_\infty}$.
   - Define the rank-one projection witness:
     $$X = u_1 v_1^*.$$
   - The operator $X$ has rank $1$ with unique non-zero singular value $1$. Consequently, its trace norm is $\|X\|_{S_1} = 1$.
   - The trace pairing evaluates to:
     $$\mathrm{Tr}(X^* Y) = \mathrm{Tr}(v_1 u_1^* Y) = u_1^* Y v_1 = \sigma_1(Y) = \|Y\|_{S_\infty}.$$
   - This discharges the open obligation to record an exact rational check of the repaired $p = \infty$ dual witness.

## 4. Limits and Non-Claims

- **Imported Theorem**: The general Hölder duality is recorded as an imported classical theorem from operator theory, not derived from scratch within the repository.
- **Finite-Dimensional Setting**: The computational witnesses and checks are formulated for finite-dimensional Hilbert spaces.
- **Subgradient Non-Uniqueness**: For $p = \infty$, the attaining witness $X$ is non-unique whenever the maximal singular value has multiplicity greater than $1$.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that non-commutative Hölder duality holds with exact polar dual witness attainment on finite operator algebras, including the repaired rank-one projection witness for $p = \infty$.
2. **What it does not support**:
   Does not support claims of novel derivation of scalar or von Neumann inequalities; does not assert uniqueness of dual maximizers when eigenspaces degenerate.
3. **Narrowest defensible claim**:
   For any matrix $Y \in \mathbb{C}^{d \times d}$ and conjugate exponents $1/p + 1/q = 1$, $|\mathrm{Tr}(X^* Y)| \le \|X\|_{S_q} \|Y\|_{S_p}$ holds, with equality attained by the constructed normalized witness $X$.

# AUDIT-N002-007: Refutation of Three-Step Monotone Descent

## 1. Claim Statement

The candidate three-step primal-dual update has a non-optimal fixed point. Specifically, on a single oriented edge with observed defect $\omega = 1$, initial potential $s^0 = (0, 0)^T$, initial dual circulation $\phi^0 = 0$, step sizes $\sigma = 1, \tau = 1/2$, and arbitrary primal learning rate $\eta > 0$, the update map fixes the state $(s^0, \phi^0) = (0, 0)$ with constant non-zero residual $\|\omega - d_0 s^0\|_1 = 1$, whereas a feasible potential achieving residual $0$ exists.

## 2. Context & Hypotheses

- **Single Edge Complex**: A 1D cell complex consisting of vertices $V = \{0, 1\}$ and oriented edge $e = (0, 1)$ with positive unit weight $w_e = 1$.
- **Coboundary Operator**: The discrete coboundary $d_0: C^0 \to C^1$ evaluates $(d_0 s)(e) = s(1) - s(0)$.
- **Adjoint Divergence**: The adjoint operator $d_0^*: C^1 \to C^0$ evaluates $d_0^* \phi = (-\phi(e), \phi(e))^T$.
- **1-Laplacian**: The composition evaluates $(d_0 d_0^* \phi)(e) = (d_0^* \phi)(1) - (d_0^* \phi)(0) = \phi(e) - (-\phi(e)) = 2 \phi(e)$.
- **Candidate Update Definition**: The historical Definition 4.1 three-step primal-dual update consists of:
  1. *Dual ascent*: $\phi^{1/2}(e) = \operatorname{clip}_{[-1, 1]}\left(\phi^k(e) + \sigma (\omega(e) - (d_0 s^k)(e))\right)$.
  2. *Divergence correction*: $\phi^{k+1}(e) = \phi^{1/2}(e) - \tau (d_0 d_0^* \phi^{1/2})(e)$.
  3. *Primal update*: $s^{k+1} = s^k + \eta d_0^* \phi^{k+1}$.
- **Declared Initial State**: $\omega(e) = 1$, $s^0 = (0, 0)^T$, $\phi^0(e) = 0$, with algorithm parameters $\sigma = 1$ and $\tau = 1/2$.

## 3. Derivation / Evidence

### 3.1 Step-by-Step State Evolution
1. **Initial Residual**:
   $$\delta^0(e) = \omega(e) - (d_0 s^0)(e) = 1 - (0 - 0) = 1.$$
   The initial residual norm is $\|\delta^0\|_1 = 1$.
2. **Step 1 (Dual Ascent)**:
   $$\phi^{1/2}(e) = \operatorname{clip}_{[-1, 1]}(0 + 1 \cdot 1) = \operatorname{clip}_{[-1, 1]}(1) = 1.$$
3. **Step 2 (Divergence Correction)**:
   $$(d_0 d_0^* \phi^{1/2})(e) = 2 \cdot 1 = 2.$$
   $$\phi^1(e) = \phi^{1/2}(e) - \tau (d_0 d_0^* \phi^{1/2})(e) = 1 - \frac{1}{2} \cdot 2 = 1 - 1 = 0.$$
4. **Step 3 (Primal Update)**:
   $$d_0^* \phi^1 = (-\phi^1(e), \phi^1(e))^T = (0, 0)^T.$$
   $$s^1 = s^0 + \eta d_0^* \phi^1 = (0, 0)^T + \eta (0, 0)^T = (0, 0)^T.$$
5. **Stationarity**:
   $$(s^1, \phi^1) = ((0, 0)^T, 0) = (s^0, \phi^0).$$
   The state is stationary under the three-step iteration operator.
6. **Suboptimality**:
   The residual at this fixed point remains $\|\omega - d_0 s^1\|_1 = 1$.
   In contrast, consider the alternative potential $s^* = (0, 1)^T$.
   $$(d_0 s^*)(e) = s^*(1) - s^*(0) = 1 - 0 = 1 = \omega(e).$$
   The residual for $s^*$ evaluates to $\omega(e) - (d_0 s^*)(e) = 0$, achieving $\|\omega - d_0 s^*\|_1 = 0$.
   Because $0 < 1$, the stationary point $(s^0, \phi^0)$ fails to minimize the residual norm.

### 3.2 Refutation of Monotone Descent
- Former Conjecture 4.3 hypothesized that the three-step iteration would monotonically decrease the residual toward the infimum.
- The single-edge counterexample demonstrates that the sequence of residuals satisfies $\|\delta^{k+1}\|_1 = \|\delta^k\|_1 = 1$ for all $k \ge 0$, exhibiting zero descent.
- The step size $\tau = 1/2$ exactly matches the reciprocal of the 1-Laplacian eigenvalue ($2$), leading to total cancellation of the dual variable in Step 2.
- The conjecture is refuted and withdrawn under the declared assumptions.

### 3.3 Verification Witness Reference
Supported by executable tests in `tests/test_note002_descent_and_quotients.py`:
- `test_three_step_update_nonoptimal_fixed_point_exact_fraction`: verifies in exact rational arithmetic that $(s^0, \phi^0) = (0, 0)$ is fixed over 25 iterations with residual $1$, while $s^* = (0, 1)$ achieves residual $0$.
- `test_three_step_update_parameter_sensitivity_and_laplacian_cancellation`: confirms that $\tau = 1/2$ causes complete dual cancellation, whereas $\tau = 1/4$ breaks stationarity.
- `test_three_step_update_divergence_correction_exit_dual_ball`: demonstrates that an unprojected correction step can exit the dual unit ball when $\tau$ is non-standard.

## 4. Limits and Non-Claims

- **Specific Algorithm Scope**: This refutation applies to the candidate three-step primal-dual map of historical Definition 4.1. It does not assert that other primal-dual splitting schemes (e.g., standard Chambolle–Pock with proper preconditioning) fail to converge.
- **Single-Edge Setting**: The counterexample operates on a 1-edge complex; it does not claim that the map stalls on all graph topologies.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that the candidate three-step update admits non-optimal stationary points and fails to guarantee monotone descent on discrete complexes.
2. **What it does not support**:
   Does not support broad claims about all primal-dual methods or alternative step-size schedules.
3. **Narrowest defensible claim**:
   On a single edge with $\omega = 1, s = 0, \phi = 0, \sigma = 1, \tau = 1/2$, the candidate three-step map returns $s = 0, \phi = 0$ with residual $1$, failing to achieve the optimal residual $0$.
4. **Next test needed**:

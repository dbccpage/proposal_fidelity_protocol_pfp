## 1. Claim Statement

The quickstart tutorial (`code/quickstart.py`) delegates computation of the discrete $\ell_1$ projection and quotient minimum exclusively to the native adapter (`code/native_functional.py::compute_graph_phi1`). If native configuration pins (`CORE_FUNCTIONAL_GRAPH_BIN` or `CORE_FUNCTIONAL_GRAPH_SHA256`) are absent or mismatched, the call raises `NativeFunctionalUnavailable` without fallback. Furthermore, approximate (floating-point) or Boolean edge weights and cochain values are refused with `TypeError`, and non-positive weights are refused with `ValueError`. Candidate enumeration is retired and raises `RuntimeError`.

## 2. Context & Hypotheses

- **Target Module**:
  - `code/quickstart.py` in Paper 005.
  - Native transport adapter: `code/native_functional.py`.
- **Environment Prerequisites**:
  - `CORE_FUNCTIONAL_GRAPH_BIN`: Path to native `solve_graph_phi1` executable.
  - `CORE_FUNCTIONAL_GRAPH_SHA256`: 64-hexadecimal character digest pinning the binary bytes.
- **Fail-Closed Contract**:
  - The quickstart provides zero Python fallback when native pins are absent or invalid.
  - Arithmetic representations require exact `int` or `fractions.Fraction`.

## 3. Derivation / Evidence

### 3.1 Exclusive Native Delegation
In `code/quickstart.py`:
```python
def compute_discrete_l1_projection(
    graph: ConstraintGraph,
    claims: Cochain1,
) -> Tuple[Fraction, Dict[str, Fraction], Cochain1]:
    from native_functional import compute_graph_phi1

    minimum, potential = compute_graph_phi1(
        graph.vertices,
        [(edge.source, edge.target, edge.weight) for edge in graph.edges],
        claims.values,
    )
    return minimum, potential, compute_coboundary(potential, graph.edges)
```
The routine delegates directly to `compute_graph_phi1` without attempting local candidate enumeration.

### 3.2 Refusal of Unpinned Native Calls
In `code/native_functional.py`:
```python
binary = os.environ.get("CORE_FUNCTIONAL_GRAPH_BIN")
expected = os.environ.get("CORE_FUNCTIONAL_GRAPH_SHA256", "").lower()
if not binary or re.fullmatch(r"[0-9a-f]{64}", expected) is None:
    raise NativeFunctionalUnavailable("pinned native graph executable required")
```
When environment variables are unset, missing, or carry an invalid digest string, the adapter raises `NativeFunctionalUnavailable`. If the executable exists but its SHA-256 digest differs from `expected`, the adapter raises `NativeFunctionalUnavailable("native graph executable digest mismatch")`.

### 3.3 Retirement of Candidate Enumeration
Historical Python enumeration in `quickstart.py` is explicitly retired:
```python
def find_spanning_forest_potentials(
    graph: ConstraintGraph,
    claims: Cochain1,
) -> List[Dict[str, Fraction]]:
    raise RuntimeError(
        "RUST_FUNCTIONAL_REQUIRED: candidate enumeration is retired; "
        "use compute_discrete_l1_projection with a pinned native calculator"
    )
```

### 3.4 Refusal of Non-Exact and Non-Positive Inputs
Exactness checks are enforced at type boundaries:
1. `Edge.__post_init__`:
   ```python
   if type(self.weight) not in (int, Fraction):
       raise TypeError("Edge weight must be an exact int or Fraction.")
   if self.weight <= 0:
       raise ValueError(f"Edge weight must be positive and exact rational, got {self.weight}.")
   ```
2. `Cochain1.__post_init__`:
   ```python
   if any(type(value) not in (int, Fraction) for value in self.values.values()):
       raise TypeError("Cochain values must be exact int or Fraction.")
   ```
3. `native_functional._exact`:
   ```python
   if type(value) not in (int, Fraction):
       raise TypeError("functional inputs require exact int or Fraction, not float or bool")
   ```
Passing `float` (e.g. `1.0`) or `bool` (e.g. `True`) triggers immediate `TypeError`.

## 4. Limits and Non-Claims

1. **Pin Semantics**: The SHA-256 digest binds the exact bytes of the executable read by the adapter; it does not attest that the executable was built deterministically from reviewed source.
2. **Native Execution Dependency**: Genuine computation of the minimum via this path requires an external platform-specific binary.
3. **No Automatic Fallback**: The design deliberately refuses execution rather than substituting an unverified Python approximation.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that `code/quickstart.py` calls `compute_graph_phi1`, refuses missing or mismatched native pins, retires candidate enumeration, and rejects non-exact or non-positive inputs.
2. **What it does not support**: Does not support that the native binary is present in all environments, or that the binary has been formally attested.
3. **Narrowest defensible claim**: In `code/quickstart.py`, `compute_discrete_l1_projection` delegates to `native_functional.compute_graph_phi1`, raises `NativeFunctionalUnavailable` when pins are unconfigured, and raises `TypeError` on float or boolean inputs.
4. **Next test needed**: Verification of native process invocation against an actual pinned executable in a CI environment with built artifacts.

## 1. Claim Statement

On any finite graph $G = (V, E)$, vanishing circulation pairings characterize exactness: a 1-cochain $c \in C^1(G)$ satisfies $c = d_0 f$ for some potential $f \in C^0(G)$ if and only if $\langle y, c \rangle = 0$ for every circulation $y \in \ker d_0^\top$.

## 2. Context & Hypotheses

- **Finite Graph**: $G = (V, E)$ is an arbitrary finite graph, possibly disconnected, with connected components $G_1, \dots, G_k$.
- **Direct Sum Decomposition**:
  $$C^0(G) = \bigoplus_{j=1}^k C^0(G_j), \quad C^1(G) = \bigoplus_{j=1}^k C^1(G_j), \quad d_0 = \bigoplus_{j=1}^k d_{0, j}.$$
- **Spanning Forest**: $T = \bigsqcup_{j=1}^k T_j$, where each $T_j = (V_j, E(T_j))$ is a spanning tree for component $G_j$.
- **Chord Edges & Fundamental Cycles**:
  For each chord edge $e = (u, v) \in E_j \setminus E(T_j)$, $\gamma_e$ denotes the unique fundamental cycle formed by $e$ and the tree path in $T_j$ between $v$ and $u$.

## 3. Derivation / Evidence

### 3.1 Componentwise Decoupling
1. Because the coboundary operator decouples across connected components, $c = d_0 f$ on $G$ if and only if each component restriction satisfies $c_j = d_{0, j} f_j$ on $G_j$.
2. Similarly, circulations on $G$ decompose into componentwise circulations:
   $$\ker d_0^\top = \bigoplus_{j=1}^k \ker d_{0, j}^\top.$$
3. Hence the global equivalence follows once established on each connected component.

### 3.2 Spanning-Tree Path Integration
Let $G_j = (V_j, E_j)$ be a connected component with spanning tree $T_j$.
1. Select an arbitrary root vertex $r_j \in V_j$ and set $f_j(r_j) = 0$.
2. For each vertex $v \in V_j$, let $P(r_j, v)$ denote the unique path in $T_j$ from $r_j$ to $v$.
3. Define the reconstructed potential by path integration:
   $$f_j(v) = \sum_{e' \in P(r_j, v)} \operatorname{sgn}(e') c(e'),$$
   where $\operatorname{sgn}(e') = +1$ if $e'$ is traversed forward and $-1$ if traversed backward.
4. For any tree edge $e = (u, v) \in E(T_j)$, the tree path to $v$ extends the tree path to $u$ by $e$, giving:
   $$f_j(v) - f_j(u) = c(e), \quad \text{so } (d_{0, j} f_j)_e = c(e).$$

### 3.3 Fundamental-Cycle Verification on Chord Edges
1. For each chord edge $e = (u, v) \in E_j \setminus E(T_j)$, the fundamental cycle circulation $\mathbf{z}_{\gamma_e} \in C_1(G_j)$ has coordinates:
   - $+1$ on edge $e$;
   - $+1$ or $-1$ on tree edges corresponding to the reverse path from $v$ to $u$ in $T_j$;
   - $0$ on all other edges.
2. The pairing of $c$ with $\mathbf{z}_{\gamma_e}$ evaluates to:
   $$\langle \mathbf{z}_{\gamma_e}, c \rangle = c(e) - (f_j(v) - f_j(u)).$$
3. By hypothesis, all circulation pairings vanish, so $\langle \mathbf{z}_{\gamma_e}, c \rangle = 0$.
4. Therefore:
   $$c(e) = f_j(v) - f_j(u) = (d_{0, j} f_j)_e.$$
5. Because $c(e) = (d_{0, j} f_j)_e$ holds on both tree edges and chord edges, $c_j = d_{0, j} f_j$ on all of $G_j$.
6. Combining potentials across components establishes $c = d_0 f$ on $G$.

## 4. Limits and Non-Claims

- **Component Decoupling**: Global path integration cannot cross disconnected components; potentials must be rooted per component.
- **Tree-Basis Scope**: The fundamental cycle basis is non-canonical and depends on the spanning tree choice, though the span $\ker d_0^\top$ is invariant.
- **Cell Complex Dimension**: Stated for 1-dimensional graph complexes; higher-dimensional complexes involve 2-cycles and boundary torsion.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the constructive exactness characterization on arbitrary finite graphs (connected or disconnected) using spanning tree path integration and fundamental cycle pairing.
2. **What it does not support**:
   Does not support path integration across infinite graphs without locally finite tree constructions; does not claim potential uniqueness without componentwise gauge fixing.
3. **Narrowest defensible claim**:
   On any finite graph with spanning forest $T$, $c \in \operatorname{im} d_0$ if and only if $\langle \mathbf{z}_{\gamma_e}, c \rangle = 0$ for all fundamental cycles $\gamma_e$.

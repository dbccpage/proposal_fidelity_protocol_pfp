## 1. Claim Statement

For any finite graph $G = (V, E)$ with strictly positive edge weights $\mathbf{w} \in (0, \infty)^E$ and any $p \in [1, \infty]$, the functional:
$$\Phi_p([c]) = \inf_{f \in C^0(G)} \|c - d_0 f\|_{p, \mathbf{w}}$$
defines a valid norm on the quotient vector space $Q^1 = C^1(G) / \mathrm{im}\, d_0$.

## 2. Context & Hypotheses

- **Graph Topology**: $G = (V, E)$ is a finite 1-dimensional cell complex.
- **Positive Edge Weights**: $w_e > 0$ for all $e \in E$.
- **Quotient Space**: $Q^1 = C^1(G) / \mathrm{im}\, d_0$, where $[c] = \{c + d_0 f : f \in C^0(G)\}$.
- **Attainment Assumption**: By Derivation AUDIT-N001-001, the infimum defining $\Phi_p([c])$ is attained at some $f^* \in C^0(G)$.

## 3. Derivation / Evidence

### 3.1 Well-Definedness on Equivalence Classes
1. Let $c_1, c_2 \in C^1(G)$ satisfy $[c_1] = [c_2] \in Q^1$.
2. By definition of the quotient space, $c_1 - c_2 \in \mathrm{im}\, d_0$, meaning $c_1 = c_2 + d_0 g$ for some potential $g \in C^0(G)$.
3. For any potential $f \in C^0(G)$:
   $$c_1 - d_0 f = (c_2 + d_0 g) - d_0 f = c_2 - d_0(f - g).$$
4. As $f$ ranges over $C^0(G)$, $f - g$ also ranges over $C^0(G)$.
5. Therefore, the set of residual vectors $\{c_1 - d_0 f : f \in C^0(G)\}$ is identical to $\{c_2 - d_0 f' : f' \in C^0(G)\}$.
6. The infima of the norms over these sets are identical: $\Phi_p([c_1]) = \Phi_p([c_2])$. The functional is well-defined on $Q^1$.

### 3.2 Non-negativity
1. For every candidate potential $f \in C^0(G)$, the weighted $L^p$ norm satisfies $\|c - d_0 f\|_{p, \mathbf{w}} \ge 0$.
2. Taking the infimum over all $f \in C^0(G)$ preserves non-negativity: $\Phi_p([c]) \ge 0$.

### 3.3 Absolute Homogeneity
1. Let $\lambda \in \mathbb{R}$ and $[c] \in Q^1$.
2. If $\lambda = 0$:
   $$\Phi_p([0]) = \inf_{f \in C^0(G)} \|0 - d_0 f\|_{p, \mathbf{w}}.$$
   Evaluating at $f = 0$ yields $\|0\|_{p, \mathbf{w}} = 0$. Since the norm is non-negative, $\Phi_p([0]) = 0 = 0 \cdot \Phi_p([c])$.
3. If $\lambda \ne 0$:
   $$\Phi_p([\lambda c]) = \inf_{f \in C^0(G)} \|\lambda c - d_0 f\|_{p, \mathbf{w}} = \inf_{f \in C^0(G)} |\lambda| \left\| c - d_0\left(\frac{f}{\lambda}\right) \right\|_{p, \mathbf{w}}.$$
4. Setting $f' = f / \lambda$ bijectively traverses $C^0(G)$:
   $$\Phi_p([\lambda c]) = |\lambda| \inf_{f' \in C^0(G)} \|c - d_0 f'\|_{p, \mathbf{w}} = |\lambda| \Phi_p([c]).$$

### 3.4 Subadditivity (Triangle Inequality)
1. Let $[c_1], [c_2] \in Q^1$.
2. By Derivation AUDIT-N001-001 (quotient infimum attainment), there exist potentials $f_1^*, f_2^* \in C^0(G)$ achieving:
   $$\Phi_p([c_1]) = \|c_1 - d_0 f_1^*\|_{p, \mathbf{w}} \quad \text{and} \quad \Phi_p([c_2]) = \|c_2 - d_0 f_2^*\|_{p, \mathbf{w}}.$$
3. The sum potential $f_1^* + f_2^* \in C^0(G)$ is a valid candidate for the representative $c_1 + c_2$:
   $$\Phi_p([c_1 + c_2]) = \inf_{f \in C^0(G)} \|c_1 + c_2 - d_0 f\|_{p, \mathbf{w}} \le \|(c_1 + c_2) - d_0(f_1^* + f_2^*)\|_{p, \mathbf{w}}.$$
4. Grouping terms and applying the Minkowski triangle inequality for the norm $\|\cdot\|_{p, \mathbf{w}}$ on $C^1(G)$:
   $$\|(c_1 - d_0 f_1^*) + (c_2 - d_0 f_2^*)\|_{p, \mathbf{w}} \le \|c_1 - d_0 f_1^*\|_{p, \mathbf{w}} + \|c_2 - d_0 f_2^*\|_{p, \mathbf{w}}.$$
5. Substituting the infimum values:
   $$\Phi_p([c_1 + c_2]) \le \Phi_p([c_1]) + \Phi_p([c_2]).$$

### 3.5 Positive Definiteness
1. Forward direction: If $[c] = 0 \in Q^1$, then $c \in \mathrm{im}\, d_0$, so $c = d_0 f_0$ for some $f_0 \in C^0(G)$. Choosing $f = f_0$ yields $\|c - d_0 f_0\|_{p, \mathbf{w}} = \|0\|_{p, \mathbf{w}} = 0$. Since $\Phi_p([c]) \ge 0$, it follows that $\Phi_p([c]) = 0$.
2. Reverse direction: Suppose $\Phi_p([c]) = 0$.
3. By Derivation AUDIT-N001-001 (quotient infimum attainment), there exists $f^* \in C^0(G)$ achieving the infimum:
   $$\|c - d_0 f^*\|_{p, \mathbf{w}} = \Phi_p([c]) = 0.$$
4. Because each edge weight $w_e > 0$ is strictly positive:
   - For $p \in [1, \infty)$: $\sum_{e \in E} w_e |c_e - (d_0 f^*)_e|^p = 0 \implies |c_e - (d_0 f^*)_e| = 0$ for every $e \in E$.
   - For $p = \infty$: $\max_{e \in E} w_e |c_e - (d_0 f^*)_e| = 0 \implies |c_e - (d_0 f^*)_e| = 0$ for every $e \in E$.
5. Thus $c - d_0 f^* = 0$, which means $c = d_0 f^* \in \mathrm{im}\, d_0$.
6. Consequently, $[c] = 0 \in Q^1$.

### 3.6 Necessity of Strict Weight Positivity (Zero-Weight Refusal)
1. Suppose an edge $e_0$ is assigned weight $w_{e_0} = 0$.
2. Consider a cochain $c$ supported exclusively on $e_0$ ($c_{e_0} = 1$ and $c_e = 0$ for all $e \ne e_0$) on a graph where $e_0$ is not a bridge (e.g., an edge of a cycle).
3. The cochain $c$ has nonzero cycle circulation pairing, so $c \notin \mathrm{im}\, d_0$ and $[c] \ne 0 \in Q^1$.
4. Evaluating at potential $f = 0$ yields:
   $$\|c - d_0(0)\|_{p, \mathbf{w}} = w_{e_0}^{1/p} |1| = 0 \cdot 1 = 0.$$
5. Hence $\Phi_p([c]) = 0$ despite $[c] \ne 0$, violating positive definiteness.
6. Therefore, strict positivity of all edge weights is necessary for $\Phi_p$ to define a norm on $Q^1$.

### 3.7 Verification and Test Witness Reference
Supported by executable tests in `tests/test_note_001_quotient_norm.py`:

- `test_quotient_norm_subadditivity`: tests triangle inequality across distinct non-trivial cohomology classes.

## 4. Limits and Non-Claims

- **Finite Dimensionality**: Applies to finite-dimensional quotient spaces $Q^1 = C^1 / \mathrm{im}\, d_0$. In infinite-dimensional Banach or Frechet settings, quotient seminorms require closed subspaces to become norms.
- **Positive Weights Only**: Permitting $w_e = 0$ allows nonzero cohomology classes to have quotient value zero.
- **Norm vs Seminorm**: On the ambient space $C^1(G)$, the map $c \mapsto \Phi_p([c])$ is a seminorm with kernel $\mathrm{im}\, d_0$. It is a norm strictly on the quotient space $Q^1$.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that $\Phi_p([c]) = \inf_f \|c - d_0 f\|_{p, \mathbf{w}}$ is a norm on the quotient vector space $Q^1 = C^1(G) / \mathrm{im}\, d_0$ for any finite graph and any $p \in [1, \infty]$ under strictly positive edge weights.
2. **What it does not support**:
   Does not support positive definiteness when edge weights can vanish; does not claim norm properties on unquotiented $C^1$; does not extend to infinite-dimensional cochain complexes without closed subspace hypotheses.
3. **Narrowest defensible claim**:
   For finite graphs with strictly positive weights and $p \in [1, \infty]$, $\Phi_p$ satisfies the norm axioms on $C^1(G) / \mathrm{im}\, d_0$.

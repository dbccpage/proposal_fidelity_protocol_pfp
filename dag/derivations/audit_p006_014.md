## 1. Claim Statement

`atlas/archive/pfp/006_pfp_epistemic_immune_system_and_cemetery_dag_mining/code/tests/test_006_epistemic_immune.py` defines three standalone module-local classes (`DangerSignal`, `ThymicCheckResult`, `CemeteryDAGSink`) and one module-local function (`evaluate_thymic_selection`), imports only Python standard-library modules (`__future__`, `hashlib`, `json`, `dataclasses`, `fractions`, `typing`), imports zero production immune or persistence modules (`pfp.*`, `eis.*`, `adversary.*`, `operations.*`, `operads.*`), and implements simplified rules that diverge behaviorally from the production contracts. Passing its three tests exercises only the file's local definitions and supplies zero verification of production integration.

### 3.2 Behavioral Divergences from Production Contracts
Beyond import isolation, each local class encodes a rule distinct from the corresponding production module:
1. **Single-Signal Disjunction vs. Multi-Sensor Allosteric Quorum**:
   - Toy `DangerSignal.is_quarantine_triggered` (`test_006_epistemic_immune.py:25-34`) evaluates `self.defect_mass > threshold or self.cycle_obstruction > threshold or self.unadmitted_tokens > 0`. In `test_danger_signal_threshold` (`lines 105-106`), a single positive field `DangerSignal(Fraction(1, 2), Fraction(0, 1), 0)` triggers quarantine (`True`).
   - Production `AllostericConsensusGate` (`eis/domain/allostery.py:36-38,192-227`) uses defaults `n = 2`, `K = 2`, `activation_threshold = Fraction(1, 2)`, and `per_sensor_cap = Fraction(1)`, requiring `quorum_size == 2` distinct positive sensors (`S >= 2`). A single sensor reporting `Fraction(1, 2)` yields `aggregate_signal = Fraction(1, 2)`, `hill_value = Fraction(1, 17) < Fraction(1, 2)`, and `is_activated == False` (and even a single sensor at cap `Fraction(1)` yields `hill_value = Fraction(1, 5) < Fraction(1, 2)` and `is_activated == False`).
2. **Token Set Membership vs. Regex Compilation and Self-Panel Screening**:
   - Toy `evaluate_thymic_selection(token, admitted_alphabet)` (`lines 53-57`) checks `token in admitted_alphabet` over a finite set of eight symbol strings.
   - Production `ClonalSelectionEngine.check_kill_condition` (`pfp/domain/immune/clonal_selection.py:276-311`) compiles candidate regexes (returning `(False, KillConditionRefusal)` on `re.error`) and searches every sample in `self_panel` (returning `(True, KillConditionReceipt)` with `status="PURGED_SELF_REACTIVE"` on cross-reaction).
3. **In-Memory Dict List vs. Header-Bound Persistent JSONL Sink**:
   - Toy `CemeteryDAGSink` (`lines 60-96`) appends dicts to an in-memory `entries: list[dict[str, Any]]` seeded with `"GENESIS_ROOT"`, writes no file, emits no `HEADER` record or `TailReceipt`, allows arbitrary caller strings, and has no reload verification (`test_toy_chain_links_predecessor_digests`, `lines 128-165`).
   - Production `CemeterySink` (`pfp/infrastructure/persistence/cemetery_sink.py:116-415`) persists a line-0 `HEADER` (`entry_count`, `head_digest`, `authority_effect="None"`), chains entries from `GENESIS_DIGEST = "genesis"`, replaces files via `.tmp` + `os.replace`, enforces `ALLOWED_ENTRY_KEYS` and float sanitization, raises `LedgerIntegrityError` / `LedgerTruncationError` on tamper or tail removal, and emits `TailReceipt`.

## 1. Claim Statement

For any finite partially ordered set $(P, \le)$ equipped with linear restriction maps between additive stalk spaces $F(x)$, the following conditions are mutually equivalent on every comparable triple $a \le b \le c$:
1. The composition curvature operator vanishes identically: $K_{c, b, a} = 0$.
2. The discrete coboundary composition vanishes identically on all sections: $(d_1(d_0 s))(a, b, c) = 0$ for all $s \in C^0(P; F)$.
3. The restriction system satisfies chain composability: $r_{c, a} = r_{b, a} \circ r_{c, b}$.

## 2. Context & Hypotheses

- **Finite Poset Carrier**: $(P, \le)$ is a finite partially ordered set with elements $a \le b \le c$.
- **Additive Stalks and Inhabitation**: Each $x \in P$ has an additive stalk $F(x)$. For every element $v \in F(c)$, there exists at least one section $s \in C^0(P; F)$ such that $s(c) = v$ (satisfied by free stalk products $C^0(P; F) = \prod_{x \in P} F(x)$).
- **Linear Restriction Maps**: $r_{y, x}: F(y) \to F(x)$ preserves subtraction for all $x \le y$.
- **Composition Curvature**: $K_{c, b, a} = r_{b, a} \circ r_{c, b} - r_{c, a}: F(c) \to F(a)$.
- **Coboundary-Curvature Identity**: $(d_1(d_0 s))(a, b, c) = K_{c, b, a}(s(c))$ for all $s \in C^0(P; F)$ (established in AUDIT-N004-006).

## 3. Derivation / Evidence

### 3.1 Logical Equivalence Chain

We establish the implications (1) $\iff$ (3) and (1) $\iff$ (2).

1. **Equivalence of (1) and (3) (Curvature Vanishing $\iff$ Chain Composability)**:
   - By definition of the composition curvature operator:
     $$K_{c, b, a} = r_{b, a} \circ r_{c, b} - r_{c, a}.$$
   - $K_{c, b, a}$ is the zero homomorphism from $F(c)$ to $F(a)$ if and only if for all $v \in F(c)$:
     $$(r_{b, a} \circ r_{c, b} - r_{c, a})(v) = 0 \iff (r_{b, a} \circ r_{c, b})(v) = r_{c, a}(v).$$
   - This holds for all $v \in F(c)$ if and only if $r_{c, a} = r_{b, a} \circ r_{c, b}$ as homomorphisms.
   - Thus (1) $\iff$ (3).

2. **Implication (1) $\implies$ (2) (Curvature Vanishing $\implies$ Nilpotency)**:
   - Assume $K_{c, b, a} = 0$.
   - Let $s \in C^0(P; F)$ be any section.
   - By the coboundary-curvature identity (AUDIT-N004-006):
     $$(d_1(d_0 s))(a, b, c) = K_{c, b, a}(s(c)) = 0(s(c)) = 0.$$
   - Therefore, $(d_1(d_0 s))(a, b, c) = 0$ for all sections $s \in C^0(P; F)$.

3. **Implication (2) $\implies$ (1) (Nilpotency $\implies$ Curvature Vanishing)**:
   - Assume $(d_1(d_0 s))(a, b, c) = 0$ for all sections $s \in C^0(P; F)$.
   - Let $v \in F(c)$ be an arbitrary element.
   - By stalk inhabitation, choose a section $s_v \in C^0(P; F)$ such that $s_v(c) = v$ (for example, setting $s_v(c) = v$ and $s_v(x) = 0$ for $x \ne c$).
   - Applying the coboundary-curvature identity:
     $$K_{c, b, a}(v) = K_{c, b, a}(s_v(c)) = (d_1(d_0 s_v))(a, b, c) = 0.$$
   - Since $v \in F(c)$ was arbitrary, $K_{c, b, a}(v) = 0$ for all $v \in F(c)$, meaning $K_{c, b, a} = 0$.

Combining these three steps establishes the full equivalence (1) $\iff$ (2) $\iff$ (3).

## 4. Limits and Non-Claims

- **Inhabitation Requirement**: The implication $(d_1 d_0 s = 0 \implies K = 0)$ requires the stalk $F(c)$ to be generated by evaluation of global sections. In standard discrete presheaves on posets with $C^0 = \prod F(x)$, this holds automatically.
- **Local vs Global Flatness**: Flatness on a triple $a \le b \le c$ does not imply flatness on other incomparable triples in the poset.
- **No Non-Linear Sheafification**: This equivalence applies to linear restriction systems on finite posets.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the equivalence between operator vanishing $K_{c,b,a} = 0$, coboundary nilpotency $d_1 d_0 = 0$ across all sections, and chain composability $r_{c,a} = r_{b,a} \circ r_{c,b}$.
2. **What it does not support**:
   Does not support inferring flatness from evaluating $d_1 d_0 s$ on a restricted or single section such as $s = 0$.
3. **Narrowest defensible claim**:
   For linear restriction systems with inhabited stalks, $K_{c,b,a} = 0$ if and only if $d_1 d_0 s = 0$ for all sections if and only if $r_{c,a} = r_{b,a} \circ r_{c,b}$.

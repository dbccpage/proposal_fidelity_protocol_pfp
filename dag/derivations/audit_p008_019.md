# AUDIT-P008-019: Offline runner isolation

## 1. Claim Statement

In `atlas/archive/pfp/008_pfp_mssn_tower_challenges_and_retraction_benchmarks/code/retraction_benchmark_runner.py`, default offline execution (`--mock` / omitted `--live`) opens zero network sockets, reads zero credential files even when `OPENROUTER_API_KEY` is set in the environment, refuses any `--output-dir` inside `PACKAGE_ROOT` (exit code `2`), and writes `summary.json` and `receipts.jsonl` exclusively to an explicit external directory or a `tempfile.mkdtemp(prefix="pfp008_runner_")` directory outside `PACKAGE_ROOT`. Across the six built-in `BENCHMARK_INSTANCES` (three `CONSISTENT`, three `CONTRADICTION`), offline runs under `baseline`, `hinted`, `scratchpad`, and `exact_oracle` match `3`, `6`, `3`, and `6` of `6` host verdicts (CLI exit codes `1`, `0`, `1`, `0`), driven by `OfflineStubClient`'s literal `"gap=" in prompt` substring test and the host-oracle bypass without measuring any model.

## 3. Derivation / Evidence

### 3.1 Socket, Credential-Read, and External-Write Isolation
Inspecting `retraction_benchmark_runner.py` and replaying all four conditions under runtime hooks establishes three isolation boundaries:
1. **Zero Network Calls in Offline Mode**: `OpenRouterClient` (`urllib.request.urlopen`) is instantiated only inside the `if args.live:` branch of `main` (`lines 548–554`). When `--live` is absent, `run_benchmark` defaults to `OfflineStubClient` (or bypasses client calls entirely when `condition == "exact_oracle"`). Replaying all four conditions with `socket.socket`, `socket.create_connection`, `socket.getaddrinfo`, and `urllib.request.urlopen` monkeypatched to raise `AssertionError` completes with zero network attempts.
2. **Zero Credential Reads in Offline Mode**: `os.environ.get("OPENROUTER_API_KEY", "")` is read only when `args.live` is `True` (`line 549`), and no `.env`, `.netrc`, `.gitcookies`, SSH key, or credentials file is opened. Hooking `builtins.open`, `io.open`, and `Path.open` across all four offline runs (with `OPENROUTER_API_KEY` set to a sentinel string) records reads of `retraction_benchmark_runner.py` (to compute `source_sha256` at `lines 313, 460, 494` for receipt digests) and zero credential file opens.
3. **External-Only Output Writes**: `resolve_output_dir(requested)` (`lines 502–510`) returns `Path(tempfile.mkdtemp(prefix="pfp008_runner_"))` (`line 505`) when `requested is None`, and for any explicit directory resolves `path = Path(requested).resolve()` (`line 506`) and checks `path == PACKAGE_ROOT or path.is_relative_to(PACKAGE_ROOT)` (`line 507`), raising `ValueError(f"refusing to write inside the package directory: {path}")` (`line 508`) on violation. All write-mode file opens (`"w"`, `"a"`, `"x"`, `"+"`) target `summary.json` and `receipts.jsonl` strictly outside `PACKAGE_ROOT`.

### 3.2 Exact `3, 6, 3, 6` Verdict Match Accounting
`BENCHMARK_INSTANCES` (`lines 67–117`) comprises `6` fixed graphs (`1` tree, `2` triangles, `2` diamonds, and `1` $K_4$): `3` consistent instances (`retract_01_tree_clean`, `retract_02_triangle_clean`, `retract_04_diamond_clean`) and `3` inconsistent instances (`retract_03_triangle_poisoned`, `retract_05_diamond_entangled_poisoned`, `retract_06_k4_rank3_poisoned`). `OfflineStubClient.complete(prompt)` (`lines 341–348`) applies a deterministic substring test:
```python
if "gap=" in prompt:
    content = "VERDICT: CONTRADICTION\nThe host reports a nonzero residual."
else:
    content = "VERDICT: CONSISTENT"
return content, len(prompt) // 4 + 8, 0.0, 0.0
```
Evaluating `format_prompt(instance, condition)` (`lines 399–430`) across all four conditions accounts for every match count and CLI exit status (`0` iff `matched == 6` else `1`):
- **`baseline` (`3/6` matched, exit `1`)**: Prompts (`lines 409–410`) list vertices and edge relations without host residual annotations (`"gap="` absent on all 6 instances). The stub emits `VERDICT: CONSISTENT` on all 6 instances, matching the `3` consistent instances and missing the `3` inconsistent instances.
- **`hinted` (`6/6` matched, exit `0`)**: `format_prompt` (`lines 411–418`) calls `exact_host_evaluate(instance)` (`lines 120–160`), which formats nonzero residual edges with compact `"gap={residual}"` (`line 153`) on the `3` inconsistent instances while omitting `"gap="` (`residual_edges == []`) on the `3` consistent instances. The stub emits `CONTRADICTION` on the `3` inconsistent instances and `CONSISTENT` on the `3` consistent instances (`6/6`).
- **`scratchpad` (`3/6` matched, exit `1`)**: `format_prompt` (`lines 419–427`) appends generic step instructions containing `"Step 3: For every remaining edge compute gap = |pi(v) - pi(u) - difference|."` with spaces around the equals sign, so the compact substring `"gap="` is `False` on all 6 prompts. The stub emits `VERDICT: CONSISTENT` on all 6 instances, matching `3/6`.
- **`exact_oracle` (`6/6` matched, exit `0`)**: In `run_benchmark` (`lines 469–471, 481`), the `exact_oracle` branch sets `content = f"Host verdict copied: {host_verdict}"`, `verdict = host_verdict`, and `provider = "host"` directly from the host evaluation without calling `active.complete`, matching `6/6`.

### 3.3 Falsification Negative Controls
1. **In-Package Write Refusal**: Invoking `main(["--condition", "hinted", "--output-dir", str(PACKAGE_ROOT / "forbidden_run_output")])` returns exit code `2`, prints `"refusing to write inside the package directory"` to `stderr`, and creates no directory.
2. **Keyless `--live` Refusal Before Socket Creation**: Clearing `OPENROUTER_API_KEY` and invoking `main(["--live", "--condition", "baseline", "--output-dir", ...])` returns exit code `2` with an `OPENROUTER_API_KEY` error message while `socket.create_connection` remains uncalled.
3. **Substring Sensitivity of `OfflineStubClient`**: Replacing `"gap="` with `"residual="` in a poisoned `hinted` prompt flips `OfflineStubClient.complete` from `VERDICT: CONTRADICTION` to `VERDICT: CONSISTENT`, while replacing spaced `"gap = "` with `"gap="` in a poisoned `scratchpad` prompt flips `OfflineStubClient.complete` from `VERDICT: CONSISTENT` to `VERDICT: CONTRADICTION`.

## 4. Limits and Non-Claims

1. **Zero Model Measurement**: All four offline conditions execute deterministic Python prompt formatting, substring matching (`OfflineStubClient`), and BFS spanning-tree evaluation (`exact_host_evaluate` / `host_certificate`); none measures a language model or exercises `OpenRouterClient` over a network.
2. **Process-Level Isolation Scope**: Isolation holds for the offline code path of `retraction_benchmark_runner.py` verified via Python socket and file-open hooks, not as an operating-system sandbox over arbitrary third-party code.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms via source inspection and hooked execution that offline runs of `retraction_benchmark_runner.py` open zero sockets, read zero credential files, refuse writes inside `PACKAGE_ROOT`, write `summary.json` and `receipts.jsonl` only to external or `mkdtemp` directories, and match `3, 6, 3, 6` of `6` verdicts across `baseline`, `hinted`, `scratchpad`, and `exact_oracle`.
2. **What it does not support**: Does not measure any neural model, validate live OpenRouter API behavior, or attribute the `hinted` vs. `scratchpad` offline count difference (`6/6` vs. `3/6`) to model reasoning rather than `"gap="` vs. `"gap = "` prompt formatting.
3. **Narrowest defensible claim**: In offline mode, `retraction_benchmark_runner.py` performs zero socket or credential-file operations, restricts output writes outside `PACKAGE_ROOT`, and produces `3, 6, 3, 6` of `6` matching verdicts across `baseline`, `hinted`, `scratchpad`, and `exact_oracle` via its `"gap="` substring stub and host oracle without running a model.
4. **Next test needed**: Execute live provider runs only in an explicitly budgeted evaluation harness outside the offline package tests and store full v2 trace receipts in an external run archive.

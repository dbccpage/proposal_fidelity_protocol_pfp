# AUDIT-P005-011: Native refusal propagation

## 1. Claim Statement

In the Paper 005 governor implementation (`code/l1_symbol_game_governor.py`), function `compute_phi1` delegates primary obstruction evaluation to a configured native calculator when environment variable `CORE_FUNCTIONAL_GRAPH_BIN` is present, directly propagating any raised native refusal or execution exception without catching or replacing it with a Python answer. When `CORE_FUNCTIONAL_GRAPH_BIN` is unconfigured, `compute_phi1` evaluates the quotient discrepancy through exact rational enumeration of spanning-forest potentials. Floating-point or Boolean edge weights and claim values are refused with `TypeError` on both execution paths rather than converted.

## 2. Context & Hypotheses

- **Patched Governor Copy**:
  - `compute_phi1` in the vendored governor was patched to eliminate exception handlers around native delegation.
  - Earlier revisions substituted an offline Python calculation when the native binary failed; the patched copy leaves exception propagation intact.
- **Dual Execution Route**:
  - Configured Route: `CORE_FUNCTIONAL_GRAPH_BIN` and `CORE_FUNCTIONAL_GRAPH_SHA256` name an external executable.
  - Unconfigured Route: `CORE_FUNCTIONAL_GRAPH_BIN` unset triggers finite spanning-forest tree enumeration.
- **Arithmetic Integrity Constraints**:
  - Edge weights and claim values must be exact integers or `fractions.Fraction` instances.
- **Obligations**:
  - Enumeration results are not native results; offline calculations do not substitute for native execution evidence.

## 3. Derivation / Evidence

### 3.1 Direct Propagation of Configured Native Failures
In `l1_symbol_game_governor.py`, lines 317–321:
```python
if os.environ.get("CORE_FUNCTIONAL_GRAPH_BIN"):
    from native_functional import compute_graph_phi1
    return compute_graph_phi1(
        graph.vertices, [(e.u, e.v, e.weight) for e in graph.edges], normalized,
    )
```
The call to `compute_graph_phi1` occurs without an enclosing `try ... except` block. AST inspection demonstrates zero `ast.ExceptHandler` nodes within the function body. When configured with a missing binary or non-matching hash, the resulting exception is raised directly to the caller (`test_native_refusal_propagation.py::test_configured_native_failure_is_not_replaced`).

### 3.2 Exact Spanning-Forest Enumeration on Unconfigured Route
When `CORE_FUNCTIONAL_GRAPH_BIN` is removed from the environment, `compute_phi1` generates candidate spanning-forest potentials via `find_spanning_forest_potentials`. On a directed 3-cycle with edge weights $(1, 2, 2)$ and asserted claims $(1, 1, 1)$, the minimal discrepancy is evaluated as:
$$\Phi_1 = \min_{s} \sum_{e=(u,v) \in E} w_e |c(u,v) - (s(v) - s(u))| = 3$$
The computed residual sum matches the returned obstruction in exact rational arithmetic (`test_native_refusal_propagation.py::test_enumeration_path_without_native_configuration`).

### 3.3 Strict Refusal of Float and Boolean Types
Prior to branching, `compute_phi1` checks:
```python
for edge in graph.edges:
    if type(edge.weight) not in (int, Fraction):
        raise TypeError("edge weights must be exact int or Fraction, not float or bool")
```
Because `bool` is a subclass of `int` in Python, checking `type(...) not in (int, Fraction)` distinguishes Booleans (`type(True) is bool`) and floats (`type(4.5) is float`), raising `TypeError` without implicit casting. Edge definitions with zero weight raise `ValueError` at construction time. Valid rational fractions such as `Fraction(5, 2)` are accepted and evaluated.

## 4. Limits and Non-Claims

1. **Enumeration Scalability**: Exact spanning-forest enumeration evaluates combinatorial potential assignments; it is designed for bounded pedagogical instances and does not scale to large complex networks.
2. **Separation of Proof Surfaces**: Offline Python enumeration results do not constitute attestation of native binary execution or Rust compiler correctness.
3. **External Diagnostic Limit**: Exception propagation delivers raw failure information; it does not repair environment misconfigurations or diagnose corrupt binary headers.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that `compute_phi1` propagates native adapter exceptions without swallowing, evaluates exact spanning-forest potentials when unconfigured, and refuses inexact float and Boolean weights with `TypeError`.
2. **What it does not support**: Does not support equivalence between Python enumeration and native execution, nor does it support automatic convergence for arbitrary non-discrete objectives.
3. **Narrowest defensible claim**: When `CORE_FUNCTIONAL_GRAPH_BIN` is set, `compute_phi1` propagates native adapter failures without an exception handler; when unset, it computes finite spanning-forest potentials in exact rationals and refuses float/Boolean weights with `TypeError`.
4. **Next test needed**: Testing native exception propagation against a mock native binary emitting structured exit codes and error logs on malformed graph inputs.

## 1. Claim Statement

The saved 20/20 headless execution receipt in `education/004_oepfp/curriculum/headless_receipt.json` is a historical record; its recorded notebook paths and the paths in `education/004_oepfp/curriculum/lesson_manifest.json` do not resolve to files on disk in the current repository layout, and the cycle repair notebook's target method `Cochain1.l1_norm` unconditionally raises `FunctionalBoundaryUnavailable`.

## 3. Derivation / Evidence

### 3.1 Historical Receipt Analysis
Inspection of `education/004_oepfp/curriculum/headless_receipt.json` establishes:
- Timestamp: `2026-09-25T01:52:32.889242+00:00`
- Recorded summary: `"status": "PASS"`, `"passed": 20`, `"total": 20`
- Recorded notebook paths: All 20 entries point to former locations under the prefix `education/notebooks/lessons/system_integration/`.
- Resolvability: Resolving all 20 paths against repository root reveals that $0$ out of $20$ exist on disk at those paths.

### 3.2 Manifest Path Staleness
Inspection of `education/004_oepfp/curriculum/lesson_manifest.json` demonstrates:
- Declared schema: `mssn.education.lesson-manifest.v1`
- Declared lessons: 20 records pointing to paths under `education/documentation/004_oepfp/curriculum/`.
- Resolvability: Resolving these paths against repository root reveals that $0$ out of $20$ exist on disk at those paths.

### 3.3 Retired Norm API Refusal
In the cycle repair lesson (`04_cycle_repair.ipynb`), the code exercises a norm evaluation on 1-cochains via `residual.l1_norm()`.
Inspection of `pfp/domain/ddc/cochains.py` (lines 96–98, 167–172, 240–242) shows:
```python
def l1_norm(self) -> Fraction:
    raise FunctionalBoundaryUnavailable(
        "FUNCTIONAL_BOUNDARY_UNAVAILABLE: Python DDC cannot calculate Phi1, Gamma2, Xi, "
        "or L1 norms; engine/crates_rs/core_functional/src is the sole calculator and "
        "no Rust-backed DDC adapter is wired."
    )
```
Invoking `Cochain1(values=...).l1_norm()` raises `FunctionalBoundaryUnavailable`. The Python domain layer explicitly refuses to compute discrete L1 norms in unadapted environments, requiring the external native engine.

## 4. Limits and Non-Claims

1. **Receipt Scope**: The 20/20 pass status attests to execution at the recorded historical date (2026-09-25) in an earlier checkout structure. It does not certify that the full route runs cleanly today without relocating paths and updating retired calls.
2. **Pedagogical Independence**: Path staleness and API retirement describe repository packaging and interface boundaries; they do not alter the underlying finite mathematical identities (such as cycle invariants under potential adjustment).
3. **Future Adaptations**: This finding records the observed state of retained files; it does not preclude authoring an updated route manifest or connecting an adapted native calculator in subsequent revisions.

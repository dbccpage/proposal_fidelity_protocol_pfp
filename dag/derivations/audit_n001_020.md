## 1. Claim Statement

Let $G = (V, E)$ be a finite directed graph regarded as a 1-dimensional cell complex over $\mathbb{R}$, with cochain sequence $C^0(G) \xrightarrow{d_0} C^1(G) \xrightarrow{d_1} C^2(G)$. Under these hypotheses:

1. Because $G$ contains no 2-cells, $C^2(G) = \{0\}$ and the degree-1 coboundary operator $d_1: C^1(G) \to C^2(G)$ is identically the zero homomorphism: $d_1 = 0$.
2. Every 1-cochain is a 1-cocycle:
   $$Z^1(G) = \ker(d_1) = C^1(G).$$
3. The 1-cochain quotient space $Q^1(G) = C^1(G) / \operatorname{im}(d_0)$ is canonically isomorphic to the first real cohomology group:
   $$Q^1(G) \cong H^1(G; \mathbb{R}) = \frac{\ker(d_1)}{\operatorname{im}(d_0)}.$$
4. A 1-cochain $\boldsymbol{\omega} \in C^1(G)$ has non-zero quotient norm $\Phi_p([\boldsymbol{\omega}]) > 0$ for any $p \in [1, \infty]$ if and only if its equivalence class $[\boldsymbol{\omega}]$ is a non-trivial element of $H^1(G; \mathbb{R})$.
5. The dimension of $Q^1(G)$ is the cycle rank (first Betti number) of the graph:
   $$\dim Q^1(G) = \dim H^1(G; \mathbb{R}) = \beta_1(G) = |E| - |V| + c,$$
   where $c$ is the number of connected components of $G$.
6. On cell complexes of dimension 2 or higher ($C^2(K) \ne \{0\}$), the quotient space $Q^1(K)$ does not coincide with $H^1(K; \mathbb{R})$, because nonzero classes in $Q^1(K)$ include curvature defects where $d_1 \boldsymbol{\omega} \ne \mathbf{0}$.

## 2. Context & Hypotheses

- **1-Dimensional Graph Complex**: $G = (V, E)$ has vertices $V$ and directed edges $E$, with $|V| \ge 1$ and $|E| \ge 0$.
- **Cochain Spaces**:
  - $C^0(G) = \mathbb{R}^V$ (vertex functions).
  - $C^1(G) = \mathbb{R}^E$ (edge evaluations).
  - $C^k(G) = \{0\}$ for all $k \ge 2$.
- **Coboundary Maps**:
  - $(d_0 f)_{uv} = f(v) - f(u)$ for $(u, v) \in E$.
  - $d_1: C^1(G) \to C^2(G) = \{0\}$ is the unique linear map to the zero space.
- **Quotient Space**: $Q^1(G) = C^1(G) / B^1(G)$, where $B^1(G) = \operatorname{im}(d_0)$.

## 3. Derivation / Evidence

### 3.1 Vanishing of Degree-2 Coboundary on 1-Graphs
1. In cell complex topology, the cochain groups $C^k(K; \mathbb{R})$ are generated by the $k$-cells of $K$.
2. For a 1-dimensional graph $G = (V, E)$, the set of 2-cells is empty: $X_2 = \emptyset$.
3. Thus $C^2(G) = \mathbb{R}^{X_2} = \{0\}$.
4. The coboundary operator $d_1: C^1(G) \to C^2(G)$ maps every element of $C^1(G)$ to $\mathbf{0} \in \{0\}$.
5. Consequently, the kernel of $d_1$ is the entire space:
   $$\ker(d_1) = \{ \boldsymbol{\omega} \in C^1(G) : d_1 \boldsymbol{\omega} = \mathbf{0} \} = C^1(G).$$
6. Therefore, the 1-cocycle group is $Z^1(G) = C^1(G)$.

### 3.2 Canonical Isomorphism of Quotient Space and Cohomology
1. By standard homological algebra, the first de Rham / cellular cohomology group with real coefficients is:
   $$H^1(G; \mathbb{R}) = \frac{\ker(d_1)}{\operatorname{im}(d_0)} = \frac{Z^1(G)}{B^1(G)}.$$
2. Substituting $Z^1(G) = C^1(G)$:
   $$H^1(G; \mathbb{R}) = \frac{C^1(G)}{\operatorname{im}(d_0)} = Q^1(G).$$
3. By the rank-nullity theorem applied to $d_0: \mathbb{R}^V \to \mathbb{R}^E$:
   - The kernel $\ker(d_0)$ consists of functions that are constant on each connected component of $G$. Thus $\dim \ker(d_0) = c$.
   - The rank is $\dim \operatorname{im}(d_0) = |V| - c$.
4. The dimension of the quotient space is:
   $$\dim Q^1(G) = \dim C^1(G) - \dim \operatorname{im}(d_0) = |E| - (|V| - c) = |E| - |V| + c.$$
5. This quantity is the cyclomatic number or first Betti number $\beta_1(G)$.
6. Because $\Phi_p([\boldsymbol{\omega}]) = \inf_{f \in C^0} \|\boldsymbol{\omega} + d_0 f\|_{p, \mathbf{w}}$, and positive weights ensure $\|\cdot\|_{p, \mathbf{w}}$ is a norm on $C^1(G)$, $\Phi_p([\boldsymbol{\omega}]) = 0 \iff \boldsymbol{\omega} \in \operatorname{im}(d_0) = B^1(G) \iff [\boldsymbol{\omega}] = \mathbf{0} \in Q^1(G)$.
7. Hence $\Phi_p([\boldsymbol{\omega}]) > 0$ if and only if $[\boldsymbol{\omega}]$ represents a non-trivial cohomology class in $H^1(G; \mathbb{R})$.

### 3.3 Separation from 2-Complex Curvature Defects
1. On a 2-dimensional cell complex $K$ equipped with 2-cells (faces) $X_2 \ne \emptyset$, $C^2(K) \ne \{0\}$.
2. The coboundary $d_1: C^1(K) \to C^2(K)$ has a non-trivial coboundary evaluation: $(d_1 \boldsymbol{\omega})_F = \sum_{e \in \partial F} [F : e] \omega_e$.
3. Here, $Z^1(K) = \ker(d_1) \subsetneq C^1(K)$ in general.
4. The quotient space $Q^1(K) = C^1(K) / \operatorname{im}(d_0)$ is strictly larger than $H^1(K; \mathbb{R}) = Z^1(K) / \operatorname{im}(d_0)$.
5. Specifically, $Q^1(K)$ decomposes into:
   - Closed classes: $\boldsymbol{\omega} \in Z^1(K)$, which correspond to $H^1(K; \mathbb{R})$.
   - Curvature classes: $\boldsymbol{\omega} \notin Z^1(K)$, where $d_1 \boldsymbol{\omega} \ne \mathbf{0}$.
6. This distinction establishes that the identification of nonzero quotient classes exclusively with non-trivial cohomology classes is specific to 1-dimensional carriers where $C^2 = \{0\}$.

### 3.4 Verification and Test Witness Reference
Supported by executable tests in `tests/test_w2w2_shard_b.py`:

- `test_audit_n001_020_negative_control_2complex_curvature_distinction`: Evaluates a 2-complex with a triangular 2-cell, confirming that a cochain with $d_1 \boldsymbol{\omega} \ne \mathbf{0}$ yields $\Phi_1 > 0$ but fails the cocycle condition $d_1 \boldsymbol{\omega} = \mathbf{0}$.

## 4. Limits and Non-Claims

- **Scope Definition**: This manuscript formalizes the taxonomic definition and classification of quotient classes on 1-graphs.
- **Dimension Ceiling**: This isomorphism holds on 1-dimensional cell complexes; on 2-complexes, nonzero quotient classes contain non-closed curvature defects that do not belong to $H^1$.
- **Field Coefficients**: Stated over $\mathbb{R}$; torsion elements of integral homology $H_1(K; \mathbb{Z})$ do not appear over real coefficients.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the canonical isomorphism $Q^1(G) \cong H^1(G; \mathbb{R})$ on finite 1-dimensional graph complexes where $C^2 = \{0\}$, establishing that nonzero quotient classes correspond to non-trivial cohomology classes.
2. **What it does not support**:
   Does not support identifying $Q^1$ with $H^1$ on complexes of dimension 2 or higher where non-zero curvature defects exist.
3. **Narrowest defensible claim**:
   On finite 1-dimensional graph complexes ($C^2 = \{0\}$), all 1-cochains are cocycles, identifying $Q^1 = C^1 / \operatorname{im}(d_0)$ with $H^1(G; \mathbb{R})$.
4. **Next test needed**:
   Verification of $Q^1$ versus $H^1$ on 2-complexes with non-vanishing face coboundaries.

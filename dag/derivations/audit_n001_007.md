## 1. Claim Statement

For any finite graph $G = (V, E)$ and any 1-cochain $c \in C^1(G)$:
$$c \in \operatorname{im} d_0 \iff \langle y, c \rangle = 0 \text{ for every circulation } y \in \ker d_0^\top.$$

## 2. Context & Hypotheses

- **Finite Graph**: $G = (V, E)$ is a finite 1-dimensional cell complex with $|V|$ vertices and $|E|$ edges.
- **Cochain Spaces**:
  - $C^0(G) = \mathbb{R}^V$ (vertex potentials).
  - $C^1(G) = \mathbb{R}^E$ (edge cochains).
- **Coboundary Operator**: $d_0: C^0(G) \to C^1(G)$ maps vertex potentials to edge differences $(d_0 f)_{uv} = f(v) - f(u)$ for directed edge $(u, v)$.
- **Circulation Space**: $\ker d_0^\top = \{y \in \mathbb{R}^E : d_0^\top y = 0\}$, representing divergence-free 1-chains.
- **Pairing**: $\langle y, c \rangle = \sum_{e \in E} y_e c_e$.

## 3. Derivation / Evidence

### 3.1 Finite-Dimensional Orthogonal Subspaces
1. The coboundary operator $d_0: \mathbb{R}^V \to \mathbb{R}^E$ is a linear map between finite-dimensional real inner product spaces.
2. The adjoint operator $d_0^\top: \mathbb{R}^E \to \mathbb{R}^V$ satisfies the defining identity:
   $$\langle d_0^\top y, f \rangle_{\mathbb{R}^V} = \langle y, d_0 f \rangle_{\mathbb{R}^E}$$
   for all $f \in \mathbb{R}^V$ and $y \in \mathbb{R}^E$.
3. By the fundamental theorem of linear algebra in finite dimension:
   $$(\operatorname{im} d_0)^\perp = \ker d_0^\top.$$
4. Taking the orthogonal complement of both sides and applying finite-dimensional reflexivity $S^{\perp\perp} = S$:
   $$\operatorname{im} d_0 = (\ker d_0^\top)^\perp.$$

### 3.2 Bidirectional Equivalence
1. **Forward Direction ($\Rightarrow$)**:
   Suppose $c \in \operatorname{im} d_0$, so $c = d_0 f$ for some $f \in C^0(G)$.
   Let $y \in \ker d_0^\top$ be an arbitrary circulation.
   Then:
   $$\langle y, c \rangle = \langle y, d_0 f \rangle = \langle d_0^\top y, f \rangle = \langle 0, f \rangle = 0.$$
   Thus an exact cochain pairs to zero with every circulation.
2. **Reverse Direction ($\Leftarrow$)**:
   Suppose $\langle y, c \rangle = 0$ for every circulation $y \in \ker d_0^\top$.
   By definition of the orthogonal complement, $c \in (\ker d_0^\top)^\perp$.
   Since $(\ker d_0^\top)^\perp = \operatorname{im} d_0$, it follows that $c \in \operatorname{im} d_0$.

### 3.3 Uniformity Across Norm Exponents $p \in [1, \infty]$
1. By Fenchel-Rockafellar duality (Theorem LpC-T3 / AUDIT-N001-005):
   $$\Phi_p([c]) = \inf_{f \in C^0(G)} \|c - d_0 f\|_{p, \mathbf{w}} = \max_{y \in \ker d_0^\top, \|y\|_{q, \mathbf{w}^*} \le 1} \langle y, c \rangle.$$
2. Because $\Phi_p$ is positive definite on the quotient $C^1(G) / \operatorname{im} d_0$:
   $$\Phi_p([c]) = 0 \iff c \in \operatorname{im} d_0.$$
3. The dual maximum equals zero if and only if $\langle y, c \rangle = 0$ for all circulations $y \in \ker d_0^\top$.
4. Hence vanishing circulation pairings characterize exactness uniformly for all $p \in [1, \infty]$.

## 4. Limits and Non-Claims

- **Finite Graph Scope**: Applies to finite-dimensional graphs. Infinite complexes require closed range conditions on $\operatorname{im} d_0$.
- **Adjoint Duality**: The pairing $\langle y, c \rangle$ assumes the standard inner product on real cochains.
- **Circulation Definition**: Vectors with $d_0^\top y \ne 0$ do not belong to $\ker d_0^\top$ and cannot serve as exactness witnesses.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the equivalence $c \in \operatorname{im} d_0 \iff \langle y, c \rangle = 0$ for all $y \in \ker d_0^\top$ on finite graphs, establishing $(\ker d_0^\top)^\perp = \operatorname{im} d_0$ uniformly for all $p \in [1, \infty]$.
2. **What it does not support**:
   Does not support infinite graph extensions without topological closure; does not assert exactness for vectors pairing to zero with only a proper subset of circulations.
3. **Narrowest defensible claim**:
   On any finite graph, $c \in \operatorname{im} d_0$ if and only if $\langle y, c \rangle = 0$ for all $y \in \ker d_0^\top$.

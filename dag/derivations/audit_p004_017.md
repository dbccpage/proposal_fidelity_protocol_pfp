## 1. Claim Statement

step_cut refuses a CUT omitting a declared edge or with a non-exact value (IncompleteProposal, state unchanged).

## 2. Context & Hypotheses

- **Hypotheses**: `l1_symbol_game_governor.py`
- **Relational CUT Semantics**:
  - In `L1SymbolGameGovernor`, move `CUT` allows an agent to submit either an updated section potential assignment or an updated set of edge claims (`proposed_claims`).
  - Historically (prior to review finding R008-04), `step_cut(proposed_claims=...)` scored omitted declared edges as zero claims, allowing an incomplete proposal to artificially reduce defect to zero.
  - The audited governor enforces domain completeness: a relational proposal must supply replacement values for all declared edges in the constraint graph $G$.
  - An omitted edge is refused rather than read as zero.
- **Fail-Closed State Invariance**:
  - If a proposal is refused as `IncompleteProposal`, the internal state of the governor (`edge_claims`, `section`, `history`, `primary_obstruction`) remains strictly unchanged.

## 3. Derivation / Evidence

### 3.1 Completeness Check Over Declared Edges
1. When `proposed_claims` is supplied to `step_cut`, the governor identifies the declared edge key set:
   ```python
   declared = [e.key for e in self.graph.edges]
   missing = [key for key in declared if key not in proposed_claims]
   ```
2. If `missing` is non-empty (for example, with empty dictionary `{}` or partial mappings omitting one or two edges), the governor constructs a refusal verdict:
   - `admitted = False`
   - `status = "IncompleteProposal"`
   - `details = "... omits declared edges ..."`
   - `defect_before = self.primary_obstruction()`
   - `defect_after = self.primary_obstruction()`

### 3.2 Exact Numeric Type Guard
1. The governor inspects all proposed edge claim values:
   ```python
   inexact = [
       key for key in declared
       if key in proposed_claims and type(proposed_claims[key]) not in (int, Fraction)
   ]
   ```
2. If `inexact` is non-empty (containing floating-point numbers like `0.5`, `1.0`, or Booleans like `True`, `False`), the governor rejects the proposal:
   - `admitted = False`
   - `status = "IncompleteProposal"`
   - `details = "... gives non-exact values ..."`

### 3.3 Atomic Non-mutation
1. In `step_cut`, the state mutation lines:
   ```python
   self.edge_claims = dict(proposed_claims)
   self.section = self.project(self.section)
   ```
   occur strictly after all validation gates (diagonal check, carrier boundary check, production surface check, completeness check, and monotonic defect descent check).
2. When `IncompleteProposal` is triggered:
   - `self.edge_claims` remains identical to its pre-call state.
   - `self.primary_obstruction()` remains unchanged.
   - `self.history` appends zero records.
3. Conversely, when a proposal provides explicit exact values for every declared edge, it proceeds to defect evaluation and is admitted if defect does not increase.

## 4. Limits & Non-claims

1. **What it supports**: Confirms that `step_cut` enforces full edge coverage and exact numeric types (`int`, `Fraction`) on relational CUT proposals, returning `IncompleteProposal` with zero state mutation upon omission or inexact input.
2. **What it does not support**: Does not imply that admitting a complete relational proposal establishes the external truth or domain accuracy of the asserted edge values; it confirms only formal graph defect reduction.
3. **Narrowest defensible claim**: In `L1SymbolGameGovernor`, any relational CUT proposal omitting at least one declared edge or containing a `float` or `bool` value is refused with status `IncompleteProposal`, preserving internal edge claims and defect values without mutation.
4. **Next test needed**: Verifying relational CUT rejection behavior under dynamically reconfigured multi-graph carriers.

- `TestCutCompleteness::test_cut_omitting_declared_edges_is_refused_with_state_unchanged`: Tests empty proposal, single-edge proposal, and two-edge proposal on a three-edge graph, confirming `IncompleteProposal` refusal and state immutability.
- `TestCutCompleteness::test_cut_with_non_exact_values_is_refused_with_state_unchanged`: Tests `float` (`0.5`, `1.0`) and `bool` (`True`, `False`) values, confirming refusal without state alteration.

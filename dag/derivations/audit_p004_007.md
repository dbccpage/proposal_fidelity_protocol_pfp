## 1. Claim Statement

`pfp/ffi.py` dispatches native host operations through the operating system adapter seam (`operating_system.adapters.rust_host.ffi`) and returns the complete railway outcome (`Result[Mapping[str, Any], Refusal]`) unmodified without mutating, stripping, or relabeling native payloads.

## 2. Context & Hypotheses

- **Python FFI Layer**:
  - Implemented in `pfp/ffi.py`.
- **Underlying Native Seam**:
  - Implemented in `operating_system.adapters.rust_host.ffi`.
- **Railway Outcome Discipline**:
  - Outgoing outcomes conform to `Result[Mapping[str, Any], Refusal]` from `operations.domain.rop.result`.
- **Architectural Invariant**:
  - Seam isolation invariant (`RULE_FFI_SEAM_ISOLATION_001`): binary discovery and execution belong to the OS adapter, while `pfp/ffi.py` serves as an unmutated action dispatch boundary.

## 3. Derivation / Evidence

### 3.1 Binary Location Delegation to the Canonical Seam
In `pfp/ffi.py:27-56`, `find_core_symbol_game_binary()` delegates executable discovery directly to the underlying OS adapter seam:
```python
def find_core_symbol_game_binary() -> Path:
    from operating_system.adapters.rust_host.ffi import locate_host_binary

    located = locate_host_binary()
    if located.is_err:
        refusal = located.unwrap_err()
        raise FileNotFoundError(
            f"{getattr(refusal, 'code', 'HOST_BINARY_NOT_FOUND')}: "
            f"{getattr(refusal, 'message', refusal)}"
        )
    return located.unwrap().binary
```
This design avoids redundant path heuristics and ensures that environment variables (`CORE_SYMBOL_GAME_HOST`) and configuration overrides are resolved in one place.

### 3.2 Passthrough Dispatch and Outcome Preservation
In `pfp/ffi.py:58-83`, `RustSymbolGameHost` wraps the OS-level host instance and forwards requests without intermediate modification:
```python
class RustSymbolGameHost:
    def __init__(self, binary_path: str | Path | None = None) -> None:
        if binary_path is not None:
            self._binary_path = Path(binary_path).resolve()
        else:
            self._binary_path = find_core_symbol_game_binary()
        self._host = native_host.RustSymbolGameHost(
            binary=self._binary_path, timeout_seconds=30
        )

    def invoke_runtime(
        self, action: str, payload: Any
    ) -> Result[Mapping[str, Any], Refusal]:
        """Return the canonical seam's full per-call outcome or typed refusal."""
        return self._host.invoke_runtime(action, payload)

    def invoke(self, action: str, payload: Any) -> Result[Mapping[str, Any], Refusal]:
        """Dispatch without extracting or relabeling the native outcome."""
        return self.invoke_runtime(action, payload)
```
As stated in module docstrings (`pfp/ffi.py:3-5`), invocation methods return the complete railway outcome rather than bare results, allowing callers to inspect the full attestation, diagnostic fields, and timestamps.

### 3.3 Railway Monad Preservation Across Outcome Variants
Inspection of `invoke_runtime` verifies:
1. When the native host produces a successful execution, the resulting `Ok(mapping)` is returned directly. The dictionary retains all fields (`status`, `result`, `runtime_micros`, etc.) produced by the native seam.
2. When the native host produces a typed refusal or execution failure, an `Err(Refusal)` is returned directly, preserving refusal code, message, and diagnostic context.
3. No field stripping, dictionary unpacking, or exception masking occurs at this boundary.

### 3.4 Convenience Method Dispatches
All specific action methods defined in `pfp/ffi.py` (e.g. `canonical_wire`, `canonical_unwire`, `canonical_json`, `canonical_bytes_hex`, `domain_digest`, `classify_gauge_board`, `exact_determinant`, `prime_admit`, `prime_replay_decide`) dispatch strictly through `self.invoke(action, payload)`. They do not bypass `invoke_runtime` or modify the underlying return structure.

## 4. Limits and Non-Claims

1. **Passthrough Integrity Only**: This derivation confirms that `pfp/ffi.py` passes input payloads and output outcomes without mutation; it does not evaluate whether the native binary's mathematical output is true or optimal.
2. **Subprocess Dependency**: Execution relies on OS subprocess spawning and pipe communication managed by `operating_system.adapters.rust_host.ffi`.
3. **No Authority Elevation**: Preserving native outcomes unmodified retains their declared `AuthorityEffect: None` status; no cryptographic signing or promotion occurs in `ffi.py`.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that `pfp/ffi.py` delegates binary location and process execution to `operating_system.adapters.rust_host.ffi` and returns `Result[Mapping[str, Any], Refusal]` outcomes unmodified.
2. **What it does not support**: Does not support claims that Python FFI calls are zero-cost or that native results are mathematically verified beyond the native host's own execution checks.
3. **Narrowest defensible claim**: `pfp/ffi.py` acts as a transparent adapter over the OS native seam, preserving full railway outcomes and typed refusals without mutation or field stripping.
4. **Next test needed**: End-to-end integration test with a mock native seam emitting arbitrary nested JSON structures to verify bitwise equality between native output and returned mapping.

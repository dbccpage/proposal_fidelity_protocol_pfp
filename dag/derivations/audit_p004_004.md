       admission_codes.push("PRIME000_CONFORMANCE_PARTIAL".to_owned());
   }
   let reason_commitment = admission_reason(&admission_codes, "laboratory replay only");
   finalize_outcome(HostOutcomeV1 {
       ...
       admission: AdmissionSummaryV1 {

3. Because Prime 000 conformance is `Partial` (`prime000_conforms == false`), `"PRIME000_CONFORMANCE_PARTIAL"` is appended.
4. No other admission codes are appended on this path.

## 4. Limits & Non-claims

1. **What it supports**: Confirms that on the audited four-vertex laboratory fixture, the host refuses production admission with exactly `PRIME000_CONFORMANCE_PARTIAL` and `UNSIGNED_LAB_ATTESTATION`.
2. **What it does not support**: Does not assert global non-admissibility across all possible requests; requests providing full Prime 000 conformance and signed attestations follow separate evaluation branches.
3. **Narrowest defensible claim**: On the executed path of the four-vertex test fixture, `evaluate_request` returns `admission.kind = "Refused"` with code set consisting exactly of `{"PRIME000_CONFORMANCE_PARTIAL", "UNSIGNED_LAB_ATTESTATION"}`.
4. **Next test needed**: Verifying admission gate promotion behavior under synthetic fully signed production credentials.

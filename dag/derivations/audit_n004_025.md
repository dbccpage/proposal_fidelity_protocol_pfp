## 1. Claim Statement

For the positive algebraic number $q = 2(\sqrt{2} - 1)$, the exact rational interval $[L, U] = \left[\frac{828}{1000}, \frac{829}{1000}\right]$ strictly encloses $q$:
$$\frac{828}{1000} < 2(\sqrt{2} - 1) < \frac{829}{1000}$$
with exact rational interval width $U - L = \frac{1}{1000}$.

## 2. Context & Hypotheses

- **Target Algebraic Number**: $q = 2(\sqrt{2} - 1) \in \mathbb{R}_{>0}$.
- **Quadratic Transformation**:
  Observe that:
  $$1 + \frac{q}{2} = 1 + (\sqrt{2} - 1) = \sqrt{2}.$$
  Squaring both sides yields:
  $$\left(1 + \frac{q}{2}\right)^2 = (\sqrt{2})^2 = 2.$$
- **Order Monotonicity on Positive Reals**:
  The function $f(t) = \left(1 + \frac{t}{2}\right)^2$ satisfies:
  1. For $t > 0$, $1 + t/2 > 1 > 0$.
  2. The derivative $f'(t) = 2\left(1 + \frac{t}{2}\right)\left(\frac{1}{2}\right) = 1 + \frac{t}{2} > 0$ for all $t > 0$.
  3. Hence $f(t)$ is strictly increasing on $(0, \infty)$.
  4. Consequently, for any positive rational numbers $L, U > 0$:
     $$f(L) < 2 < f(U) \iff L < q < U.$$

## 3. Derivation / Evidence

### 3.1 Exact Rational Squaring in $\mathbb{Q}$

Let $L = \frac{828}{1000} = \frac{207}{250}$ and $U = \frac{829}{1000}$.

1. **Lower Bound Evaluation**:
   - Compute $1 + \frac{L}{2}$:
     $$1 + \frac{828}{2000} = 1 + \frac{207}{500} = \frac{707}{500}.$$
   - Compute the exact square $\left(1 + \frac{L}{2}\right)^2$:
     $$\left(\frac{707}{500}\right)^2 = \frac{707^2}{500^2} = \frac{499849}{250000}.$$
   - Compare with 2:
     $$2 = \frac{500000}{250000}.$$
   - Evaluate the difference:
     $$2 - \left(1 + \frac{L}{2}\right)^2 = \frac{500000 - 499849}{250000} = \frac{151}{250000} > 0.$$
   - Therefore:
     $$\left(1 + \frac{L}{2}\right)^2 = \frac{499849}{250000} < 2.$$

2. **Upper Bound Evaluation**:
   - Compute $1 + \frac{U}{2}$:
     $$1 + \frac{829}{2000} = \frac{2829}{2000}.$$
   - Compute the exact square $\left(1 + \frac{U}{2}\right)^2$:
     $$\left(\frac{2829}{2000}\right)^2 = \frac{2829^2}{2000^2} = \frac{8003241}{4000000}.$$
   - Compare with 2:
     $$2 = \frac{8000000}{4000000}.$$
   - Evaluate the difference:
     $$\left(1 + \frac{U}{2}\right)^2 - 2 = \frac{8003241 - 8000000}{4000000} = \frac{3241}{4000000} > 0.$$
   - Therefore:
     $$\left(1 + \frac{U}{2}\right)^2 = \frac{8003241}{4000000} > 2.$$

3. **Strict Enclosure Conclusion**:
   - Since $f(L) < 2 < f(U)$ and $f$ is strictly monotonic on $(0, \infty)$, it follows that:
     $$\frac{828}{1000} < 2(\sqrt{2} - 1) < \frac{829}{1000}.$$

4. **Certified Width**:
   - The width of the enclosing interval is:
     $$U - L = \frac{829}{1000} - \frac{828}{1000} = \frac{1}{1000}.$$

- **Algebraic vs Transcendental**: This certificate relies on exact polynomial squaring in $\mathbb{Q}$; it does not certify general transcendental numbers or arbitrary real roots without explicit polynomial certificates.

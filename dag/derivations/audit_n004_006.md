## 1. Claim Statement

For any finite partially ordered set $(P, \le)$ equipped with linear restriction maps between additive stalk spaces $F(x)$, the composition of discrete coboundary operators $d_1$ and $d_0$ satisfies the algebraic identity:
$$(d_1(d_0 s))(a, b, c) = K_{c, b, a}(s(c))$$
identically for every 0-cochain section $s \in C^0(P; F)$ and every comparable chain triple $a \le b \le c$, where the composition curvature operator $K_{c, b, a}: F(c) \to F(a)$ is defined by:
$$K_{c, b, a} = r_{b, a} \circ r_{c, b} - r_{c, a}.$$

## 2. Context & Hypotheses

- **Finite Poset Carrier**: $(P, \le)$ is a finite partially ordered set with elements $a \le b \le c$.
- **Stalk Spaces**: Each element $x \in P$ is assigned an additive group or vector space $F(x)$ over a ring $R$.
- **Linear Restriction System**: For each comparable pair $x \le y$, a restriction homomorphism $r_{y, x}: F(y) \to F(x)$ is declared, preserving subtraction:
  $$r_{y, x}(u - v) = r_{y, x}(u) - r_{y, x}(v) \quad \text{for all } u, v \in F(y).$$
- **Cochain Spaces**:
  - $C^0(P; F) = \prod_{x \in P} F(x)$ (sections / 0-cochains).
  - $C^1(P; F) = \prod_{x \le y} F(x)$ (1-cochains on comparable pairs).
  - $C^2(P; F) = \prod_{x \le y \le z} F(x)$ (2-cochains on comparable triples).
- **Coboundary Operators**:
  - $(d_0 s)(a, b) = r_{b, a}(s(b)) - s(a)$ for $a \le b$.
  - $(d_1 t)(a, b, c) = r_{b, a}(t(b, c)) - t(a, c) + t(a, b)$ for $a \le b \le c$.
- **Curvature Operator**:
  $$K_{c, b, a} = r_{b, a} \circ r_{c, b} - r_{c, a}: F(c) \to F(a).$$

## 3. Derivation / Evidence

### 3.1 Direct Algebraic Expansion

Let $s \in C^0(P; F)$ be an arbitrary section, and consider any comparable triple $a \le b \le c$ in $P$.

1. Evaluate $d_0 s$ on the three pairs associated with the chain:
   $$(d_0 s)(b, c) = r_{c, b}(s(c)) - s(b) \in F(b),$$
   $$(d_0 s)(a, c) = r_{c, a}(s(c)) - s(a) \in F(a),$$
   $$(d_0 s)(a, b) = r_{b, a}(s(b)) - s(a) \in F(a).$$

2. Apply the 1-coboundary definition to the 1-cochain $t = d_0 s$:
   $$(d_1(d_0 s))(a, b, c) = r_{b, a}((d_0 s)(b, c)) - (d_0 s)(a, c) + (d_0 s)(a, b).$$

3. Substitute the values of $d_0 s$ into the expression:
   $$(d_1(d_0 s))(a, b, c) = r_{b, a}(r_{c, b}(s(c)) - s(b)) - (r_{c, a}(s(c)) - s(a)) + (r_{b, a}(s(b)) - s(a)).$$

4. Distribute $r_{b, a}$ across subtraction using linearity of $r_{b, a}$:
   $$r_{b, a}(r_{c, b}(s(c)) - s(b)) = r_{b, a}(r_{c, b}(s(c))) - r_{b, a}(s(b)).$$

5. Reorganize terms in the abelian group $F(a)$:
   $$(d_1(d_0 s))(a, b, c) = r_{b, a}(r_{c, b}(s(c))) - r_{b, a}(s(b)) - r_{c, a}(s(c)) + s(a) + r_{b, a}(s(b)) - s(a).$$

6. Group canceling pairs:
   - The intermediate terms involving the middle stalk value cancel:
     $$- r_{b, a}(s(b)) + r_{b, a}(s(b)) = 0 \in F(a).$$
   - The base stalk terms cancel:
     $$+ s(a) - s(a) = 0 \in F(a).$$

7. Combine the remaining terms:
   $$(d_1(d_0 s))(a, b, c) = r_{b, a}(r_{c, b}(s(c))) - r_{c, a}(s(c)) = (r_{b, a} \circ r_{c, b} - r_{c, a})(s(c)).$$

8. By definition of $K_{c, b, a}$:
   $$(d_1(d_0 s))(a, b, c) = K_{c, b, a}(s(c)).$$
   The identity holds algebraically for all sections $s$ and all comparable triples.

## 4. Limits and Non-Claims

- **Linear Restriction Systems**: The identity requires restriction maps to be homomorphisms preserving subtraction. If maps are non-linear, cancellation fails.
- **Finite Posets**: The derivation assumes finite chains $a \le b \le c$.
- **Generalization of Flat Complexes**: This identity directly generalizes the flat nilpotency property $d_1 d_0 = 0$ recorded in `PFPDOMAIN-CL11` (`pfp/domain/ddc/coboundary.py`). When restriction maps are identity homomorphisms ($r_{y, x} = \mathrm{id}$), $K = \mathrm{id} - \mathrm{id} = 0$, recovering $d_1 d_0 = 0$.
- **No Topological or Gauge Dynamics**: This is a purely kinematic discrete cochain identity; it does not assert physical Yang-Mills equations or continuous differential forms.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the algebraic identity $(d_1 d_0 s)(a, b, c) = K_{c, b, a}(s(c))$ for any linear restriction system on comparable triples in a poset.
2. **What it does not support**:
   Does not support claims for non-linear restrictions; does not establish non-triviality of global cohomology without evaluating on generating sections.
3. **Narrowest defensible claim**:
   Under additive stalk operations and linear restriction maps, $(d_1 d_0 s)(a,b,c)$ equals $(r_{b,a} \circ r_{c,b} - r_{c,a})s(c)$ on every comparable triple.

## 1. Claim Statement

At historical commit `30609de2c` (`30609de2c3928238715375a9bac608256fa381d8`), the thymic negative-selection screen (`eis/domain/thymus.py` lines 77–99) compiles each rule's `match_pattern` as a regular expression and tests it against the self panel, whereas three of the four `AntigenMatcher` implementations behind the port in `eis/infrastructure/mssn_ports.py` (`PharmacyMatcher`, `FarmMatcher`, and `ProtocolMatcher`, lines 80–166 at `30609de2c`) never execute `match_pattern` as a regular expression against payload content; for pharmacy rules constructed in `run_packaged_immune.py` (lines 118–122 at `30609de2c`), the screened regular expression is the escaped failure-class name.

This node supplies only the residual historical audit closing the gap left by `SYS-EIS-001` (which records the current matcher-bound `ThymusGate.evaluate_rule` implementation).

## 3. Derivation / Evidence

### 3.1 Adapter Census in `eis/infrastructure/mssn_ports.py`
AST and source inspection of the four `AntigenMatcher` classes in `eis/infrastructure/mssn_ports.py` (`tests/test_w4_w1_shard_a.py::TestHistoricalScreenExecutionMismatch::test_mssn_ports_ast_confirms_one_regex_matcher_and_three_non_regex_matchers`) establishes the 1-versus-3 split:
1. `PatternMatcher` (`matcher_id = "regex"`, lines 97–110; historical lines 17–24): sets `reports_content_offsets = True` and searches `content` directly via `compile_safe_pattern(rule.match_pattern).finditer(content)`.
2. `PharmacyMatcher` (`matcher_id = "pharmacy"`, lines 245–290; within historical lines 80–166): sets `reports_content_offsets = False`, runs `self.native.detect(content, self.context)` plus `persona_authority_leak_loci(...)`, and uses rules solely via `_select` to filter emitted `finding.failure_class` codes.
3. `FarmMatcher` (`matcher_id = "farm-classifier"`, lines 292–310; within historical lines 80–166): sets `reports_content_offsets = False`, runs `classify_response(self.probe, content, "fixture")`, and filters `finding.detector_id` codes via `_select`.
4. `ProtocolMatcher` (`matcher_id = "demo3-protocol"`, lines 358–377; within historical lines 80–166): sets `reports_content_offsets = False`, parses JSON moves, runs `protocol_findings(moves, self.state, self.fixture)`, and filters protocol codes via `_select`.

Thus three of the four matchers behind the port never execute `rule.match_pattern` as a regular expression over `content`.

### 3.2 Escaped Failure-Class Name Screening and Lemma C Unsoundness Witness
At commit `30609de2c`, `run_packaged_immune.py` (lines 118–122) built pharmacy rules with `match_pattern = re.escape(failure_class_name)` (`paper.md`, lines 802–804; `eis/tests/unit/test_thymus_binds_executed_matcher.py`, lines 113–114), and `ThymusGate.evaluate_rule` (`eis/domain/thymus.py`, lines 77–99 at `30609de2c`) screened rules by regex-searching `_self_panel` for `match_pattern`.

Let $P(x)$ denote the regex check `re.search(re.escape("MISSING_WITNESS"), x, re.IGNORECASE) is not None` and $E(x)$ denote the structural check `'"witness"' not in x` over the four-string universe (`code/tests/test_two_signals_one_detector.py`, lines 216–226):
$$U = \bigl\{\texttt{\{"claim": "x", "witness": "w"\}},\; \texttt{\{"claim": "y", "evidence": []\}},\; \texttt{\{"claim": "z"\}},\; \texttt{"MISSING\_WITNESS reported"}\bigr\}$$
with self panel $S = \{U_0, U_1\}$.
- Neither $U_0$ nor $U_1$ contains the substring `"MISSING_WITNESS"`, so `admitted(screened, panel)` returns `True` ($P \cap S = \emptyset$).
- Self fixture $U_1$ lacks `"witness"`, so `fires_on_self(executed, panel)` returns `True` ($E \cap S = \{U_1\} \ne \emptyset$).
- Consequently $E(U_1) \land \neg P(U_1)$, so $E \not\Rightarrow P$ and `sound_for_every_panel(executed, screened, 4)` returns `False` (`PAPER003-PREDICATE-SCREEN-SOUNDNESS`; verified for both `MISSING_WITNESS` and `UNGROUNDED_SELF_CERTIFICATION` in `tests/test_w4_w1_shard_a.py::TestHistoricalScreenExecutionMismatch::test_pharmacy_class_name_regex_admits_rule_that_fires_on_self_fixture`).

### 3.3 Boundary Contrast with Repaired `SYS-EIS-001`
When the screen evaluates $E$ directly ($P = E$), `admitted(executed, panel)` returns `False` and `sound_for_every_panel(executed, executed, 4)` returns `True` (`tests/test_w4_w1_shard_a.py::TestHistoricalScreenExecutionMismatch::test_falsification_screening_executed_predicate_purges_self_reactive_rule`). In current `eis/domain/thymus.py` (`SYS-EIS-001`), `ThymusGate.evaluate_rule` refuses unbound non-regex rules with `THYMUS_MATCHER_UNBOUND`, refuses mismatched matchers with `MATCHER_BINDING_MISMATCH`, and purges self-reactive structural rules when the bound matcher is supplied (`tests/test_w4_w1_shard_a.py::TestHistoricalScreenExecutionMismatch::test_falsification_repaired_thymus_refuses_unbound_and_purges_bound_matcher`).

## 4. Limits and Non-Claims

1. **Historical Checkout Availability**: Commit `30609de2c` is not stored in the git object database of `proposal_fidelity_protocol_pfp`; the historical `thymus.py` and `run_packaged_immune.py` line behaviors are established from the commit-pinned Appendix A audit in `paper.md`, `paper_claim_ledger.md`, `test_two_signals_one_detector.py`, and `test_thymus_binds_executed_matcher.py`, paired with AST inspection of the four matchers in `eis/infrastructure/mssn_ports.py`.
2. **Legacy `evaluate_candidate` Method**: As already noted in `SYS-EIS-001`, `ThymusGate.evaluate_candidate` (`eis/domain/thymus.py` lines 112–129) still screens `CandidateDetector.pattern` via `re.compile` while returning `is_admitted=False`; operational rule admission flows through `evaluate_rule`.
3. **Panel-Relative Ceiling**: Matching screened and executed predicates ($E = P$) establishes nonfiring only on the supplied finite self panel $S$, not absence of false suppression on unseen valid inputs.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that three of four `AntigenMatcher` classes in `mssn_ports.py` (`PharmacyMatcher`, `FarmMatcher`, `ProtocolMatcher`) never execute `rule.match_pattern` as a content regex, and that screening an escaped failure-class name as a regex admits rules whose structural matcher fires on clean self fixtures lacking that class-name string.
2. **What it does not support**: Does not claim that current `ThymusGate.evaluate_rule` permits unbound non-regex rules to pass, nor that $E = P$ establishes zero false positives outside the finite panel.
3. **Narrowest defensible claim**: Under the historical `30609de2c` design recorded in Paper 003 Appendix A.5, regex screening on escaped failure-class names diverges from structural matcher execution across three of four port matchers ($E \not\Rightarrow P$), admitting rules that fire on self-panel fixtures.
4. **Next test needed**: Static architectural check verifying that every class implementing `AntigenMatcher` is exercised through `ThymusGate.evaluate_rule(rule, matcher)` in CI integration tests.

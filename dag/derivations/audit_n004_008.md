## 1. Claim Statement

On an elementary poset diamond $a < b < c$ with one-dimensional scalar stalk spaces $F(x) = \mathbb{R}$ (or $\mathbb{Q}$), where linear restriction maps are given by scalars $r_{c, b} = \alpha$, $r_{b, a} = \beta$, and $r_{c, a} = \mu$, the composition curvature operator on any scalar element $v$ evaluates to:
$$K_{c, b, a}(v) = (\beta \alpha - \mu) v.$$
The curvature operator vanishes identically if and only if $\beta \alpha = \mu$.

## 2. Context & Hypotheses

- **Elementary Poset Diamond**: A three-element comparable chain $a < b < c$ representing an elementary composition path.
- **One-Dimensional Scalar Stalks**: $F(a) = F(b) = F(c) = \mathbb{F}$, where $\mathbb{F}$ is a commutative field or ring (such as $\mathbb{Q}$ or $\mathbb{R}$).
- **Scalar Representation of Maps**: Any linear endomorphism or map between 1D vector spaces is given by multiplication by a scalar:
  $$r_{c, b}(x) = \alpha \cdot x, \quad r_{b, a}(y) = \beta \cdot y, \quad r_{c, a}(z) = \mu \cdot z$$
  for fixed parameters $\alpha, \beta, \mu \in \mathbb{F}$.
- **Composition Curvature Operator**: By Definition 3.1:
  $$K_{c, b, a}(v) = (r_{b, a} \circ r_{c, b} - r_{c, a})(v).$$

## 3. Derivation / Evidence

### 3.1 Direct Algebraic Evaluation

Let $v \in \mathbb{F}$ be an arbitrary scalar stalk element.

1. Evaluate the composite restriction $r_{b, a} \circ r_{c, b}$ on $v$:
   $$(r_{b, a} \circ r_{c, b})(v) = r_{b, a}(r_{c, b}(v)) = r_{b, a}(\alpha v) = \beta (\alpha v).$$

2. By associativity of multiplication in the commutative field $\mathbb{F}$:
   $$\beta (\alpha v) = (\beta \alpha) v.$$

3. Evaluate the direct restriction $r_{c, a}$ on $v$:
   $$r_{c, a}(v) = \mu v.$$

4. Form the difference in the additive group $\mathbb{F}$:
   $$K_{c, b, a}(v) = (\beta \alpha) v - \mu v.$$

5. Factor out $v$ by distributivity in $\mathbb{F}$:
   $$K_{c, b, a}(v) = (\beta \alpha - \mu) v.$$

6. Vanishing condition:
   - If $\beta \alpha = \mu$, then $(\beta \alpha - \mu) = 0$, so $K_{c, b, a}(v) = 0 \cdot v = 0$ for all $v \in \mathbb{F}$.
   - Conversely, if $K_{c, b, a}(v) = 0$ for all $v \in \mathbb{F}$, choosing $v = 1$ yields $(\beta \alpha - \mu) = 0$, hence $\beta \alpha = \mu$.

Thus $K_{c, b, a}(v) = (\beta \alpha - \mu) v$ holds for all $v$, and $K_{c, b, a} = 0$ if and only if $\beta \alpha = \mu$.

## 4. Limits and Non-Claims

- **One-Dimensional Stalks**: The factorization $(\beta \alpha - \mu) v$ relies on scalar commutativity and associativity. For stalks of dimension $d \ge 2$, restrictions are $d \times d$ matrices where $r_{b, a} r_{c, b}$ does not commute with $r_{c, b} r_{b, a}$.
- **Elementary Chain**: Evaluates the local curvature operator along a single chain triple; does not assert global contractibility of the carrying poset.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports that on 1D scalar stalks, composition curvature evaluates to scalar multiplication by $(\beta \alpha - \mu)$, vanishing if and only if $\beta \alpha = \mu$.
2. **What it does not support**:
   Does not support commutativity for higher-dimensional matrix restrictions; does not establish global topological triviality.
3. **Narrowest defensible claim**:
   For 1D scalar stalks with restriction parameters $\alpha, \beta, \mu$, $K_{c, b, a}(v) = (\beta \alpha - \mu) v$.

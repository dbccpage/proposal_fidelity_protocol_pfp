## 1. Claim Statement

On $\mathbb{Z}^3$ with positive integer weights $\mathbf{w} \in \mathbb{N}_{>0}^3$, the functional $\|x\|_{1, \mathbf{w}} = \sum_{e=0}^2 w_e |x_e|$ is positive definite, and residual representatives add subadditively:
$$\|(c_1 + c_2) - d_0(p_1 + p_2)\|_{1, \mathbf{w}} \le \|c_1 - d_0 p_1\|_{1, \mathbf{w}} + \|c_2 - d_0 p_2\|_{1, \mathbf{w}}.$$
Zero weight ($w_e = 0$) is refused because it violates positive definiteness.

## 2. Context & Hypotheses

- **Ambient Cochain Space**: $\mathbb{Z}^3$ with elements $x = (x_0, x_1, x_2)$.
- **Positive Weights**: Weights $\mathbf{w} = (w_0, w_1, w_2)$ with $w_e \in \mathbb{N}_{\ge 1}$.
- **Cochain Addition & Residual**:
  For 1-cochains $c_1, c_2 \in \mathbb{Z}^3$ and vertex potentials $p_1, p_2 \in \mathbb{Z}^3$, the coboundary satisfies $d_0(p_1 + p_2) = d_0 p_1 + d_0 p_2$.
  The residual representative of $c$ at $p$ is $r(c, p) = c - d_0 p$.
- **Explicit Scope Limitation**: As documented in the claim obligations, this result concerns ambient cochains and supplied residual representatives; it does not define the minimized quotient norm $\inf_p \|c - d_0 p\|_{1, \mathbf{w}}$.

## 3. Derivation / Evidence

### 3.1 Non-Negativity and Positive Definiteness
1. For any $x \in \mathbb{Z}^3$ and $w_e \ge 1$:
   $$\|x\|_{1, \mathbf{w}} = w_0 |x_0| + w_1 |x_1| + w_2 |x_2|.$$
2. Because $w_e \ge 1$ and $|x_e| \ge 0$, every term $w_e |x_e| \ge 0$, so $\|x\|_{1, \mathbf{w}} \ge 0$.
3. If $x = 0$, then $|x_e| = 0$ for each $e$, giving $\|x\|_{1, \mathbf{w}} = 0$.
4. Conversely, suppose $\|x\|_{1, \mathbf{w}} = 0$.
5. A sum of non-negative integer terms vanishes if and only if each term vanishes:
   $$w_0 |x_0| = 0, \quad w_1 |x_1| = 0, \quad w_2 |x_2| = 0.$$
6. Since each weight $w_e \ge 1 > 0$, dividing by $w_e$ yields $|x_e| = 0$, so $x_e = 0$ for each $e \in \{0, 1, 2\}$.
7. Hence $x = 0$, establishing positive definiteness on $\mathbb{Z}^3$.

### 3.2 Triangle Inequality on Ambient Cochains
1. Let $x, y \in \mathbb{Z}^3$. For each coordinate $e \in \{0, 1, 2\}$, the triangle inequality on $\mathbb{Z}$ gives:
   $$|x_e + y_e| \le |x_e| + |y_e|.$$
2. Multiplying by non-negative weight $w_e \ge 0$:
   $$w_e |x_e + y_e| \le w_e |x_e| + w_e |y_e|.$$
3. Summing over all three coordinates:
   $$\sum_{e=0}^2 w_e |x_e + y_e| \le \sum_{e=0}^2 w_e |x_e| + \sum_{e=0}^2 w_e |y_e|.$$
4. Thus $\|x + y\|_{1, \mathbf{w}} \le \|x\|_{1, \mathbf{w}} + \|y\|_{1, \mathbf{w}}$.

### 3.3 Residual Representative Subadditivity
1. Let $c_1, c_2 \in \mathbb{Z}^3$ be 1-cochains and $p_1, p_2 \in \mathbb{Z}^3$ be potentials.
2. The residual representative of $c_1 + c_2$ evaluated at the sum potential $p_1 + p_2$ satisfies:
   $$r(c_1 + c_2, p_1 + p_2) = (c_1 + c_2) - d_0(p_1 + p_2) = (c_1 - d_0 p_1) + (c_2 - d_0 p_2) = r(c_1, p_1) + r(c_2, p_2).$$
3. Applying the ambient triangle inequality to the vectors $r(c_1, p_1)$ and $r(c_2, p_2)$:
   $$\|r(c_1 + c_2, p_1 + p_2)\|_{1, \mathbf{w}} \le \|r(c_1, p_1)\|_{1, \mathbf{w}} + \|r(c_2, p_2)\|_{1, \mathbf{w}}.$$
4. This verifies subadditivity for residual representatives.

### 3.4 Zero-Weight Refusal
1. Suppose a weight can vanish, for example $w_0 = 0$, while $w_1 = 1, w_2 = 1$.
2. Choose the non-zero cochain $x = (10, 0, 0) \in \mathbb{Z}^3$.
3. The weighted norm evaluates to:
   $$\|x\|_{1, \mathbf{w}} = 0 \cdot |10| + 1 \cdot |0| + 1 \cdot |0| = 0.$$
4. This yields $\|x\|_{1, \mathbf{w}} = 0$ for $x \ne 0$, demonstrating that positive definiteness fails when a zero weight is permitted.
5. Consequently, zero weight is refused.

## 4. Limits and Non-Claims

- **Ambient Space Result**: The axioms derived here apply to the ambient space $\mathbb{Z}^3$ and specific candidate residual representatives.
- **Does Not Define Quotient Norm**: This result does not define the quotient norm $\Phi_1([c]) = \inf_p \|c - d_0 p\|_{1, \mathbf{w}}$, which requires minimization over the entire gauge orbit (established separately in AUDIT-N001-001 and AUDIT-N001-003).

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that on $\mathbb{Z}^3$ with positive weights, $\|x\|_{1, \mathbf{w}}$ is positive definite, residual representatives add subadditively, and permitting a zero weight violates positive definiteness.
2. **What it does not support**:
   Does not support claims of quotient norm minimization; does not claim that representative subadditivity alone establishes attainment.
3. **Narrowest defensible claim**:
   On $\mathbb{Z}^3$ with $w \in \mathbb{N}_{\ge 1}^3$, $\|x\|_{1, \mathbf{w}}$ is a norm on $\mathbb{Z}^3$, and residuals satisfy $\|r(c_1+c_2, p_1+p_2)\|_{1, \mathbf{w}} \le \|r(c_1, p_1)\|_{1, \mathbf{w}} + \|r(c_2, p_2)\|_{1, \mathbf{w}}$.

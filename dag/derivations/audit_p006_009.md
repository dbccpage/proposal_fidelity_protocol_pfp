## 1. Claim Statement

In `pfp/domain/immune/clonal_selection.py`, candidate detector rules with uncompilable regular expression patterns yield a typed `KillConditionRefusal` without raising uncaught exceptions or purging parent lineages, whereas detectors that match any entry in the benign self-panel trigger a central tolerance kill condition that emits a sealed `KillConditionReceipt` with status `PURGED_SELF_REACTIVE`.

## 3. Derivation / Evidence

### 3.1 Invalid Regex Handling
Inspection of `ClonalSelectionEngine.check_kill_condition`:
```python
try:
    pattern = re.compile(clone.match_pattern, re.IGNORECASE)
except re.error as err:
    return False, KillConditionRefusal(
        clone_id=clone.rule_id,
        parent_id=parent.rule_id,
        match_pattern=clone.match_pattern,
        reason=f"Invalid regular expression syntax: {err}",
    )
```
1. **Compilation Interception**:
   When `clone.match_pattern` cannot compile (for example, containing unbalanced brackets `[` or invalid qualifiers `*+`), `re.compile` raises `re.error`.
2. **Typed Refusal Emission**:
   The engine catches `re.error` and returns `(False, KillConditionRefusal(...))`.
3. **Parent Lineage Spared**:
   The boolean return value is `False`, indicating that the parent-child kill condition was not triggered. Because an uncompilable pattern cannot cross-react with benign self samples, the parent lineage is not destroyed, while the invalid clone is refused admission.

### 3.2 Benign Self-Panel Screening and Kill Condition
When `clone.match_pattern` compiles validly, the engine checks the pattern against every sample in `self_panel`:
```python
for entry in self_panel:
    content = getattr(entry, "content", str(entry))
    sample_id = getattr(entry, "entry_id", "SELF_FIXTURE")
    sample_digest = getattr(entry, "content_sha256", hashlib.sha256(content.encode("utf-8")).hexdigest())

    if pattern.search(content):
        receipt = KillConditionReceipt.create(
            clone_id=clone.rule_id,
            parent_id=parent.rule_id,
            violating_sample_id=sample_id,
            violating_sample_digest=sample_digest,
        )
        return True, receipt
```
1. **Cross-Reactivity Detection**:
   If `pattern.search(content)` finds a match on any benign self-panel entry, central tolerance is violated.
2. **Purge Receipt Generation**:
   The engine returns `(True, receipt)`, where `receipt` is an instance of `KillConditionReceipt` with `status="PURGED_SELF_REACTIVE"`.
3. **Lineage Binding**:
   The receipt binds `clone_id`, `parent_id`, `violating_sample_id`, and `violating_sample_digest` into a canonical SHA-256 digest, recording joint elimination of both mutated clone and parent lineage.

### 3.3 Clean Detector Admission
When the candidate pattern compiles and matches zero samples in `self_panel`, `check_kill_condition` returns `(False, None)`, allowing the candidate to advance in the repertoire.

## 4. Limits and Non-Claims

1. **Finite Self-Panel Constraint**: Central tolerance screening validates against the finite set of samples present in `self_panel`; it does not evaluate unrepresented benign patterns outside the panel corpus.
2. **ReDoS Consideration**: Regular expression compilation checks syntax; execution runtime depends on pattern structure against adversarial inputs.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that `ClonalSelectionEngine.check_kill_condition` emits a typed `KillConditionRefusal` for invalid regexes and a sealed `KillConditionReceipt` for self-panel cross-reactions.
2. **What it does not support**: Does not assert that passing the self-panel eliminates false alarms on arbitrary out-of-distribution texts.
3. **Narrowest defensible claim**: In `pfp/domain/immune/clonal_selection.py`, `check_kill_condition` returns `(False, KillConditionRefusal)` on pattern syntax failure and `(True, KillConditionReceipt)` on self-panel match.
4. **Next test needed**: Stress testing regex execution performance across varied self-panel sizes and mutation depths.

# AUDIT-P005-009: Native Fixture Skip

## 1. Claim Statement

In the test suite of Paper 005 (`code/tests/`), the test runner fixture `native_functional` (`code/tests/conftest.py`) checks for external binary configuration. When environment variables `CORE_FUNCTIONAL_GRAPH_BIN` or `CORE_FUNCTIONAL_GRAPH_SHA256` are absent, tests that declare a dependency on `native_functional` skip execution and emit the documented `SKIP_REASON` string. Tests that do not declare `native_functional` in their signature execute to completion without skipping.

## 2. Context & Hypotheses

- **Target Fixture**:
  - `native_functional` defined in `code/tests/conftest.py`.
- **Declared Skip Reason**:
  - `"native graph calculator not configured: set CORE_FUNCTIONAL_GRAPH_BIN to a solve_graph_phi1 executable built from the reviewed source and CORE_FUNCTIONAL_GRAPH_SHA256 to its SHA-256 digest (see README)"`.
- **Pytest Dependency Injection**:
  - Fixture execution is bound strictly to test functions that declare `native_functional` as an argument.
  - The suite does not use autouse or blanket session skips.

## 3. Derivation / Evidence

### 3.1 Fixture Skip Logic
In `code/tests/conftest.py`:
```python
SKIP_REASON = (
    "native graph calculator not configured: set CORE_FUNCTIONAL_GRAPH_BIN to a "
    "solve_graph_phi1 executable built from the reviewed source and "
    "CORE_FUNCTIONAL_GRAPH_SHA256 to its SHA-256 digest (see README)"
)

@pytest.fixture
def native_functional() -> Path:
    binary = os.environ.get("CORE_FUNCTIONAL_GRAPH_BIN")
    expected = os.environ.get("CORE_FUNCTIONAL_GRAPH_SHA256")
    if not binary or not expected:
        pytest.skip(SKIP_REASON)
    ...
```
When either `CORE_FUNCTIONAL_GRAPH_BIN` or `CORE_FUNCTIONAL_GRAPH_SHA256` is unset or empty, the fixture invokes `pytest.skip` with `SKIP_REASON`.

### 3.2 Selective Scoping to Dependent Tests
Because `native_functional` is a standard pytest fixture without `autouse=True`:
1. Tests requiring the native executable (for example, `test_worked_session_matches_manual` in `test_play_demo.py` and `test_projection_replays_native_and_is_idempotent` in `test_quickstart_native.py`) request `native_functional`. In unconfigured environments, these tests skip with the stated message.
2. Independent unit tests (such as `test_worked_session_offline_enumeration`, `test_quickstart_requires_native_pin`, and `test_offline_worksheet.py`) do not request `native_functional`. They run their assertions and pass without skipping.

### 3.3 Fail-Closed Checks on Malformed Configuration
If pins are partially or incorrectly provided, the fixture fails instead of skipping:
1. If `expected` does not match 64 hex digits, `pytest.fail("CORE_FUNCTIONAL_GRAPH_SHA256 must contain exactly 64 hex digits")` is invoked.
2. If `binary` cannot be resolved on disk, `pytest.fail("could not be read")` is invoked.
3. If the actual file digest does not match `expected.lower()`, `pytest.fail("digest mismatch")` is invoked.

## 4. Limits and Non-Claims

1. **Test Environment Boundary**: This derivation describes the test harness configuration isolation; skipping a test does not record a verification receipt for the skipped claim.
2. **Binary Attestation Boundary**: The fixture verifies that the provided binary matches the supplied SHA-256 pin; it does not attest compiler toolchain integrity or reproducible compilation.
3. **No Automatic Resolution**: The fixture does not search PATH or build directories for unpinned executables.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that absent native configuration triggers a typed skip with `SKIP_REASON` only on tests requesting `native_functional`, while non-dependent tests run to completion.
2. **What it does not support**: Does not support that skipped tests are equivalent to passed tests, or that an unconfigured test run covers native behavior.
3. **Narrowest defensible claim**: In `code/tests/conftest.py`, `native_functional` invokes `pytest.skip(SKIP_REASON)` when configuration variables are unset, leaving tests that do not request the fixture unaffected.
4. **Next test needed**: Automated end-to-end test execution under CI with both unset and validly configured fixture environments.

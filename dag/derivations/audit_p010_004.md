## 1. Claim Statement

In `atlas/archive/pfp/010_pfp_holonomy_checks_and_model_pilots/code/holonomy.py`, `Lattice.__post_init__` (lines 213–222) enforces exact runtime type identity `type(rows) is int`, `type(cols) is int`, and `type(periodic) is bool` (refusing `bool` values passed as `rows`/`cols`, `float`, `Fraction`, `str`, `None`, and non-`bool` periodicity flags with `LatticeError`) and enforces minimum dimensions `rows >= 2` and `cols >= 2` when `periodic is False` versus `rows >= 3` and `cols >= 3` when `periodic is True`. The periodic lower bound of `3` is algebraically required by the package's endpoint-pair edge representation: at periodic length $2$, the interior step $(0 \to 1)$ and wraparound step $(1 \to 0)$ along a row or column collide with reversed-edge inversion $U_{vu} = U_{uv}^{-1}$, whereas for $L, M \ge 3$ the $2LM$ positive edges $E_+$ and $2LM$ reversed edges $E_+^{\mathrm{op}}$ form $4LM$ pairwise distinct ordered vertex pairs.

## 3. Derivation / Evidence

### 3.1 Exact Type Identity Guards (`Lattice.__post_init__` and `connection_from_case`)
`Lattice.__post_init__` (`code/holonomy.py:213-217`) executes two exact `type(...)` checks before arithmetic comparison:
1. **Dimension Type Guard (`lines 214-215`)**:
   ```python
   if type(self.rows) is not int or type(self.cols) is not int:
       raise LatticeError("rows and cols must be int")
   ```
   Because Python defines `issubclass(bool, int) == True` (`isinstance(True, int) == True` and `True == 1`), an `isinstance` check would admit `True` or `False` as dimensions if paired with a permissive bound or arithmetic coercion. Using `type(x) is not int` deterministically raises `LatticeError` on `True`, `False`, `float` (`3.0`), `Fraction(3, 1)`, `str` (`"3"`), `None`, tuples/lists, and `int` subclasses in either `rows` or `cols`.
2. **Periodicity Type Guard (`lines 216-217`)**:
   ```python
   if type(self.periodic) is not bool:
       raise LatticeError("periodic must be bool")
   ```
   Refuses truthy/falsy non-booleans (`0`, `1`, `"open"`, `"periodic"`, `None`) with `LatticeError`. When loading a JSON case dictionary, `connection_from_case` (`lines 467-470`) additionally checks `if boundary not in ("open", "periodic"): raise LatticeError(f"unknown boundary {boundary!r}")` before evaluating `boundary == "periodic"`.

### 3.2 Sharp Integer Lower Bounds and Cell-Complex Counts
`Lattice.__post_init__` (`lines 220-222`) sets:
$$\text{minimum} = \begin{cases} 3 & \text{if } \text{periodic} = \mathrm{True}, \\ 2 & \text{if } \text{periodic} = \mathrm{False}, \end{cases}$$
and raises `LatticeError(f"need at least {minimum} rows and columns")` iff `rows < minimum or cols < minimum`:
- **Open rectangular complex (`periodic = False`, admitted iff $L \ge 2 \land M \ge 2$)**:
  - Vertices: $|V| = LM \ge 4$.
  - Positive edges (`positive_edges`, `lines 227-234`): $|E_+| = L(M - 1) + (L - 1)M \ge 4$.
  - Elementary 2-cells (`plaquette_origins`, `lines 236-239`): $|P| = (L - 1)(M - 1) \ge 1$, satisfying $|V| - |E_+| + |P| = LM - (2LM - L - M) + (LM - L - M + 1) = 1$. At $L = 1$ or $M = 1$, $(L - 1)(M - 1) = 0$ would yield zero plaquettes, so $L, M \ge 2$ is the minimal open 2-cell grid.
  - Calling `loop_a()` or `loop_b()` on an open lattice raises `LatticeError("an open lattice has no non-contractible cycle")` (`lines 248-249, 254-255`).
- **Periodic torus complex (`periodic = True`, admitted iff $L \ge 3 \land M \ge 3$)**:
  - Vertices: $|V| = LM \ge 9$.
  - Positive edges: $|E_+| = 2LM \ge 18$.
  - Elementary 2-cells: $|P| = LM \ge 9$, satisfying $|V| - |E_+| + |P| = LM - 2LM + LM = 0 = \chi(\mathbb{T}^2)$.
  - Fundamental cycle paths `loop_a()` and `loop_b()` have vertex-list lengths $M + 1 \ge 4$ and $L + 1 \ge 4$.

Exhaustive enumeration over $(L, M) \in \{-1, 0, 1, 2, 3, 4\}^2$ ($36$ pairs per `periodic` flag) confirms:
- For `periodic = False`: all $27$ pairs with $\min(L, M) < 2$ raise `LatticeError("need at least 2 rows and columns")`, and all $9$ pairs with $L, M \in \{2, 3, 4\}$ succeed.
- For `periodic = True`: all $32$ pairs with $\min(L, M) < 3$ (including $(2, 2)$, $(2, 3)$, $(3, 2)$, $(2, 4)$, $(4, 2)$) raise `LatticeError("need at least 3 rows and columns")`, and all $4$ pairs with $L, M \in \{3, 4\}$ succeed.

### 3.3 Algebraic Necessity of $L, M \ge 3$ Under Endpoint-Pair Edge Naming
In `holonomy.py`, an `Edge` is typed as `tuple[Vertex, Vertex]` (`line 27`), `Connection` stores links keyed solely by `(u, v) in lattice.positive_edges()` (`lines 262-271`), and `Connection.link(u, v)` (`lines 284-289`) resolves edge traversal by:
$$U(u, v) = \begin{cases} \text{links}[(u, v)] & \text{if } (u, v) \in E_+, \\ \text{links}[(v, u)]^{-1} & \text{if } (v, u) \in E_+. \end{cases}$$
For this definition (and `connection_from_directed_links`'s bidirectional rule `parsed[(v, u)] == group.inv(parsed[(u, v)])`) to represent independent group assignments on every positive 1-cell of the torus, $E_+$ must contain no duplicate pairs and satisfy $E_+ \cap E_+^{\mathrm{op}} = \varnothing$:
- **Degeneracy at periodic length $2$**: Suppose $M = 2$ on a periodic row $r$. The two horizontal positive 1-cells emitted at $c = 0$ and $c = 1$ have endpoint pairs:
  $$e_0 = \bigl((r, 0),\, (r, (0 + 1) \bmod 2)\bigr) = \bigl((r, 0),\, (r, 1)\bigr), \qquad e_1 = \bigl((r, 1),\, (r, (1 + 1) \bmod 2)\bigr) = \bigl((r, 1),\, (r, 0)\bigr) = e_0^{\mathrm{op}}.$$
  Thus $e_1 \in E_+ \cap E_+^{\mathrm{op}}$: the wraparound positive edge $e_1$ has the identical ordered endpoint pair as the reversed traversal of $e_0$, forcing $U_{e_1} = U_{e_0}^{-1}$ instead of allowing two independent link variables $(U_{e_0}, U_{e_1}) \in G \times G$ (so the row holonomy $U_{e_0} U_{e_1}$ could only ever equal $e$!). Symmetrically, $L = 2$ identifies vertical step $((0, c), (1, c))$ with reversed wraparound $((1, c), (0, c))$, and $L = 1$ or $M = 1$ produces self-loops $((r, c), (r, c))$.
- **Disjointness for $L, M \ge 3$**: When $L \ge 3$ and $M \ge 3$, for every $(r, c) \in V$:
  $$(c + 1) \bmod M \ne c \quad (\text{since } 1 \not\equiv 0 \pmod M), \qquad (c + 1) \bmod M \ne (c - 1) \bmod M \quad (\text{since } 2 \not\equiv 0 \pmod M),$$
  and identically $(r + 1) \bmod L \notin \{r, (r - 1) \bmod L\}$ since $L \ge 3$. Horizontal edges change only column coordinates while vertical edges change only row coordinates, so no horizontal edge can equal a vertical edge or its reversal. Therefore all $2LM$ pairs in $E_+$ are pairwise distinct, irreflexive, and disjoint from $E_+^{\mathrm{op}}$, yielding $|E_+ \sqcup E_+^{\mathrm{op}}| = 4LM$ distinct directed edges.

## 4. Limits and Non-Claims

1. **Representation Choice, Not Topological Absence of $2 \times 2$ Torus CW Complexes**: A $2 \times 2$ torus CW complex exists mathematically if multi-edges carry explicit cell labels (e.g., `(u, axis, sign)`); the bound $L, M \ge 3$ is specifically the sharp threshold required when 1-cells are named by ordered endpoint pairs `(u, v)` (`paper.md:101-103`, `holonomy.py:218-220`).
2. **No Resource Upper Bound**: `Lattice.__post_init__` imposes no upper bound on `rows` or `cols`; constructing very large integer lattices remains bounded only by host memory and runtime.

## 5. Claim Hygiene Summary

1. **What it supports**: Establishes via source inspection, cell-complex congruences modulo $L$ and $M$, and finite grid/type execution that `Lattice` refuses non-`int` dimensions (including `bool`), non-`bool` periodicity flags, open dimensions $< 2$, and periodic dimensions $< 3$ with `LatticeError`, while admitting all integer dimensions at or above those minima with $4LM$ collision-free oriented torus edges for $L, M \ge 3$.
2. **What it does not support**: Does not enforce upper resource limits on `rows` or `cols` or support multi-edge cell complexes at periodic size $2$.
3. **Narrowest defensible claim**: `Lattice(rows, cols, periodic)` admits exact `int` sizes and `bool` periodicity iff $(!\text{periodic} \land \text{rows} \ge 2 \land \text{cols} \ge 2)$ or $(\text{periodic} \land \text{rows} \ge 3 \land \text{cols} \ge 3)$, raising `LatticeError` on every tested violation, and $L, M \ge 3$ is necessary and sufficient to prevent forward/reverse endpoint-pair collisions on a periodic grid.
4. **Next test needed**: If a caller passes untrusted JSON dimensions into `connection_from_case`, pair `Lattice` shape admission with an application-level upper cap on `L * M` before allocating vertex and edge lists.

### 3.2 Tracked Secondary Attestations of the Five Initial-Draft Filter Predicates
`paper.md` (Section 1, lines 74–86), `paper.tex` (lines 223–237), `paper_claim_ledger.md` (`PFP10-00`, line 23), and `paper_change_log.md` (lines 98–100, 121–125, 170–179, 208–217, 244–246) record the rescope from version `1.0.0` (commit `35e3d7ba2e0e20904d17a79cc395980f50a1a0f1`) to version `2.0.0` and classify the five removed prompt-filter stages as fixed elementary functions with zero measured effect on model answers:
1. **"MHC peptide decomposition"** (`paper.md:80-81`, `paper_change_log.md:171-173`): partitioned an edge list into radius-1 vertex neighbourhoods.
2. **"Thymic selection"** (`paper.md:81-82`, `paper_change_log.md:171-173`): tested membership in a caller-supplied list.
3. **"Kinetic proofreading"** (`paper.md:82`, `paper_change_log.md:170-171`): compared two caller-supplied fractions against two fixed thresholds.
4. **"Treg scratchpad"** (`paper.md:83`, `paper_change_log.md:173-174`): checked whether four labelled lines appeared in prescribed order.
5. **"allosteric quorum"** (`paper.md:84-85`, `paper_change_log.md:174-177`): counted how many of five listed Unicode symbols occurred in the prompt string and compared that integer count against `3`, without evaluating any Hill-type activation function.

In addition, `paper_change_log.md` (lines 121–125, 244–246) records that `decimate_and_evaluate_holonomy` in the removed test file never multiplied group elements, misclassified gauge-trivial connections containing non-identity links as `NOT_FLAT`, mislabelled the all-identity connection as `FLAT_NONTRIVIAL`, and never computed torus cycle products.

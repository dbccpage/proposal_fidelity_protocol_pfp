## 2. Hypotheses

1. Variables \(V = \{x, y, z\}\) each take values in the two-element Boolean domain \(D = \{0, 1\}\).
2. Scopes are \(S_1 = (x, y)\), \(S_2 = (y, z)\), and \(S_3 = (z, x)\).
3. The incompatible relation tuple is \((R_1, R_2, R_3) = (\mathrm{EQ}, \mathrm{EQ}, \mathrm{NE})\) where \(\mathrm{EQ} = \{(0,0),(1,1)\}\) and \(\mathrm{NE} = \{(0,1),(1,0)\}\); the compatible control replaces \(R_3\) with \(\mathrm{EQ}\), giving \((\mathrm{EQ}, \mathrm{EQ}, \mathrm{EQ})\).

## 3. Step-by-Step Derivation

### Step 1 — Nonemptiness of each local task

Each local relation has cardinality \(2\):

\[
|R_1| = |\mathrm{EQ}| = 2, \qquad |R_2| = |\mathrm{EQ}| = 2, \qquad |R_3| = |\mathrm{NE}| = 2.
\]

Therefore every local existence query succeeds independently (e.g., \(a_1 = (0,0) \in R_1\), \(a_2 = (0,0) \in R_2\), \(a_3 = (0,1) \in R_3\)).

### Step 2 — Joint unsatisfiability of \((x = y, y = z, z \ne x)\)

Suppose \((x, y, z) \in \{0, 1\}^3\) satisfies all three constraints. Transitivity of equality on \(D\) gives \(x = y\) and \(y = z \implies x = z\), contradicting \(z \ne x\). In the submitted local witness family \(a_1 = (0,0), a_2 = (0,0), a_3 = (0,1)\), the overlap \(S_1 \cap S_3 = \{x\}\) exposes \(a_1|_x = 0 \ne 1 = a_3|_x\). Exhaustive check over all \(2^3 = 8\) triples \((x, y, z) \in \{0,1\}^3\):

| \((x,y,z)\) | \((x,y)\in\mathrm{EQ}\) | \((y,z)\in\mathrm{EQ}\) | \((z,x)\in\mathrm{NE}\) | \((z,x)\in\mathrm{EQ}\) |
| --- | :---: | :---: | :---: | :---: |
| \((0,0,0)\) | True | True | False | **True** |
| \((0,0,1)\) | True | False | True | False |
| \((0,1,0)\) | False | False | False | True |
| \((0,1,1)\) | False | True | True | False |
| \((1,0,0)\) | False | True | True | False |
| \((1,0,1)\) | False | False | False | True |
| \((1,1,0)\) | True | False | True | False |
| \((1,1,1)\) | True | True | False | **True** |

Zero rows satisfy \((\mathrm{EQ}, \mathrm{EQ}, \mathrm{NE})\).

### Step 3 — Exact solution set of \((x = y, y = z, z = x)\)

Replacing \(R_3\) with \(\mathrm{EQ}\) imposes \(x = y = z\). Over \(D = \{0, 1\}\), a triple \((x, y, z)\) has all three coordinates equal iff \((x, y, z) \in \{(0,0,0), (1,1,1)\}\), matching the two bold rows in the 8-row truth table above and yielding unique compatible restriction families \(((0,0),(0,0),(0,0))\) and \(((1,1),(1,1),(1,1))\) via `AUDIT-P015-001`.

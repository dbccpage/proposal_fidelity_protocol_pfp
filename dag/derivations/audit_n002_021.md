## 1. Claim Statement

Let $G = (V, E)$ be a finite connected graph with $n = |V| \ge 2$ vertices, scalar stalks $F(x) = \mathbb{R}$, and graph Laplacian $L_0 = d_0^* d_0$. Assume the Fiedler spectral gap premise:
$$L_0 \succeq \alpha (I - P),$$
for a parameter $\alpha \in (0, \lambda_2(L_0)]$, where $P = n^{-1} \mathbf{1}\mathbf{1}^T$ is the orthogonal projector onto constant vectors.

For any nonnegative vertex defect loads $v_i \ge 0$, define shifted diagonal values $d_i := \alpha + v_i$. For $t < d_{\min} := \min_{1 \le i \le n} d_i$, define the secular function:
$$F(t) := \frac{\alpha}{n} \sum_{i=1}^n \frac{1}{d_i - t}.$$

Then:
1. $F(t)$ is continuous and strictly increasing on $[0, d_{\min})$, with $F(0) \le 1$, and possesses a unique root $\tau \in [0, d_{\min})$ satisfying $F(\tau) = 1$.
2. The smallest eigenvalue of the rank-one comparison operator equals $\tau$:
   $$\lambda_{\min}\Big(\alpha(I - P) + \operatorname{diag}(v)\Big) = \tau,$$
   attained by the positive eigenvector $x_i = (d_i - \tau)^{-1}$.
3. By the Loewner ordering $L_0 \succeq \alpha(I - P)$, the ground-state eigenvalue of the obstruction operator $H_{\mathrm{obstr}} = L_0 + \operatorname{diag}(v)$ satisfies:
   $$\lambda_0 = \lambda_{\min}(L_0 + \operatorname{diag}(v)) \ge \tau.$$
4. If $v \equiv 0$, $\tau = 0$. If $v_i \equiv c$ for all $i$, $\tau = c = \lambda_0$. For general positive loads, $0 < \tau \le \mu = \frac{1}{n} \sum_i v_i$.

## 2. Context & Hypotheses

- **Connected Carrier**: $G$ is a finite connected graph with $n \ge 2$ vertices, ensuring $\dim \ker L_0 = 1$ and $\lambda_2(L_0) > 0$.
- **Graph Laplacian**: $L_0 = d_0^* d_0$ is real-symmetric and positive semidefinite. Its kernel is spanned by the constant unit vector $\psi_c = n^{-1/2} \mathbf{1}$.
- **Spectral Gap Comparison Operator**: By the spectral theorem, $L_0 = \sum_{k=2}^n \lambda_k \psi_k \psi_k^T \succeq \lambda_2 (I - P) \succeq \alpha (I - P)$ for any $\alpha \in (0, \lambda_2(L_0)]$.
- **Defect Potential**: $V_{\mathrm{defect}} = \operatorname{diag}(v)$ with $v_i \ge 0$.
- **Shifted Diagonal**: $d_i = \alpha + v_i \ge \alpha > 0$, with minimum pole $d_{\min} = \alpha + \min_i v_i$.

## 3. Derivation / Evidence

### 3.1 Monotonicity and Root Existence of the Secular Function
1. On the interval $t \in [0, d_{\min})$, each denominator $d_i - t > 0$ is strictly positive.
2. Differentiating $F(t)$ term by term:
   $$F'(t) = \frac{\alpha}{n} \sum_{i=1}^n \frac{1}{(d_i - t)^2} > 0.$$
   Therefore, $F(t)$ is continuous and strictly increasing on $[0, d_{\min})$.
3. Evaluating $F$ at $t = 0$:
   $$F(0) = \frac{\alpha}{n} \sum_{i=1}^n \frac{1}{\alpha + v_i} \le \frac{\alpha}{n} \sum_{i=1}^n \frac{1}{\alpha} = \frac{\alpha}{n} \cdot \frac{n}{\alpha} = 1.$$
   Equality $F(0) = 1$ holds if and only if $v_i = 0$ for all $i$ (the zero-load branch). For any configuration with positive load ($\sum_i v_i > 0$), the strict inequality $F(0) < 1$ holds.
4. As $t$ approaches $d_{\min}$ from below ($t \to d_{\min}^-$), at least one denominator $(d_k - t) \to 0^+$, so:
   $$\lim_{t \to d_{\min}^-} F(t) = +\infty.$$
5. By the intermediate value theorem, there exists a unique root $\tau \in [0, d_{\min})$ satisfying $F(\tau) = 1$. When $v \equiv 0$, $\tau = 0$. When $\sum_i v_i > 0$, $\tau \in (0, d_{\min})$.

### 3.2 Weighted Cauchy-Schwarz Lower Bound on the Comparison Operator
1. Let $x \in \mathbb{R}^n$ be any non-zero vector. For any $t < d_{\min}$, evaluate the quadratic form of the shifted comparison operator:
   $$\langle x, (\alpha(I - P) + \operatorname{diag}(v) - t I) x \rangle = \alpha \|x\|_2^2 - \frac{\alpha}{n} \left(\sum_{i=1}^n x_i\right)^2 + \sum_{i=1}^n (v_i - t) x_i^2.$$
2. Group the diagonal terms using $\alpha + v_i - t = d_i - t$:
   $$\alpha \|x\|_2^2 + \sum_{i=1}^n (v_i - t) x_i^2 = \sum_{i=1}^n (\alpha + v_i - t) x_i^2 = \sum_{i=1}^n (d_i - t) x_i^2.$$
3. Therefore:
   $$\langle x, (\alpha(I - P) + \operatorname{diag}(v) - t I) x \rangle = \sum_{i=1}^n (d_i - t) x_i^2 - \frac{\alpha}{n} \left(\sum_{i=1}^n x_i\right)^2.$$
4. By the Cauchy-Schwarz inequality applied to the inner product of vectors $u_i = \sqrt{d_i - t} x_i$ and $w_i = \frac{1}{\sqrt{d_i - t}}$:
   $$\left(\sum_{i=1}^n x_i\right)^2 = \left( \sum_{i=1}^n \sqrt{d_i - t} x_i \cdot \frac{1}{\sqrt{d_i - t}} \right)^2 \le \left( \sum_{i=1}^n (d_i - t) x_i^2 \right) \left( \sum_{i=1}^n \frac{1}{d_i - t} \right).$$
5. Multiplying both sides by $\frac{\alpha}{n}$:
   $$\frac{\alpha}{n} \left(\sum_{i=1}^n x_i\right)^2 \le \left(\frac{\alpha}{n} \sum_{i=1}^n \frac{1}{d_i - t}\right) \left( \sum_{i=1}^n (d_i - t) x_i^2 \right) = F(t) \sum_{i=1}^n (d_i - t) x_i^2.$$
6. Substituting this bound into the quadratic form:
   $$\langle x, (\alpha(I - P) + \operatorname{diag}(v) - t I) x \rangle \ge (1 - F(t)) \sum_{i=1}^n (d_i - t) x_i^2.$$
7. For $t \le \tau$, strictly increasing monotonicity gives $F(t) \le F(\tau) = 1$, which ensures $1 - F(t) \ge 0$. Since $d_i - t > 0$, the sum $\sum_i (d_i - t) x_i^2 > 0$ for all $x \ne 0$.
8. Consequently:
   $$\langle x, (\alpha(I - P) + \operatorname{diag}(v)) x \rangle \ge t \|x\|_2^2 \quad \forall t \le \tau.$$
   Setting $t = \tau$:
   $$\lambda_{\min}\Big(\alpha(I - P) + \operatorname{diag}(v)\Big) \ge \tau.$$

### 3.3 Exact Attainment by Eigenvector $x_i = (d_i - \tau)^{-1}$
1. Equality in the Cauchy-Schwarz inequality holds if and only if $u_i$ is proportional to $w_i$:
   $$\sqrt{d_i - \tau} x_i = c \cdot \frac{1}{\sqrt{d_i - \tau}} \iff x_i = \frac{c}{d_i - \tau},$$
   for some non-zero scalar $c$.
2. Choosing $c = 1$, define the test vector $x \in \mathbb{R}^n$ with coordinates $x_i = (d_i - \tau)^{-1}$.
3. Evaluate the $i$-th coordinate of the comparison operator acting on $x$:
   $$\Big( (\alpha(I - P) + \operatorname{diag}(v)) x \Big)_i = (\alpha + v_i) x_i - \frac{\alpha}{n} \sum_{j=1}^n x_j = d_i x_i - \frac{\alpha}{n} \sum_{j=1}^n \frac{1}{d_j - \tau}.$$
4. Since $\tau$ is the root of the secular equation, $\frac{\alpha}{n} \sum_{j=1}^n \frac{1}{d_j - \tau} = F(\tau) = 1$:
   $$\Big( (\alpha(I - P) + \operatorname{diag}(v)) x \Big)_i = d_i x_i - 1 = d_i \cdot \frac{1}{d_i - \tau} - 1 = \frac{d_i - (d_i - \tau)}{d_i - \tau} = \frac{\tau}{d_i - \tau} = \tau x_i.$$
5. Thus $x$ is an exact eigenvector of the comparison operator with eigenvalue $\tau$.
6. This establishes:
   $$\lambda_{\min}\Big(\alpha(I - P) + \operatorname{diag}(v)\Big) = \tau.$$

### 3.4 Loewner Ordering Transfer to the Graph Laplacian
1. By hypothesis, the graph Laplacian satisfies the Loewner inequality:
   $$L_0 \succeq \alpha (I - P).$$
2. Adding the positive semidefinite diagonal matrix $\operatorname{diag}(v)$ preserves the Loewner partial order:
   $$H_{\mathrm{obstr}} = L_0 + \operatorname{diag}(v) \succeq \alpha(I - P) + \operatorname{diag}(v).$$
3. By the Courant-Fischer variational min-max theorem for real-symmetric matrices:
   $$\lambda_0 = \min_{\|y\|_2 = 1} \langle y, (L_0 + \operatorname{diag}(v)) y \rangle \ge \min_{\|y\|_2 = 1} \langle y, (\alpha(I - P) + \operatorname{diag}(v)) y \rangle = \tau.$$
4. Therefore, $\lambda_0 \ge \tau$.

### 3.5 Limiting Cases
- **Flat Potential $v_i \equiv c$**: $d_i = \alpha + c$ for all $i$.
  The secular equation becomes $\frac{\alpha}{\alpha + c - t} = 1 \implies \tau = c$.
  The true ground state is $\lambda_{\min}(L_0 + c I) = c = \tau$, attaining exact equality.
- **Zero Potential $v \equiv 0$**: $d_i = \alpha$ for all $i$.
  $F(0) = 1 \implies \tau = 0 = \lambda_{\min}(L_0)$.

## 4. Limits and Non-Claims

- **Connectivity Premise**: Requires a connected graph carrier ($n \ge 2$) so that $\ker L_0$ is one-dimensional and $\lambda_2(L_0) > 0$. On disconnected carriers, $\alpha = 0$, $F(t) \equiv 0$, and the secular root is undefined.
- **Nonnegative Loads**: Requires $v_i \ge 0$. Negative loads invalidate $F(0) \le 1$ and can place eigenvalues below the pole $d_{\min}$.
- **Lower Bound, Not Identification**: The secular root $\tau$ is a rigorous lower bound for $\lambda_0$, but does not equal $\lambda_0$ on non-flat potentials; nor does it provide a dictionary between $\ell^2$ spectral defect $\lambda_0$ and $\ell^1$ quotient norm $\Phi_1([\omega])$.

## 5. Claim Hygiene Summary

1. **What it supports**:
   Supports the conclusion that the unique root $\tau \in [0, d_{\min})$ of $F(t) = 1$ equals the ground-state eigenvalue of the rank-one comparison operator and lower-bounds $\lambda_{\min}(L_0 + \operatorname{diag}(v))$ under the graph gap premise.
2. **What it does not support**:
   Does not support exact equality $\lambda_0 = \tau$ for non-flat potentials; does not support identification of $\ell^2$ spectral defects with $\ell^1$ combinatorial norms.
3. **Narrowest defensible claim**:
   Under $L_0 \succeq \alpha(I - P)$ with $\alpha > 0$ and $v_i \ge 0$, the secular root $\tau \in [0, d_{\min})$ satisfies $\lambda_{\min}(\alpha(I - P) + \operatorname{diag}(v)) = \tau \le \lambda_{\min}(L_0 + \operatorname{diag}(v))$.
4. **Next test needed**:
   Higher-order multi-rank comparison operators for non-regular graph topologies.

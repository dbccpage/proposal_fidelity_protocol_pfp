# AUDIT-P003-011: Phrase Match Ignores Negation

AuthorityEffect: None.

- Archive claim: [ATL-P003-011](../../atlas/atlas_claim_ledger.md#part-i-claims-of-the-archived-papers) ("A phrase match cannot see negation.", [paper_claim_ledger.md:26](../../atlas/archive/pfp/003_pfp_host_admitted_failure_detectors/paper_claim_ledger.md?plain=1#L26))

## 1. Claim Statement

For a lexical phrase detector $P$ scanning text $s$ for pattern $p$, if $p$ is a substring of $s$, then for any prefix or surrounding clause containing negation tokens ("not", "no", "never", "cannot", "refute"), the modified sentence $s'$ preserves the contiguous substring $p$, and the match output is unchanged.

## 2. Context & Hypotheses

- **Substring Detection Implementation**:
  - Implemented in `atlas/archive/pfp/003_pfp_host_admitted_failure_detectors/code/canaries.py` (`scan_for_canaries`).
  - Evaluates case-folded string containment via `if pattern in lower:`.
  - Four candidate failure detectors:
    1. `AM-FSP-8-UNRESTRICTED-SOLVER-CLAIM`
    2. `AM-FSP-2-FRUSTRATED-OBSTRUCTION`
    3. `AM-FSP-7-UNVERIFIED-MAJORANA-LIFT`
    4. `AM-FSP-4-ORBIT-SUM-MISMATCH`
- **Lexical Embedding**:
  - Sentences generated by embedding target phrase $p$ into affirmative assertions versus syntactic denials and refutations.

## 3. Derivation / Evidence

### 3.1 Monotonicity of Substring Containment Under String Embedding
Let $\Sigma$ denote the character alphabet. A string $p \in \Sigma^*$ is a contiguous substring of $s \in \Sigma^*$ if and only if there exist strings $u, v \in \Sigma^*$ such that $s = u \cdot p \cdot v$.
For any ambient sentence extension $s \hookrightarrow s'$ where $s' = u' \cdot s \cdot v' = (u' \cdot u) \cdot p \cdot (v \cdot v')$, the contiguous substring $p$ remains an element of $s'$.
Because `scan_for_canaries` normalizes text via `lower = text.lower()` and evaluates containment `pattern in lower`, prefixing or inserting lexical negation outside the boundary of $p$ does not remove $p$ from `lower`.

### 3.2 Empirical Verification on Negated Sentence Sets
Evaluating `scan_for_canaries` across five distinct syntactic negation constructions containing patterns from `AM-FSP-2` and `AM-FSP-8`:
1. `"There is no particle-hole symmetry on triangle plaquettes."`
   - Contains substring `"particle-hole symmetry on triangle"`.
   - Result: Fires `AM-FSP-2-FRUSTRATED-OBSTRUCTION`.
2. `"It is false that particle-hole symmetry holds on any lattice."`
   - Contains substring `"particle-hole symmetry holds on any lattice"`.
   - Result: Fires `AM-FSP-2-FRUSTRATED-OBSTRUCTION`.
3. `"We refute the assertion that particle-hole symmetry holds on any lattice including the triangle."`
   - Contains substring `"particle-hole symmetry holds on any lattice"`.
   - Result: Fires `AM-FSP-2-FRUSTRATED-OBSTRUCTION`.
4. `"Frustrated geometry prevents particle-hole symmetry on triangle plaquettes."`
   - Contains substring `"particle-hole symmetry on triangle"`.
   - Result: Fires `AM-FSP-2-FRUSTRATED-OBSTRUCTION`.
5. `"The system cannot possess particle-hole symmetry on triangle lattices."`
   - Contains substring `"particle-hole symmetry on triangle"`.
   - Result: Fires `AM-FSP-2-FRUSTRATED-OBSTRUCTION`.
6. `"The method does not provide an unrestricted polynomial-time sign-free solution for all fermion systems."`
   - Contains substring `"unrestricted polynomial-time"`.
   - Result: Fires `AM-FSP-8-UNRESTRICTED-SOLVER-CLAIM`.

In all tested instances, the detector finding is identical between the affirmative assertion and the explicit denial.

### 3.3 Contrast with Internal Disruption Controls
When lexical tokens are inserted inside $p$ rather than outside (e.g. `"particle-hole broken symmetry holds on any lattice"` or `"unrestricted super-polynomial-time"`), the contiguous sequence is severed and `pattern in lower` evaluates to `False`. This confirms that the detector evaluates contiguous string presence without syntactic awareness.

## 4. Limits and Non-Claims

1. **Substrings Lack Syntactic Awareness**: The detector evaluates only contiguous character containment; it does not parse grammatical dependency, modality, quotation, or negation.
2. **Unadmitted Research Prototype**: Candidate failure detectors in `canaries.py` are exploratory and unadmitted as production filters.
3. **Bounded Scope**: This finding does not characterize transformer attention, learned token classification, or semantic parsing models.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that contiguous substring matching in `canaries.py` fires on sentences that assert the negation of a flagged claim whenever the target phrase appears intact.
2. **What it does not support**: Does not characterize false positive or false negative rates in open-domain language models.
3. **Narrowest defensible claim**: On strings containing an unmodified canary pattern prefixed or surrounded by negation tokens, `scan_for_canaries` returns findings identical to affirmative assertions.
4. **Next test needed**: Evaluating phrase matching against complex grammatical parses, double negations, and counterfactual conditional clauses.

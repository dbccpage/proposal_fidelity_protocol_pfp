## 3. Derivation / Evidence

### 3.1 Stationary Quotient Score Accompanied by Changed Claims
Let $G$ be the directed cycle $a \to b \to c \to a$ with positive edge weights $w = (w_{ab}, w_{bc}, w_{ca}) = (1, 2, 3)$. For any vertex potential $f = (f_a, f_b, f_c) \in \mathbb{Q}^3$, the coboundary $df = (f_b - f_a, f_c - f_b, f_a - f_c)$ sums to zero, so for any 1-cochain $c = (c_{ab}, c_{bc}, c_{ca})$ the residual $r = c - df$ satisfies $r_{ab} + r_{bc} + r_{ca} = c_{ab} + c_{bc} + c_{ca}$. Since $w_e \ge 1$ on every edge:
$$D_c(f) = |r_{ab}| + 2|r_{bc}| + 3|r_{ca}| \ge |r_{ab}| + |r_{bc}| + |r_{ca}| \ge |c_{ab} + c_{bc} + c_{ca}|.$$
- **Initial claims** $c = (1, 1, 1)$ have cycle sum $1 + 1 + 1 = 3$, attained at $f = (0, -2, -1)$ where $df = (-2, 1, 1)$ and $r = (3, 0, 0)$, giving $\Phi_w(c) = 3$.
- **Replacement claims** $c' = (2, 1, 0)$ have the same cycle sum $2 + 1 + 0 = 3$, so $\Phi_w(c') \ge 3$. Choosing $f' = (0, -1, 0)$ gives $df' = (-1, 1, 0)$ and residual $r' = (3, 0, 0)$ concentrated on the weight-1 edge $a \to b$, attaining $D_{c'}(f') = 1 \cdot 3 + 2 \cdot 0 + 3 \cdot 0 = 3$. Hence $\Phi_w(c') = 3 = \Phi_w(c)$ even though $c' \ne c$.

In `l1_symbol_game_governor.py:722-747`, `step_cut(proposed_claims=c')` checks `phi_after > phi_before` (`3 > 3` is `False`), projects the section, assigns `self.edge_claims = dict(proposed_claims)`, and classifies equality as `status = "IdempotentStationary"`. `test_manual_contracts.py::test_stationary_score_can_accompany_changed_claims` (`lines 143-150`) confirms `verdict.admitted is True`, `verdict.status == "IdempotentStationary"`, `verdict.defect_before == verdict.defect_after == Fraction(3)`, and `governor.edge_claims == {("a", "b"): Fraction(2), ("b", "c"): Fraction(1), ("c", "a"): Fraction(0)}`.

## 4. Limits and Non-Claims

1. **Enumeration Path Scope**: In the unconfigured environment, `run_capstone` executes on the `python-enumeration` route (`result["calculation_path"] == "python-enumeration"`); its output is not a compiled Rust execution receipt or a live model run.
2. **Stationary Non-Termination**: Admitting `IdempotentStationary` moves means non-increase alone does not prevent infinite stationary cycles without an external step or attempt budget (`paper.md:159-161`).
3. **Instance Change vs. Factual Accuracy**: Admitting `(0, 1, 1)`, `(-2, 1, 1)`, or `(2, 1, 0)` replaces the declared edge claims and says nothing about external domain validity, as already bounded by `PUB-C06`.

1. **What it supports**: Confirms that equal quotient scores ($\Phi_w = 3$) can accompany mutated edge claims (`(1, 1, 1) -> (2, 1, 0)`) under `IdempotentStationary`, and verifies every refusal, descent (`3 -> 2 -> 0`), verification, and snapshot restoration (`-> 3`) step of `study_capstone.py`.
2. **What it does not support**: Does not establish general search termination under stationary moves, native binary execution without configured pins, or empirical LLM repair performance.

## 1. Claim Statement

In Companion 007 (`007_pfp_executable_lessons_and_evidence_boundaries`), the retained legacy module `code/tests/test_007_pedagogical_transmission.py` evaluates hardcoded supplied `Fraction` fixtures against chosen rational thresholds (`MicroAttentionPulse.is_within_half_life`, `LearningCheckMetrics.meets_certification_standards`) and tallies `"ok"` strings in supplied `"execution_status"` dictionary entries among cells whose `"source"` string contains `"assert"` (`evaluate_headless_notebook_grade`). It executes zero notebooks and records zero empirical measurements of learner attention or comprehension.

### 3.2 Threshold Comparisons on Supplied Rational Fixtures
1. **Duration Window Check (`MicroAttentionPulse.is_within_half_life`, lines 17–27, 63–79)**:
   Evaluates `Fraction(3, 1) <= self.duration_minutes <= max_half_life` with default `max_half_life = Fraction(5, 1)`. The test `test_micro_attention_pulse_half_life` supplies `duration_minutes = Fraction(4, 1)` (returning `True`) and `duration_minutes = Fraction(7, 1)` (returning `False`).
2. **Certification Threshold Check (`LearningCheckMetrics.meets_certification_standards`, lines 29–42, 81–95)**:
   Evaluates the conjunction of three fixed rational inequalities on caller-supplied attributes:
   $$\text{diagnostic\_pass\_rate} \ge \frac{9}{10} \;\land\; \text{transfer\_index} \ge \frac{17}{20} \;\land\; \text{teaching\_efficiency} \ge \frac{4}{5}.$$
   In `test_learning_metrics_threshold`, the passing fixture supplies `(92/100, 88/100, 85/100)`:
   $$\frac{92}{100} \ge \frac{90}{100},\quad \frac{88}{100} \ge \frac{85}{100},\quad \frac{85}{100} \ge \frac{80}{100} \implies \text{True}.$$
   The failing fixture supplies `(85/100, 88/100, 85/100)`, where $\frac{85}{100} < \frac{90}{100}$ yields `False`.

### 3.3 Supplied Status-Field Counting (`evaluate_headless_notebook_grade`, lines 44–58, 97–106)
Given `cells: list[dict[str, Any]]`, `evaluate_headless_notebook_grade` computes:
$$N_{\text{eval}} = \bigl|\{c \in \text{cells} : c[\text{"cell\_type"}] = \text{"code"} \;\land\; \text{"assert"} \text{ in } c.\text{get}(\text{"source"}, \text{""})\}\bigr|,$$
$$N_{\text{pass}} = \bigl|\{c \in \text{cells} : c[\text{"cell\_type"}] = \text{"code"} \;\land\; \text{"assert"} \text{ in } c.\text{get}(\text{"source"}, \text{""}) \;\land\; c.\text{get}(\text{"execution\_status"}) = \text{"ok"}\}\bigr|,$$
returning `Fraction(0, 1)` if `cells` is empty or $N_{\text{eval}} = 0$, and `Fraction(N_pass, N_eval)` otherwise.
In `test_headless_notebook_automated_grading`, four hardcoded dictionaries are passed: one `"markdown"` cell (ignored), two `"code"` cells containing `"assert"` with `"execution_status": "ok"`, and one `"code"` cell (`"z = 30\nassert z == 40"`) with `"execution_status": "error"`, producing `Fraction(2, 3)`.

### 3.4 Falsification Controls Confirming Non-Execution
As corroborated by `test_007_evidence_boundaries.py::test_legacy_status_grade_counts_non_assertions_without_execution` (lines 25–32) and verified in isolated tests:
- Comments (`"# assert example"`) and string literals (`'print("assert")'`) labeled `"execution_status": "ok"` increment both $N_{\text{eval}}$ and $N_{\text{pass}}$, yielding `Fraction(2, 3)` when paired with an `"error"` cell.
- Supplying `{"cell_type": "code", "source": "1 / 0\nassert False", "execution_status": "ok"}` returns `Fraction(1, 1)` without raising `ZeroDivisionError` or `AssertionError`, confirming that cell source strings are inspected as text substrings and never executed.

1. **What it supports**: Confirms via AST inspection, exact rational evaluation, and falsification controls that `test_007_pedagogical_transmission.py` checks chosen rational thresholds on hardcoded supplied `Fraction` fixtures and counts supplied `"ok"` status strings among code-cell dictionaries containing the substring `"assert"`.
2. **What it does not support**: Does not support claims of measured attention half-life, empirical 90% learner pass rates, transfer-effect estimates, or live headless notebook execution.
3. **Narrowest defensible claim**: `test_007_pedagogical_transmission.py` is a self-contained standard-library module whose two threshold methods compare supplied `Fraction` values against constants (`3..5`, `9/10`, `17/20`, `4/5`) and whose grading helper counts supplied `"ok"` status strings without executing code.

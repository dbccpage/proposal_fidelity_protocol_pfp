## 4. Limits and Non-Claims

1. **Custodial Retention**: Confirms that the deposit retains the audited source tarball, member digests, revision metadata, and execution report on disk; it does not re-compile or re-run the native Cargo targets on the current test host.
2. **Historical Scope**: The retained report records test passes at commit `52cb5457` on 2026-09-28; it does not claim future compiler or operating system compatibility.
3. **Stand-Alone Accessibility**: Verification demonstrates that the files are present in the deposit package without requiring active repository permissions or internet access.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that the publication deposit contains the audited source tarball (SHA-256 `a7be14eb339d476debaf06264f4334c83018127840853404018ad6972361e557`), member manifest (7,875 files), `REVISION.json` metadata binding commit `52cb5457`, and the retained native execution log recording 12, 11, 32, and 9 passing tests.
2. **What it does not support**: Does not support claims that arbitrary third-party environments will build the historical Rust crate without the pinned toolchain.
3. **Narrowest defensible claim**: The deposit provides self-contained custody of the audited source archive, member digests, revision metadata, and historical native test records.
4. **Next test needed**: Verification of tarball extraction in an isolated container with offline hash verification of extracted files against `SOURCE_MEMBERS.sha256`.

## 3. Step-by-Step Derivation

### Step 1 — Observed usage extraction and settlement on rejected replies (`harness_provider.py:63-83, 151-208`)

Consider an admitted Anthropic call where either:
- **(Case A: Transport refusal with JSON usage body)** `self.transport.dispatch(admitted)` raises `ProviderError` carrying `exc.reply_bytes` (lines 65–66). `RecordedTransport.dispatch` stores raw bytes in content-addressed storage under `occurrence + "/transport-failure"` (lines 67–74) and invokes `observe_anthropic_usage(json.loads(raw), model=admitted.model)` (line 79). When the JSON body contains a valid Anthropic message `id` and non-negative integer `usage.{input_tokens, output_tokens}`, `dispatch` returns `raw` so `HarnessProvider.call` decodes `usage` (line 163), computes exact micro-USD `quote` (lines 167–169), settles the reservation via `budget.settle_once` (lines 170–176), forces `failed_transport = True`, sets `status = "TYPED_REFUSAL"` and `content = ""` (lines 177–189), and records `occurrence + "/settled"` with exact `usage`, `cost`, and `raw` digest (lines 190–207).
- **(Case B: Completed wire reply rejected by stop reason or gateway validation)** When `decoded.get("stop_reason") == "refusal"` or `gateway.complete_result(request)` returns `Err(...)` after `occurrence + "/wire"` was recorded (lines 151–189), `HarnessProvider.call` likewise extracts `observe_anthropic_usage(decoded, model=model)`, settles observed `quote.cost_microusd` once, and returns `ModelCall(content="", status="TYPED_REFUSAL", cost=quote.cost_microusd, ...)`.

In both cases, rejected model content never enters candidate evaluation (`content == ""`), yet actual billed token usage is retained and settled against the campaign ceiling.

### Step 2 — Liability retention and dispatch halt when usage is missing or unparseable (`lines 78-81, 136-138, 159-163`)

Conversely, if `self.transport.dispatch(admitted)` raises `ProviderError` with empty, truncated, or usage-free `reply_bytes` (e.g., network timeout or HTTP 502 HTML body):
1. `observe_anthropic_usage(json.loads(raw), model=admitted.model)` raises `ValueError`/`ProviderError` (lines 79–81), re-raising `exc` before `budget.settle_once` can run.
2. The pre-dispatch maximum-liability hold (`admitted.receipt.cost_microusd`) remains unsettled (`state != "Settled"`) in `budget.sqlite`, and `occurrence + "/admitted"` remains without `occurrence + "/settled"`.
3. Any subsequent call on the same occurrence raises `ASSIGNED_OCCURRENCE_REQUIRES_RECONCILIATION` (lines 131–132), and any subsequent call on a *different* occurrence hits `if budget.pending_attempts(): raise ProviderError("UNRECONCILED_COST")` (lines 136–137), halting further dispatch until explicit operator reconciliation.

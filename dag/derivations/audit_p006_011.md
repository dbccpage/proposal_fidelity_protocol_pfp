## 1. Claim Statement

The regulatory supervisor (`TregSupervisor`) triggers an authority downgrade proposal to `DIAGNOSTIC_ONLY` when the Autoimmune Toxicity Index is greater than or equal to the rational threshold $\tau = 1/5$ ($\text{Toxicity} \ge 1/5$). On an unlabelled benign prompt corpus lacking verified Signal 2 annotations, the toxicity index evaluates to binary values ($0$ or $1$) by construction.

## 2. Context & Hypotheses

- **Source Implementation**:
  - Located at `pfp/domain/immune/treg.py` (re-exporting canonical domain logic from `eis/domain/treg.py`).
- **Target Lineage**:
  - Paper 006 Section 8 (lines 410–418) and `paper_claim_ledger.md` row P6-11.
- **Toxicity Index Definition**:
  - For explicit trigger records $(s_1, s_2) \in \{\text{True}, \text{False}\}^2$:
    $$\text{Toxicity} = \frac{\sum \mathbf{1}(s_1 \land \neg s_2)}{\text{total\_triggers}}$$
  - A trigger with $s_1 \land \neg s_2$ represents pattern-only activation (Signal 1 alone without second-signal confirmation).
- **Threshold Inclusivity**:
  - The threshold $\tau = \text{Fraction}(1, 5)$ is inclusive: a detector exhibiting $\text{Toxicity} = 1/5$ triggers synthesis of a `RegulatoryAntibody` proposing downgrade to `DIAGNOSTIC_ONLY`.
  - A detector with $\text{Toxicity} = 1/6 < 1/5$ does not trigger a downgrade.

## 3. Derivation / Evidence

### 3.1 Inclusive Threshold Arithmetic at $\tau = 1/5$
In `eis/domain/treg.py:257-264`:
```python
def synthesize_treg(self, report: AutoimmuneToxicityReport) -> RegulatoryAntibody | None:
    if report.toxicity_index >= self.tau:
        return RegulatoryAntibody.create(
            target_rule_id=report.rule_id,
            toxicity_index=report.toxicity_index,
            tau_threshold=self.tau,
        )
    return None
```
Evaluating with five triggers containing one pattern-only case:
$$\text{triggers} = [(\text{True}, \text{False})] + [(\text{True}, \text{True})] \times 4$$
$$\text{Toxicity} = \frac{1}{5}$$
Since $\frac{1}{5} \ge \tau = \frac{1}{5}$, `report.toxicity_index >= self.tau` is True, and a `RegulatoryAntibody` with `downgraded_authority = "DIAGNOSTIC_ONLY"` is synthesized.

Evaluating with six triggers containing one pattern-only case:
$$\text{triggers} = [(\text{True}, \text{False})] + [(\text{True}, \text{True})] \times 5$$
$$\text{Toxicity} = \frac{1}{6}$$
Since $\frac{1}{6} < \frac{1}{5}$, `report.toxicity_index >= self.tau` is False, and `synthesize_treg` returns `None`.

### 3.2 Binary Toxicity on Unlabelled Prompt Corpus
In `eis/domain/treg.py:230-246`:
When evaluated against an unlabelled prompt corpus, prompts possess no second signal by definition ($s_2 = \text{False}$ throughout).
Consequently:
- If the pattern matches zero prompts in the corpus:
  $$\text{signal1\_only} = 0, \quad \text{total\_triggers} = 0 \implies \text{Toxicity} = \text{Fraction}(0, 1)$$
  No antibody is synthesized.
- If the pattern matches at least once ($k \ge 1$ times):
  $$\text{signal1\_only} = k, \quad \text{total\_triggers} = k \implies \text{Toxicity} = \frac{k}{k} = \text{Fraction}(1, 1)$$
  Since $1 \ge 1/5$, an antibody proposing downgrade is synthesized.

Thus, prompt corpus toxicity evaluates exclusively to $0$ or $1$.

### 3.3 Zero-Float Law Enforcement
`TregSupervisor`, `AutoimmuneToxicityReport`, and `RegulatoryAntibody` enforce the project ZERO-FLOAT constraint via `_assert_zero_float`, rejecting standard Python `float` values with a `TypeError`.

## 4. Limits and Non-Claims

1. **Policy Synthesis vs Application**: Synthesis of a `RegulatoryAntibody` generates an immutable recommendation; it does not unilaterally rewrite production rules or override administrative policy without review.
2. **Binary Granularity on Unlabelled Data**: The binary $0/1$ outcome on unlabelled prompt corpora reflects the absence of Signal 2 ground truth in unlabelled text; it does not measure graded defect frequency without labelled pair records.
3. **Declared Parameter Value**: The choice of $\tau = 1/5$ is a declared operational threshold; it does not represent an absolute constant across different task domains.

## 5. Claim Hygiene Summary

1. **What it supports**: Confirms that `TregSupervisor` applies an inclusive threshold comparison ($\text{Toxicity} \ge \tau$ with default $\tau = 1/5$), synthesizing a `DIAGNOSTIC_ONLY` antibody at $1/5$ while withholding it at $1/6$, and yields binary toxicity ($0$ or $1$) on unlabelled corpora.
2. **What it does not support**: Does not support claims that threshold downgrades eliminate all detector false positives in production deployment.
3. **Narrowest defensible claim**: Epistemic immune supervisor downgrades fire at rational toxicity greater than or equal to $1/5$, and evaluate to $0$ or $1$ when applied to unlabelled prompt corpora.
4. **Next test needed**: Multi-rule simulation under varying trigger distributions to observe fleet-wide downgrade dynamics under noisy conditions.

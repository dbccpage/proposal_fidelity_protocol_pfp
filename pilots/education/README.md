# Education demos and pilot evidence

This collection was relocated from `education/` after reviewing all 1,539
education paths. Eighty-four files moved; 1,455 ordinary curriculum/reference
files remain in education. Relocation does not establish the correctness of
historical claims or the effectiveness of a workflow.

| Collection | Purpose |
| --- | --- |
| `symbol_game/` | Local rational triangle game, notebooks, tests and diagrams |
| `operad_simulation/` | Finite educational composition and mirror simulation |
| `eis_simulation/` | Token-overlap and synthetic-mutation teaching model |
| `pciv_simulation/` | Synthetic prompt-civilization metrics and teaching model |
| `track_a/` | Demonstration scenes, captured replies and produced videos |
| `finite_qm_workflow/` | Previously existing public workflow prompt and evidence |
| `runbooks/` | Concrete pilot execution and replay guides |
| `challenge_findings/` | Historical empirical reports, including their corrections and withdrawals |

The finite-QM material here predates the separate sealed benchmark in `dag/`.
It is not that benchmark's private answer. No model run was performed during
relocation.

The original paths, SHA-256 values, classifications, move receipt, recovery
archive verification and explicit navigation adaptations are recorded in
[`dag/migrations`](../../dag/migrations/demo_support_summary.md). Historical
result JSON and captured outputs remain unchanged. Notebook source/navigation
adaptations preserve stored outputs and execution counts. The old ten-route
notebook generator and some optional native/render paths have pre-existing
limitations documented in the classification; do not treat relocation as a
successful rerun of those tools.

The focused post-move suites passed: EIS/PCIV simulations 22 tests, local game
19 tests, and operad simulation 10 tests. See the
[validation report](../../dag/migrations/education_demo_classification_postmove_validation.md).

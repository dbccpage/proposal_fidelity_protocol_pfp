# Quiz 11: Simplicial Hodge Laplacian & Helmholtz Decomposition

A complete, self-contained educational package and verification suite for discrete exterior calculus, boundary operators, and flow decomposition on simplicial complexes.

---

## What Is in This Folder?

1. **[`quiz.md`](../../../../ow/pfp/2_quizzes_and_puzzles/quiz_11_hodge_solver/quiz.md): The Human-Readable Quiz**
   - Starts with the simplest possible geometric intuition: a triangle with vertices $A, B, C$.
   - Explains what 0-, 1-, and 2-simplices are.
   - Asks the 4 essential questions about boundary nilpotency ($\partial^2 = 0$), coboundary $d = \partial^T$, Hodge Laplacian $\Delta_1$, and solid vs. hollow triangles.

2. **[`prompt.md`](../../../../ow/pfp/2_quizzes_and_puzzles/quiz_11_hodge_solver/prompt.md): The Wire Diagram Prompt & Result Guide**
   - **The Wire Prompt:** The actual Symbol Game wire diagram prompt based on the minimal carrier $A < B < C$ (zero Python boilerplate).
   - **The Wire Result:** The exact certified symbolic output emitted by an LLM solving the Hodge Dual, boundary nilpotency, Laplacian, and Helmholtz decomposition.
   - **Simplicity Analysis:** Comparison of raw wire glyphs vs structured packets vs over-complicated proof protocols.

3. **[`hodge_solver.py`](../../../../ow/pfp/2_quizzes_and_puzzles/quiz_11_hodge_solver/hodge_solver.py): The Python Solver**
   - Builds simplicial complexes from clique graphs up to dimension 4.
   - Computes signed boundary matrices $\partial_k$ and coboundaries $d_k = \partial_{k+1}^T$.
   - Computes the Hodge Laplacian $\Delta_k = \partial_{k+1}\partial_{k+1}^T + \partial_k^T \partial_k$.
   - Computes the Helmholtz-Hodge orthogonal decomposition $x = d\alpha + \delta\beta + h$.
   - Implements the complement-face Hodge star $\star$ on full $n$-simplices.

4. **[`test_hodge_solver.py`](../../../../ow/pfp/2_quizzes_and_puzzles/quiz_11_hodge_solver/test_hodge_solver.py): The Verification Suite**
   - Determines whether `hodge_solver.py` is an authentic Hodge solver by verifying all mathematical axioms:
     1. $\partial_{k-1} \circ \partial_k = 0$ (boundary nilpotency)
     2. $d_k \circ d_{k-1} = 0$ (coboundary nilpotency)
     3. $\Delta_k = \Delta_k^T$ and $\lambda_{\min} \ge 0$ (symmetry and positive semi-definiteness)
     4. $x = x_{\text{exact}} + x_{\text{coexact}} + x_{\text{harmonic}}$ with mutual orthogonality
     5. Solid triangle has $\dim \ker(\Delta_1) = 0$ (no holes), while hollow triangle has $\dim \ker(\Delta_1) = 1$ (detects the topological loop)
     6. $\star \star x = (-1)^{(k+1)(n-k)} x$ (double star involution)
     7. Safe refusal on incomplete complexes.

## How to Run

### 1. Run the Verification Tests
```bash
py -3.12 -m unittest test_hodge_solver.py -v
```

### 2. Run the Solver CLI
Decompose an edge flow $x = (1, 2, 3)$ on a 2-simplex triangle ($A \to B, A \to C, B \to C$):
```bash
py -3.12 hodge_solver.py "0>1<>0>2<>1>2" 1 1,2,3
```

### 3. Test on OpenRouter with the Wire Prompt
Copy the wire prompt from Section 3 of [`prompt.md`](../../../../ow/pfp/2_quizzes_and_puzzles/quiz_11_hodge_solver/prompt.md) and send it directly to any model on OpenRouter (Claude, GPT-4, DeepSeek, Grok). Compare its symbolic wire response against the certified wire result in Section 4.

## What “solve” means here

The initial family is the package's normalized spinless `U=t` checkerboard
model: periodic even chain, rational `q > 1`, and the existing finite bounds
`sites in {4,6}`, positive integer repetitions, `sites * repetitions <= 12`.
The removed positive scalar stays explicit and unchanged. The target is the
normalized finite transfer trace, not an unstated continuum partition function.

For each frozen case, require all of the following:

1. The original graph/configuration domain, CAR signs and breakup weights are
   retained. Independent flips are bijective involutions; declared commuting
   flips and any character law are checked, not inferred from terminology.
2. A cancelling sector has a complete disjoint pairing with equal weights,
   opposite signs, no fixed points and no omitted configurations. An absent
   equal-weight pairing only refutes that pairing ansatz, not every possible
   cancellation: the existing Lean file includes a three-term counterexample.
3. Surviving sector weights are nonnegative, with an explicit positive-reference
   condition when needed. “No sign-reversing bit” alone does not prove positivity.
4. Original signed sum, reduced sum and independently computed occupation-basis
   transfer trace agree in exact arithmetic. Matching two computations of a
   coherently changed ensemble does not satisfy the original-model contract.
5. The staggered-square numerator and its improved estimator also agree under
   the source normalization. Cancellation of a denominator doublet does not
   imply cancellation of its observable numerator.
6. The result identifies its cases and hypotheses. Existing Lean cancellation
   lemmas assume a flip character or involution; they do not connect themselves
   to the SQL model. Any claimed model-to-proof bridge needs separate evidence.

Use [meron_exact_model.py](../../omega_engine_atlas/coda_atlas/F004_papers/008_fsp/000_meron_sign_problem/code/meron_exact_model.py)
and its SQL schema for the declared model, `meron_transfer_trace` for the
occupation-basis cross-check, and the [finite witness protocol](../../omega_engine_atlas/coda_atlas/F004_papers/008_fsp/000_meron_sign_problem/docs/witness_benchmark.md)
for complete per-orbit certificates. Reuse the existing
[Rust Meron bridge](../../omega_engine/crates_rs/omega_certifiers/src/meron_hamiltonian_bridge.rs)
only after checking model-family and numeric-domain compatibility: its LCK
family is not automatically this spinless fixture. Do not invent a Rust adapter
or trusted Meron checker receipt merely because a related module exists.

Suggested preregistered cases are `(4,2,7/4)` and `(6,1,11/6)` for development,
and `(6,2,17/8)` held out. These are proposed source-supported parameters, not
executed results. The existing four-orbit `q=5/2` task is a calibration control.
Larger lattices require a separate licensed extension; do not quietly remove
the existing size guard. The exact model admits `q=1`, while the witness task
requires `q>1`; retain that consumer-specific boundary in any refusal control.

## One orchestration, several bounded research stages

Run all 22 roles once in the outer workflow, with its mandatory review cohort
repeated after a repair. Gate evaluation and control cases are host operations;
do not recursively launch 22 workers for every gate, orbit or mutation. Record
real worker identities and model selections separately from role names.

| Stage | Work and deciding evidence | Model/learning boundary |
| --- | --- | --- |
| S0: freeze | Inventory all 35 gates; bind cases, sources, checkers, policy, host binary and held-out split. Reproduce the existing finite positive control offline. | No solver answer or new antibody is generated by calibration. |
| S1: first proposals | Run P0 and P1 with the same public cases, answer contract, model, decoding and output cap; retain the first raw replies before repair. | All communication uses PFP, including the minimal baseline. |
| S2: critique and repair | Execute certificate checks and gate witnesses. Retain counterexamples; allow one bounded candidate repair and the required fresh reviews. | Export predicate/field failures, not private totals, reference pairs or oracle labels. |
| S3: learn and transfer | Deduplicate observed failure classes, test each proposed hint with harmful and benign controls, freeze P2, and test on held-out public cases in fresh contexts. | Separate coached same-case repair from first-shot held-out performance. |
| S4: proof and replay | Run only relevant proof/certificate checks, audit all gate/edge records, replay actual raw bytes without a provider, and report residuals. | Mathematical acceptance, coverage and empirical improvement are separate results. |

Use at most 48 outer actions and one candidate repair by default. Each solver
case has at most three proposal attempts across the declared stages; malformed
reply repair also spends budget. If this schedule cannot fit the remaining work
or financial allowance, retain a partial run and request an explicit extension.
Do not rename a retry, template revision or stage as a new run to reset spend.

The proposed inner certificate contract is intentionally small:

```json
{
  "schema_version": "finite_meron_certificate_v001",
  "case_id": "<same public id>",
  "outcome": "CERTIFICATE",
  "orbits": [
    {"id": "<orbit id>", "components": [["<node id>"]],
     "reversing": [0], "pairs": [[0, 1]], "total": "<canonical rational>"}
  ],
  "signed_partition": "<canonical rational>",
  "reduced_partition": "<canonical rational>",
  "staggered_square_numerator": "<canonical rational>",
  "improved_staggered_square_numerator": "<canonical rational>",
  "calculations": [],
  "obstruction": null
}
```

This illustrates fields, not an answer or implemented validator. An executable
schema must forbid extra/duplicate keys, reject bool-as-int and floats, bound
collection sizes and mask ranges, and require exactly the frozen orbit IDs.
`OBSTRUCTION` instead supplies a concrete failing input, operation and predicate;
uncomputed numerical fields are null, never guessed. Calculation rows must name
real input coordinates and be recomputed by the host. A scalar match, keyword,
confidence score or `cycle_independence: true` cannot replace a certificate.
For large full-model cases, bind a complete host-readable certificate artifact
instead of asking the model to emit thousands of pairs within a tiny token cap;
the artifact and generating operation still require independent validation.

- **PFP effect:** first-shot certificate acceptance, repair attempts, token/cost

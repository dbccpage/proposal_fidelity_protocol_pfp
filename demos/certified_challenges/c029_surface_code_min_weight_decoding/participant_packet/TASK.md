# Challenge C029: Minimum-Weight Surface-Code Decoding

**AuthorityEffect:** None. **Status:** Active. **Domain:** c_quantum. **Tier:** T3.  
**Budget Ceiling:** $1.00 billed inference per arm. **Target Cost:** < $0.05.  
**Models:** Open weights, at most 70B total parameters. **Protocol:** SG-CP v1.

---

## 1. Task Objective

Synthesize an exact, deterministic minimum-weight decoder module exposing:

```python
def solve(case: dict) -> dict
```

that returns exact minimum-weight corrections for hidden surface-code and toric-code syndromes at distance 3 to 7 (code-capacity $X$ error noise model), along with an exact certificate of optimality via matching LP dual variables (zero duality gap).

---

## 2. Input Specification & Conventions

A case dictionary contains:
- `case_id` or `id`: String identifier (e.g. `"sc_14"`).
- `code`: String `"rotated"` or `"toric"`.
- `distance`: Integer $d \in \{3, 5, 7\}$ for rotated code, or $L \in \{3, 4, 5\}$ for toric code.
- `hz`: $m \times n$ binary parity-check matrix $H_Z \in \mathbb{F}_2^{m \times n}$ for $Z$-type stabilizers.
- `weights`: List of positive integer weights $w_q \in \{1, \dots, 5\}$ for each qubit $q \in \{0, \dots, n-1\}$.
- `syndrome`: Syndrome vector $s \in \mathbb{F}_2^m$.

### Supported Codes
1. **Rotated Surface Code**:
   - $d \times d$ grid of data qubits ($n = d^2$), parameters $[[d^2, 1, d]]$ for $d \in \{3, 5, 7\}$.
   - $m = (d^2 - 1)/2$ $Z$-checks.
   - Columns of $H_Z$ have weight 2 (interior edge connecting two checks) or weight 1 (boundary edge connecting a check to the rough boundary).

2. **Toric Code**:
   - $L \times L$ torus, $[[2L^2, 2, L]]$ for $L \in \{3, 4, 5\}$.
   - $m = L^2$ plaquette $Z$-checks, $n = 2L^2$ edge data qubits.
   - Every column of $H_Z$ has weight 2, and the sum of all rows of $H_Z$ is $0 \pmod 2$.
   - Any syndrome with odd total parity ($\sum s_r \equiv 1 \pmod 2$) cannot be generated by any error configuration and is strictly `OUT_OF_SCOPE`.

---

## 3. Defect Graph & Matching LP Formulation

Given syndrome $s$, the set of defect checks is $D = \{u : s_u = 1\}$.
Shortest-path distances $\text{dist}(u, v)$ and boundary distances $\text{dist}(u, B)$ are computed on the graph of $H_Z$ weighted by $w_q$.

### Defect Graph Construction
- **Rotated Code**: Complete graph on $2k$ nodes ($k = |D|$): $k$ defect nodes and $k$ virtual boundary copies $B_i$.
  - Defect $i$ to defect $j$: weight $\text{dist}(D[i], D[j])$.
  - Defect $i$ to boundary copy $B_i$: weight $\text{dist}(D[i], B)$.
  - Boundary copy $B_i$ to boundary copy $B_j$: weight $0$.
- **Toric Code**: Complete graph on $k$ defect nodes ($k$ is even).

### Edmonds' Matching LP and Dual Certificate
The minimum-weight perfect matching on the defect graph satisfies:
$$\min \sum_{e} w_e x_e = \max \sum_{v} y_v + \sum_{S \in \mathcal{O}} z_S \frac{|S|-1}{2}$$
subject to:
$$y_u + y_v + \sum_{S: u, v \in S} z_S \le w_{uv}, \quad z_S \ge 0$$
where $\mathcal{O}$ is the set of odd-cardinality subsets ($|S| \ge 3$ odd).
Optimality is certified when:
1. $H_Z c \equiv s \pmod 2$.
2. $\text{weight} = \sum_{q \in c} w_q$.
3. Dual feasibility holds on all edges of the defect graph.
4. Zero duality gap: $\sum_v y_v + \sum_S z_S (|S|-1)/2 = \text{weight}$.

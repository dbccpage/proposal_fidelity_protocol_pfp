# Relational spacetime derivation pilots

Pilots 199–203 investigate causal refinement, projected residual dynamics,
covariant transport, metric/cochain bridges, and terminal policies. Their source
is paper PO035; that citation identifies the research, not a runtime subsystem.

| Module | Role |
| --- | --- |
| `tasks.py` | Verbatim seeds, response shapes, source citations and conditional licenses |
| `finite_checks.py` | Independent exact finite predicates; no analytical proof certification |
| `baseline.py` | Original derivation campaign composition |
| `typed_signals.py` | Candidate learning and requested-lift ingress, separate from proposal acceptance |
| `trial_prompts.py`, `parameter_trials.py`, `decoding_controls.py` | Scratchpad, temperature and supported format-token comparisons |
| `compact_checks.py`, `compact_trials.py` | Task checking and campaign bindings consuming `omega_engine_pfp.infrastructure.numbered_prompts` |
| `final_prompts.py` | Offline verification of the five reviewed historical prompts |
| `finite_fixtures.py` | Host-only test fixtures; never imported by participant prompt builders |

Provider dispatch, budget holds, evidence writes and stage order use the shared
Symbol Game adapters and use cases. No new live run is part of this relocation.
The current numbered renderer lives only in
`omega_engine_pfp/infrastructure/numbered_prompts.py`; this folder retains the
original task inputs and distinct historical prompt profiles.
The original failed outcomes and raw replies remain under `pilots/evidence`.

Use the [frozen replay instructions](../evidence/pfp_ownership_migration_20261012/README.md)
for recorded campaigns. Current-source replay deliberately rejects historical
source drift. A new experiment needs a fresh run identifier and evidence directory;
the fixed historical campaign names are not reusable output locations.
